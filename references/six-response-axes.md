# The six response axes (6-axes)

## ― What "interesting" is made of: six reactions, their mechanisms, and their failure modes ―

The aim of writing is to move the reader's heart and leave something in memory. These six axes are the six **reactions** that do this — six routes to "面白い (interesting)". Each is distinct in its **mechanism (正体)** and its **failure mode**, so none reduces to another.

## The six axes

| axis | reaction | mechanism (正体) | failure mode |
|---|---|---|---|
| 感嘆 (admiration) | a groan — "I've been had" | exceed prediction × make it feel inevitable | predictable (boring) / incomprehensible |
| ユーモア (humor) | a laugh | gap (ズレ) × safe recovery | falls flat (lame) / absurd |
| 感動 (emotion) | tears, a tight chest | identification × confirmation of a value | preachy / embarrassing |
| 楽しい (fun) | pleasant, exhilarating | positive emotion × flow | boring / satiating |
| 恐怖 (fear) | on edge, cold sweat | a threat shown × no escape | clichéd / becomes funny |
| かわいい (cuteness) | "precious", protective | protectiveness × lovability | ingratiating / cheap |

## The axis test (軸の物差し)

A candidate is an **axis** only if it has a distinct **mechanism** AND a distinct **failure mode**. Otherwise it is a flavor or a structure of an existing axis.

- 切なさ (bittersweet) → a flavor of 感動 ／ 爽快 (exhilaration) → an intensity of 楽しい ／ 燃え (burning) → 楽しい＋感動
- catharsis → the structure of release ／ surprise → the "exceed" ingredient of 感嘆・ユーモア ／ beauty → the E layer (style)

## Interest is the engine, not an axis

"Curious / want to know" is not a kind of reaction. It is the **forward pull** that coexists with all six axes — an orthogonal dimension. Whichever axis a work rides, if interest breaks, the reader leaves.

## The north star is memory, not admiration

The six axes are equal routes to the same north star: **memorable / retellable** (記憶に残る／語りたくなる). 感嘆 once looked special only because it is the most *designable*, not the most *valuable*.

## Design: four steps on two scales

Each axis's mechanism unfolds into a four-step process (四工程). It runs on **two scales** — the whole-work arc (全体の弧) and the scene arc (場面の弧).

| axis | four steps (全体の弧) |
|---|---|
| 感嘆 | lead → exceed → make inevitable → deliver quietly |
| ユーモア | serious ground → make the gap → recover safely → the laugh |
| 感動 | identification → show the value → pay the cost → restraint |
| 楽しい | seed the emotion → flow → exceed the scale → the release |
| 恐怖 | secure the distance → show the threat → close the escape → release |
| かわいい | show the weakness → encode → deepen protectiveness → the precious |

The scene arc fires a small reaction every page. Its three kinds (三種) per axis:

| axis | scene-level reactions |
|---|---|
| 感嘆 | へえ (expectation twists) ・ なるほど (meaning clicks) ・ うまい (craft) |
| ユーモア | クスッ ・ ニヤリ ・ ぷっ |
| 感動 | じんわり ・ 胸が熱い ・ こみ上げる |
| 楽しい | 心地よい ・ ワクワク ・ ぞくぞく |
| 恐怖 | ゾクッ ・ ヒヤッ ・ ぞわり |
| かわいい | かわいい ・ 守りたい ・ 尊い |

A scene that delivers none of its axis's three kinds is a scene that loses the reader. Space the reactions (don't break), vary the intensity (don't saturate), and climb toward the whole-work peak (the staircase).

## How the skills use this

- **premise** — the promise (約束) selects which axis the work rides.
- **plot-design** — design the chosen axis's four steps as the whole-work arc.
- **fast-draft** — run the four steps small, per scene.
- **entertainment** — inspect the draft against the six axes and fill the weak one, without breaking expression and restraint.
- **revise-for-reader** — check whether the reaction landed.
