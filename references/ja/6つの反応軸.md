# 6つの反応軸（6-axes）

## ― 「面白い」は何から出来ているか：6つの反応と、その正体・失敗モード ―

書く目的は、読者の心を動かし、記憶に何かを残すことである。この6つの軸は、それを担う6つの**反応**——「面白い」への6つの経路——である。それぞれが別の**正体（機構）**と別の**失敗モード**を持つから、どれも他の軸に還元されない。

## 6つの軸

| 軸 | 反応 | 正体（機構） | 失敗モード |
|---|---|---|---|
| 感嘆 | 唸る・「やられた」 | 予測を超える × 納得させる | 予定調和（つまらない）／意味不明 |
| ユーモア | 笑う | ズレ × 安全な回収 | 滑る／不条理 |
| 感動 | 泣く・胸が熱い | 同一化 × 価値の確認 | 説教臭い／白ける |
| 楽しい | 心地よい・爽快 | 正の情動 × 流れ | 退屈／飽きる |
| 恐怖 | 冷や汗・身構える | 脅威の提示 × 逃げ場のなさ | 陳腐な脅威／笑いになる |
| かわいい | 尊い・庇護したい | 庇護欲 × 愛らしさ | 媚びる／安っぽい |

## 軸の物差し

候補が**軸**であるのは、別の**正体**と別の**失敗モード**を併せ持つときだけである。そうでなければ、既存の軸の「味」か「構造」である。

- 切なさ → 感動の味 ／ 爽快 → 楽しいの強度 ／ 燃え → 楽しい＋感動
- カタルシス → 解放の構造 ／ 驚き → 感嘆・ユーモアの「超出」成分 ／ 美 → E層（文体）

## 興味はエンジンであり、軸ではない

「気になる・知りたい」は反応の一種ではない。6つの軸すべてと共存する**前へ引く力**——直交する次元である。どの軸に乗っても、興味が切れた瞬間、読者は離れる。

## 北極星は記憶であり、感嘆ではない

6つの軸は、同じ北極星——**記憶に残る／語りたくなる**——へ至る対等な経路である。感嘆がかつて特別に見えたのは、最も*設計しやすい*からであって、最も*価値がある*からではない。

## 設計：二つの縮尺の四工程

各軸の正体は四工程（四工程）へ展開する。それは**二つの縮尺**——作品全体の弧（全体の弧）と場面の弧（場面の弧）——で走る。

| 軸 | 四工程（全体の弧） |
|---|---|
| 感嘆 | 誘導 → 超出 → 必然 → 頂点 |
| ユーモア | 真面目の土台 → ズレの仕込み → 安全な回収 → 笑いの頂点 |
| 感動 | 同一化の土台 → 価値の提示 → 代償の支払い → 抑圧の頂点 |
| 楽しい | 情動の種 → 流れの設計 → スケールの超出 → 爽快の頂点 |
| 恐怖 | 安全の担保 → 脅威の提示 → 逃げ場を塞ぐ → 解放 |
| かわいい | 無力さの提示 → 記号化 → 庇護欲の強化 → 尊さへの昇華 |

場面の弧は、毎ページに小さな反応を撃つ。その三種（三種）は軸ごとに：

| 軸 | 場面の三種 |
|---|---|
| 感嘆 | へえ ・ なるほど ・ うまい |
| ユーモア | クスッ ・ ニヤリ ・ ぷっ |
| 感動 | じんわり ・ 胸が熱い ・ こみ上げる |
| 楽しい | 心地よい ・ ワクワク ・ ぞくぞく |
| 恐怖 | ゾクッ ・ ヒヤッ ・ ぞわり |
| かわいい | かわいい ・ 守りたい ・ 尊い |

三種のどれも渡さない場面は、読者を失う場面である。反応を**間隔**（途切れない）・**強度**（飽和しない）で組み、全体の頂点へ向かう**階段**で積む。

## スキルはどう使うか

- **premise** — 約束が、作品の乗る軸を選ぶ。
- **plot-design** — 選んだ軸の四工程を全体の弧として設計する。
- **fast-draft** — 四工程を場面ごとに小さく走らせる。
- **entertainment** — 草案を6軸で検品し、弱い軸を発露と抑制を壊さずに補う。
- **revise-for-reader** — 反応が着地したかを確かめる。

厚い方法論（軸ごとの設計・場面篇）は `資料/エンターテイメント創作構想/` にある。このファイルは、引用のための薄い原則である。
