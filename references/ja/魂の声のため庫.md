# 魂の声のため庫（voice-ledger）—— 執筆者の魂の声を貯め、読み返す

> 設計原則「内的な声がすべての源。内省して聞く」の**永続化**。
> [内省問い.md](内省問い.md)（A 書き手設定／B 発想／C 設計／D 草稿ループ）で聞こえた声と、
> 草稿中の逸脱・筆が乗った瞬間を、作品をまたいで貯め、後の発想・停滞脱出・writer-persona の更新に読み返す。

---

## 1. なぜ貯めるか

- **声は文脈に住んでいる。** 聞いた瞬間を逃さない。内省はセッションごとに消える——記録しない限り、声は残らない。
- **記録しておけば後で結びつく**。別の作品で聞こえた声が、新しい問いに意外な形で応える。種をためる母数が閃きの母数になる。
- **魂の物語は書くごとに深まる。** ため庫はその深化の記録で、writer-persona（現在形の設定）の**更新材料**になる。
- **この書き手にしかない台帳。** 貯めた声で書けば、誰の文でもない文になる。

## 2. 何を貯めるか（6種の声）

| 種 | 出所 | 例 |
|---|---|---|
| 発想の声 | B 問い・閃き | 「この素材は、何度も書き続ける問いにこう応える」と聞こえた断片 |
| 設計の声 | C 問い・逸脱の記録 | 設計が約束から逸れて深まった場所、あるいは「この書き手のもの」と定まった択 |
| 草稿の声 | D 問い・逸脱の記録 | 人物が計画を離れて動き始めた場所・その台詞 |
| 筆が乗った瞬間 | フロー | エマージェンスが起きた条件（材料・制約・空白）。**その条件自体**を記録して、再現の手がかりにする |
| 禁じ手に触れた瞬間 | A-4 | 破りかけた・破った。それが深さになったか、壊れになったか |
| 評価の響き | 読者反応 | 外部評価で響いた・響かなかったこと。流されず、音だけ残す |

## 3. いつ貯めるか（誘発であって強制でない）

- **声が聞こえた時だけ**（D-4）。聞こえない日に無理に書かず、ため庫に空行を増やさない。
- 逸脱が「深める」と判定された時。
- 問いに答えて「これだ」となった時。
- 筆が乗った時・渇いた時（後で水源にするために）。
- 問いの定型（A/B/C/D）が答えを聞いた時、その場で貯める。

## 4. どう貯めるか（1件の書式）

| 欄 | 内容 |
|---|---|
| 日付・作品・場面 | いつ・どの作品の・どこで聞こえたか |
| 聞こえた声 | **原文のまま。** 要約しない——声は要約で死ぬ |
| 文脈（どの問いに答えた声か） | 問いの定型（A/B/C/D）を引用し、同じ問いで再誘発できるようにする |
| 使った／未使用 | 閃き→執筆の遷移。後で結びつくための印 |

**書式例**

```
- [x] 2026-08-14 / 夜を歩く男 / 第2章・クライマックスの台詞
  声：この男は「謝らない」んじゃなくて「謝れない」。謝ると何かが終わるから。
  文脈：D-1（この台詞は計画の要求から出た？人物自身から出た？）
  使った：第2章のクライマックス。評価の響きもここ（originality が高かった）。
```

## 5. 読み返す（ためて終わりにしない）

ため庫は貯めるだけでなく、**読む**ためにある。読まない台帳はゴミ捨て場になる。

- **発想の開始時**（premise の B 問い）——前の作品の声を新しい問いに呼び込む
- **writer-persona の更新時**——貯まった声を「魂の物語がどこへ向かったか」として読み、設定を改訂する
- **停滞時**——書けない時の水源。自分の声を聞けば、誰でもない声でなく自分の声が聞こえる
- **fast-draft の渇いた時**（D-4 聞こえない→追従に戻る）——追従に戻る前に、ため庫を聞く

## 6. ため庫と writer-persona の関係

- `writer-persona` = **声を定める**（現在形の設定・肖像）。A 問い（人間との対話）で定め、永続させる。
- `voice-ledger` = **声を貯める**（過去形の声・日記）。A/B/C/D 問いで聞こえた声を積む。
- ため庫が貯まると persona は**更新される**（魂の物語の深化・禁じ手の改訂・声の成熟）。
- 両者は別ファイル：persona は「私はこう書く」、ため庫は「私はこう書いてきた」。
- 魂の物語・声は**人間（ユーザー）のもの**。AI はそれを映し・貯め・反映する鏡であって、作者ではない。

## 7. スキル化の性質

- **記録・台帳は外部化しやすい** → スキル化に適する。
- ただし「**何が声か**」の選択は判断が要る（観測であって判定でない・内省問い §0）。ため庫自体は**判定しない**——貯めて、読む。声の選択は問いかけ型スキル（persona / premise / plot-design / fast-draft）が行う。
