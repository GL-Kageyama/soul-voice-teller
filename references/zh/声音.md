# 灵魂之声的声音库（voice-ledger）—— 存写作人的心声，并回读

> 设计原则「内在的声音是一切之源。内省而倾听」的**持久化**。
> 在 [内省.md](内省.md)（A 写作者设定／B 构思／C 草稿循环）中听到的声音，与
> 草稿中的偏离 · 笔兴勃发之瞬，跨作品存放，供后来的构思 · 挣脱停滞 · 更新 writer-persona 时回读。

---

## 1. 为何要存

- **声音住在语境里。** 不错过听到的瞬间。内省随每次会话消失——不记录，声音就不留。
- **记录下来，日后便会连起**。在另一部作品听到的声音，会以意外之形回应新的问句。存种子的母数，就是灵感的母数。
- **灵魂故事每写一次便更深一层。** 声音库是这深化的记录，是 writer-persona（现在式设定）的**更新素材**。
- **唯有此人才有的账本。** 以存下的声音来写，文字就成为谁都不是的文字。

## 2. 存什么（五种声音）

| 种类 | 出处 | 例 |
|---|---|---|
| 构思之声 | B 问句 · 灵感 | 听到「这素材如此回应我反复书写的问句」的片段 |
| 草稿之声 | C 问句 · 偏离的记录 | 人物离开计划、开始自行行动之处 · 那句台词 |
| 笔兴勃发之瞬 | 文思 | 涌现发生的条件（素材 · 约束 · 空白）。记录**条件本身**作为再现的线索 |
| 触碰禁忌之瞬 | A-4 | 险些破 · 破了。它成了深度，还是成了破坏 |
| 评价的回响 | 读者反应 | 在外在评价中回响 · 未回响之事。不被裹挟，只留其音 |

## 3. 何时存（诱发而非强迫）

- **只在听到声音之时**（C-4）。听不到的日子不强写，不给声音库添空行。
- 偏离被判定为「深化」之时。
- 答问句时觉得「就是它」之时。
- 笔兴勃发时 · 干涸时（为了日后成为水源）。
- 问句定式（A/B/C）听到答案时，当场存下。

## 4. 怎么存（一条的格式）

| 栏 | 内容 |
|---|---|
| 日期 · 作品 · 场次 | 何时 · 哪部作品的 · 在哪里听到 |
| 听到的声音 | **照原文。不概括——声音死在概括里** |
| 语境（回答了哪个问句的声音） | 引用问句定式（A/B/C），使同一问句能再次诱发 |
| 已用／未用 | 从灵感到执笔的迁移。供日后连起的标记 |

**格式示例**

```
- [x] 2026-08-14 / 夜行的男人 / 第 2 章 · 高潮的台词
  声音：这男人不是「不道歉」，而是「道不了歉」。因为一道歉，什么就结束了。
  语境：C-1（这句台词出自计划的要求，还是出自人物自身？）
  已用：第 2 章的高潮。评价的回响也在此（originality 高）。
```

## 5. 回读（不以存下作结）

声音库不仅为存，更为**读**。从不读的账本会成垃圾场。

- **构思开始时**（premise 的 B 问句）——把前作的声音唤入新的问句
- **更新 writer-persona 时**——把累积的声音当作「灵魂故事走向了何处」来读，修订设定
- **停滞时**——写不出时的水源
- **fast-draft 干涸时**（C-4 听不到→回到依循计划）——回到依循之前，先听声音库

## 6. 声音库与 writer-persona 的关系

- `writer-persona` = **定声音**（现在式设定 · 肖像）。由 A 问句（与人对谈）定下并持久。
- `voice-ledger` = **存声音**（过去式之声 · 日记）。累积 A/B/C 问句里听到的声音。
- 声音库积累，persona 便**更新**（灵魂故事的深化 · 禁忌的修订 · 声音的成熟）。
- 两者是不同文件：persona 是「我这样写」，声音库是「我这样写过」。
- 灵魂故事与声音是**人（用户）之物**。AI 是映照 · 存放 · 反照它们的镜子，不是作者。

## 7. 技能化的性质

- **记录 · 账本易于外化** → 适合技能化。
- 但「**何为声音**」的选择需要判断（是观察，不是判断 · 内省 §0）。声音库本身**不判断**——存，并读。声音的选择由发问型技能（persona / premise / fast-draft）承担。
