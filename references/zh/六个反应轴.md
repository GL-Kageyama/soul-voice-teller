# 六个反应轴（6-axes）

## ― 「有趣」由什么构成：六种反应、其机制与失败模式 ―

写作的目的是打动读者的心，并在记忆中留下些什么。这六个轴，就是承担这一点的六种**反应**——通往「面白い（有趣）」的六条路径。每一轴都拥有独立的**本质（机制）**与独立的**失败模式**，因此任何一轴都无法被归约为另一轴。

## 六个轴

| 轴 | 反应 | 本质（机制） | 失败模式 |
|---|---|---|---|
| 感嘆（惊叹） | 咂舌 ·「被摆了一道」 | 超出预测 × 令人感到必然 | 俗套（无聊）／不知所云 |
| ユーモア（幽默） | 发笑 | 落差 × 安全的回收 | 冷场／荒诞 |
| 感動（感动） | 落泪 · 胸口发热 | 共情 × 价值的确认 | 说教味／尴尬 |
| 楽しい（快乐） | 舒适 · 爽快 | 正性情感 × 流 | 无聊／腻 |
| 恐怖（恐惧） | 捏一把汗 · 绷紧 | 威胁的呈现 × 无路可逃 | 陈腐的威胁／变成笑料 |
| かわいい（可爱） | 珍贵 · 想保护 | 保护欲 × 惹人爱怜 | 谄媚／廉价 |

## 轴之标尺（物差し）

一个候选要成为「轴」，必须同时具备**独立的本质（机制）**与**独立的失败模式**；否则只是既有轴的「味道」或「结构」。

- 切なさ（苦涩） → 感动的味道 ／ 爽快 → 快乐的强度 ／ 燃え（燃） → 快乐＋感动
- カタルシス（宣泄） → 释放的结构 ／ 惊き（惊） → 惊叹・幽默的「超出」成分 ／ 美 → E层（文体）

## 兴趣是引擎，不是轴

「好奇 · 想知道」不是一种反应，而是与六轴都共存的**前向拉力**——一个正交维度。无论作品乘着哪一轴，兴趣一断，读者就会离开。

## 北极星是记忆，不是惊叹

六轴是通往同一北极星——**留在记忆里／想讲给别人听**——的六条对等路径。惊叹曾经显得特殊，只是因为它最*可设计*，而非最有*价值*。

## 设计：两种尺度的四步

每一轴的本质都展开为四步流程（四工程）。它在**两种尺度**上运行——作品整体之弧（全体の弧）与场景之弧（場面の弧）。

| 轴 | 四步（整体之弧） |
|---|---|
| 感嘆 | 诱导 → 超出 → 必然 → 顶点 |
| ユーモア | 认真的底子 → 制造落差 → 安全的回收 → 笑点 |
| 感動 | 共情 → 展示价值 → 付出代价 → 克制 |
| 楽しい | 情感的种子 → 流 → 超出尺度 → 释放 |
| 恐怖 | 保证距离 → 呈现威胁 → 封住退路 → 释放 |
| かわいい | 展示无力 → 符号化 → 加深保护欲 → 升华珍贵 |

场景之弧在每一页释放一个小的反应。每轴的三类（三種）：

| 轴 | 场景反应 |
|---|---|
| 感嘆 | へえ（预期扭转） ・ なるほど（豁然） ・ うまい（手法） |
| ユーモア | クスッ ・ ニヤリ ・ ぷっ |
| 感動 | じんわり ・ 胸が熱い ・ こみ上げる |
| 楽しい | 心地よい ・ ワクワク ・ ぞくぞく |
| 恐怖 | ゾクッ ・ ヒヤッ ・ ぞわり |
| かわいい | かわいい ・ 守りたい ・ 尊い |

三类中一样都未给出的场景，就是失去读者的场景。用**间隔**（不断）与**强度**（不腻）来安排反应，并以**阶梯**向整体顶点攀升。

## 各技能如何使用

- **premise** — 承诺（約束）选定作品所乘的轴。
- **plot-design** — 把所选轴的四步设计为整体之弧。
- **fast-draft** — 在每一场景里小规模地运行四步。
- **entertainment** — 用六轴检视草稿，在不破坏流露与克制的前提下补足薄弱之轴。
- **revise-for-reader** — 确认反应是否落地。
