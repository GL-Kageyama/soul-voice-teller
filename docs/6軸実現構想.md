# 6つの反応軸の実現構想

## ― 資料/ の理論を、soul-voice-teller の書き手側スキルへ落とす ―

---

# 0. 目的

[資料/エンターテイメント創作構想/](../../資料/エンターテイメント創作構想/) で整理した「6つの反応軸」（感嘆・ユーモア・感動・楽しい・恐怖・かわいい）を、soul-voice-teller の書き手側スキルとして実現する方法を定める。

あわせて、既存 `entertainment` スキルが持つ「エンタメの6軸」（フック・ページターナー・ツイスト・カタルシス・テンポ・共感）との関係を整理する。

---

# 1. 既存「6軸」と新「6反応軸」は別物

| | 既存 entertainment の「6軸」 | 新「6つの反応軸」 |
|---|---|---|
| 中身 | フック・ページターナー・ツイスト・カタルシス・テンポ・共感 | 感嘆・ユーモア・感動・楽しい・恐怖・かわいい |
| 何を測るか | 「止まらない本」にする**構造技法**（快楽の源） | 読者が**何を感じるか**（唸る・笑う・泣く…） |

新理論の「軸の物差し」は、既存6軸を次のように再分類する（どれも軸ではなくなる）。

| 旧6軸 | 再分類 | 新理論での位置 |
|---|---|---|
| フック・ページターナー | 興味 | **エンジン**（直交次元。軸ではない） |
| ツイスト | 予測を超える | 感嘆の「超出」成分 |
| 共感フック | 自分を重ねる | 感動の「同一化」成分 |
| カタルシス | 解放 | **構造**（各軸の四工程の「頂点」に共通） |
| テンポ | 緊張と緩和 | 楽しいの「流れ」／構造 |

つまり新6軸は旧6軸の**上位概念**であり、旧6軸は「成分・構造・エンジン」として吸収される。

---

# 2. 実現の構造

反応軸は「手順」でなく「物差し」。パイプライン全体を貫くため、**skill 群としても、skill の配下としても置かず**、発露と抑制・内省と同列の「原則」として references/ に置く。

```
soul-voice-teller/
├── references/six-response-axes.md   ← 薄い原則（en 正典 + ja/zh ミラー）
└── skills/ 各所が引用
      premise            … 約束＝どの軸を約束するか
      plot-design        … 選んだ軸の四工程（全体の弧）
      fast-draft         … 場面の四工程（場面の弧）
      entertainment      … 旧6軸を新6軸で置換し「反応の検品・補充」に再定義
      revise-for-reader  … 反応が着地したか
```

厚い方法論（設計.md×6・場面篇×6）は source として 資料/ に残し、soul-voice-teller 内は薄い原則＋引用に留める。

---

# 3. 原則（six-response-axes.md）の形

1ファイル。次の4部。

1. **6軸テーブル**（軸／反応／正体／失敗モード）
2. **軸の物差し**（正体×失敗が別なら軸）＋ 興味＝エンジン ＋ 北極星
3. **各軸の圧縮版**（四工程／場面三種 を2つのテーブルで）
4. **資料/ へのポインタ**（深掘りはそちら）

# 5. やらないこと

- 厚い方法論を soul-voice-teller に複製しない（資料/ が source）。
