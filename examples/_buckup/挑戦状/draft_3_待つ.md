# 場面3「待つ」

次に、白紙が必要だった。

老人から渡された白紙。宝の地図は、白紙に現れる。日光に、一時間、さらす。そう書いてあった。

深夜だった。

高野は、白紙を、蛍光灯の下に置いた。太陽はない。蛍光灯で、代わりにした。

それから、待った。

一時間。何もしないで、待った。リビングの時計が、針を刻む音。冷蔵庫のモーター。上の階の、誰かが寝返りを打つ音。高野は、テレビの前の座布団に座って、白紙を見ていた。白紙は、何も映さなかった。

何も起こらなかった。

高野は、動かずに、待った。膝の上に、両手を置いたまま、待った。電話を取ろうとは思わなかった。思わなかったのではなく、取る理由を、見つけられなかった。スマホの画面を、ちらりと見た。通知はなかった。それは、高野の一時間だった。

十分ごとに、時計を見た。十一時十分。十一時二十分。十分ごとに、一時間が、針の音だけになった。五十九分、白紙の真ん中に、うっすらと、何かが浮かんだ。

高野は、それを見た。黒い線。地図だった。

高野は、この一時間を、どこかで、待っていた気がした。

高野は、白紙を手に取った。地図は、宝の場所を指していた。ゲームが、進んだ。
