# package —— 公開稿の包み（カクヨム投稿用）

> 作品: 『白地図 — 澪ノ町』（全12章・総約10万字）
> 根拠（読者像）: 自分が何かを保持していることに、その保持が自分を支払わせていることに、まだ気づいていない者——生きている者のほぼ全員。
> 約束: 読了後、「私も、知らないうちに誰かを覚え続けることで、自分の何かを支払ってきた」という内省が、遅れて届く。
> 包みの規則: 嘘で引かない／届けるものを約束する／開示の頂の前で止まる／抑制を引き継ぐ。全部の扉が同じ作品（覚える＝支払う）を開く。

---

## 1. タイトル＋サブタイトル

**タイトル**: 白地図

**サブタイトル**: 澪ノ町

- タイトルは「白地図」——塗り戻される地図と、残る白い四角の二重の名を立てる。サブタイトルは地名「澪ノ町」で、抽象の題を具体の舞台へ降ろす。「澪ノ町＝澪」という音の一致が未知×知りたさの種になるが、開示の頂（第10章・娘が母を墓に変えていた）には触れない。

## 2. 帯（キャッチコピー）

**主**:
> 忘れられた場所は、白紙に戻る。女は一人、町を塗り戻す——歩くたび町は色づき、女は白くなる。

（余白を残す版・帯がもう一行とれるなら）:
> 覚え続けることは、その人をここに留めることなのか、それとも、自分をそこに差し出すことなのか。

- 「白紙に戻る街」=未知で引き、「歩くたび町は色づき、女は白くなる」=零和の再定義で受ける。核心の問い（留めるか差し出すか）は帯では問いのまま。テーマ（支払いこそ愛）を名指ししない。

## 3. あらすじ

### 裏表紙（短・約160字）

> 場所は、それを覚えている者の記憶の合計の解像度でしか存在しない。忘れられた街は白紙に戻る。灯は一人、澪ノ町を歩き、暖簾の朱・路地の群青・祭の金彩を塗り戻してきた。代償は自分の記憶——歩くたび、彼女は白くなる。二十年、ただ一つの四角だけを、決して塗らない。

### サイト用（中・約450字・連載プラットフォーム）

> 澪ノ町では、忘れられた場所が白紙に戻る。住人はみな町を離れ、二十年前の「ある事件」を機に、誰も思い出さなくなった。ただ一人、灯だけが町を歩き続ける。彼女の記憶が、暖簾の朱、路地の群青、祭の金彩を、手彩色の古地図のように塗り戻していく。
>
> 塗り戻すたび、灯は代償を払う。恋人の声、母の手、自分の本名——直前に色を持った具体的な何かを、ひとつずつ差し出す。歩くたび町は色づき、灯の身体は白くなっていく。
>
> それでも彼女は、たった一つの四角だけは決して塗らない。手彩色の世界の中で一点だけ、フォトリアルに残る四角——娘・澪の顔の記憶。
>
> 二十年前、この町に何があったのか。なぜ灯は、名も知らない町を一人で覚え続けるのか。町の名「澪ノ町」と娘の名「澪」が、同じ音であることに、灯は向き合うことになる。
>
> 塗りきったとき、中央に何が残るのか——灯は、最後の一区画へ向かう。

- 開示の頂（第10章・娘が母を墓に変えていた）には触れない。ここまでの設定（白紙化・零和・娘の四角・澪ノ町の一致）は第6章までに開示される範囲。

## 4. 画像生成プロンプト

### カバー（表紙）

```
文芸書の表紙・1枚。手彩色の古地図。朱・群青・黄土・金彩の微光で塗り戻された下町が広がり、その中央に、ぽっかりと人一人ぶんの白い四角が残る——色を一切乗せない紙の白。周囲の色との対比で、白い四角が浮かぶ。上方に広い余白＝タイトル文字の置き場。焦点は「色のない四角」ひとつ。水彩・紙の白を大胆に残す。
```

### キーシーン（第1章・塗り戻す）

```
1枚。下町の路地。女（灯）が背中で歩く。彼女の背後と足元では、街が手彩色に蘇る——暖簾の朱、路地の群青、壁の黄土、金彩の微光。前方はまだ純白＋薄い鉛筆グリッド。色と白の境は濡れたインクの縁がにじむ。女自身の輪郭はわずかに白く透ける。色が白を喰い戻す、その境界に焦点。水彩・余白を効かせた構図。文芸挿絵風。
```

## 5. タグ／キーワード

`文芸` `ファンタジー` `現代ファンタジー` `記憶` `喪失` `母娘` `地図` `手彩色` `下町` `切ない` `感動` `余白`

- ジャンル（文芸・ファンタジー）＋本作固有の語（地図・手彩色・記憶）で、約束（支払いの内省）が届く読者の住所にする。

---

## 包みの検品（4規則・一つの魂、多くの扉）

1. **嘘で引かない** ✓ —— 全扉が「白紙化・零和の取引」という本作の実在の設定だけから引いている。復元の万能装置や謎解きの見せ物を約束していない。
2. **届けるものを約束する** ✓ —— あらすじが約束するのは、静かに最後の一区画へ向かう話。帯もサブタイトルも同じ方向（覚える＝支払う）を向く。
3. **開示の頂の前で止まる** ✓ —— 覚えすぎた者＝澪（第7章）、娘が母を墓に変えていた（第10章）には一切触れていない。
4. **抑制を引き継ぐ** ✓ —— 帯もあらすじも「支払いこそ愛」を名指ししない。テーマを説明していない。読者に確かめさせる余白を残す。

**一つの魂、多くの扉** —— 帯（白紙に戻る街）→ あらすじ（最後の一区画へ向かう物語）→ 表紙（色のない白い四角）→ タグ（地図・手彩色・記憶）。すべて同じ問い「覚え続けることは留めることか差し出すことか」を、開かずに指している。
