# 伏線マップ —— 《白地図》（澪の隠れたロール）

## 隠れたロール

- **表のロール → 隠れたロール**: 覚えすぎた者＝最初に消えた「犠牲者」 → 死の瞬間から母を自分の墓に変えていた「意志の主体」（能動の加害者）。
- **誰から隠すか**: 読者（どんでん返し）＋灯自身。
- **幹の問い**: 「澪は、死の瞬間、何をしたのか」。
- **開示（転機）**: 第10章の逆転。悼む者＝悼まれる者が、同一人物の二つの相だったと反転する。

## 伏線一覧（章・手がかり・開示度・開示曲線・回収）

| 章 | 手がかり（答えでなく食い違い） | 開示度（0→1） |
|---|---|---|
| 3 | 二十年前の事件の中心に「誰より多くを覚え、だから最初に消えた者」がいるとされる（覚えすぎた者） | 0.1 |
| 5 | 「皆で忘れようと約束した」——誰が忘れる側で、誰が忘れられる側か、食い違い | 0.2 |
| 6 | 町の名「澪ノ町」と娘の名「澪」の一致。名は忘れても消えず、覚えても救われない（名の牢獄） | 0.4 |
| 7 | 覚えすぎた者＝澪だった、と灯が知る。澪は「死んで町＝色になった」と理解（食い違いの拡大） | 0.6 |
| 9 | 娘の顔の四角だけが色と白の外に残る（復元されない＝澪の意志の痕） | 0.8 |
| 10 | 「自分が娘を場所にした」のではなく「娘が母を墓に変えていた」（回収） | 1.0 |

- **開示曲線**: 単調増加。開示へ向かって加速する（間合い ∝ 問いの大きさ）。第10章の逆転で跳ねる。
- **回収**: 第10章の逆転が、第3章の「覚えすぎた者」を回収する（初読の犠牲者 → 再読の能動者へ読み替わる）。

## 4軸の点検

- **温存**: 澪の意志（母を墓に変えた）は開示前に答えない（「覚えすぎた者＝澪」を第7章で出しても、「墓に変えた」は第10章まで出さない）。
- **進み**: 手がかりが真実へ向かって積む（覚えすぎた者 → 忘れる側/忘れられる側 → 名の牢獄 → 澪だった → 顔の四角が外に残る → 墓に変えていた）。
- **間合い**: 開示へ向かって加速。前半は間隔を広く、第9章以降は狭く。
- **継ぎ**: 開示（娘が墓に変えていた）が、次の問い「白い四角は何の形なのか」を開く（第11-12章へ）。

## その他の伏線

- **娘の顔の四角**: 手彩色の中の一点のフォトリアルな四角。第4章で灯の固執として示し、第9章で「色と白の外に残る」と変わり、第11章で灯自身が白い四角として残る（娘の墓と母の空白が、同じ形で重なる）。
- **白い四角（三度の白）**: 第1章の「塗り戻し」→ 第8章の「自己消滅」→ 第11-12章の「人一人ぶんの空白」。同じ白が三度の形を変えて返る。結末の静止画＝取引の領収書。
- **恋人の声・母の手・本名（代償の列）**: 塗り戻しのたびに消える具体的な記憶。第1章から仕込み、第8章の「代償の会計」で総体として返る——灯が失ったものが、そのまま町が得た色だった。
