# 見通し（hakuchizu 草稿 完了後）

全48話（第1〜12章）の草稿は `草稿/draft_XX-Y_話名.md` に揃った。残る手順：

1. **生成ビュー連結** — 48話ファイルを `草稿/draft.md` へ連結（話割り順に結合。draft.md は生成ビューであり直接編集しない）。
2. **内省ループ（fast-draft）** — 場面表（話割り.md）を ground に、草稿の逸脱（deepens/breaks）を点検。連語切断・総括・名指しの禁じ手を重点確認。
3. **質（任意）** — prose / scene-writer で文体を研ぐ。revise-for-reader で読者体験、whole-work-review で全体。
4. **届ける** — package / theme-song。

※ push はユーザー自身が行う。
