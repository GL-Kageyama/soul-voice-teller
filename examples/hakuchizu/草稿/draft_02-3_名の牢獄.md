# 名の牢獄

灯は、忘れる。──塗り戻すたび、なにかを、忘れる。──声を、忘れた。──手を、忘れた。──名前を、忘れる。──けれど、ひとつだけ、忘れないものが、ある。──町の名だった。

灯は、その名を、口にする。──澪ノ町。──澪ノ町。──澪ノ町。──忘れても、消えない。──覚えても、救われない。──名は、記憶にも、忘却にも、届かない。

灯は、思う。──なぜ、この名だけが、残るのか。──灯は、町の色も、音も、人も、忘れていった。──けれど、名だけが、残る。──名は、白にならない。──白は、名を、喰えない。

灯は、町を、歩く。──澪ノ町という名を、胸に、持ちながら、歩く。──名は、灯のなかで、色にも、白にも、ならない。──ただ、残る。
