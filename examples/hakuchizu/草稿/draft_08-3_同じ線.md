# 同じ線

灯は思う。町を塗りきったとき、灯はどうなるのか。町の最後の一区画を塗り戻したとき、灯の身体はどこまで白くなるのか。

灯はその問いを見る。町の色が満ちることと、灯が白くなることは、おなじ線の上にあった。町が色に満ちる、そのとき、灯は白に満ちる。おなじ線のうえで、ふたつはすれちがう。町の色が増える線と、灯の色が減る線が、おなじ一本だった。灯は、その線のうえを、二十年、歩いてきた。

灯はその線を見つめる。塗りきるということは、消えるということだった。町を最後まで塗り戻すということは、灯が最後まで白になるということだった。灯は、そのことを、いま、はっきりと知る。二十年、うっすら知っていたことを、いま、はっきりと知る。

灯はそのことを知っている。知っていて、灯はまだ塗り戻す。塗り戻すことを、やめられない。やめる、ということが、灯には、もうない。
