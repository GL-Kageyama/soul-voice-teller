# 町になった

灯は、思う。──澪は、死んで、町に、なった。──澪が覚えていた色が、澪の身体の代わりに、なった。──澪は、暖簾の朱に、なった。──路地の群青に、なった。──祭の音に、なった。──澪は、町の色に、なった。

灯は、そのことを、理解する。──灯が塗り戻している色は、澪だった。──灯が、二十年、塗り戻してきた色のひとつひとつが、澪だった。──灯は、澪を、塗り戻していた。

灯は、色を、見る。──朱。──群青。──金彩。──灰。──すべて、澪の記憶が色になった、ものだった。──灯は、澪の記憶を、塗り戻していた。──澪の身体を、塗り戻していた。

灯は、その色に、触れる。──触れて、灯は、思う。──これは、澪だ。──この色は、澪だ。
