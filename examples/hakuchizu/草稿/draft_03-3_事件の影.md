# 事件の影

二十年前、この町は、白紙に、なった。──町が、白紙に、なった、その理由を、灯は、語らない。──語れない。──町の住人たちは、その日を、「皆で忘れよう」と、約束した。

灯は、その約束を、思う。──皆で、忘れよう。──忘れる、ということが、この町の住人たちの、祈りだった。──けれど、灯だけは、忘れなかった。──忘れられなかった。

灯は、思う。──あの事件の中心には、誰かが、いた。──誰より、多くを、覚えた、者が。──そして、その者は、最初に、消えた。──そう、灯は、聞いている。

灯は、その「覚えすぎた者」を、思う。──誰なのか。──灯は、知らない。──けれど、その者が、消えたから、この町は、白紙に、なった。──灯は、そう、信じている。
