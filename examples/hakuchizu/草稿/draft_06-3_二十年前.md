# 二十年前

灯は二十年のことを思う。澪が死んだ。町が白紙になった。どちらも二十年前だった。おなじ二十年前だった。

灯は思う。ふたつのことはつながっているのか。澪の死と町の白紙。灯は知らない。けれど、どちらも二十年前。おなじ年に、おなじ町で起きた。澪が死んだ年と、町が白くなった年が、おなじ年だった。灯はその年を、二度、忘れようとした。一度は、澪の死として。もう一度は、町の白として。けれど、どちらも忘れられなかった。

灯は町を歩く。二十年前、ここで澪が死んだ。そして、二十年前、ここで町が白紙になった。ふたつの白が灯のなかで重なる。澪の死の白と、町の消失の白。二つの白が、灯の記憶のなかで、おなじ一枚になろうとしている。

灯は思う。澪の死と町の消失は、どうつながるのか。灯はその問いを持ったまま歩く。問いは、まだ、かたちにならない。けれど、二つの白が、灯のなかで、おなじ輪郭をとりはじめている。
