# 覚えすぎた者

灯は、聞いたことが、ある。──あの事件の中心には、ひとりの者が、いた。──誰より、多くを、覚えた者。──そして、その者は、最初に、消えた、と。

灯は、その話を、思う。──覚えすぎた者は、町の色を、すべて、覚えていた。──暖簾の朱も、路地の群青も、祭の音も。──すべてを、覚えていた。──だから、最初に、消えた。

灯は、思う。──覚える、ということが、消える、ということに、なる。──ならば、忘れよう、という約束は、生きるために、だった。──忘れて、白になって、生きるために。

灯は、その「覚えすぎた者」の顔を、思う。──誰だったのか。──灯は、知らない。──けれど、その者が、消えたから、町は、白紙に、なった。──灯は、そう、信じている。
