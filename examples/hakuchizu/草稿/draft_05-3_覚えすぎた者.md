# 覚えすぎた者

灯は聞いたことがある。あの事件の中心には、ひとりの者がいた。誰より多くを覚えた者。そして、その者は最初に消えた、と。

灯はその話を思う。覚えすぎた者は町の色をすべて覚えていた。暖簾の朱も、路地の群青も、祭の音も。すべてを覚えていた。だから、最初に消えた。町が白紙になったとき、いちばん多くを抱えていた者が、いちばん先に白くなった。灯は、その順番だけを、確かなこととして覚えている。

灯は思う。覚えるということが、消えるということになる。ならば、忘れようという約束は、生きるためだった。忘れて、白になって、生きるために。多くを覚えれば覚えるほど、その者は多くを失う。だから住人たちは、忘れることを選んだ。忘れることが、生きることだった。

灯はその「覚えすぎた者」の顔を思う。誰だったのか。灯は知らない。けれど、その者が消えたから、町は白紙になった。灯はそう信じている。誰かひとりが、町じゅうの色を背負って、最初に消えた。その白が、二十年前、この町に広がった。灯は、その白のなかを、二十年、歩いている。
