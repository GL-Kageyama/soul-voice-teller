# 外に残る

灯は、最後の一区画を、見る。──白のまんなかに、一点の四角が、ある。──娘の顔の四角。──フォトリアルな四角。──色の世界のなかでも、白の世界のなかでも、ない。──その四角だけが、色と白の外に、残っている。

灯は、その四角を、見る。──二十年、灯が差し出さなかった、もの。──色にしなかった。──白にもしなかった。──写真のまま、守ってきた、娘の顔。──それが、いま、最後の白のまんなかに、ある。

灯は、思う。──この四角だけは、復元されない。──色に、戻らない。──白にも、溶けない。──色と白の外に、残る。──澪の意志の痕のように。

灯は、その四角に、手を、伸ばす。──触れない。──触れる一歩手前で、とどまる。──娘の顔は、色でも、白でも、ない。──ただ、そこに、ある。
