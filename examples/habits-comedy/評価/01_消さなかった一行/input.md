# 第1話「消さなかった一行」

前年度の出席簿が、私の机にある。手引きは開いたまま、その横にある。

私の机は、職員室のいちばん奥にある。窓のそばである。窓の外は校庭で、人は居ない。砂が白い。

年度が替わると、前年度の紙が机に来る。四月に来て、三月に帰る。帰る先は棚である。

帰る日は決まっていない。決めていないのは、私の仕事である。

棚は後ろの壁についている。鉄である。扉が四枚ある。

四枚のうち三枚は、しまってある。取っ手が四つある。取っ手はどれも同じ形である。同じ形なので、間違えても、同じである。

中に、年度ごとの束がある。背に書いてあるのは年度だけである。名は書いていない。

束は綴じてある。綴じるのは事務である。一年ぶんが一つの束になる。

束になると、棚へ行く。段は年度の順である。古いほうが上である。

いちばん下の段が空いている。今年が入る段である。

蛍光灯が点く。四つある。点くのは端の二つで、私の机の上と、そのとなりである。

点けたのは私である。この部屋では、いちばん最初に来た者が点ける。私は毎朝いちばん最初である。

机が六つある。椅子が六つある。椅子はみな、机の下に入っている。入っていないのは、私のだけである。

時計は、始業の一時間前を指している。長い針が上にある。

秒の針もある。短い。短い針がいばん速い。

机の上には、ほかの紙もある。印刷の紙である。年度初めは枚数が多い。

学級の数だけ束ねる。束ねたら、机の端に寄せる。寄せると、端がそろう。

電話がある。まだ鳴らない。

ごみ箱が横にある。中は空である。

手引きは机の端にある。開いたままである。糊の背である。指を当てると、乾いている。

開いている頁は昨日の頁である。頁の端が、少し反っている。反ったままである。

頁の中身は読まない。読まなくても、済む。読み上げる、という動作もしない。

窓の桟に、埃がたまっている。薄い埃である。冬のぶんである。

カーテンは開いている。開けたのは私である。開けると、校庭が見える。

廊下で扉が鳴る。二つ鳴る。手で押した音である。ばねの音もする。

扉が開く。事務の同僚が入ってくる。

「碓氷さん。」

「はい。」

「おはようございます。」

「おはようございます。」

同僚は、鞄を机の横に置く。上着を掛ける。掛ける場所は毎朝同じである。同じなので、私は見ない。

「前年度の紙ですけど。」

「はい。」

「うちもまだなんです。」

「はい。」

私ははいと言う。同僚は、それだけを言う。用件は、それで終わっている。

終わったあとのほうが、長い。

椅子が、机の下に入っていない。私の椅子である。右の腿が、机の板に当たっている。

左の足で、椅子を押す。入る。

足を離す。出る。

「碓氷さん。」

「はい。」

「椅子。」

「はい。」

「出てます。」

「はい。」

もう一度、押す。入る。入って、止まる。

止まっている。腿は、まだ板に当たっている。

「碓氷さん。」

「はい。」

「それ。」

「はい。」

「車です。」

「はい。」

車のついた椅子である。鳴るのは、車である。

「棚、空いてます。」

「はい。」

「空いてるうちに。」

「はい。」

立ち上がる。椅子が鳴る。

膝で、椅子を押さえる。押さえたまま、出席簿を持つ。親指を下へ入れる。入れると、落ちない。

紙は重い。重さは、一年ぶんである。

「碓氷さん。」

「はい。」

「今、空いてます。」

「はい。」

「埋めます。」

「はい。」

膝を離す。椅子が鳴る。鳴るのは、車である。

出席簿は、両手にある。両手である。

足で、椅子を押す。押す先は、見ない。

机の下へ入る音がする。抜ける音がする。向こうから、出る音がする。

音が、遠くなる。止まる。

「碓氷さん。」

「はい。」

「椅子。」

「はい。」

「行きました。」

「はい。」

私は、見ない。

＊

棚まで歩く。机から、五歩である。

歩数は決まっている。五歩で着く。帰りも、五歩である。

廊下ではない。職員室の中である。床は板である。ところどころ鳴く。

鳴くところを、私は知っている。鳴かないところも知っている。

鳴くところを踏む。三つである。三つとも踏む。

棚の前に、椅子がある。

私の椅子である。先に着いている。

足でどける。椅子は、戻る。戻って、机の横で止まる。机の下へは、入らない。

いちばん下の段を見る。空いている。

空いている幅は、ちょうどこのぶんである。去年も、ちょうどであった。

取っ手を引く。

四つのうちの、一つである。同じ形である。ゆえに、どれを引いたかは、分からない。

音がする。鉄の音である。小さい。

扉が開く。中の束が見える。

段の数は五つである。四つには束がある。

埃が、上の段にたまっている。上ほどたまっている。手の届かないところである。

ほかの段には束がある。束と束のあいだに、隙間が無い。ぎちぎちになっている。

ぎちぎちになるのは、私が入れるからである。

前へ出ている束がある。押し戻す。戻る。

また出る。押し戻す。戻って、また出る。

三度目は、押さない。

出席簿の下端を、段のへりに当てる。当てて、持ち上げる。

その前に、開く。

表紙の角が、手の中にある。角は丸い。表紙を起こす。起こすと、紙が一枚立つ。

見返しがある。白である。紙が厚い。

この紙は厚い。一年もつ厚さである。

開くと、頁が二つある。左と、右である。

左の頁に、名の欄がある。欄は、行で分かれている。行の数は決まっている。この学校の一年ぶんである。

罫が引いてある。薄い緑である。欄の幅は狭い。行の幅も狭い。

紙の匂いがする。古い紙の匂いである。

右の頁に、転出欄がある。欄は、右の端にある。

扉が戻る。

肩に当たる。当たったまま、止まる。

扉は、少し傾いている。傾いた扉は、戻る。戻って、当たる。

私は、扉と、束のあいだである。

片手で、扉を押さえる。片手で、出席簿を持つ。

両方、片手である。

手が止まる。名の欄の手前で止まる。止まるというより、動かない。

指は、まだ紙の上にある。四本の指は裏にある。親指は表にある。

指の腹が当たっている。紙は冷たい。外の空気のぶんである。

転出欄に、一行が残っている。行の上のほうである。行の高さは決まっている。

字は、その中にある。書いた字である。

ボールペンである。インクが少し濃い。濃いのは、力のぶんである。

小さい字である。まっすぐな字である。

読む。一度だけ読む。読んで、動かない。

目は字の上にある。字は消えていない。インクが、少し盛り上がっている。

同僚が、こちらへ来る。床が鳴る。三つ鳴る。

同僚は、棚の中を見る。段を、下から上へ見る。

四つ見る。五つめで止まる。五つめには、束が無い。

同僚は、上から下へ、もう一度見る。

五つめで、また止まる。

同僚の指が、五つめの段へ行く。行って、戻る。

同僚は、何も言わない。

言わない時間がある。その時間は、短くない。

同僚の手が見える。手は、何も持っていない。私の手には、出席簿がある。

「碓氷さん。」

「はい。」

「開いてます。」

「はい。」

「閉じますか。」

「はい。」

指を動かせば、頁は閉じる。動かさない。

扉は、開いたままである。

席へ戻る。五歩である。

鳴く板を踏む。踏まないところもある。鳴るところは、三つである。

出席簿は、机の上に戻る。印刷の紙の横に戻る。戻ったところで、置く。

置くと、音がする。置いた手は、まだ紙の上にある。

椅子は、机の横にある。机の下には、無い。

＊

同僚は、もう居ない。扉の音が遠くでする。廊下のほうである。給湯のほうへ行った音である。

室の中に、人は居ない。

机が六つある。椅子が六つある。入っているのは、四つである。

入っていないのが、二つある。私のと、同僚のとである。

二人ぶんである。

私の椅子は、机の横にある。机の下には、無い。

今日、この椅子は、五歩を行った。五歩を、戻った。

出席簿は、行っていない。

席へ座る。椅子が動く。車である。机の前へ、来ない。

立って、椅子を机の前へやる。座る。

来た。来たところで、座っている。

電話がある。まだ鳴らない。

ごみ箱が横にある。中は空である。

空気があたたかくなる。蛍光灯のぶんである。二つ点いている。

鞄が、椅子の背にある。私の鞄である。開いていない。開ける用が、まだ無い。

同僚の机の上に、何も無い。紙が一枚も無い。これから来るぶんである。

壁に掲示がある。紙が貼ってある。四枚ある。角が四つとも、上を向いている。

手引きは、開いたままである。開いている頁は昨日の頁である。背は、糊である。

糊のところが、机についている。端が、机の端とそろっている。そろえたのは私である。

ついたままである。ついていると、開いたところが動かない。

頁が起きている。起きたままである。

頁の数は多い。多いうちの二枚である。二枚が起きている。

動かないところへ、指を一本置く。置いて、動かさない。指の下に紙がある。紙は動かない。

閉じない。

机の上に、開いているものが二つある。手引きと、出席簿である。

片方は昨日から開いている。片方は、今朝開いた。

両方とも、私が開けた。

時計は、始業の二十分前を指している。長い針が、下のほうへ来ている。

秒の針もある。短い。短い針がいばん速い。

出席簿は、机の上にある。開いたままである。重さは、一年ぶんである。

棚へは、行っていない。

行く順は、決まっている。行っていない。

棚の段が、一つ空いている。空いたところに、埃の輪が残っている。

輪は、四角い。本の大きさである。段の幅より、少し小さい。

前年度の紙である。分厚い紙である。藍の紙である。

角が丸い。丸いのは、運んだぶんである。

窓は閉まっている。ガラスごしである。音は少し入る。

廊下で足音がする。遠い。近くならない。

別の扉が鳴る。二つ鳴る。私の扉ではない。

コピー機の音がする。遠くでする。一度止まる。またする。

給湯の蛇口の音がする。細い音である。長い。止まる。

鳥が来る。校庭に来る。砂の上に居る。

歩く。すぐ行く。

窓の外が明るくなる。砂が白い。白いところが増える。

日の光が入る。窓から入る。机の上に来る。手引きの上に来る。

開いたところが白い。白いところが広がる。広がって、止まる。止まったところは、机の端である。

端に手引きがある。出席簿はその横にある。藍のままである。

綴じ目のところで、頁が浮いている。
