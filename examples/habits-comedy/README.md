## 2. 維持した骨格

**話割りの九つのうち八つ**（話名・字数・扱う癖・記名・名を目で読む者・動き・反応軸・舞台）と、**現場・一拍・区分け**を、**一つも動かしていない。** **動いたのは「誰が居るか」一つである**（§4）。

- **毎話、記名の現場が一つ**——出席簿の転出欄の一行。
- **毎話、癖が一つ動く**——手引きの綴じ目を、開いた頁のまま置いておく。
- **誰かが名を目で読み、一拍の長さが生じる**——読むだけで、誰も声に出さない。
- **運搬は、一度も完了しない。**
- **語り**——一人称「私」・現在形・地の文に呼びかけが一度も出ない。
- **禁則**——禁則語ゼロ／感情に名を与えない／`?` を閉じない／「読者」ゼロ／「AI」ゼロ／二人称ゼロ。
- **恐怖とかわいいは、使わない。**
- **同僚に、名を与えない。** **⚠ 四人を足したことで、この項は弱まるどころか強くなった**——**来る者は五人とも、名を持たない。**

**⚠ そして、この稿は一拍に何も置いていない。** **`:297`〜`:329`（紙の匂い・止まる手・冷たい紙・残っている一行）は、一度も笑わせにいかない。** **コメディは、脊髄に触らない。** **人が四人増えても、この範囲には、一人も入れていない。**
