# 各話の作り方——一話を変換する手順

> **これは何か。** [`変換の作法.md`](変換の作法.md) を、**一話ごとの作業に落としたもの**である。**作法が原則、これは手順。**
> **使う人へ。** **作業を始める前に、[`変換の作法.md`](変換の作法.md) を最後まで読むこと。** この紙は**その要約ではない**——**読み終えた人が、抜けを作らないためのチェックリストである。**
> **見本。** **第1話**（[場面表](各話/01_消さなかった一行.md)／[本文](草稿/draft_01-01_消さなかった一行.md)）と**第2話**（[場面表](各話/02_書く前の口.md)／[本文](草稿/draft_01-02_書く前の口.md)）。**⚠ この二つは完成品である。****迷ったら、この二つと同じ形にする。**

## 0. 絶対に守ること

1. **原本（`habits-01`〜`04`）のファイルを、一字も書き換えない。** **読むだけである。**
2. **禁則七群**——金融・債務・経済／倫理・宗教／「AI」／映像と演出／「アニメ」／上限・定員・キャパ・枠／煙草。**すべて 0。**
3. **語り**——**一人称「私」・現在形。** 地の文に**呼びかけを一度も出さない**（二人称ゼロ・「読者」ゼロ）。**「彼」「彼女」ゼロ。**
4. **感情に名を与えない**——「悲し」「さびし」「うらし／嬉し」を地の文に置かない。**気づきは、身体と物で書く。**
5. **`?` を埋めない。** その話が開かない問いは、開かないまま置く。
6. **一拍（その話の芯）には、何も置かない。** **笑わせにいかない。笑わせる人物を、その範囲に入れない。**
7. **新しい物・新しい設定を作らない。** 足してよいのは**既にある物の動く回数**と**既にある席に座る人**だけである。
8. **用件を足さない。** 会話は**言い直しと返事**で増やす。
9. **恐怖とかわいさに逃げない。** **転倒・叫び・走りを置かない**（ドタバタは手順の中で起きる）。
10. **`＊` は節と節のあいだに置く。三節なら二つ。題の直下には置かない。**

## 2. 手順（作法 §2 の八段）

### 段0——測る

**原本を、数える。** **数えずに書き始めない。**

```
cd examples/habits-comedy
python3 検査/検算.py /dev/null --old ../habits-NN/草稿/draft_NN-EE_題.md
```

**見るのは四つ**——**字数・本文行・会話行・段落の文数**である。

- **段落の文数**が **1.0 前後**なら、原本は**まだ一行一文**である——**この場合は段落化が差分になる**（作法 §1 原則1）。
- **2.0 以上**なら、**原本は既に段落である**——**段落化は差分ではない**（第1話・第2話はこちら。`335bcb6`）。
- **五文以上の段落の数**を控える（**この稿の目標は 0**）。

### 段1——骨格を写す

**話割りの欄を写し、原本の場面表から「この話で、動かさないもの」を写す。** **先に、どれを動かし、どれを動かさないかを決める。**

**動かさない**——話名・字数（目安）・扱う癖・記名・現場／一拍・名を目で読む者・動き・反応軸・舞台・区分け・**「動かさないもの」の全項目**。
**動かしてよい**——**会話の相手と行数**・**誰が居るか**（**席が既にあるときだけ**。作法 §1 原則11 の註）。

⚠ **「会話」欄と「誰が居るか」欄の値は、話割りが数を名乗っているかで決まる。** **名乗っていなければ動く**（第2話）。**名乗っていれば、その数が動くかどうかを、著者裁定に照らす**（第1話）。

### 段2——器を調べる

**段0 の結果で決まる。** **1.0 前後なら段落にする。2.0 以上なら、この段は飛ばす。**

### 段3——既にある物を数える

**原本の本文から、物と席を書き出す**——机・椅子・扉・窓・棚・段・紙・束・名札・取っ手・鞄・上着・帳面……**そして、人が座れる席の数。**

**この一覧が、この話で使える札の全部である。** **一覧に無い物を、本文に置かない。**

### 段4——二拍を設計する

**この段がいちばん長い。** 作法 §1 の原則3〜8 を、**この話の物と手順に当てる**。

- **反復の梯子**（原則3）——同じ手順を、**二往復 → 一往復 → ゼロ**と下り坂にする。
- **三段オチ**（原則4）——**三度目で質を変える**（第1話の椅子は、三度目に実際にどこかへ行った）。
- **仕込みと回収**（原則5）——前半に置いた物・音を、**後半で別の場所から**返す。**回収は説明しない。**
- **註を置かない**（原則6）——**笑いの理屈を地の文で書かない。**
- **数を数えさせる**（原則7）——**同じ数が、別のものを数えて返る**と拍になる。
- **逆転を置く**（原則8）——**回収しない逆転**を一つ。

**設計の単位は「物」と「手順」である。** **「面白いことを言わせる」は設計ではない。**

### 段5——書く

**節ごとに、字数の予定に近づける**（**目安である。厳密に合わせない**）。

- **会話は、その話の「動かさないもの」が許す範囲で、思い切り増やす。** **増やすのは言い直しと返事である**（作法 §1 原則2）。**返事は、声でなくてもよい**（第2話は「うなずき」）。
- **地の文は、原本の文を土台にする。** **原本の一行を、勝手にこちらの作った一行へ差し替えない。**
- **一字一字、原本の語彙と語順を尊ぶ。** **この稿は、原本を別の作品へ変えるのではない。同じ作品を、二拍が打てる器へ移すのである。**

### 段6——註を削る

**書き終えてから、通して読む。** **「理屈を説明している文」を消す。**

⚠ **註と帰属は、別である。** **「外の空気のぶんである。」「重さは、一年ぶんである。」は帰属である——残す。** **「同じ形なので、間違えても、同じである。」は註である——消す。**

### 段7——検算する

```
python3 検査/検算.py 草稿/draft_NN-EE_題.md --old ../habits-NN/草稿/draft_NN-EE_題.md
python3 ../habits/検査/check.py "$PWD/草稿/draft_NN-EE_題.md"
```

**作法 §3 の七つを、場面表に書く。**

## 3. 出すもの——二つ

### ① 本文 `草稿/draft_NN-EE_題.md`

```
# 第N話「題」

（段落。一行ごとに空行を挟む）

（段落）

＊

（段落）
```

- **題の行の次は空行。** **段落と段落のあいだも空行。** **`＊` の前後も空行。**
- **段落は、四文まで。**（**五文以上は 0 にする**）
- **節は三つ**（原本が三つでなければ、原本に合わせる）。

### ② 場面表 `構想/各話/NN_題.md`

**第1話・第2話の場面表と、同じ形にする。** 節立ては次のとおり——**中身が無い節は「—」と書いて残す。**

| 節 | 何を書くか |
|---|---|
| 頭の引用 | これは何か・原本へのリンク（**実測字数**）・規則・⚠ 原本の場面表との関係 |
| **§0 動かしていないもの** | 表。**欄／値／原本と**。**動いた欄は ⛔ を付けて、どこで動いたかを書く** |
| **§1 場面表** | 表（#／場面／場所・時刻／起承転結／誰が居るか／反応軸／内面／字数）＋ 時間の幅・入口の掴み・**一拍の位置**・会話の設計 |
| **§2 この話で、動かさないもの** | **原本の全項目を写し、一つも動かしていないことを書く** |
| **§3 差分——コメディとして、何をしたか** | 表（#／何を／どこで／型）。**行番号つき**。**⚠ 新しい物が一つも無いことを、末尾に書く** |
| **§4 内面の欄——〔実測〕** | **本文を書いた後に読む。** 各節の値（`A`／`B`／`C`）と、**その根拠の行番号**。**⚠ 原本と一箇所も変わっていないことを書く** |
| **§5 検算** | **作法 §3 の七つ**を、実測値つきで。**原本との並置**。**⚠ 申告**（原本を置き換えた箇所・足した細部・控えの有無） |

**⚠ 場面表は、原本の場面表の写しではない。** **差分だけを書く。****同じ欄は、原本を指す。**

## 4. 内面の欄——`A`／`B`／`C` とは何か

**`examples/habits/構想/design.md`「内面の欄——C-18 の実施細目」が正文である。** 要は——

| 値 | 何か | 例（第1話） |
|---|---|---|
| **`A`** | **気づき**——身体・物を通した気づき | 「紙の匂いがする。」「指の腹が当たっている。」 |
| **`B`** | **働きの知識**——自分の仕事についての知識 | 「この仕事では、紙は年度で動く。」 |
| **`C`** | **為まいの宣言**——しない、と決めていること | 「閉じない。」 |

**各節に一つ。****節の軸になる値**を書き、**同じ節に別の値が読める場合は「二つ目の形」として行番号つきで置く**（第1話の場面表 §4 がその形）。

**⚠ 人が増えても、この欄は動かない。** **足した人物は、語り手の内面に一度も入らない。** **それは「骨格の外に触れていない」ことの検算である。**

## 5. よくある失敗

| 失敗 | なぜ |
|---|---|
| **比喩や形容で笑わせる** | 一拍しか打てない（作法 §0） |
| **説明の一文を足して、笑いの理屈を書く** | 二拍のあとの註は、笑いを打ち消す（原則6） |
| **新しい物（新しい備品・新しい設定）を作る** | 骨格の外に出る（原則11） |
| **一拍の場面に、人を入れる／笑いを入れる** | その話の芯が壊れる（原則10） |

| **五文以上の段落を置く** | 検算② |
| **走る・叫ぶ・転ぶ** | 手順の外にある（原則9） |

## 6. 巻ごとの違い——**作法 §4 は、第一巻のものである**

⚠ **これを読まずに、第二巻以降を書かない。** **作法 §4 の「語り＝一人称『私』・現在形」は、第一巻の値である。** **巻ごとに、語り手も、人称も、内面の欄の有無も、会話の区別のしかたも違う。****第一巻の既定を他の巻へ当てると、その巻の芯が壊れる。**

| | **第一巻** | **第二巻** | **第三巻** | **第四巻『書いていない名』** |
|---|---|---|---|---|
| 語り手 | 碓氷千夏 | 暮林蒼 | 侘田すみれ | さくら（頁） |
| **一人称** | **「私」** | **「僕」と「私」のあいだで揺れる** | **「私たち」** | **置かない** |
| 二人称・呼びかけ | 地の文に一度も出ない | 同じ | 同じ | **置かない** |
| 時制 | 現在形 | 現在形 | 現在形 | 現在形 |
| 声 | — | **早口。敬語が途中で崩れる。名前を呼ばずに用件から入る** | **丁寧だが語尾が遅れる。文の最後の一音だけ、少し小さい** | **声を持たない** |
| **内面の欄（`A`／`B`／`C`）** | **置く** | **置く** | **置く** | **置かない**（場面表にも持ち込まない） |
| **会話の区別** | 話割りが話ごとに名乗る | 同じ | 同じ | **問い一声のみ。鉤括弧でも改行でも区別しない。誰の声か書かない** |
| 会話なしの話（**話割りがそう名乗る話**） | 第3・5・8・10・14話 | 第5・8・10話 | 第7・9話 | 第18話のみ（他十七話は問い一声） |
| **会話なしの話（〔実測〕鉤括弧が0行の話）** | **第3・5・10・14話** | **第2・5・8・10・14話** | **第6・7・9・15・16話** | **十八話とも** |
| 「誰が居るか」欄 | 名で書く | 名で書く | 名で書く | **名のない者を名で書かない**（「誰の手でもない」「読む手」「誰かの手」「—」） |

**⚠ 第二巻の文体**——**速度である。** 一日八十から百二十軒。**文が短く、接続が速い。****この巻だけ、会話が動きに追いつけない。**

**⚠ 第三巻の人称は「私たち」である。****「私」に直さない。** **「私たち」は、名を書く手と、名を書かれる者の対だけを指す**——**ゆえに侘田すみれは「持ち主のいるとき」だけ書ける。** **書くことは一人でする行為であるのに、彼女の人称に一人がない。**

> **⛔ ただし、これは設計の値である。****原本の本文は、その語をほとんど使っていない。****〔実測〕第三巻の原本16話に「私たち」は 0件。**「私」は **8件だけ**（`03-15` に3・`03-16` に5。**残る14話は、どちらも 0件**）。**これは欠陥ではない**——**C-9 ゆえ、対が立たない話では人称が発火しない**（`03-02` の場面表は、これを「二人称の対が立たない話では、一人称も立たない」と書いている）。**ゆえに——**
> - **「私たち」を、本文へ足さない。** **設計が「立てる人称は『私たち』」と言うのは、その話で対が立つときだけである。** **原本が使っていない話に足せば、それは原則11「新しい物を足さない」の裏側から破ることになる。**
> - **原本が使っている話では、そのまま残す**（`03-15`・`03-16` の「私」）。**「私たち」へ直さない。**
> - **⚠ 設計の値を、「原本がそう書いている」と読まない。** **巻の人称は、まず原本で測る。**（[`measured-scope-vs-claimed-scope`]／[`対比は両側を測る`]）

**⚠ 第四巻には、三つの通路が無い。****人称・内面・回想である。** **さくらに内面が無いのは、この巻の規則ではなく、この人物である**（[`../../habits/構想/design.md`](../../habits/構想/design.md) 決定 C-18）。**置かれる内面が無いので、名を目で読む一拍が、内面の代わりに立つ。**

⛔ **ゆえに第四巻の変換では、会話も内面も足せない。****足せるのは、二拍だけである——しかも、物と手の側にだけ。** **これは作法 §0 の脊椎（ユーモアは「声」ではなく「二拍」）の、最も純粋な試験である。****第四巻で「会話を増やす」と書いてある手順は、第四巻には適用しない。**

**⚠ 出典。** 上の表は、四巻の `構想/design.md`「### 語り」「### 文体の方向」と `構想/話割り.md` の集計行（「会話のある話」）、および [`../../habits/構想/design.md`](../../habits/構想/design.md) §「内面の欄——C-18 の実施細目」の末尾（**「第四巻の場面表には、この欄を足さない」**）から写した。**推測の欄は一つも無い。**

**⛔ ただし——「会話なしの話」の二行は、一致しない。****別のものを数えている。**
- **上の行＝話割りの集計行から写したもの。** `habits-02/構想/話割り.md`:366「会話のある話 第1・2・3・4・6・7・9・11・12・13・14・15話の十二話。会話なしは第5・8・10話の三話」。**話割りの「会話」欄が空でないかを数えている。**
- **下の行＝原本の本文を数えたもの**（[`原本の実測.md`](原本の実測.md) の「会話行」）。**鉤括弧が一つも無い話を数えている。**
- **⚠ ゆえに、喰い違う話がある。** **第2・6・14・15・16話は、話割りが「会話」欄に何か書いているのに、本文に鉤括弧が一行も無い**（例——第二巻 第2話の欄は「四人（高橋由美・パート三名）。**沈黙が「待ち」に変わる。**」であり、**これは発話の数ではなく、場の設計である**）。**逆向きもある**——**第一巻 第8話は話割りが「会話なし」と言うが、本文に鉤括弧が1行ある。**

## 7. 第四巻を変換するとき——**いちばん難しい巻**

**⛔ 第四巻は、前三巻と、器が違う。****足せるものが、ほとんど無い。****先に、この巻の規律を写す。**

**この巻の規律（動かさない。`habits-04/構想/design.md` から写す）。**

- **一人称を置かない。二人称を置かない。**
- **内面を置かない。回想を置かない。記憶を置かない。**
- **形容は物にだけ許す。心情・回想・記憶・欲求は書かない。** **書けないのではなく、欄がない。**
- **会話は問い一声のみ。地の文と地続きに置き、鉤括弧でも改行でも区別しない。誰の声か書かない。話者を示す語を置かない。**
- **「誰が居るか」欄は、名のない者を名で書かない**（「誰の手でもない」「読む手」「誰かの手」「—」）。
- **内面の欄（`A`／`B`／`C`）を、場面表に足さない。**

⛔ **ゆえに、作法 §1 の原則2（会話は言い直しと返事で増やす）は、この巻には掛からない。****会話を一行も足せない。** **足す先が、無い。**

### 足せるのは、二拍だけである。しかも、物と手の側にだけ

**この巻で使える手は、三つである。** **どれも、この巻が既に持っている物を数え直す手である。**

| 手 | この巻での形 | 出典 |
|---|---|---|
| **原則3——反復は、梯子にする** | **この巻は、同じ一行を各節に置く**（「動いていない。」「紙の端は動かない。」「大きさは変わっていない。」）。**それを 二往復 → 一往復 → ゼロ と下り坂にする** | 第9話の実文（**第5〜8話は各場面に音の一行を置き、第9話は置かない**——**巻をまたぐ梯子が、既に一つある**） |

| **原則5——仕込みと回収** | **前半に置いた物の位置を、後半で別の場所から返す。****回収は説明しない** | 作法 §1 |

**⚠ この巻の四つの通路は、手前で止まるためのものである。****呼称の揺れ・沈黙の長さ・発話の順番・「も」の位置**——**各話は、そのうちいくつかを、手前まで行って止める。****⚠ これは一拍である。****作法 §1 原則10 の「一拍には何も置かない」は、この巻でも掛かる**——**手前で止まる場所に、笑いを置かない。**

### 各話の「動かさないもの」を、全文読む

**⚠ この巻の「動かさないもの」は、二拍にも制限を掛ける。** **第9話は、七項目を挙げる**——**さくらの名だけを大きく書かない／名の読みを置かない／読む手を名に直さない／声を出さない／運ばない／語り手がこの現場に居る理由を書かない／第17話を先取りしない。** **一つでも破れば、その話は壊れる。**

### ⚠ この巻の変換は、前三巻より薄く出る。それが正しい

**足せないものを足して、二拍に見せかけない。****薄いまま出す。****薄さは、この巻の設計である。** **⚠ 場面表 §3「差分——コメディとして、何をしたか」に、一行も書けない回があってよい。****そのときは、そう書く。****空欄を、埋めない。**

## 8. **会話のない話では、どこを増やすか**——**いちばん出やすい失敗**

⚠ **会話のない話**（第一巻 第3・5・8・10・14／第二巻 第5・8・10／第三巻 第7・9／**第四巻 第18話**）は、**増分が小さく出やすい。****それは、会話が使えないからである。****だが、会話なし回にも、増やせる場所はある。****それは、既にある手順の〝回数〟である。**

**⛔ 失敗の形。****原本の段落を割り直しただけで、二〜四行を足して終わる。****これは変換ではない。** **（実測例——段落の割り直しと数行の追加で、`+50字`。**この程度では、二拍は打てていない**）** **⚠ 段落の割り直しは、差分ではない**（作法 §2 段2——**原本は既に段落である**）。

**✅ 増やす手は、作法 §1 のどこにあるか。**

| 手 | 会話なし回での形 |
|---|---|
| **原則3——反復は、梯子にする** | **既にある動作を、二往復 → 一往復 → ゼロ と並べる。**⚠ **原本は、同じ動作を一度しか書かないことが多い。****並べるだけで、行が増える。** |
| **原則4——三段オチ。三度目で、質を変える** | **同じ動作を三度置き、三度目だけ、結果が違う。** |
| **原則5——仕込みと回収** | **前半に置いた物・音を、後半で別の場所から返す。****回収は説明しない。** |
| **原則7——数を、数えさせる** | **原本が既に数えているものを、別のものを数えて返させる。** |
| **原則8——逆転を置く。回収しない** | **一度だけ、期待の外へ出る。****そして、それを使わない。** |

**✅ 第1話の実例（`+828字`）。** **同僚が椅子を確かめる手順**（「椅子。」「出てます。」）が、**この話では三度置かれた。****三度目に、椅子は実際にどこかへ行った。** **⚠ 原本にないものは、何も足していない**——**椅子も、同僚も、手順も、原本にある。****足したのは、回数と、順番と、三度目の結末である。**

**⚠ 増えない回は、増えないままでよい。****足せないものを足して、二拍に見せかけない。****そのときは、場面表 §3 に「この話では、これ以上は置けない。理由はこれである」と、理由つきで書く。** **空欄を、埋めない。****薄いことは、失敗ではない。****薄いことを薄いと言わないことが、失敗である。**
