## 考察（私見）

**ここから先は解釈である。** ここまでの各節は両ファイルから機械的に出した。この節はそこから私が読んだことで、出典に書かれていない。数えた数は、数えた範囲のままに書く。

**これは、小説と検査装置の違いがそのまま形になったものだと思う。** 一話一カットで測るなら、最後の一カットが行為であるのが正しい。小説なら、行為のあとに何が残ったかを書ける章が要る。run-09 の「返却のあとの一章」は、この作品でいちばん小説的な部分である。

### 4. 濃淡は品質ではなく、計器の違いである

README は run-10 が run-09 の濃淡を平坦化したと書く。実測でもそうである——二巻第4話 3,200→4,100、三巻第12話 4,000→4,300、四巻第13話 4,700→5,300、四巻第18話 6,100→4,700。各巻合計は同額のまま、中だけが均されている。

一定の刻みは、章をまたいで動きを比べる装置には要る。呼吸は、小説には要る。**優劣ではない。** 章立てを選ぶというより、**どちらの計器で本文を測るかを選ぶ**ことに近い。

ただし、平坦化で確実に失われるものが一つある。**run-09 第二巻第4話「点」の 3,200字は、全63話で最短である**（居酒屋。伝票の端に、自分の出した卓の数だけ点を打つ）。run-10 はこれを 4,100字に均した。この作品には、短い章が一つ要ると思う。

### 5. 会話劇は章ではなく、章に載る層である

run-10 の会話劇回は 一巻第10話／二巻第6話／三巻第13話／四巻第14話。run-09 の同じ番号の章は——

| 会話劇回 | run-09 の同じ章 | 載るか |
|---|---|---|
| 一巻第10話 | 「転出先」4,100（碓氷千夏——名簿の同じ行を、二度読む） | 載らない |
| 二巻第6話 | 「先輩」4,200（前田亮太・主役回） | **載る** |
| 三巻第13話 | 「残す」4,100（関翔太——四本目を、捨てる前に一日置く） | 載らない |
| 四巻第14話 | 池田絵里——切った長さを、床の量で覚える | 載らない |

**四つのうち三つは、run-09 に該当する章がない。** run-09 の章立てを採るなら、会話劇は載せ替えになる。載せ替え先は、四人が同じ場所に居合わせる章——一巻なら第13話（配達員が学校へ来る）か第14話、四巻なら第16話以降。**これは章立てを決めたあとの設計作業で、いまは決められない。**

逆に run-10 の章立てを採るなら載せ替えは要らない。ただ、そのとき四巻第14話の仮題「宛名欄」が——run-09 では第四巻の巻末の題である——中ほどに来る。

### 6. 各案の内側で、決めておきたいこと

**run-10 に残っている五点。**

1. **第二巻第15話（返却の現場）の記名が「預かり札」。** 同じ巻の第5・7・10・12話は四枚の宛名票で、README の紙の表も第二巻を「重なった宛名票」とする。返却の現場だけが別の紙になっている。意図か、書き漏らしか。
2. **第二巻第14話の会話相手が 長田美穂。** 彼女の配属は第三巻第3話（主役回）。配属の重複ゼロに触れるかどうかは、配属を「主役回の巻」と読むか「登場の巻」と読むかで決まる。**先に決めておけば、あとで矛盾にならない。**
3. **第一巻第3話と第12話の記名が「名札の予備の束」「名札の予備」。** README の紙の表では、名札の予備の綴じ束は第四巻の紙である。第一巻に前倒しで出ている。別の紙なら問題ない。同じ紙なら、第四巻の一枚が第一巻から見えていることになる。
4. **第四巻第14話の仮題が「宛名欄」。** run-09 ではこれが第四巻第18話（巻末）の題である。巻末の題が中ほどへ動き、その章が会話劇回（問い一声のみ）になっている。
5. **第四巻の18話で、記名の語は14種。** うち四つが同じ語の再出で、「名札の予備」を含む語は第1・8・15・18話の四回に出る。章ごとの違いは薄いが、四巻の紙が一枚であることとは合う。

**run-09 に残っている三点。**

1. **第四巻の「返却する者はなく、返却は届かない」。** 直後の「口が訊く形に動く」と読みにくい。その口は さくら の口である。run-10 の「返却する者はさくら、される者は誰もいない」は、同じ事実を明確に言っている。**この一点は run-10 が勝っている。**
2. **第二巻の山場の書き方。** 「六、山場＝第14話」「頂点の一文は第14話末の『違う読みで呼ばれて、振り向いた。』」と書き、その同じ一文が第15話の仮題でもある。二度出るのか、第15話に一度だけ出るのか。
3. **第四巻第18話「宛名欄」6,100字は、全63話で最長。** run-10 はこれを 4,700字に均した。最長の章を巻末に置くかどうかは、決めておく価値がある。

### 7. 私の推し

**骨は run-09、層は run-10。**

| 層 | 採るもの | 理由 |
|---|---|---|
| 話数・配属・主役回・各巻合計字数 | 両案同じ（実測） | 選ぶ余地がない |
| 章立て・仮題・字数配分 | **run-09** | 返却のあとの一章、第四巻の六名の二度目、濃淡 |

| 会話劇四回 | run-10 の設計を、run-09 の章へ載せ替える | 四つのうち三つは章が合わない |
| 禁則の書き直し二箇所 | run-10 を採るのなら原文に当てる。小説には持ち込まない | — |

理由を一行で。**「アニメ化を前提とするのは検査装置であって、適応の計画ではない」という条件が、この配分をそのまま決めている。** 装置としての run-10 の精度——動き・会話・一定の刻み——は場面の層に要る。小説としての run-09 の形——返却のあとの章・濃淡・第四巻の六名——は章立ての層に要る。**層を分ければ、選ばずに両方を持てる。**

代償も書いておく。この配分では、章立てを run-09 にした時点で、**run-10 の19話ぶんの扱う癖は使えず、作り直しになる**（一巻第10・13・14話／二巻第13・15話／三巻第11・12話／四巻第1話・第8〜18話）。第四巻は11話ぶんがそれにあたる。ここが、この配分でいちばん重い作業になる。

そして、これは私の推しであって決定ではない。**第四巻を「六名の二度目の巻」とするか「頁だけの巻」とするかは、作品の主張に関わる。** そこは私が決められる場所ではない。
