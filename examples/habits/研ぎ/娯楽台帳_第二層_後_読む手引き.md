## 3. 書き方——**七つの欄の形**

**一行が一場面である。** 出力は **TSV**（タブ区切り）で、**次の九つの欄**を、この順に書く。

```
話	場面	実現した軸	三種	掴んでいるか	器（与えた／欠けさせた）	設計との差	ズレの有無	案
```

| 欄 | 書ける値 | 例 |
|---|---|---|
| **話** | `NN-NN`。**台帳と同じ字** | `01-01` |
| **場面** | `1`／`2`／`3` | `1` |
| **実現した軸** | `なし`、または **`ユーモア`・`楽しい`・`感嘆`・`感動`・`恐怖`・`かわいい`** の一つ以上を **`＋`** で繋ぐ | `感嘆` / `ユーモア＋感嘆` / `なし` |

### 3-1. 逐語の検査に掛かる（**飾りは落とされるが、句は一字も動かさない**）

**器と `ズレの有無` は、機械で検査される**——**引いた `(:NNN)` の行に、引いた句が逐語で在ること。**
**⚠ ゆえに、句は草稿から一字も変えずに写す。** **読点・句点も、そのまま写す。**
**⚠ 行番号は、その場面の範囲（台帳の `行` の欄）の内から引く。**

**⚠ `器` は、場面より手前の行から借りてもよい**（フックの設計上、正しい。註になるだけで違反ではない）。
**⚠ `ズレの有無` は、その場面の内から引く。**

### 3-2. `掴んでいるか` の目安（一度目と同じ）

- **`○`**——この場面を読んで、**先へ進みたいと思った**。
- **`△`**——読めるが、**引っ張られない**。
- **`×`**——**置いていかれる**。

**⚠ `実現した軸` と `掴んでいるか` は、同じ一人が同じ場面に書く**（一度目と同じ）。
**ゆえに `なし` と `×` は重なりやすい。** **それは誤りではない。**
