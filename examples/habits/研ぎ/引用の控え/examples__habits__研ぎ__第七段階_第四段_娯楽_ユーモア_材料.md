### 0-3. ⚠ そして、この作品には既にユーモアが在る——**その型を写す**

**`01-01:277`**（第三場面）——

```
時計は始業の二十分前を指している。長い針が下のほうへ来ている。秒の針もある。

```

## 1. 何を作るか

**189場面のそれぞれに、場面の三種（`クスッ`・`ニヤリ`・`ぷっ`）のどれか一つを届ける。**
**一つは、一行の差し替えで足りる。**（`娯楽台帳.tsv` の `ズレの有無` が `有` の4場面は除く。**実質 185場面**）

### 1-1. 三種（`references/ja/6つの反応軸.md`）

| 種 | 反応 | ずらしたもの |
|---|---|---|
| **クスッ** | 「そう来るか」 | **展開**の予測 |
| **ニヤリ** | 「してやられた」 | **意味**の予測 |
| **ぷっ** | 「言い得て妙」 | **表現**の予測 |

### 1-2. 四工程（**縮尺は場面**。`資料/00_done/エンターテイメント創作構想/ユーモア/場面ごとのユーモア.md`）

```
① 真面目の土台 ── この作品では、既に在る。地の文の平坦さそのものである。作り足さない。
② ズレの仕込み ── ★ ここを作る。これがこの段の成果物である。
③ 安全な回収 ──── この作品では、平坦な一文がそのまま回収になる（驚きを説明しない）。
④ 笑いの頂点 ──── 三種のどれか一つ。静かに落とす。
```

**⚠ ①を作り足してはならない。** **この作品の土台は「真面目であること」であり、それは既に本文の全体である。**

### 1-3. この作品で使えるズレの型——**四つ**。すべて本文に先例がある

| 型 | 何をするか | 本文の先例 |
|---|---|---|
| **字面のすり替え** | 同じ語を、**別の物**へ当て直す | `01-01:277`「短い針がいちばん速い。」 |
| **逆転** | 予測される側が動かない／予測されない側が動く | `02-04:321`「十二、も。」（言い返さない側が、ひとつ足す） |
| **過剰な精密さ** | **数える必要のないもの**を、数える | `01-01:307`「鳴るところは三つである。」 |
| **三段オチ** | 同じ型を二度置き、**三度目だけ**別のほうへ | `02-05:81`「車輪が一つ鳴る。鳴って、止まる。」→`:275`「…もう一度押す。」 |

### 1-4. ⛔ 禁じ手——**この作品が自分で立てた不変を、破ってはならない**

**⚠ 第三段で、四人がこれを12件見つけた。**（[`第七段階_第四段_娯楽_届いた_案_当てた.md`](第七段階_第四段_娯楽_届いた_案_当てた.md) §5）

| 禁じ手 | 実例（**当ててはならなかった**） |
|---|---|
| **「一度だけである」を破る** | `02-06:275`「一度である。**それから、もう一度鳴る。**」← `:269`「もう鳴らない。」と衝突 |
| **「動かない」を破る** | `02-02:47`「袋が、ひとつ揺れる。」← `:49`「袋は動かない。動かす者が居ない。」と衝突 |
| **同じ物を二度、消す／鳴らす／止める** | `02-15:419`「事務所の灯りが、ひとつ、消える。」← `:405`「営業所の中の灯りが消える。」と衝突 |
| **居ない者に、させる** | `02-02:229`「台車の車輪が、ひとつ鳴る。」← その場面に押す者が居ない |
| **場面表の「動かさないもの」に触る** | `02-07:313`「戸の内側で、スリッパの音がする。」← 場面表が「届け先の玄関の内側を、書かない」と定める |

**★ ゆえに、ズレは「事実を裏切る」ことで作ってはならない。** **裏切ってよいのは、`読者の予測` だけである。**
**この作品のユーモアは、`何かが起きる` ことからではなく、`何に目を向けるか` のずれから来る。**

### 1-5. その他の規則（`第七段階_第四段_entertainment_指示書.md` §4）

1. **新しい物・出来事を、持ち込まない。** 使ってよいのは、**既にその場面にある物・行為・音・声**だけである。
2. **説明・解釈・総括を書かない。状態を書く。出来事を書かない。**
3. **感情に名を与えない**（`悲し/さびし/うれし/怖/つらい` は全63話で 0件。**塀**）。
4. **現在形。**
5. **禁則語ゼロ**（`../README.md` の「## 禁則」）。
6. **第四巻だけ**——**色語**（青緑黄茶灰銀紫桃橙）・**匂いの語**（匂・におい・臭・香・嗅）を新しく持ち込まない。**「〜は、答えない。」「その、ままである。」を使わない。**
7. **`?` を閉じない。** 設計が読者へ投げた問いに、答えを足さない。
8. **鉤括弧の中は、一行も触らない**（②③が宣言した分担線。**第四巻は、そもそも鉤括弧を置かない**——決定5 が問い一声を地の文に置く）。
9. **数を新しく作らない。** 数は、本文が既に持っているものだけを使う。

## 2. 出すもの

**TSV、八欄**——

```
巻<TAB>話<TAB>場面<TAB>行番号<TAB>いまの文<TAB>案<TAB>三種<TAB>根拠
```

- **`いまの文` は、草稿から一字ずつ写す**（**行番号は、ファイルの物理行番号である。空行も見出しも数える**）。
  ⚠ **行番号は使える。逐語は使えない**——前段で、読み手が申告した逐語 23件のうち 3件が、行の一部だけを引いていた（`第七段階_第四段_娯楽_ズレ_当てた.md` §1-1）。**自分で引き直すこと。**
- **`案` は、その行の差し替え後の全文である。** **行は足さない。行は消さない。**
- **`三種` は `クスッ`／`ニヤリ`／`ぷっ` のどれか一つ。**
- **`根拠` に、必ず四つを書く**——**①どの型か ②土台は何か（本文のどこ） ③外した予測は何か ④回収はどの一文か。**
  **この四つが書けない案は、出さない**（`ユーモアの設計.md` §6——「この笑いは、どこで・どの予測をズラし・何がそれを安全に回収するか、を言えるか」）。

### 2-1. 機械の検査（出す前に、自分で走らせる）

```sh
cd /Users/user/AI創作工房/soul-voice-teller/examples
python3 habits/研ぎ/台帳を検める.py <自分のTSV> --add-sentences --quiet
```

**⚠ `--add-sentences` が、この段のための旗である**（**文の増加を ⛔ にしない。代わりに、当てたあとの文数を註に出す**）。

**⚠ 実測（2026-10-14）——`--add-sentences` のとき、器は五文以上を ⛔ にしない。** **⚠ 註を出すだけである**（`台帳を検める.py`:256-270。`n_new >= 5` の枝も `notes.append` である）。
**ゆえに「四文以下」の上限は、器が守るのではない。** **この段の規則であり、[`娯楽_ユーモア_案を作る.py`](娯楽_ユーモア_案を作る.py) が守る**（差し替え後が五文以上なら、台帳を出さずに ⛔ で止める）。

**⚠ 文の数え方も、器の物差しである**——`inner_periods(s) + 1` すなわち **`。` の数**（末尾が `。` ならそれ自体、さもなくば +1）。
**言語学の文の数ではない。** 鉤括弧の行（`「同じです。」`）は、末尾が `」` ゆえ **2 文**と数えられる。**それでよい**——要るのは、**前と後で同じ物差し**であることだけである。

**⛔ が出たら、直す。** ⚠ **⚠（註）は読む。** **註は「その行はもともと一文である」「当てると五文になる」等の申し送りであり、⛔ ではない。**
