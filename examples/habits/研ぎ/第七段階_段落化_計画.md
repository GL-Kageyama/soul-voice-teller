## 2. 段落の切り方——規則の候補

| | 規則 | 採るか |
|---|---|---|
| **a** | **文の数を数えて、機械で切る**（三文ごと、など） | **採らない**——**内容でなく数で切ることになる** |
| **b** | **拍で切る**——物・動作・場所・手の変わり目 | **採る**（**`/prose` の 7-E「段落の位置——決定的な一撃で切る」が、この判断の技能である**） |
| **c** | ~~**第二巻の分布へ寄せる**——複数文の行を、およそ三割にする~~ → ~~**場面ごとの勾配へ寄せる**——**場面1は 1.62・場面2は 1.42・場面3は 1.33 のあたり**~~ → **場面ごとに、その場面を読んで決める**——**音の列か、指の動きか、会話かで変える**（**§8-2 の六件目・2026-09-26 の裁定**） | **採る。⚠ 勾配は目安にしない**——**⚠ 規範にも、目標にもしない。** **⚠ 台帳ごとに、その話の勾配を「申し送り」として書き、著者が読む** |
| **d** | **型は、そのまま守る** | **採る**（下の四つ） |

**⚠ d の四つ——これは、機械が守れる。**

1. **会話（鉤括弧）は、必ず単独の段落である。** **実測——四巻とも、鉤括弧を含む 149 行は、行頭が「が 145 行・

   いまの形を、保つだけである。**
2. **頂点の一文は、単独の段落である**（`01-13:932`・`02-14:581`・`03-15:383`・`04-17:182`）。
3. **第四巻の問い一声を、単独の段落にしない。** **⚠ この巻の設計が「地の文と地続きに置き、鉤括弧でも

## 5. 器——二つ作る

### 5-1. `段落を組む.py`——組む器

**⚠ 台帳の形式**——**タブ区切り、一行一件。前三欄は既存の器と同じである。**

```
ファイルパス<TAB>行番号<TAB>組む|切る
```

**⚠ 既定は「切る」である**（**いまの形**）。**⚠ 台帳は、例外だけを書く**——
**「組む」と書かれた行は、直前の行と繋がる**（**台帳が短いほど、いまの形に近い**）。

**⚠ 当てる前に確かめる**——① ファイルがある、② 行がある、③ その行が、いま空行でない本文行である、
④ 見出し行を狙っていない、⑤ 同じ行を二度狙っていない。

**⚠ 当てた後に確かめる**——**四つ。**
1. **内容の不変**——**本文行を連結した文字列が、前後で一バイトも違わない。**

   **⚠ 空の検査は OK と言う。** **ゆえに「相手が空なら落ちる」を入れる**——**連結した文字列が空なら、
   照合せずに落とす**（**`0 == 0` で通さない**）。
2. **字数の不変**——**非空白文字が、一字も動いていない。**
3. **空行の規律**——**段落の間は空行一つ。連続した空行は 0。** **⚠ 見出し（`## N`）の前後も、同じである。**
4. **段落の数**——**本文行数 − 「組む」と書かれた行数**に、一致する。

**⚠ そして、行番号の対応表を書き出す**（**旧 `<TAB>新`。5-2 の入力になる**）。

### 5-2. `引用を貼り直す.py`——番号を引く器

**⚠ 対応表だけを使う。内容では引かない。** **⚠ 台帳は、上と同じ形である。**

**⚠ する こと**——**リポジトリ全体の `*.md` から `NN-NN:NNN` と「本文 N」を見つけ、`NNN` を対応表で引き直す。**
**⚠ 引けない番号（対応表に無い行を指す引用）は、書き換えずに「引けない」として報告する**（**`貼り直し.py` と同じ流儀**）。

**⚠ 当てた後に確かめる**——**① 書き換えた件数が、走査した件数と一致すること。② 書き換えた前後で、
`NN-NN:` の部分が一字も動いていないこと**（**動くのは `:NNN` だけである**）。
