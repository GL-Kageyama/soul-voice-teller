## 1. 読点の解放——禁じ手に戻す

### 何が起きていたか

`構想/design.md:81` と `persona.md` は、そろって同じ禁じ手を置いている。

> 読点は並列を一息で流し、**要の一打（反転・定型句）だけ**に刻む。連語を原子に分解しない。

> 禁じ手——冗長な説明、嘘くさい感傷、**連語の読点切断**、アンカーの表層の模倣。

ところが、六十三話の本文は、この禁じ手を破って書かれていた。

```
私の机は、職員室の、いちばん、奥にある。      → 私の机は職員室のいちばん奥にある。
校庭に、人は、居ない。                        → 校庭に人は居ない。
扉が、四枚、ある。                            → 扉が四枚ある。
開いた、ままである。                          → 開いたままである。
```

`段0_判定材料.md:160` はこれを「地の文の律」と呼び、`系列_⑥反映_裁定材料.md:40` は
`preserve` の第三項に「読点による並列体と、一行ごとの空行」を挙げ、`系列_軸1_改稿案.md:117` は
「行の内側の作りは、この回では動かさない」と書いている。**破れていることが、記録の側でも
見落とされていた。** 著者の裁定により、全巻を禁じ手へ戻す。

### 規則の正文

`構想/design.md:81`（および `persona.md` の「声・筆致」）が正文である。この器は新しい様式を
足していない。**削るだけ**である。

残すもの——従属節（〜と、／〜ば、／〜ので、／〜とき、）、連用中止（〜て、）、並列（〜と、／〜や、）、
挿入・要の一打（「止まるというより、動かない。」）、会話のためらい（「棚、空いてます。」）。

削るもの——助詞のあとの読点、連体形と被修飾語を割る読点、副詞と用言を割る読点、
数と助数詞を割る読点、後置詞の手前が漢語か「の」であるもの。

### 補助用言——一巻だけが残していたもの

`〜て、` のあとに**補助用言**が続く形は、連用中止ではなく**連語**である。ゆえに削る。

```
〜て、いる／いない／くる／いく／おく／しまう／みる／ある
開いて、いる。   → 開いている。      （連語——削る）
行って、腰を下ろす。                  （連用中止——残す）
```

**⚠ 第四巻だけが、これを 834 個 残していた。** 第一巻から第三巻は 1 個ずつしか持っていなかった。
巻によって判断が割れていたのである。正文（`design.md:81`「連語を原子に分解しない」）に照らして
**連語**と定め、全巻で統一的に削った（第一巻 1／第二巻 1／第三巻 1／第四巻 834）。
**見本の第一巻第一話も、自分の分を一つ持ち残していた**——「開いて、いない。」（人が上から重ねた
四行に、これが混ざっていた）。

### 器の分と、人の分

`読点の解放.py` がやるのは、**いちばん確からしい削除だけ**である。

```
python3 読点の解放.py <draft.md>            # 標準出力へ（書かない）
python3 読点の解放.py <draft.md> --write    # 同じ場所へ上書き
python3 読点の解放.py <草稿ディレクトリ> --write
```

そのあと、**人が残りを読んで上から重ねる**。器は、その手前までしか行かない。

### 三つの道具

| 道具 | すること |
|---|---|
| `読点の解放.py` | 読点を削る（器） |
| `検める.py <草稿ディレクトリ>` | **読点以外が動いていないか**を、git の HEAD と一行ずつ突き合わせる |
| `前後を較べる.py` | HEAD の草稿に同じ検査器を当て、⛔ が**この段で生じたのか、前から在ったのか**を数える |
| `貼り直し.py [--write]` | 記録に散らばる `NN-NN:NNN「…」` の**引用の本文だけ**を、凍った本文に合わせて貼り直す |

`検める.py` の不変条件は一行である——変わった行について

```
（新の読点を全部取ったもの）== （旧の読点を全部取ったもの）
```

が成り立ち、かつ**行数が変わっていない**こと。

> **⚠ 2026-09-26——この検め方が、一度、空で通った。**
> `head_version()` が `Path.cwd()` を根として相対パスを作っていたゆえ、研ぎの外から当てると
> **六十三本すべてを黙って飛ばしたうえで「✅ 読点だけが削られている」と出した**。
> 測っていないものは、通ったのではない。根を `git rev-parse --show-toplevel` から取り、
> **飛ばしたファイルが一本でもあれば ✅ を出さずに落ちる**よう直した。

### この段で増えた道具

| 道具 | すること |
|---|---|
| `差し替える.py <台帳> [--write]` | 台帳（`パス<TAB>行<TAB>いまの文<TAB>置き換える文`）の一行を、一行に置き換える。**行数を動かさない**——当てる前に「その行がいまその文であること」を、当てたあとに「行数が変わっていないこと」を確かめる |

ゆえに `一案を検める.py` が ✅ を出した案は、**まだ採れる案ではない**。根拠の行番号をつけて人が採る。
