## 1. 読点の解放——禁じ手に戻す

### 何が起きていたか

`構想/design.md:81` と `persona.md` は、そろって同じ禁じ手を置いている。

> 読点は並列を一息で流し、**要の一打（反転・定型句）だけ**に刻む。連語を原子に分解しない。

> 禁じ手——冗長な説明、嘘くさい感傷、**連語の読点切断**、アンカーの表層の模倣。

ところが、六十三話の本文は、この禁じ手を破って書かれていた。

```
私の机は、職員室の、いちばん、奥にある。      → 私の机は職員室のいちばん奥にある。
校庭に、人は、居ない。                        → 校庭に人は居ない。
扉が、四枚、ある。                            → 扉が四枚ある。
開いた、ままである。                          → 開いたままである。
```

`段0_判定材料.md:160` はこれを「地の文の律」と呼び、`系列_⑥反映_裁定材料.md:40` は
`preserve` の第三項に「読点による並列体と、一行ごとの空行」を挙げ、`系列_軸1_改稿案.md:117` は
「行の内側の作りは、この回では動かさない」と書いている。**破れていることが、記録の側でも
見落とされていた。** 著者の裁定により、全巻を禁じ手へ戻す。

### 規則の正文

`構想/design.md:81`（および `persona.md` の「声・筆致」）が正文である。この器は新しい様式を
足していない。**削るだけ**である。

残すもの——従属節（〜と、／〜ば、／〜ので、／〜とき、）、連用中止（〜て、）、並列（〜と、／〜や、）、
挿入・要の一打（「止まるというより、動かない。」）、会話のためらい（「棚、空いてます。」）。

削るもの——助詞のあとの読点、連体形と被修飾語を割る読点、副詞と用言を割る読点、
数と助数詞を割る読点、後置詞の手前が漢語か「の」であるもの。

### 補助用言——一巻だけが残していたもの

`〜て、` のあとに**補助用言**が続く形は、連用中止ではなく**連語**である。ゆえに削る。

```
〜て、いる／いない／くる／いく／おく／しまう／みる／ある
開いて、いる。   → 開いている。      （連語——削る）
行って、腰を下ろす。                  （連用中止——残す）
```

**⚠ 第四巻だけが、これを 834 個 残していた。** 第一巻から第三巻は 1 個ずつしか持っていなかった。
巻によって判断が割れていたのである。正文（`design.md:81`「連語を原子に分解しない」）に照らして
**連語**と定め、全巻で統一的に削った（第一巻 1／第二巻 1／第三巻 1／第四巻 834）。
**見本の第一巻第一話も、自分の分を一つ持ち残していた**——「開いて、いない。」（人が上から重ねた
四行に、これが混ざっていた）。

### 器の分と、人の分

`読点の解放.py` がやるのは、**いちばん確からしい削除だけ**である。

```
python3 読点の解放.py <draft.md>            # 標準出力へ（書かない）
python3 読点の解放.py <draft.md> --write    # 同じ場所へ上書き
python3 読点の解放.py <草稿ディレクトリ> --write
```

そのあと、**人が残りを読んで上から重ねる**。器は、その手前までしか行かない。

### 三つの道具

| 道具 | すること |
|---|---|
| `読点の解放.py` | 読点を削る（器） |
| `検める.py <草稿ディレクトリ>` | **読点以外が動いていないか**を、git の HEAD と一行ずつ突き合わせる |
| `前後を較べる.py` | HEAD の草稿に同じ検査器を当て、⛔ が**この段で生じたのか、前から在ったのか**を数える |
| `貼り直し.py [--write]` | 記録に散らばる `NN-NN:NNN「…」` の**引用の本文だけ**を、凍った本文に合わせて貼り直す |

`検める.py` の不変条件は一行である——変わった行について

```
（新の読点を全部取ったもの）== （旧の読点を全部取ったもの）
```

が成り立ち、かつ**行数が変わっていない**こと。

> **⚠ 2026-09-26——この検め方が、一度、空で通った。**
> `head_version()` が `Path.cwd()` を根として相対パスを作っていたゆえ、研ぎの外から当てると
> **六十三本すべてを黙って飛ばしたうえで「✅ 読点だけが削られている」と出した**。
> 測っていないものは、通ったのではない。根を `git rev-parse --show-toplevel` から取り、
> **飛ばしたファイルが一本でもあれば ✅ を出さずに落ちる**よう直した。

### 試し——第一巻第一話

| 読点 | 558 | 28 |

**行数は動かない。** 読点を削るだけだからである。したがって、記録に散らばる
`NN:NNN` の行番号は生きたままで、貼り直しが要るのは**引用の本文だけ**になる。

削ったあとに人が重ねたのは、この五行である。

### 貼り直し——引けない六件

記録の中の `NN-NN:NNN「…」` を、凍った本文に合わせて貼り直した（**310件**）。

**⚠ 引けなかった六件は、器が正しく拒んだものである。直してはならない。**

| 引用 | なぜ引けないか | 扱い |
|---|---|---|
| `series-bible.md` `01-01:135「窓枠に、埃が、たまっている。」` | **変更の記録である**——「窓枠に…」→「窓の、桟に…」という差し替えの前後を書いている。**旧い綴りが記録の中身である** | 触らない |
| `進捗表_履歴.md` `01-01:135`（同上） | 同上 | 触らない |
| `⑥反映と④再開_作業指示.md` `02-13:409「蓋は、閉まって、いる。中は、見えない。」` | **与えられた指示の記録である**。同じファイルの `:41` が「文面は直さない、当てるときは :409 を :411 と読み替える」と既に明記している | 触らない |
| `series-bible.md` `01-01:197「うちも、まだ、なんです。」` | **行番号が +2 ずれていた**（本文は 195行目。:197 は「私ははいと言います。」） | 貼り直した → `01-01:195「うちもまだなんです。」` |
| `進捗表_履歴.md` `01-13:931「その字、誰の字。」` | **行番号が +1 ずれていた**（本文は 932行目。:931 は空行） | 貼り直した → `01-13:932「その字誰の字。」` |
| `habits-02/構想/各話/08_寝ぐせ.md` `02-08:39「…」` | **省略記号つきの引用**ゆえ器が対応づけられない。行番号は正しい | 読点だけ貼り直した |

**規則——引用が「いまの本文を指す」なら貼り直す。引用が「昔の本文そのもの」なら残す。**
変更の記録と指示の記録は後者である。この六件は、次に同じ器を当てても**また六件出る**。
それは正しい——三件は残すべきものだからである。

### 検査器の側で、見えるようになったもの

読点を削ると、**読点の違いだけがあった二行が、同じ行になる**。`検査/check.py` の
「逐語の再利用」は、十二字以上の行が**二話にしか現れない**ときに、二行以上の連なりを ⛔ とする。

第二巻は 14 → 10件と減ったが、**減った七件は閾値の産物**である（読点が消えて行が十二字を割り、
索引から外れて連なりが切れた）。**増えた三件は、閾値の産物ではない。**

| 話 | 行 | 連なり |
|---|---|---|
| 02-02 ↔ 02-03 | `:65` | 「僕は少し離れて、立っている。」／「冷ケースの音がする。低い音である。低い音は遠くへ行かない。」 |
| 02-05 ↔ 02-10 | `:561` / `:313` | 「手の甲に筋がある。筋は動かない。」／「手のひらは下を向いている。」 |

**この二組は、読点が違っていたゆえに、いままで検査器から見えていなかった。** 四巻を数えると、
四つの文はどれも**二話にしか現れない**（三話以上に現れる語＝基底語ではない）。他巻には無い。
つまり**書き手が気づかないまま、同じ文を二度書いている**。読点の解放は、これを**直したのでは
なく、見えるようにした**。直すのは後の段（`/revise-for-reader`）である。

第一巻（2 → 2件）と第三巻（0 → 0件）は、**一件も動かなかった**。第四巻（3 → 3件）の
「`[上限]「枠」`」は、⛔ の本文が引用する行の綴りが変わっただけで、中身は同じである。
