## 1. 検品の観点——七つ

`SKILL-ja.md` の §7 を、この作品に合わせて読む。

| # | 観点 | この作品での見方 |
|:--:|---|---|
| 1 | **リズム** | 行の長さの配分（長文＝流す／短文＝切る）。**この作品は短文が本体である**——長くする案は、まず疑う |
| 2 | **読点の呼吸** | 解放済み。**見るだけ**（新しく打つ案は出さない） |
| 3 | **段落の切れ目** | 第二巻のみ。**動かさない** |
| 4 | **語彙の精度** | 「もの」「それ」「こと」「ところ」で済ませている箇所。名詞の具体性・動詞の力 |
| 5 | **感覚** | 視覚・聴覚・触覚・嗅覚・平衡。**ただし基底語は砕かない**（§2） |
| 6 | **比喩** | **この作品は比喩をほとんど持たない。足さない。** 既にあるものが陳腐でないかだけを見る |
| 7 | **表記** | ひらがな・漢字のゆれ（§3 の実測を見る） |

### ⚠ 基底語は、欠陥ではない

**三話以上に現れる形は、この作品の基底語である。** 検査器 `検査/check.py` が
十二字以上の行を**二話にしか現れない**ときにだけ ⛔ とするのは、同じ考え方である。

**たとえば「音がする。」を、砕かない。** この作品では定型である——

```
とってを引く。
音がする。
鉄の音である。
```

**一般から名へ降りる、二拍である。** 「音がする。」を「鉄の音がする。」に畳むと、この二拍が消える。
**同じく、「〜である。」の終わり方・「〜が、〜である。」の組み方・「まだ〜ない。」の型を、
崩さない。**

## 3. 返す形式——台帳

**タブ区切り、一行一件。前置きも後書きも書かない。**

```
巻<TAB>話<TAB>行番号<TAB>いまの文<TAB>案<TAB>観点<TAB>根拠
```

- **巻**——`01`〜`04`
- **話**——`01`〜`18`（その巻の話数まで）
- **行番号**——**そのファイルの行番号**（空行も数える。`1` から）
- **いまの文**——**一字一句そのまま**。前後の空白を入れない
- **案**——置き換える一行。**行数を動かさないゆえ、必ず一行**
- **観点**——§1 の番号（`1`〜`7`）
- **根拠**——**その案が、なぜこの話に真であるか**。**行番号と、その行の逐語**を書く。
  例——`145「欄は空いたままである。」と147「欄の中は白い。」が根拠。`

**⚠ 根拠の引けない案は、採らない。**

### 見つからなかった話は、行を書かない

**空の台帳は、失敗ではない**（§0）。**一話あたり 0〜3 行を目安にする。**
**数を埋めるために案を作らない。**

## 4. 厳守すること

1. **その話の本文に、既に真である事実だけを書く。** 新しい物・出来事を持ち込まない。
2. **その話の他の行と、逐語で重ならないこと。** 同じ語の組み合わせを、すぐ近くで二度使わない。
3. **禁則語を持ち込まない**（[`../README.md`](../README.md) の八つの語群）。**色語**
   （青・緑・黄・茶・灰・銀・紫・桃・橙）と**匂いの語**（匂・におい・臭・香・嗅）を、
   **新しく持ち込まない**（**第四巻は、この二つが既に閉じている**——`第四巻_七軸_裁定材料.md` §4・§5）。
4. **第四巻では、「〜は、答えない。」「その、ままである。」を使わない**（同 §12〜§14）。
5. **説明・解釈・総括を書かない。** 状態を書く。出来事を書かない。
6. **話の問いに、答えない。**
7. **確信の無い案は、出さない。**

## 6. 案ができたあと

1. **機械で検める**——`一案を検める.py` と同じ観点（逐語・他の話への出現・色語・匂い・
   「答えない」・同じ話の既存行との近さ）を、全件に当てる。
2. **落ちた案は、捨てる。**
3. **著者へ渡す**——台帳と、その要約（何行か・どんな種類か・実例）。
4. **承認ののち、`差し替える.py` で当てる。** **行数は動かない。**
