# 第九段——**目録区間の内側へ、体を一つ入れる**（指示書。2026-10-14）

**⚠ これは本文を触る段である。** 案を作る者は、**本文を一字も書かない**。**案（TSV）を書くだけである。**

---

## 0. なぜ、この段を打つか

**著者の判定は「面白さが極めて薄く、説明ばかりしている」である**（2026-10-14、本セッション）。
**娯楽の段は 300 行を超える手を当てたが、この訴えにいちばん近い計器は動かなかった**（[`README.md`](README.md) §3-27）。

**いまの実測**（器＝[`目録区間を数える.py`](目録区間を数える.py)。物差しは [`入口の流れを検める.py`](入口の流れを検める.py) と同一）——

| | 数 |
|---|---:|
| **目録行が 4 行以上続く区間**（全場面） | **283 区間・1,585 行** |
| うち **場面1**（入口） | **98 区間・556 行** |
| うち **場面2・3 で 8 行以上** | **24 区間・248 行** |
| **最長** | **23 行** |

**目録行とは**——**行の内側のすべての文の文末が**、`ある／いる／ない／無い／ている／てある／である／ままだ／ままである。` のいずれかである行。**物と状態を並べる行である。**

**⚠ 一行だけの目録は、様式である。** 器の docstring がそう書いている——
「**一つずつ数える行が一件なのは様式である。四行以上続くと、読む側には目録になる。**」
**ゆえにこの段は、目録行を消さない。** **続いている区間を、割るのである。**

## 1. この段の根拠——**設計が三つ挙げているのに、長い区間は一つしか持っていない**

**第四巻の規則**（[`../構想/design.md`](../構想/design.md) 決定5）——

> **地の文に置くのは、書かれた名と、それに触れた手と、物の位置だけである。形容は、物にだけ許す。**

**⇒ 三つである——`名`・`手`・`位置`。** **⚠ いまの長い目録区間は、`位置`だけを持つ。**

**全巻の規則**（`design.md`「感情の置き場——手と物の動作の側」）も、同じ側を指す。

**⚠ そして、この一手は既に一度、効いている。** [`README.md`](README.md) §3-27 が実測した `01-14` の一行——

| | |
|---|---|
| 前 | 退職の日である。午後である。 |
| 後 | **退職の日の午後、私は棚から出席簿を下ろす。名の書かれた位置に、もう一度立つ。** |

**静的な報告から、体のある動作へ。** **この形を、長い区間の内側へ一つずつ入れる。**

---

## 2. 一手——**一字で言えば、これだけである**

> **区間の内側の一行を、「物の報告」から「その物に、体が関わる」行へ変える。**

**守ること（八つ）**——

1. **物と状態の情報は、残す。** 「机がある。机の面が平らである。」から「机」と「平ら」を消さない。
2. **行は足さない・減らさない。** 一行を、一行に置き換えるだけである。**行番号は動かない。**
3. **新しい物・新しい人物を足さない。** その話の内側に既に在る物と、既に其処に居る者だけを使う。
4. **鉤括弧を足さない。** 会話を足さない。
5. **感情に名を与えない。** 「悲しい」「うれしい」等の語を、新しい字として入れない。
6. **その行の文数は、4 文を超えない。** 元の行が 3 文なら、足してよいのは 1 文までである。
7. **置き換えた行は、目録行でなくなること。** つまり、**少なくとも一つの文の文末が、上の九つの形の外にあること**（例「…指をかける。」「…手を離す。」）。
8. **区間の内側を、3 行以下の塊に割ること。** 4〜6 行の区間なら 1 行、7〜9 行なら 2 行、10〜12 行なら 3 行、13 行以上なら 4 行以上を差し替える。**⚠ 等間隔に置く。** 区間の**最初の行と最後の行は、なるべく避ける**（最初は場面の anchor、最後は次への繋ぎであることが多い）。

**⚠ 体とは、これである**——`手・指・指先・手首・掌・腕・肘・肩・背・首・顔・目・耳・口・唇・腹・胸・膝・足・踵・爪先・髪`。
**⚠ 動作とは、これである**——`触れる・なぞる・掴む・離す・引く・押す・開ける・閉じる・取る・置く・運ぶ・めくる・数える・立つ・座る・歩く・かける・拭く・当てる・入れる・出す・重ねる・並べる・止める・動かす`。

**⚠ 第四巻では、主語に人称を置けない**（`design.md:44`。2026-10-14 著者裁定 A5-1）。
**ゆえに第四巻では、体の部位そのものを主語にする**——**`指が…する。`／`手が…にある。`**（**既に本文がそうしている**——`04-13:35`「指が動く。糸のほうへ行く。」）。
**第一〜第三巻では、`私` を主語にしてよい。**

## 3. 対象——[`目録_対象区間.tsv`](目録_対象区間.tsv)

**列＝`話／場面／行／長さ／ファイル`。** `行` は**草稿ファイルの行番号**（空行も数える）で、`NNN-MMM` は**区間の最初の行と最後の行**である。
**⚠ 行番号は一つ飛びではない**（本文行の間に空行が在る）。

**この段の対象は、この台帳の全区間である**——**場面1の 98 区間**と、**場面2・3 の 8 行以上の 24 区間**。

**⚠ 触ってはならない行**——

- その話の `構想/各話/*.md`（場面表）の「**動かさないもの**」に挙げられた行。
- **一拍**・**記名の現場**・**扱う癖**の行（毎話に一つずつ。設計が守っている）。**見分け方＝その話の場面表に書いてある。**
- **第四巻の締めの連**（`04-18` の末尾の連）と、**巻の頂点の一文**。
- **鉤括弧の内側**。
- `＊` の行。

**⚠ 見分けが付かないときは、その行を避けて隣を選ぶ。** **避けたことは、`根拠` の欄に一行で書く。**

---

## 4. 出すもの——**七欄の TSV**

**ファイル名＝`娯楽_体_案_0N.tsv`**（`0N`＝自分の巻）。**置き場＝`examples/habits/研ぎ/`。**

**一行目に、必ずこの見出しを置く**（**`#` を付けない**。器が `巻` を値に持つ行を見出しとして読み飛ばす）——

```
巻	話	行番号	いまの文	案	観点	根拠
```

| 欄 | 書くこと |
|---|---|
| `巻` | `01`／`02`／`03`／`04` |
| `話` | `NN-NN` |
| `行番号` | **草稿ファイルの行番号**（数）。⚠ **その行の全文が `いまの文` と逐語で一致すること。** |
| `いまの文` | **いまの本文の、その行の全文。一字も変えない。** |
| `案` | **置き換えた後の、その行の全文。** 一行である。 |
| `観点` | **どの物に、誰の体が、どう関わるか**を一行で。例 `取っ手に、私の指がかかる` |
| `根拠` | **①その体が其処に居る理由**（その場面の誰か／`design.md` 決定5）、**②避けた行があるならその旨**、**③文数**（前→後）。 |

**⚠ 空の欄を一つも作らない。**
**⚠ 案は一行である。** 改行を含めない。

---

## 5. 出す前に、自分で確かめること

1. **`python3 台帳を検める.py 娯楽_体_案_0N.tsv --quiet`** を走らせる。**⛔ を 0 にする。**
   （⚠ この器は、行の在否・一行性・文数の非増加・逐語・巻をまたいだ反復・禁則語・第四巻の色語と匂い・閉じた形・話の中の近さを見る。）
   ⚠ **「逐語」と「近さ」の ⚠ は、註である**——**必ず中身を読んで、真偽を自分で決める。**
   ⚠ **文数の非増加は、この段では満たさない**（体の一文を足すゆえ）。**`--add-sentences` を付けて走らせ、増えた文数が +1 までであることを確かめる。**
2. **`python3 入口の流れを検める.py --at HEAD`** と **`python3 目録区間を数える.py`** を走らせ、**当てる前の数を控える**（担当の巻の分）。
3. **`wc -l 娯楽_体_案_0N.tsv`** を数える。**対象区間の数と、出した案の数**を、報告に書く。

---

## 6. 報告に書くこと

- **対象区間の数**（台帳の、自分の巻の行数）と、**出した案の数**。
- **差し替えなかった区間と、その理由**（例——区間の内側に体の居ない場面である／「動かさないもの」に当たった）。
- **迷った一件**を、一つ。
- **`台帳を検める.py` の ⛔ の数**（0 でなければ、その中身）。

**⚠ 「面白くなった」とは書かない。** **書けるのは「何を、どう変えたか」までである。**
