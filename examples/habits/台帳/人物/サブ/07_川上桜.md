## 呼ばれ方の履歴

**この作品では、これが造形そのものである。**

| | |
|---|---|
| 職場で | 園児が**「さくら先生」**、同僚が**「桜さん」**、給食室では**「桜」。** **この園で、いちばん多く発音される名である**（run-09） |
| 家族に | 夫が「さくら」、実母が「さっちゃん」（run-09） |
| 誰にも呼ばれない名 | **「川上」。** **この園で、姓を一度も呼ばれたことがない**（run-09） |

**世界でいちばん呼ばれる名と、一度も呼ばれない名が、同じ音である。**

**職場で発音される三つの形は、すべて下の名前である。** 「さくら先生」「桜さん」「桜」——**二十四名のうち、職場で下の名前だけが使われる者は、この一人だけである**（他の二十三名は、姓＋さん／先生か、姓そのものである）。**そして姓は、この園で一度も発音されない。**

**危険は、漢字一字とひらがな三字の差で管理する**（run-09 依頼者コメント）。**この規律は動かさない。**

## 動きの署名（run-10）

**配膳の前に、食札を見ずに三つの机の顔を順に目で確認し、最後に食札へ目を落とす。**

**その動作を目に入れている者——給食の時間の担任。**（run-10）

## テーマとの結びつき〔導出〕

核心の問い「**呼ばれた名は、誰のものか。**」——第一巻の問いは「書かれた名は、書いた者のものか、呼ぶ者のものか」である。

→ 記名＝アレルギー表（run-09）。**アレルギー表は、事故を防ぐために名を書く紙である。** 癖は「名ではなく顔で覚えている」——**書かれた名を、彼女は当てにしていない。** そして run-10 の会話の一行——**「桜という音が一度も出ない。」**

**第一巻の問いに対して、彼女は最も重い事例である。** 書かれた名（佐藤美咲）、呼ばれる前（片山大翔）、読んだ者（碓氷千夏）、来なかった者（石川久美子）——**そのどれでもなく、彼女は「いちばん呼ばれている名」である。** 呼ばれた名は誰のものか。**彼女の場合、その名は、この作品のなかで誰の口にも渡らない。**
