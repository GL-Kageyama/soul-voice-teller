## 呼ばれ方の履歴

**この作品では、これが造形そのものである。**

| | |
|---|---|
| 職場で | **「鈴木さん」。** 点呼では**「鈴木、一番」。** 運行表には姓だけ（run-09） |
| 家族に | 妻が「お父さん」、長男が「父さん」、二女が「パパ」（run-09） |
| 誰にも呼ばれない名 | **「和彦」。** **最後に呼んだのは、平成十四年に死んだ母親である**（run-09） |

**家族の欄に、名が一つも無い。** 「お父さん」「父さん」「パパ」——**三つとも、役割の語である。** **二十四名のうち、家族の欄に名が一つも出ない者は六名いる**（**彼**・[`03_高橋由美.md`](03_高橋由美.md)・[`06_大森徹.md`](06_大森徹.md)・[`14_三宅隆.md`](14_三宅隆.md)・[`19_斎藤悦子.md`](19_斎藤悦子.md)・[`23_石川久美子.md`](23_石川久美子.md)）。**六名とも、家族は役割で呼ぶ。**

**その六名のうち、職場の欄にも名が出ない者は、彼を含めて五名である**——大森徹の職場の欄には姓そのものが無い（**「誰も『大森』と呼ばない」**）。

**そして職場の欄も、名を出さない。** 「鈴木さん」は姓、「鈴木、一番」は姓と順番である。**「一番」は、名ではなく、順番である。** **二十四名のうち、職場で順番とともに呼ばれる者は二名いる**（**彼**の「鈴木、一番」と、[`10_根本湊.md`](10_根本湊.md) の「湊、二号卓」）。**根本湊のほうは、下の名前である。**

**その動作を目に入れている者——誰もいない。**（run-10）

**二十四名のうち、「その動作を目に入れている者」が「誰もいない」である者は四名いる**（**彼**・[`12_山田健太.md`](12_山田健太.md)・[`19_斎藤悦子.md`](19_斎藤悦子.md)・[`22_橋本悠斗.md`](22_橋本悠斗.md)）。**四名とも、一話で立ち、誰にも見られない。**

**彼は自分の運転する路線に乗らない。** それでも**手の高さは、停留所ごとに覚えている**——**覚えているのは、乗る側の高さではなく、迎える側の高さである。**
