## 凡例 —— 4つの状態を混ぜない

各欄は、必ず次のどれかである。**印を付けて区別する。**

| 印 | 意味 | 書き方 |
|---|---|---|
| （印なし） | **出典にある。** | 出典の語をそのまま引き、行末に `（run-09）` のような出典記号を付す |
| 〔導出〕 | **出典から導ける。** | 出典の該当箇所を `→` で示してから書く |
| `—（規律）` | **出典になく、書かないことが設計である。** | 一行で理由を書く |
| `?` | **出典になく、まだ決めていない。** | 空欄のまま許す（character-forge の既定） |

**この4つを混ぜると台帳が嘘になる。** とくに〔導出〕を出典と読み違えないこと。導出は推論であり、出典の語ではない。

### 出典記号には、段がある——上位と下位

**`handoff/` と `_process/` は、同じ出典ではない。** `elevate-draft-engine/examples/habits-ja/` の下で、**run-09・run-10 は `handoff/` にあり、run-01〜run-08 は `_process/` にある。**

| 段 | 記号 | 何が |
|---|---|---|
| **上位** | `（run-09）` `（run-10）` | **執筆に渡る側**（`handoff/`）。作品の設計語——`呼ばれ方の履歴`・`癖`・`動きの署名`・`記名`・`配属`・`主役回`——を持つ |
| **下位** | `（run-06 下位）` | **渡らない側**（`_process/`）。**決定 II（2026-09-18、著者）により、出典に含める** |

**記号の書き方。** **`・` は既に run と run を結ぶ**（`（run-09・run-10）`）。**修飾は空白で書く**——`（run-10 第6話）`・`（run-09 の roster 番号）` と同じ形である。**ゆえに `（run-06・下位）` とは書かない。**

**下位出典にできるのは、`_process/run-NN/artifacts/` と `_process/run-NN/knowledge.md` だけである。** `drafts/`（八名の草案）と `_stage8/` は**生成過程であり、出典ではない。**

**下位は、上位で引けるものを支えない。** 同じ語が両方にあるときは、**上位から引く**——`半歩下がる` は run-05 にも run-10 にもあり、**引くのは run-10 である。**

**下位の一行は、そのままでは渡らない。** **「`handoff/` にあるものだけが執筆に渡る」**（[`../../../elevate-draft-engine/examples/habits-ja/README.md`](../../../../../elevate-draft-engine/examples/habits-ja/README.md)）。**渡すと決めたときに、著者の一行が付く。**

**出典宣言。** 下位を引くファイルは、**冒頭の出典宣言に「その run が何を与えるか」を書く。** **記号は宣言の索引である**——**宣言に無い run を引いてはならない。** 上位だけを引くファイルは、いまのまま一行でよい——`（run-09＝呼ばれ方の履歴・癖・配属／run-10＝動きの署名）` が、そのまま索引になっている。

### `「」` は、引用と、台帳自身の呼び名の両方に使う

- **引用**——出典の語を一字も変えずに引く。**句点も含める。** 行末に `（run-09）`／`（run-10）` を付す。**「癖は「…」」「run-10 の一行——「…」」の形は引用である。**
- **呼び名**——台帳がその人物の位置を名づけた語（「名の代わりに数が届く」「書かれない名」「保管される名」など）。**引用ではない。**
- **〔導出〕の節で「掟は『…』と言う」と書くとき、その『…』は、その段階を台帳が名づけたものである。** 出典にある掟の語は**「名は呼ばれた回数でできている」**である（run-10）。

**引用を引用で挟むときは、内側の `「」` を `『』` に開く。** これは**表記の入れ子の規則であって、語を変えることではない。** 一字も変えないという規則は、**内側の `『』` を `「」` に戻して読んだときに効く。** 実例——出典は「園児が「さくら先生」、同僚が「桜さん」、給食室では「桜」。**この園で、いちばん多く発音される名である。**」（run-09）と書き、台帳は**「園児が『さくら先生』、同僚が『桜さん』、給食室では『桜』。**この園で、いちばん多く発音される名である。**」**と引く（[`サブ/07_川上桜.md`](サブ/07_川上桜.md)）。**出典自身も `『』` を使う箇所がある**——「彼女を『ゆみちゃん』と呼んだ」（run-09）。**その場合も、入れ子では `『』` のまま据え置く**（[`サブ/03_高橋由美.md`](サブ/03_高橋由美.md)）。

**迷ったら引用に寄せる。** 引用は一字でも違えば落とす。

### 出典が食い違ったときの2つの扱い

| | 条件 | 書き方 |
|---|---|---|
| **`⚠ 要確認`** | run-09 と run-10 が食い違い、**series-bible にも決定が無い** | 両方を併記し、**推測でどちらかに倒さない。** 著者が決める |
| **出典の相違（決定済み）** | run-09 と run-10 が食い違い、**series-bible が決定を書いている** | 決定を引き、**食い違う記述も消さずに残す。** `⚠` は付けない |

**決定がある食い違いに `⚠` を付けると、決まっていることが未決に見える。** 読み分けの規則（[`../series-bible.md`](../series-bible.md) 三、連載レコード 3）は決定の代表である——**話数・並び・字数配分・扱う癖・記名・主役回・問いは run-09。動きと会話は run-10。話名と巻題は正である**（2026-09-16、著者決定——出典の**仮題**は run-09／run-10 の記録）。

`⚠ 要確認` の一覧は [`../series-bible.md`](../series-bible.md) の改稿履歴にある。

#### 字数の食い違いは、系統的である（実測）

**run-10 は各話の字数を組み替えるが、巻の合計は動かさない。** 四巻すべてで一致する（59,900／64,100／71,700／88,600）。

**そして run-10 自身が「各話の話題・目安字数・扱う癖・記名。一字も動かさない。」と書いている**（run-10 の「動かさないものの目録」）——**そのうえで、自分の章立て表を「run-09 の確定値を転記したものであり、本稿の作業対象ではない」と述べている。** **しかし、その表の各話の数字は run-09 と一致しない。** 第一巻十四話のうち十一話で違い、三話（第4・6・11話）で一致する。

**扱い**——決定は run-09（読み分けの規則）。**`⚠` は付けない。** 合計が一致しているので、**巻の長さについては食い違いが無い。**

**各話の字数は、四巻六十三話の全話で突き合わせない限り「どちらが正か」を判断しない。** この台帳は、各ファイルの記名欄に **run-09 の字数** を引き、run-10 の数字が違う場合だけ併記する。

## `?` の埋め方（後で埋めるための置き場）

`?` は「まだ決めていない」。**空欄のまま置くことが許されている欄であると同時に、埋めるための欄である。**

### 4つの規則

1. **埋めるときは、`?` を消して印を変える**——**〔導出〕** か **（印なし）** のどちらかへ。欄ごと書き換えるので、**あとから何を足したかが分かる。**
2. **根拠を必ず添える。**（印なし）なら出典記号（`（run-09）`）、〔導出〕なら `→` で出典の行。**根拠の無い記入は、この台帳では記入ではない。**
3. **各 `?` には「埋めるなら——」の一行が付いている。** その一行が、**何を探せばよいか**を示す。出典を読み返さずに、その一行だけを見て埋められるようにしてある。
4. **`?` は、埋めなくてよい。`—（規律）` へ移せる。** 出典と著者の決定が**「書かない」を支える**とき、**`?` は `—（規律）` へ移る。** **これは記入ではない**——欄は空のままだからである。**「まだ決めていない」から「決めた」への移動である。** **移したときは、理由を一行で書く**——それが `—（規律）` の書き方そのものである。

### 一覧の引き方

**一覧は表にしない。** 欄が増えるたびに表を直すことになり、表のほうが古くなる。**その場で数える。**

```
grep -rn '——`?`' 台帳/人物/メイン/ 台帳/人物/サブ/
```

これが**そのまま作業一覧**になる。`?` を埋めた行は出なくなるので、**一覧は自動で更新される。**

**`——` を付けるのは、欄の行だけを拾うためである**（2026-09-18、実測）。**欄の行は `——` の直後に `?` が来る。** **メイン四人の末尾にある「埋め方は README に従う」の一行は、この形を取らない**——**それは欄ではない。** **README を引かないのは、この節自身が検索語を含むためである。**

**ゆえに、欄を書くときは `——` の直後に `?` を置く。** **これがこの引き方の前提である**——**この形を取らない `?` は、一覧から漏れる。** **漏れても気づけるように、欄でない `?` を本文に置かない。**

### 埋めやすい順番——欄ごとに、まとめて

**サブ二十四名は、`?` になる欄が共通している。** 動機／信念・価値観／声／賭け。**欄が共通なら、判断も一つになる**——一人ずつ24回決めるのではなく、**同じ欄を24人分まとめて一度に決めるほうが速く、ぶれない。**

**中核四人は逆である。** `?` は人によって違う（碓氷千夏の信念、さくらの賭け）。**一人ずつ決める。** **——四人分を、一人ずつ決め終えた**（2026-09-18。下の「決着済み——中核四人の三欄」）。

### `?` がゼロになって、できるようになったこと（2026-09-18）

**ゼロは、この台帳の `?` のことである。** **作品の側には、まだ在る**——`habits*/構想/` を引くと **104行**が返る（実測。うち四巻の `話割り.md` が 89行、索引 [`../../構想/残件.md`](../../構想/残件.md) が 10行）。**このメモが言うゼロは、人物の欄のゼロである。**

**一、欄が、三つの状態のどれかになった。** 凡例の四つのうち、`?` が空になった。**ゆえに、どの欄も「出典にある」「出典から導ける」「書かないと決めた」のいずれかである。** **読んだ欄には、必ず根拠がある**——規則2（**根拠の無い記入は、この台帳では記入ではない**）が、**いま全ての欄で満たされている。** **「これは空いているのか、決めてあるのか」を、読む者が問い直さなくてよい。**

**二、`—（規律）` が、欄ごとに立った。** サブ二十四名の四欄、**九十六欄**が `—（規律）` へ移った。**「書かない」が、作品全体の決定から、欄の一行へ降りた。** 決定 I・II の段では「**この作品は、癖の理由を書かない**」という一段だけだった。**いまは、どの人物のどの欄で書かないかが、欄そのものに書いてある。** **本文を書く者が、空欄を善意で埋める事故は、ここで止まる。**

**三、一覧の引き方が、作業一覧から検算になった。** **コマンドは変わらない。返るものが変わった**——以前は「**まだ決めていない欄**」の一覧であり、**いまは `?` が戻っていないかの検査である。** **⚠ 検査が効くのは、書き方の前提のうえである**——欄は `——` の直後に `?` を置く（上の「一覧の引き方」）。**この形を取らない `?` は、0行の中に隠れる。** **このゼロは、その前提のもとでのゼロである。**

**四、〔導出〕が、出典の語と混ざらなくなった。** 凡例は既に「**導出は推論であり、出典の語ではない**」と言っている（上の「4つの状態を混ぜない」）。**決定 V・VI は、その一行に作法を足した**——**決定 V が性格づけの一文を、決定 VI が呼び方の字面を、欄に置いた。** **後者は、出典の語と見分けがつかない形をしている**——「碓氷さん」は、出典が二十四名について書いているのと同じ形である。**ゆえに——字面を台帳が置いたときは、そう書く。** 各ファイルの「出典に無い欄と、その理由」が、**いまその一行を持つ。** **これが無ければ、〔導出〕は引用として読まれる。**

**五、`?` の行き先が、四つとも実例を持つ。** **`—（規律）`**（九十六欄）／**（印なし）**（出典にある欄）／**〔導出〕**（決定 III は下位から、決定 V・VI は上位から）／**欄そのものを消す**（決定 IV）。**次に `?` が立ったとき、行き先を探す必要はない。** **そして、この一件で台帳自身の一行が直った**——「`?` の行き先」は「二つ」と書いていた（下の「`?` が下位から埋まるとき」）。**〔導出〕は、下位の専用ではない。**

**六、残るのは、埋めることではない。** 三つある。

- **①未裁定の二点**——蒼の `家族に` を〔導出〕と読むか `—（規律）` と読むか。すみれの「家族」の一行を、どう扱うか。
- **②`?` を生まない書き方**——人物を足すとき、欄を足すときの規則。**いまは無い。** **ゼロは、次に欄を足せば終わる。**
- **③作品の側の 104行**——四巻の `構想/話割り.md`。**この台帳の外である。**

**六つは、順に書いた。強い順ではない。** **そして——この六つは、「ゼロ」が生んだのではない。「決めた」ことが生んだ。** **ゼロが足したのは、一つだけである**——**決め残しが無いことを、一行で検査できるようになった。**

### `?` が下位から埋まるとき——さくら（2026-09-18）

**`?` の行き先は、二つではない。四つある。**

| 行き先 | 何が支えるか | 欄は |
|---|---|---|
| `—（規律）` | 出典と著者の決定が、**書かないこと**を支える | **空のまま**——記入ではない（上の規則4） |
| **（印なし）** | **出典にある**一行 | **埋まる** |
| **〔導出〕** | **出典から導ける**一行——**上位でも、下位でも** | **埋まる。** **下位から引くときだけ、著者の一行が付く** |
| **欄そのものを消す** | 欄が、**問いの重複**である（決定 IV） | **欄が、無くなる** |

**〔導出〕は、下位の専用ではない。** 凡例のとおり「**出典から導ける**」であり、**上位からも導ける**——**決定 V（中核の `信念・価値観`）と決定 VI（`職場で／家族に何と呼ばれるか`）が、上位から導いた〔導出〕である。** **著者の一行が要るのは、下位から引くときだけである**——`handoff/` にあるものは、**それだけで執筆に渡る**からである。

**下位から引いた欄は、いまのところ一つだけである**（実測——`grep -rn '〔導出〕' メイン/ サブ/ | grep '下位'` は二行を返すが、**うち一行はさくらの「出典に無い欄と、その理由」の記録であり、欄ではない**）。**中核四人のうち、さくらの `賭け`**——**「無い」を記入として採る**（2026-09-18、著者）。**下位が、理由ではなく答えを差し出した最初の欄である**（[`メイン/04_さくら.md`](メイン/04_さくら.md)）。

**この一件で、`—（規律）` と〔導出〕の違いが、いちばん鋭く出た。** **サブ二十四名の `賭け` も「失い得るものを持たない」である**——**それでも欄は空のままだ。** 支えているのが**層の設計**（一話で立ち、弧を持たない）だからである。**さくらは、支えているのが下位の一行だから、埋まる。** **同じ答えが、支えの在りかによって、記入になり、ならなくなる。**

### `?` と `⚠ 要確認` は別の置き場

|---|---|---|---|

## 書かないことの決定

**出典に無いことは書かない、のではなく——書かないことが設計である場合を、設計として書く。**

**⚠ この節は、逆の事故も止める——書けるのに、書かないと思われているものを、書けると書く。** **中核四人の内面が、それである**（決定 C-18——[`../../構想/内面の規律_破棄と置き換え.md`](../../構想/内面の規律_破棄と置き換え.md)）。

- **中核四人の内面は、書かないことに含まれない。** **内面は、地の文に現れてよい**（人称を立てている一・二・三の三巻）。**禁じられていないものは、この節に書く**——書かないと、本文を書く者が、空欄を善意で埋めるか、逆に内面を避けて動作だけを並べる。**C-18 は後者を破棄した。** **感情に名を与えないことだけが、規律である**——「悲しい」「さびしい」を置かず、**感情はその現れの場所（何をしたか、どこで止まったか、何を数えたか）の側に置く。** **識別を「癖」と「欲望の勾配」が担うという決定は、生きている**——**各メインの「内面葛藤（1つ）」欄は、地の文へ降りてよい。** **第四巻のさくらだけは、適用外である**（[`メイン/04_さくら.md`](メイン/04_さくら.md)）。
- **家族をファイルにしない。** 母・父・夫・妻・長女・長男・義母は、各人物の `呼ばれ方の履歴` の一行としてだけ現れる。**家族自身の呼ばれ方の履歴は書かない。** この作品で名を持つのは、名を呼ばれる者と、呼ばれない者の二種類だけである。
- **二十四名の名の字面を捻らない。** 出典のまま据え置く。珍しさはこの作品では有限の資源であり、中核三人の珍姓がすでに担っている。**捻る余地があるのは読みであり、片山大翔がその型である。**
- **二十四名に変化弧を与えない。** 各巻六名はそれぞれ一話で主役として立つ。**一話で立ち、弧を持たないことがこの層の設計である。** 第四巻の六名が第10〜15話にもう一度立つのは、弧ではなく**反復**である——二度目はいちばん小さい動作になる。
- **敵役を置かない。** 中核四人が立ち向かう相手は「名は呼ばれた回数でできている」という掟そのものであり、**掟は仕掛けてこない。人物が問いを立て、掟が応答しない。** その応答のなさを段階として書く（各メインの「ロール」）。
- **「誰のものか」を回収しない。** 各巻はその巻の紙の上で一度だけ回収し、名の持ち主を置かない。伏線は [`../series-bible.md`](../series-bible.md)「二、伏線レコード」。

## 禁則語

[`../../README.md`](../../README.md) の語群は、**この台帳でも書かない。** 語群の一覧はそちらにある。`series-bible.md` はその語群のヒットが0件であり、**この記録を下げない。**

**出典の語は言い換えない**——「呼ばれ方の履歴」「動きの署名」「記名」「癖」「配属」「主役回」は、出典の語のまま使う。
