## 凡例 —— 4つの状態を混ぜない

各欄は、必ず次のどれかである。**印を付けて区別する。**

| 印 | 意味 | 書き方 |
|---|---|---|
| （印なし） | **出典にある。** | 出典の語をそのまま引き、行末に `（run-09）` のような出典記号を付す |
| 〔導出〕 | **出典から導ける。** | 出典の該当箇所を `→` で示してから書く |
| `—（規律）` | **出典になく、書かないことが設計である。** | 一行で理由を書く |
| `?` | **出典になく、まだ決めていない。** | 空欄のまま許す（character-forge の既定） |

**この4つを混ぜると台帳が嘘になる。** とくに〔導出〕を出典と読み違えないこと。導出は推論であり、出典の語ではない。

### `「」` は、引用と、台帳自身の呼び名の両方に使う

- **引用**——出典の語を一字も変えずに引く。**句点も含める。** 行末に `（run-09）`／`（run-10）` を付す。**「癖は「…」」「run-10 の一行——「…」」の形は引用である。**
- **呼び名**——台帳がその人物の位置を名づけた語（「名の代わりに数が届く」「書かれない名」「保管される名」など）。**引用ではない。**
- **〔導出〕の節で「掟は『…』と言う」と書くとき、その『…』は、その段階を台帳が名づけたものである。** 出典にある掟の語は**「名は呼ばれた回数でできている」**である（run-10）。

**引用を引用で挟むときは、内側の `「」` を `『』` に開く。** これは**表記の入れ子の規則であって、語を変えることではない。** 一字も変えないという規則は、**内側の `『』` を `「」` に戻して読んだときに効く。** 実例——出典は「園児が「さくら先生」、同僚が「桜さん」、給食室では「桜」。**この園で、いちばん多く発音される名である。**」（run-09）と書き、台帳は**「園児が『さくら先生』、同僚が『桜さん』、給食室では『桜』。**この園で、いちばん多く発音される名である。**」**と引く（[`サブ/07_川上桜.md`](サブ/07_川上桜.md)）。**出典自身も `『』` を使う箇所がある**——「彼女を『ゆみちゃん』と呼んだ」（run-09）。**その場合も、入れ子では `『』` のまま据え置く**（[`サブ/03_高橋由美.md`](サブ/03_高橋由美.md)）。

**迷ったら引用に寄せる。** 引用は一字でも違えば落とす。

### 出典が食い違ったときの2つの扱い

| | 条件 | 書き方 |
|---|---|---|
| **`⚠ 要確認`** | run-09 と run-10 が食い違い、**series-bible にも決定が無い** | 両方を併記し、**推測でどちらかに倒さない。** 著者が決める |
| **出典の相違（決定済み）** | run-09 と run-10 が食い違い、**series-bible が決定を書いている** | 決定を引き、**食い違う記述も消さずに残す。** `⚠` は付けない |

**決定がある食い違いに `⚠` を付けると、決まっていることが未決に見える。** 読み分けの規則（[`../series-bible.md`](../series-bible.md) 三、連載レコード 3）は決定の代表である——**話数・並び・仮題・字数配分・扱う癖・記名・主役回は run-09。動きと会話は run-10。**

`⚠ 要確認` の一覧は [`../series-bible.md`](../series-bible.md) の改稿履歴にある。

#### 字数の食い違いは、系統的である（実測）

**run-10 は各話の字数を組み替えるが、巻の合計は動かさない。** 四巻すべてで一致する（59,900／64,100／71,700／88,600）。

**そして run-10 自身が「各話の話題・目安字数・扱う癖・記名。一字も動かさない。」と書いている**（run-10 の「動かさないものの目録」）——**そのうえで、自分の章立て表を「run-09 の確定値を転記したものであり、本稿の作業対象ではない」と述べている。** **しかし、その表の各話の数字は run-09 と一致しない。** 第一巻十四話のうち十一話で違い、三話（第4・6・11話）で一致する。

**扱い**——決定は run-09（読み分けの規則）。**`⚠` は付けない。** 合計が一致しているので、**巻の長さについては食い違いが無い。**

**各話の字数は、四巻六十三話の全話で突き合わせない限り「どちらが正か」を判断しない。** この台帳は、各ファイルの記名欄に **run-09 の字数** を引き、run-10 の数字が違う場合だけ併記する。

## `?` の埋め方（後で埋めるための置き場）

`?` は「まだ決めていない」。**空欄のまま置くことが許されている欄であると同時に、埋めるための欄である。**

### 3つの規則

1. **埋めるときは、`?` を消して印を変える**——**〔導出〕** か **（印なし）** のどちらかへ。欄ごと書き換えるので、**あとから何を足したかが分かる。**
2. **根拠を必ず添える。**（印なし）なら出典記号（`（run-09）`）、〔導出〕なら `→` で出典の行。**根拠の無い記入は、この台帳では記入ではない。**
3. **各 `?` には「埋めるなら——」の一行が付いている。** その一行が、**何を探せばよいか**を示す。出典を読み返さずに、その一行だけを見て埋められるようにしてある。

### 一覧の引き方

**一覧は表にしない。** 欄が増えるたびに表を直すことになり、表のほうが古くなる。**その場で数える。**

```
grep -rn '`?`' 台帳/人物/
```

これが**そのまま作業一覧**になる。`?` を埋めた行は出なくなるので、**一覧は自動で更新される。**

### 埋めやすい順番——欄ごとに、まとめて

**サブ二十四名は、`?` になる欄が共通している。** 動機／信念・価値観／声／賭け。**欄が共通なら、判断も一つになる**——一人ずつ24回決めるのではなく、**同じ欄を24人分まとめて一度に決めるほうが速く、ぶれない。**

**中核四人は逆である。** `?` は人によって違う（碓氷千夏の信念、さくらの賭け）。**一人ずつ決める。**

### `?` と `⚠ 要確認` は別の置き場

| | 何か | 誰が決めるか | 置き場 |
|---|---|---|---|
| `?` | **まだ決めていない**（決めれば済む） | この台帳 | 各ファイル |
| `⚠ 要確認` | **出典どうしが食い違っている**（外の判断が要る） | 著者 | [`../series-bible.md`](../series-bible.md) の改稿履歴 |

## 書かないことの決定

**出典に無いことは書かない、のではなく——書かないことが設計である場合を、設計として書く。**

- **家族をファイルにしない。** 母・父・夫・妻・長女・長男・義母は、各人物の `呼ばれ方の履歴` の一行としてだけ現れる。**家族自身の呼ばれ方の履歴は書かない。** この作品で名を持つのは、名を呼ばれる者と、呼ばれない者の二種類だけである。
- **二十四名の名の字面を捻らない。** 出典のまま据え置く。珍しさはこの作品では有限の資源であり、中核三人の珍姓がすでに担っている。**捻る余地があるのは読みであり、片山大翔がその型である。**
- **二十四名に変化弧を与えない。** 各巻六名はそれぞれ一話で主役として立つ。**一話で立ち、弧を持たないことがこの層の設計である。** 第四巻の六名が第10〜15話にもう一度立つのは、弧ではなく**反復**である——二度目はいちばん小さい動作になる。
- **敵役を置かない。** 中核四人が立ち向かう相手は「名は呼ばれた回数でできている」という掟そのものであり、**掟は仕掛けてこない。人物が問いを立て、掟が応答しない。** その応答のなさを段階として書く（各メインの「ロール」）。
- **「誰のものか」を回収しない。** 各巻はその巻の紙の上で一度だけ回収し、名の持ち主を置かない。伏線は [`../series-bible.md`](../series-bible.md)「二、伏線レコード」。

## 禁則語

[`../../README.md`](../../README.md) の語群は、**この台帳でも書かない。** 語群の一覧はそちらにある。`series-bible.md` はその語群のヒットが0件であり、**この記録を下げない。**

**出典の語は言い換えない**——「呼ばれ方の履歴」「動きの署名」「記名」「癖」「配属」「主役回」は、出典の語のまま使う。

### 実測した例外は、二つだけである（申告）

**この台帳の全文を語群で grep した結果、意図した例外が二つある。** どちらも**黙って通さず、ここに書く。**
