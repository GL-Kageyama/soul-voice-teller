## C-9｜「私たち」という複数が誰を指すか

**求められたこと**（narrative-originality・巻三）

> 「「私たち」という人称が宣言されているだけで、その複数が誰を指すのかが文書のどこにも定義されておらず、この巻で唯一の人称レベルの逸脱が構築されないまま主張されている」

**既にあるもの**

- [`../構想/design.md`](../構想/design.md)「語り」——視点は一人称、**第三巻の立てる人称は「私たち」**
- [`../台帳/人物/メイン/03_侘田すみれ.md`](../台帳/人物/メイン/03_侘田すみれ.md):28,63——**立てる人称＝私たち／欠けている人称＝単数**
- 同——**欲求＝名を、持ち主のいるときに書きたい**（出典）
- 同:66——**変化弧＝「『私たち』が立ち、単数が欠けたまま閉じる」**（出典）
- **四人称の並び**——**私**（一）→ **揺れる私**（二）→ **私たち**（三）→ **なし**（四）

**選択肢**

| | 誰を指すか | 根拠 |
|---|---|---|
| **a** | **書き手と持ち主**——名を書く手と、名を書かれる者 | **欲求「名を、持ち主のいるときに書きたい」** |
| b | 職域の複数——三十八件を分ける同職者 | 語の自然な読み |
| c | 訊き返される者たちの総称 | 第三巻の値 |
| d | 侘田すみれとさくら（第三巻第16話の二人） | 会話が成立しないので「私たち」になれない |
| e | 読者を含む（頁の側と、読む側） | 第四巻の「頁」と対 |

**推奨＝a。** これが最も強く立つのは、**彼女の欠けている人称が「単数」であることを説明するからである。**

**書くことは、一人でする行為である。** しかし彼女の人称に、**一人がない**（台帳 03:63）。**ゆえに彼女は「持ち主のいるとき」だけ書ける**——**その瞬間だけ、書き手と持ち主の対が立ち、それが「私たち」である。** 書き終われば対は解け、**単数は欠けたまま残る。**

**そして d を、自然に除く。** 第三巻第16話で、相手は**さくら**である。**さくらは「名の書かれる場所すべて」であり、持ち主ではない**（台帳 04）。**ゆえに「私たち」が立たない。****会話が成立しないのは、対が組めないからである。****この一点が、第三巻の閉じ方を説明する。**

## C-13｜第四巻の問い一声が落ちる場面

**求められたこと**（world-building・巻四）

> 「問い一声の落ちる位置が、前半の六話では停止の場面に、後半では読む場面に散っており、**これが規律としても未決の印としても立てられていない**」

**⚠ 指摘は「散っていること」ではなく、「どちらでもないこと」である。**

**測った——十八話。**

| 場面 | 話 | 数 |
|---|---|---|
| **第3場面** | 01・02・03・04・05・06・12・13・15 | **9** |
| **第2場面** | 07・08・09・10・14・16・17 | **7** |
| **第1場面** | 11 | **1** |
| なし | 18（会話を持たない） | **1** |

**そして、この散り方には既に形がある。**

- **前半六話（01〜06）は、六話とも第3場面である。**
- **後半の非◆五話（07・08・09・16・17）は、五話とも第2場面である。**
- **散っているのは ◆ の六話だけである**——10＝第2・11＝第1・12＝第3・13＝第3・14＝第2・15＝第3。

**◆ は「run-10 の動きを言い直した六話」である**（[`../../habits-04/構想/design.md`](../../habits-04/構想/design.md) 決定2）。**散っているのは、その六話の中だけだった。** **`?` は、見た目より狭い。**

**選択肢**

| | |
|---|---|
| **a** | **第3場面に固定する。** 問いと停止が重なる。**八話を動かす** |
| **b** | **既に成り立っている二つの規則を書く**（前半＝第3場面・後半＝第2場面）＋**◆ の六話だけを `?` として残す** |
| c | 話ごとに任せる、を決定として明示する |
| d | `?` のまま残す |

**推奨＝b。** 評価者が求めたのは**「規則か未決の印か、どちらかにせよ」**であり、**b は八話を動かさずにそれを満たす。** そして `?` が**六話へ絞られる**ので、次に読む人が迷わない。

**⚠ a には代償がある。** 第17話は**「六十三話で、ここだけ順序が入れ替わる」**話である（[`../../habits-04/構想/各話/17_口は、訊く形に動いて、音にならなかった。.md`](../../habits-04/構想/各話/17_口は、訊く形に動いて、音にならなかった。.md) の〔設計〕）。**問い（第2場面）と停止（第3場面）が今は離れている。****固定すると同じ場面で重なり、頂点の話の逸脱が消える可能性がある。**

## C-16｜第十六話（巻三）を最も厚くする理由、第十八話（巻四）を最長にする理由

**求められたこと**（narrative-originality・巻二、他）

> 「この後日譚が山場より長いことを**形式の主張として明示**し、なぜ最も長いのかを設計の側で**一度だけ決めておく**ことを勧める」

**⚠ 理由は、既に二つとも書いてある。**

| 場所 | 一行 |
|---|---|
| [`../../habits-03/構想/design.md`](../../habits-03/構想/design.md) 決定2 | 「**第16話がこの巻の最厚（5,700字）。** 返却のあとの一枚…**返却そのものより、返却のあとが厚い巻は、これが最初である**」 |
| [`../../habits-04/構想/design.md`](../../habits-04/構想/design.md) 決定7 | 「**第18話 6,100字は全63話の最長。** 返却のあとの一章が最も厚い」 |

**足りないのは「形式の主張として、一度だけ」の部分である。** 今は二巻に分かれて書いてあり、**系列の主張になっていない。**

**測った——最終話の字数**

| 巻 | 最終話 | 字数 | その巻の最長 |
|---|---|---|---|
| 一 | 第14話 | 4,200 | **第7話 4,600**（≠最終話） |
| 二 | 第15話 | 5,200 | 第15話 ✓ |
| 三 | 第16話 | 5,700 | 第16話 ✓ |
| 四 | 第18話 | 6,100 | 第18話 ✓ |

**4,200 → 5,200 → 5,700 → 6,100。****四巻とも、単調に増えている。**

**⚠ ただし、第一巻だけ、最終話がその巻の最長ではない。**（第7話 4,600 ＞ 第14話 4,200）。**「四巻とも返却のあとが最も厚い」と書くと、実測に反する。**

**選択肢**

| | |
|---|---|
| **a** | **系列に一節を置く。**「返却のあとの章は、巻を追うごとに厚くなる」を形式の主張とし、**実測四行を添える**。**第一巻は、その最初の一段である**（まだ山が返却のあとに無い） |
| b | 各巻の決定2・決定7で足りている、として `?` を閉じる |
| c | `?` のまま残す |

**推奨＝a。** **単調増加は四巻すべてで成り立ち、例外がない。** 「四巻とも最長」という壊れる主張を避けつつ、**形式の主張としてはむしろ強くなる。****「返却のあとの章は、巻ごとに厚くなる」は、四巻が一つの勾配であることの、いちばん数のはっきりした証拠である。**

## C-5 の四｜加害の起きる話

**`?` の中身**（[`../構想/design.md`](../構想/design.md)「立ち向かう対象と、損」）

> `?` —— **加害の起きる話を、一話置く。** **埋めるなら——**どの巻の、どの話で、誰が、損なわれるか。

**⚠ 最初に、測って分かった制約を一つ。**

**話数は動かせない。** **14／15／16／18 は出典の骨であり、既に六十三話すべてに場面表まで置いてある。** ゆえに「一話置く」は、**新しい話を足すことではなく、既存の話の一つを加害の話として定めること**を意味する。

**既にあるもの**

- **敵は人物ではない**（掟そのもの）／**悪意は置かない**——決定済み（`../構想/design.md` 同節の一・二）
- **損は七件、既にある**（一10・一14・二3・二13・三9・三16・四18）——**ただし全部「物が失われる」型であり、加害者は一人もいない**
- 台帳の敵の四段階——**制止／拒否／威圧／最終対峙**

**選択肢**

| | どの巻 | 形 | 根拠 |
|---|---|---|---|
| **a** | **一** | **正しさが加害になる**——正しく名を書いた・正しく呼んだ結果、その人が損なわれる | 巻一の値は「**正しく呼ばれる**」。**正しさが善でないことを出す場所。** 損も二件既にある（第10話・第14話） |
| b | 二 | **善意の書き換え**——誰かが親切で名を書き直し、元の名が消える | 巻二の値は「呼び間違えられる」。**悪意なしで起きる** |
| c | 三 | **訊き返すことが加害になる**——訊き返される一瞬、その人が名の分からない者になる | 第三巻第9話「**減った一件**」が既に近い |
| d | 四 | **呼ばないことが加害**——不作為 | 巻四の値「呼ばれない」。**ただしさくらは損なわれ得ない**——何も受け取っていないので、失い得るものを持たない（台帳 04:67） |

**推奨＝a（第一巻）。** 理由は三つ。

1. **この作品の核心をいちばん鋭く出す**——掟は善ではない。**正しく書くことが、誰かを損なう。**
2. **「悪意は置かない」を破らない**——**加害者は、正しくやった者である。**
3. **損が既に二件あり、片方（第14話）は碓氷千夏自身が損なわれる話である。** **加害と被害を、同じ巻に並べられる。**

**⚠ ただし、これは話を作ることになる。** [`../構想/design.md`](../構想/design.md) に「**ここには、私が話を作らない**」と書いた。**a を採るなら、どの話かまでは決めず、「第一巻に置く」までで止める**のが、その一行を守る形である。**話の同定は、著者の側である。**

## 決定（2026-09-19、著者）

**著者は、六件とも推奨のとおりに決めた。** **C-6・C-9・C-12・C-13・C-16 は決定となり、C-5 の四は `?` のまま第一巻へ絞られる。** 逐語は [`所見.md`](所見.md) §3、当てた先は同 §3 の「適用の記録」、一行ずつは [`../台帳/series-bible.md`](../台帳/series-bible.md)「5. 改稿履歴」にある。

**これで C は十七件とも決まり、保留はゼロになった。** **残るのは C-5 の四の `?` 一件だけである**——**それは保留ではなく、置かれた `?` である。**

**⚠ 適用のとき、C-12 の一文を、細くした。** 選択肢 a の文は「**会計年度任用職員である。ゆえに年度の終わりに辞める者である**」であった。**当てた文は「ゆえに彼女の職は、毎年、年度の終わりで切れる——辞めるのではなく、切れる」である。****「辞める」は、彼女の側の行為に読める。****台帳はそう書いていない**——「**毎年二月に、更新の可否を書いた紙が一枚、封筒で配られる**」（[`../台帳/人物/メイン/01_碓氷千夏.md`](../台帳/人物/メイン/01_碓氷千夏.md):66）。**切れるのは職であって、彼女が辞めるのではない。****この一語が、第5話「開けない封筒」と噛み合う。**（選択肢の文そのものは、上に残したままである。）
