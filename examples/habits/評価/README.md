## 評議会に渡す文脈（`context`）——決定リストは渡さない

五単位に共通して、事実だけを一行渡す。

> これは小説の執筆前の設計文書である。散文はまだ一行も無い。`?` は著者が意図的に未決定として残した印であり、欠落ではない。

**決定リスト・禁則・触れない三つの規則は渡さない。** 渡せば評議会は「適合検査器」になり、それは既に書き手側が機械的にやっている（場面表の不変条件の検算）。外部の目に価値があるのは**何も知らない読み**のほうであり、**決定に由来する減点は「その制約がいくら払われているか」の測定値**として読む。その読み分けは反映の段で行う（`所見.md` の A と D）。

> `?` の一行だけは渡す。渡さないと、六十三話すべてで「話末の引きが未設計」という同趣旨の所見が並び、報告がそれで埋まる。**事実の陳述であって、弁明ではない。**

## 担当外（先に申告する）

**語り・人称・時間の問題は、この評価の担当外である。** plot 入力では `narrative-technique` が招集されない。第四巻の「頁そのものが語る」「四つの通路が全部閉じる」は `narration-design` の領分であり、既に著者の決定リストが答えている。**評議会にこの判定は期待しない。**

## ループ

評価 → `revision_direction`（次回の修正方向）→ **反映** → 再評価 → `compare_reports.py` で差分。

**評議会は書き換え指示を出さない。** 材料（`weaknesses`・`improvement_suggestions`・`expected_disagreement_points`）を出すだけである。反映は書き手側が行い、所見を **A（決定に触れる＝動かさない）／B（設計内部の不整合＝書き手が直す）／C（著者が決める）／D（この評価の読み方）** に仕分ける。**`?` は絶対に自動で埋めない。**

再評価は**同じ回にやらない**——B は内部整合の修正で設計の中身が動かないため差分が出ない。**設計が実際に動くのは C の判断のあとである。**
