## 3.5 2026-10-15 の Upgrade——会話劇へ（独白を、どう置いたか）

**作法 §0-2 が「声は二つある。形が違う」と定め、§1 原則12 が「独白を、置く（`（…）`）」を足した。** **⚠ 独白の形（全角丸括弧の、それだけの行）は、原本63話にも、それまでの変換稿63話にも 0件であった**（2026-10-15 実測）。

**この話は、Upgrade の「中間の場合」である**——**第5話（会話ゼロ）ほど難しくはない。第3話・第4話のような会話劇でもない。** **第二場面には、会話が 12行ある。第一・第三場面には、一行も無い**（**原本・この稿とも**）。**ゆえに、声を配る先が二つに割れている**——**会話の無い二節は、独白が担い、会話のある一節には、置かない。**

**作法 §2「段4 の内側」の手順に従うと——**

1. **原本の鉤括弧を、行番号で書き出す**——**5行である**（原本 `:121`・`:125`・`:129`・`:133`・`:147`）。**⚠ 五つとも、第二場面に在る。第一・第三場面には、0行である。**
2. **梯子に組む**——**組む相手は、第二場面にだけある**（まだいい → まだいい → まだだ）。**第一・第三場面は、初めから「ゼロ」である。**
3. **ゼロになったところを `（…）` で受ける**——**第一・第三場面が、まるごとそれである。**
4. **一人だけの節は `（…）` を主にする**——**第一場面は、語り手（暮林蒼）のほかに、声を持つ者がいない**（**関翔太は数えるだけであり、通り過ぎる人は、何も言わない**）。**第三場面も同じである**（**関翔太は、ひもを持って、止まるだけである**）。
5. **節ごとに声を数え、声が一つも無い節を作らない**——**声の無いのは二節ゆえ、二つ置く。****⚠ 第二場面には、置かない**——**会話が 12行あり、声が既に満ちている**（作法 §1 原則12「会話が既に在る節に独白を足すには、別の理由が要る」。**この節の〝手前で止まる〟ところは、`:239` の一拍の芯そのものであり、そこには置けない**——原則10）。

**置いたのは、二行である。** **数は、原本が決めた**（§1 原則12——**原本の〝黙り〟の芯に、一つずつ**）。**⚠ 二つの手を、混ぜた**（原則12・原則4。**二つとも同じ手にしない**——**§7 の ⑴⑵⑶ の判定を見よ**）。

## 迷った点・確信が持てなかった点（正直に）

- **⚠ 独白① `:115`「（三本は、いつから、ここにある。）」が、いちばん確信の持てない一行である。** **理由は三つ。** **⑴ この話の二拍に、この行が寄与しているか。** **この行は、外す相手を持たない**（§3.5 の ⑶）——**§3.5 では、それを「手が違う」ことの根拠に使ったが、裏返せば「二拍を打っていない」ということでもある。****⑵ 「いつから」は、原本に 0件の語である**（§6⑦）——**ゆえに、この一行は、この稿が起こした問いである。** **原本の〝手前で止まる〟ところから出た、というより、私が置きたかった問いである疑いが残る。** **⑶ コメディへの寄与が、ゼロに近い。** **この行は、笑わせにいかない**（それは正しい——一拍ではない）。**だが、本来の Upgrade は、独白もまた二拍の担い手であると定めている**（作法 §0-2）。**この一行は、担い手になっていない可能性がある。** **——それでも置いた。** **理由は、声の無い節を残せないこと（検算⑧の門）と、問いの側にこの話の二拍があると読んだことである**——**四本目の来歴は問えないが、三本の来歴は問える。その非対称が、この話の形である、と読んだ。** **この読みは、確かではない。**
- **⚠ 独白② `:375`「（今日、持って行く。）」の確信は、①より高い。** **理由は、次の行が、字面で外しているからである**（`:377`「持って、止まる。動かない。」）。**⚠ そして、外す語「持って」は、原本の語である**（原本 `:343` の同じ行）——**この稿は、原本の一語を、その手前へ先取りしただけである。****②のような形（予測を先に置き、地の文が外す）は、`02-02`・`02-05`・`02-06` も使っている**（§1 原則12 の一覧表の「予測→外れ」）。**ゆえに、手としては、この Upgrade で最も出やすい形に寄っている**——**内容（一日が経ったこと）と、置き場所（② 一拍の手前）と、外す語（原本の「持って」）で、別の手に作り直したつもりであるが、機械は同じである。**
- **⚠ 第二場面に、独白を置かなかった。** **会話が 12行あり、声が既に満ちているからである**（§3.5 の 5）。**⚠ この判断は、見本四本の倣い（三節に三つ）から外れている。****作法は「会話のある話では、独白は 0 でもよい」「見本四本が三つずつ置いたのは、四本とも声の無い節が三つあったからである」と明記しているゆえ、私はそれに従った**（§1 原則12・[`../依頼文.md`](../依頼文.md) §3）。**——が、第二場面の一拍（`:239`〜`:255`）の〝手前〟（`:237`「エプロンの裾が床に着く。」の直後、`:239` の直前）に、独白を一つ置く余地はあった、とも読める。****置かなかった理由**——**その位置は、蒼の宣言 `:253`「私はその名を読みません。」へ向かう道の途中であり、声を足せば、宣言が弱まる**（`02-05` の担い手が「C 欄の判断を、独白が先取りして弱めていないか」と問うたのと、同じ問いである）。**ゆえに、置かなかった。この判断も、確かではない。**
- **⚠ 独白① と ② は、一つの読者行動を共有している。** **①は「三本は、いつから」と問い、②は「今日、持って行く」と予測する**——**どちらも、語り手が、物の来歴や行く末を読もうとする形である。** **ゆえに、二つを並べて読むと、語り手の癖（来し方と行く末を測る）として見えてしまう余地がある。** **⚠ 意図していない。** **①は、この話でいちばん古い物へ、②は、いちばん新しい物へ、それぞれ向かせたつもりである。**
