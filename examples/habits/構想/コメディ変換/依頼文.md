## 3. 出すもの——二つ

### ① 本文 `草稿/draft_NN-EE_題.md`

```
# 第N話「題」

（段落）

＊

（段落）

＊

（段落）
```

- 題名行の次は空行。**段落ごとに空行を一行**。
- `＊` は**節と節のあいだ**に一つずつ。**一話に二つ**（三節ゆえ）。**題の直下には置かない。**
- 節の数は**原本と同じ**。増やさない、減らせない。
- 禁則七群（金融・債務・経済／倫理・宗教／「AI」／映像と演出／「アニメ」／上限・定員・キャパ・枠／煙草）。
- 地の文に**「読者」0・二人称0・呼びかけ0・感情に名を与えない**。
- **五文以上の段落を一つも作らない**（最長4文）。

**⛔ 声は、二つある。形が違う。混ぜない**（作法 §0-2）。

| | 形 | 宛先 | 誰の声か |
|---|---|---|---|
| **会話** | `「…」` **鉤括弧。それだけの行** | **ある**（人に向けた声） | 名を持つ者・名のない者 |
| **独白** | `（…）` **全角の丸括弧。それだけの行** | **無い**（一人で言う声） | **語り手**（巻ごとに異なる。§2 の表） |

- **独白は、その者の素の形で書く。** **敬語は宛先に払うものゆえ、宛先が無ければ落ちる**（第一巻・碓氷千夏の独白は、です・ますではなく素——彼女の内省は既に素である。第2話「私の口は、閉じている。」）。
- **⛔ 独白は、註ではない。** **判定は二つ。** **⑴括弧の中を、声に出して読めるか。** **⑵その独白は、直前の地の文の言い換えになっていないか。** **⑴だけでは足りない**——**`03-06` の見本で、三つとも⑴は通って⑵で落ちた**（「固定は**まだ**来ない。」→「（……**まだ**。）」）。**地の文が既に書いたことを、括弧の中でもう一度言わせない。**
- **⛔ 同じ手を、三度置かない。** **三節の回で、三つとも「言いかけて、やめる」形にしない。** **長短を変えても、形が同じなら、それは梯子ではなく、判を三度押したものである**（原則3・4）。**三節なら、三つの手を混ぜる**（黙りの直後の声／手順の途中の声／節の終わりの声）。
- **⛔ 同じ手かどうかは、巻をまたいでも数える。** **⛔ 作法 §1 原則12 の「見本四本が既に使った手」の表を、書く前に読む。** **この装置には前例が無いゆえ、書き手は見本の形へ収束する**——**〔実測〕`01-03` の担い手が、自分の三つのうち①と③が同じ手で、②③が `01-05`・`02-02` と同型である、と申告した**（2026-10-15）。**載っている形を、そのまま別の話で使わない。****使うなら、その話の物で、別の手に作り直す**（原則11）。
- **⛔ 独白は、宛先を持たない。** **ゆえに二人称（あなた・あんた・お前・きみ）を置かない。呼びかけない。**
- **⛔ 独白は、語り手の声である。** **現場の誰かに言わせたいなら、それは `「」` である。** **⚠ どちらの声かが決まらない独白は、まだ書けていない独白である**（`04-13` で実際に問いが立った——語り手か、名を読む者か）。
- **⛔ 「一拍の手前」は、一拍の芯の〝すぐ外〟である。** **芯の中に置かない**（検算④）。**芯の位置は、場面表 §0 の「現場／一拍」の欄から読む。** **⚠ 読めなければ、芯から遠い方へ逃がす**——**逃がすのは失敗ではない。芯に置くより正しい**（`04-13` の担い手が実際にそうした）。
- **⚠ 「節の先頭」は、置き場所の外ではない。** **前の節の終わりの直後である**——**`＊` をまたいで読めば「黙りの直後」である**（`04-13` と `01-02` が独立にここへ置き、二人とも「四つには入らない」と記録した。**入る**）。
- **⛔ 例を、地の文から取らない。** **地の文を丸括弧に入れたものは、独白ではなく註である**（作法 §6 ⑤、統括が踏んだ誤り）。
- **声が一つも無い節を作らない。** **節ごとに声を数える**（§5 の ⑧）。**⚠ これは下限であって、目標ではない。** **会話が既に在る節に独白を足すには、別の理由が要る**——**その節に、原本が〝手前で止まる〟ところを持っているか**（原則12「独白の数は、原本が決める」）。**⚠ 会話のある話では、独白は 0 でもよい。** **⛔ 見本四本が三つずつ置いたのは、四本とも声の無い節が三つあったからである。三節に三つ、が規則なのではない**（`01-13` の担い手がここで倣いを疑い、申告した）。

### ② 場面表 `構想/各話/EE_題.md`

原本の場面表を写し、次の節を足す／直す。**形式は見本（`01_…`／`02_…`）に合わせる。**

- **§0 この話について**——話名・扱う癖・記名・現場／一拍・名を目で読む者・動き・会話・反応軸・舞台・誰が居るか・区分け。**原本の話割りの値を写し、動かした欄には印をつける。**
- **§1 節立て**——三節の字数と、何が起きるか。
- **§2 動かさないもの**——原本の「動かさないもの」を**全文写す**。そして**この稿でそれを破っていないことを、行番号つきで示す**。
- **§3 差分——コメディとして、何をしたか**——表（#／何を／どこで／型）。**型は作法 §1 の原則名で書く。**
- **§4 内面の欄〔実測〕**——**本文を書いた後に読む**（第一〜三巻のみ。第四巻はこの節を置かない）。`A`＝気づき（身体・物を通した）／`B`＝働きの知識／`C`＝為まいの宣言。**原本と三値が同じであることを示す。**
- **§5 検算**——§5 の八つを、実測で埋める。**引用はすべて実在の行番号で**（機械で照合する）。

## 5. 検算——出す前に、必ず打つ

**作法 §3 の八つ。**

| # | 見るもの | 合格の形 |
|---|---|---|
| ① | 禁則 | check.py が 0件 |
| ② | 五文以上の段落 | **0個**（最長4文） |
| ③ | 内面の欄が動いていないこと | 原本と三値が同じ（第四巻は、人称・内面・回想がどこにも無いこと） |
| ④ | 一拍に人が入っていないこと | 一拍の範囲に、足した文が一つも無い |
| ⑤ | 落とした文を句点単位で数える | **⛔ 数は門ではない。中身が門である。** **見るのは「註でない文が消えていないこと」だけ**（下の ⚠⚠ を見よ） |
| ⑥ | 註の比率 | である末・一文の長さが、原本から跳ねていない |
| ⑦ | 声の帰属を数える | 鉤括弧の持ち主を数える。**語り手の側が一語でできていないか** |
| ⑧ | **独白を、数える**（2026-10-15 に足した） | **節ごとに、`「」` と `（…）` を数える。****声が一つも無い節が 0**。`「」` と `（…）` を混ぜていない。**括弧の中を声に出して読める**（註でない） |

⚠ **⑦は、鉤括弧が 0個の話では鳴らない。**（第1話＝62行 31/31、第2話＝19行 0/19 で鳴った。**会話のない話では、空の検査である**——「全部が誰かのもの」ではなく「声そのものが無い」。）**空の検査を「合格」と読まない**（[`empty-file-not-content`]）。**そのときは、そう書く。** **⚠ 2026-10-15 以降、鉤括弧が 0行の話は ⑦ が空になるが、⑧ は鳴る**——**`（…）` が声として入るからである。** **⑦が空になったことを理由に、⑧ を省かない。**

⚠ **⛔ 印は、現象ではない。** **括弧を置けば数は増えるが、声は増えない。** **註を括弧に入れた回は、⑧ の数だけが増えて、二拍は打てていない。****数ではなく、声に出して読んで判定する**（[`marker-is-not-the-phenomenon`]）。**第四巻は、この検算が初めて鳴る巻である。**
⛔ **⑧ の「声の無い節 0」は、門であって、合格ではない。** **〔実測〕見本の四本は、四本とも 声の無い節 0 になった。** **だが `03-06` の三つの独白は、判定⑵（地の文の言い換え）で三つとも落ちた**——**数は門を通り、中身は落ちた。** **節ごとに数えたあと、三つを並べて読み直す。** **三つとも同じ形なら、その節の声は、まだ一つも無い。**
⛔ **⚠ 検査器の穴を、一度踏んでいる**（2026-10-15、`04-13` の担い手が実測で見つけた）。**⑤（落とした文）が、正しく書いた稿に「落とし 1」を返していた**——**地の文から独白へ〝声として〟移しただけの文が、落とした文に化けていた。** **既に直した**（`検査/検算.py` の `sentences_of`）。**⚠ だが、同じ形の偽陽性が他にもありうる**——**⑤ が 0 でないとき、まず「その文は本当に消えたか」を、独白の側で検索する。**

⚠⚠ **〔2026-10-15 の訂正——⑤ は、門ではなかった。〕** **統括が、担い手への指示文に「落とし 0 が門である」と書いていた。****⛔ 誤りである。** **⑤ は、原本の文が〝逐語で〟残っているかを数える**——**ゆえに、一句でも書き換えれば増える。** **そして——**
> **著者が「1巻1話・1巻2話は、よかった」と言った、その二本が、⑤ の最大である。** **〔実測〕`01-01` は 141/347文・`01-02` は 195/414文。**

**⛔ ゆえに、0 を目指さない。** **0 は「一句も書き換えていない」の意味であり、それは美点でも欠点でもない。** **削ってよいと言われているのは、註（理屈）だけである**（原則6・手順八段の段6）。**註を消したぶんは、⑤ に数えられる——それは正しい。**
**⚠ 見るのは、数ではなく、中身である。** **`--missing` を目で読み、消えた文が註（理屈の説明）であることを、一句ずつ確かめる。** **註でない文——物・手順・黙り——が消えていたら、それは誤りである。** **⛔ 逆に、註を残すために書き換えを避けるのも誤りである。**

## 6. ⛔ やってはいけないこと

- **原本を書き換える**（`../habits-NN/` は読むだけ）。
- **新しい物・新しい人を足す**——ただし**話割りが席の数を名乗っていないとき**は人が増えてよい（原則11 の註。第一巻 第1話はこれで二人→六人になった）。
- **一拍（笑わせる場所）に、何かを置く。** 一拍は**手前で止まる**ためのものである。

### 9-1 ⛔ 「落とし 0」は門ではなかった——**統括の誤りの訂正**
