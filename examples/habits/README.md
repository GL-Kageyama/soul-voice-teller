**分け方の軸は「巻」である。** 巻をまたぐものは共通へ、一つの巻に閉じるものは各巻へ。

**⚠ 2026-09-21——共通の側には、軸がもう一つある。役割である。** 巻をまたぐものは、まず共通へ出て、**そこで役割ごとに分かれる**——設計（`構想/`）・人物と全巻（`台帳/`）・出典（`出典/`）・**著者が決めるための材料（`構想/決定材料/`）**・**貼るだけの手順（`構想/指示書/`）**・**外部評価とその記録（`評価/`）**。**一つの役割は、一つの置き場を持つ。**

### 下位——`_process/`（run-01〜run-08）

**上の四点は `handoff/` にある。その下にもう一段ある。** **決定 II（2026-09-18、著者）により、下位の出典として引ける**（`elevate-draft-engine/examples/habits-ja/README.md`:79-83）。

| | 何が |
|---|---|
| **引ける** | `_process/run-NN/artifacts/` と `_process/run-NN/knowledge.md` |
| **引けない** | `drafts/`（八名の草案）・`_stage8/`——**生成過程である** |

**台帳が下位を引くのは、一つの用途である**——**`—（規律）` の理由を示すため。** 欄が「書かない」と決まったとき、**その理由を著者の判断ではなく、出典の語で言う。** サブ二十四名の `動機` がこれで、**run-06 がストック層を「ひとつの癖＋その帰属の未決」で定義していることを引く**（`_process/run-06/artifacts/reconciliation.md`:158）。

**記号は `（run-06 下位）` と書く。** **`・` は run と run を結ぶので、修飾は空白で書く**——`（run-10 第6話）` と同じ形である。**ゆえに `（run-06・下位）` とは書かない。**

**下位から引いた一行は、そのままでは渡らない。渡すと決めたときに、著者の一行が付く。** いまのところ、その例は**さくらの `賭け` 一つ**である。

**規則の全文は [`台帳/人物/README.md`](台帳/人物/README.md)「出典記号には、段がある——上位と下位」にある。**

## 禁則

**小説の地の文と会話に効く。全巻ゼロ。**

- 金融・債務・経済——利子・利息・借り・貸し・返済・清算・負債・帳簿・残高・請求・**担保**・信用
- 倫理・宗教——愛・所有・**関係**・恩・**縁**・功徳
- 「AI」——地の文と会話では使わない（見出しを除く）
- 映像と演出——カット／シーン／カメラ／アングル／アップ／演出／観客／視聴者。地の文と会話ではゼロ（見出しと企画の語彙には現れる）
- 「アニメ」「アニメ化」も、地の文と会話ではゼロ
- 上限・定員・キャパ・枠／煙草・煙管・吸い殻・路上喫煙
- 「読者」を主語にした文は各節に一つまで。【独自フック】には置かない

**地の文の「読者」もゼロ。** 禁則語は全巻ゼロ。この二つは作品の不変条件である。

なお `縁` は、**ふち**（台の縁）の意味で使う場合は同字別語であり、禁則の対象ではない。
