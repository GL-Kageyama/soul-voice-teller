# axes —— 反応軸のパターン集

6つの反応軸（感嘆・ユーモア・感動・楽しい・恐怖・かわいい）を、それぞれ**主軸**に据えた6本の新規サンプル。

- 目的: 「反応軸」欄が固定値でなく、作品ごとに**別の主軸・副軸**を選ぶことを見せる。
- それぞれ `premise.md`（反応軸の選定）→ `design.md`（四工程＋三種の割り当て）→ `draft.md`（軸を場面ごとに小さく撃った草稿）の順に流れる。

| ディレクトリ | 主軸 | 副軸 | 種（一言） |
|---|---|---|---|
| admiration | 感嘆 | 恐怖 | 記憶を売れる店の落とし |
| humor | ユーモア | 楽しい | 勇者一行の就職難 |
| emotion | 感動 | かわいい | 老時計職人と亡き妻の腕時計 |
| fun | 楽しい | ユーモア | 夜に飛び出す図書館の本 |
| fear | 恐怖 | 感嘆 | 隣の部屋がない家 |
| cute | かわいい | 感動 | 子猫騎士団の雨宿り作戦 |

## 補足

- **humor（ユーモア主・楽しい副）と fun（楽しい主・ユーモア副）は主軸と副軸を入れ替えた対**。同じ二軸でも、主軸がどちらかで重心が変わることを示す。
- **`longform` は長編の実演**。主軸（感動）が全体の弧を担い、場面（＝各世界）ごとに別の軸を撃つ——S2 恐怖・S3 ユーモア・S4 かわいい・S5 感嘆・S6 楽しい・S7-8 感動。一つの design の中で「シーンごとに反応軸を設計」する見本。
- 声（文体）は軸に合わせて変えてある。**軸は「作品が目指す感情」、声は「誰が書くか」**——直交する。一つの persona の声が6軸すべてに合うとは限らないので、このパターン集では軸を際立たせる声を作品ごとに選んでいる（persona を通したデモは `../sample/` と `../bonodori/` を参照）。
- 各軸の「四工程（全体の弧）」「三種（場面の弧）」「失敗モード」の定義は `../../references/ja/6つの反応軸.md` を参照。
