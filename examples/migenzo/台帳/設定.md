# 設定レコード —— 《未現像》

## 世界観の機構（なぜこの世界が成り立つか）

- **世界法則**: 撮られなかった瞬間は、あらゆる可能な像を無限に含む重ね合わせとして保存される。現像とは、その無限を一つの像へ崩壊させる喪失の行為である。見ることは可能態を殺し、見ないことは可能態を無限に生かしつつ永久に留置する。
- **三則＋第四則**: ①現像できるのはシャッターが降ろされた瞬間のみ。②像はネガの重ね合わせとして待機し、浮かぶ瞬間だけ正像へ反転。③現像のたび、現像者は自身の可能態を一つ崩壊させる（＝記憶を失う）。④現像とは崩壊である（規則でなく自己記述）。
- **限界**: 一度も重ね合わせでなかったもの（娘の顔）は現像できない。何も浮かばない印画紙＝この世界で最も重い像。
- **脂痕**: 現像の代償（消えた記憶）が、レンズの指紋・手の脂として像に残る。暴力の道具である撮影者の痕跡が、唯一の生身の証拠＝救済の形になる。
- **白の三義**: 読者の顔／娘の無限／判決の不在。どの読みにも収束させない（第四則の自己言及として全ページで保証）。

## 固有名・人物台帳

- **絹**（主人公・「見ないことの記録者」）—— 撮ることを拒む被写体の「拒んだ瞬間」を現像する写真家。娘の一枚だけは現像しない。現像するたび記憶を一つ失う。能動の原理「娘を現像しない＝愛、を守るために動く。それが脅かされれば（盗まれる）、追う（Y）。それなら他人の拒否を現像し続ける（＝自分の記憶を差し出す）ことをやめない（Z＝記憶の喪失）」。中盤（第6章）で自ら一枚を現像し、記憶を一つ能動的に差し出す（受動の「追われる」を破る本人起点の能動）。変化弧＝現像＝加算の誤解 → 現像＝崩壊 → 崩壊の受容。
- **娘**（現像されないまま無限に残る者・名を持たない）—— 死の瞬間、自ら撮られることを拒んだ（レンズを内側から押さえる小さな手）。隠れたロール：犠牲者 → 意志の主体。名も顔も現像されない＝白に保つ。手に迷いの痕跡（押す前に一瞬迷い、押した後に離そうとした）——意志を結末でなく動作の葛藤にする。
- **盗人（被写体の子供）**—— 絹の現像した像に人生を壊された者の子供。唯一の未現像（娘の一枚）を奪い、「あなたの見ないことは誰かを崩壊させてきた」と突きつける。敵役の論理の正しさ。内面葛藤＝復讐こそ自分の可能性を一つの像へ現像している、という絹と同じ自己欺瞞（気づかぬまま／やめられずに）。
