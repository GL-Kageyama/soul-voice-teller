# package —— 公開稿の包み（カクヨム投稿用）

> 作品: 『未現像（みげんぞう）』（全12章・総約10万字）
> 根拠（読者像）: 見られることに疲れ、それでも見られることをやめられない者。SNSで自分の像へ固定されていく息苦しさを知り、それでも像を手放せない者。
> 約束: 読了後、あなたが「現像しないこと」で生かしたつもりの誰かが、実は留置だった、という内省が届く。最後の白に、あなた自身の顔が浮かぶ。
> 包みの規則: 嘘で引かない／届けるものを約束する／開示の頂の前で止まる／抑制を引き継ぐ。全部の扉が同じ作品（現像＝崩壊）を開く。

---

## 1. タイトル＋サブタイトル

**タイトル**: 未現像（みげんぞう）

- 写真用語「未現像」を名のまま立て、何が現像されなかったかを言わない。読みの非自明な語のため、括弧つきの読み（みげんぞう）を題そのものに含める。副題は置かない——題だけで十分強く、「現像＝崩壊」の再定義は帯が担う。開示の頂（第10章・娘が自ら撮られることを拒んでいた）には触れない。

## 2. 帯（キャッチコピー）

**主**:
> 撮られなかった瞬間は、無限の重ね合わせとして眠っている。現像とは、その無限を一つの像へ崩す喪失。女は二十年、娘の一枚だけを現像しなかった。

（余白を残す版・帯がもう一行とれるなら）:
> 見ないことは、愛なのか、留置なのか。

- 「無限を一つの像へ崩す」=未知で引き、「現像しない一枚」=物語の心臓で受ける。核心の問い（見ないことは愛か留置か）は帯では問いのまま。テーマ（現像しないことも暴力）を名指ししない。

## 3. あらすじ

### 裏表紙（短・約160字）

> 撮られなかった瞬間は、無限の重ね合わせとして保存され、現像とはそれを一つの像へ崩す喪失である。現像師・絹は「撮ることを拒んだ瞬間」を現像し、畏れられてきた。現像のたび記憶を一つ失う。二十年、ただ一枚——娘の死の瞬間の未露光フィルムだけを、現像しなかった。

### サイト用（中・約450字・連載プラットフォーム）

> 現像師・絹の仕事は、撮られることを拒んだ人々の「拒んだ瞬間」を現像すること。撮られなかった瞬間は無限の重ね合わせとして保存され、現像とはそれを一つの像へ崩壊させる喪失。現像のたび、絹は自分の記憶を一つ失う。その代償は、像に残る指の脂痕として、いつも彼女に返ってくる。
>
> 彼女には二十年、現像しない一枚があった。娘の死の瞬間の未露光フィルム。現像しないことが、娘を無限のまま生かす唯一の愛だと、絹は信じてきた。
>
> ある夜、その一枚が盗まれる。暗室の戸は内側から開けられ、残るのは指の脂痕だけ。盗んだのは、絹の現像した像に人生を壊された被写体たちの子供。絹の「見ないこと」が、実は誰かを崩壊させてきた暴力だった——その全容が、犠牲者の顔で立ち上がる。
>
> 子供は突きつける。「あなたの見ないことは、誰かを崩壊させてきた。あなた自身の娘さえ」。
>
> 二十年守った「現像しない」が外から破られ、絹は最後の暗室へ向かう。二十年ぶりに、娘の一枚を現像するために。

- 開示の頂（第10章・娘が自ら撮られることを拒んでいた）には触れない。ここまでの設定（現像＝崩壊・盗難・子供・加害）は第6章までに開示される範囲。

## 4. 画像生成プロンプト

### カバー（表紙）

```
文芸書の表紙・1枚。暗室。赤い安全光だけが灯る暗がりに、真っ白の印画紙が一枚、浮かぶ。像は浮かんでいない——未現像の白。その白に、現像者の指の脂痕が淡く残る。銀塩のモノクロ。上方に広い暗がり＝タイトル文字の余白。焦点は「何もない白」ひとつ。写実寄りの銀塩写真。赤い安全光の照り返しだけが唯一の色。紺・黒・白基調、一点の赤。
```

### キーシーン（第1章・現像）

```
1枚。暗室。赤い安全光の下、女（絹）が現像トレイの上に白い印画紙を掲げる。紙の上に、モノクロの像が滲み出る途中——輪郭が、眼が、口元が、ゆっくり浮かぶ。女の指には、失った記憶の痕（脂痕）が淡く残る。銀塩のモノクロ、赤い安全光だけが色。焦点は「像が浮かぶ白い紙」。静寂と、畏れられる仕事の重み。文芸挿絵風。
```

## 5. タグ／キーワード

- ジャンル（文芸・サスペンス・現代ファンタジー）＋本作固有の語（現像・暗室・白）で、約束（見ないことの内省）が届く読者の住所にする。

## 包みの検品（4規則・一つの魂、多くの扉）

1. **嘘で引かない** ✓ —— 全扉が「現像＝崩壊・撮られなかった瞬間の重ね合わせ」という本作の実在の設定だけから引いている。幽霊退治や怪談の見せ物を約束していない。
2. **届けるものを約束する** ✓ —— あらすじが約束するのは、静かに娘の一枚へ向かう話。帯もサブタイトルも同じ方向（現像＝崩壊）を向く。
3. **開示の頂の前で止まる** ✓ —— 娘が自ら撮られることを拒んでいた（第10章）、娘の顔が白のまま（第11-12章）には一切触れていない。
4. **抑制を引き継ぐ** ✓ —— 帯もあらすじも「現像しないことも暴力」を名指ししない。テーマを説明していない。読者に確かめさせる余白を残す。

**一つの魂、多くの扉** —— 帯（現像＝崩壊の再定義）→ あらすじ（娘の一枚へ向かう物語）→ 表紙（未現像の白）→ タグ（現像・暗室・白）。すべて同じ問い「見ないことは愛か留置か」を、開かずに指している。
