# 娘さえ

その者は言う。あなたの見ないことは、だれかを崩壊させてきた。あなた自身の娘さえ。

絹はその言葉を聞く。娘さえ。そのことばが絹のなかに落ちてくる。落ちて、二十年のうえにのしかかる。娘、ということばが、この者の口のなかで、かたちを持つ。絹が二十年、現像しなかった、その一枚のことばが、いま、だれかの口から出る。口から、出た、ことばが、部屋の、空気の、なかを、すこし、進んで、絹の、胸の、あたりで、とまる。とまった、ことばの、重さが、二十年ぶりに、絹の、からだの、まんなかに、置かれる。

絹は言う。娘は死んでいる。死んだ娘を現像しないことが、なぜ崩壊なのか。

その者は言う。あなたは娘を、二十年、暗室の引き出しのなかに置いてきた。死んでいる娘を。ひとつの像にもせずに。死んで、動かなくなった娘を、動かさないまま、二十年、置いてきた。それが、あなたの愛だというのなら。その者の、言いかたは、ゆっくり、だった。ゆっくり、ひとつ、ひとつ、ことばを、置く、ように、言って、いた。置かれた、ことばが、絹の、二十年の、暗室の、床に、ひとつ、ずつ、落ちて、並んで、いた。

絹は思う。この者は、絹が二十年、暗室のなかでひとり、見ないでいたことを、いま口にしている。引き出しのなかの冷たい筒。一度だけ転がって、あとは動かなかった、あの筒。二十年、絹はそれに触れなかった。触れないことが、娘を生かしていると、信じてきた。この者は、その二十年を、いま、絹の前に、ことばとして置いている。絹の、指が、触れる、一歩、手前で、二十年、とまって、いた、その、距離を、この者は、いま、ことばで、詰めて、きて、いる。

絹はその者の手を見る。ポケットのなかの、折り畳まれた像。二十年、この者も、その像をひとつのかたちに現像してきた。絹が父を現像したように、この者も、絹を現像してきた。絹の見ないという行為の二十年を、一枚の像のなかに現像してきた。いま、その像を、絹に見せようとしている。絹を、現像した、像、という、ものが、この者の、手の、なかに、二十年、折り畳まれて、持たれて、いた。その、像の、折り目が、絹の、二十年の、しわと、おなじ、向きに、ついて、いた。
