# 娘さえ

その者は言う。あなたの見ないことは、だれかを崩壊させてきた。あなた自身の娘さえ。

絹はその言葉を聞く。娘さえ。そのことばが絹のなかに落ちてくる。落ちて、二十年のうえに、のしかかる。

絹は言う。娘は死んでいる。死んだ娘を現像しないことが、なぜ崩壊なのか。

その者は言う。あなたは娘をひとつの像にしていない。ひとつの像にしないということは、無限に留めておくということだ。あなたの愛は、留置だ。

絹は思う。この者は、絹が二十年、見ないでいたことばを、いま口にしている。

絹はその者の手を見る。ポケットのなかの、折り畳まれた像。二十年、この者も、その像を、ひとつのかたちに現像してきた。絹が父を現像したように、この者も、絹を、現像してきた。
