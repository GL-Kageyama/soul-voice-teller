# 最初の一人

その者は、言う。──わたしの父を、現像した。と。

絹は、その者の父を、思い出そうとする。──思い出せない。現像した、ということだけが、残っている。現像して、なにかを置いてきた。その、なにかに、父が、いた。

その者は、つづける。──父は、その像を見た。見て、家を出ていった。戻らない。

絹は、聞いている。──像を見た。絹は、現像したものを、見ない。だから、その像に、なにが写っていたか、知らない。けれど、それを、父が、見た。

その者は、言う。──あなたは、見ない。だから、あなたは、知らない。わたしの父が、なにを見て、出ていったかを。

絹は、その者を、見る。──見なければならない。二十年、見ないことで、守ってきた。けれど、いま、この者の前に、絹は、見ないでは、いられない。
