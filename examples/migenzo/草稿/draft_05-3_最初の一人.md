# 最初の一人

その者は言う。わたしの父を、現像した。と。

絹はその者の父を思い出そうとする。思い出せない。現像した、ということだけが残っている。現像して、なにかを置いてきた。その、なにかに、父がいた。

その者はつづける。父は、その像を見た。見て、夕飯の皿を置いたまま、家を出ていった。戻らない。

絹は聞いている。像を見た。絹は現像したものを見ない。だから、その像になにが写っていたか、知らない。けれど、それを、父が見た。

その者は言う。あなたは見ない。だから、あなたは知らない。わたしの父が、なにを見て出ていったかを。

絹はその者を見る。見なければならない。二十年、見ないことで守ってきた。けれど、いま、この者の前に、絹は見ないではいられない。
