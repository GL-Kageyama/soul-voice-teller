# 最初の一人

その者は言う。わたしの父を、現像した。と。

絹はその者の父を思い出そうとする。思い出せない。現像した、ということだけが残っている。現像して、なにかを置いてきた。その、なにかに、父がいた。なにかを置いた、その、なにかの、なかに、この者の父が、入っていた。置いてきた、ものの、なかに、父が、入って、いって、戻って、こない。

その者はつづける。父は、その像を見た。見て、夕飯の皿を置いたまま、家を出ていった。戻らない。皿のなかの、汁が、夜のうちに、冷えて、固まった。汁の表面に、うすい膜が、張っていた。朝になっても、だれも、その皿を、下げなかった。膜の、うえに、ほこりが、すこし、たまって、いった。二日目、三日目と、膜は、厚く、なって、いった。だれも、下げなかった。下げる、という、ことが、父を、待つのを、やめる、という、ことに、思えたから。

絹は聞いている。像を見た。絹は現像したものを見ない。だから、その像になにが写っていたか、知らない。けれど、それを、父が見た。絹の現像した像を、この者の父が、見て、夕飯の皿を、置いた。置いて、出て、戻らなかった。汁の、膜の、ことを、絹は、現像液の、膜と、おなじように、思う。うすく、張って、冷えて、固まる。だれも、さわれなく、なる。

その者は言う。あなたは見ない。だから、あなたは知らない。わたしの父が、なにを見て出ていったかを。あなたは、現像して、見ない。見ないから、あなたの指が、だれを、どうしたのかを、あなたは、二十年、知らずにきた。見ない、ということが、あなたの、指を、だれにも、見えなく、して、いた。

絹はその者を見る。見なければならない。二十年、見ないことで守ってきた。けれど、いま、この者の前に、絹は見ないではいられない。この者の眼の、奥の、父の、眼が、絹を、見ている。
