# 距離

絹は人と話さない。話す必要があるときも、最小の言葉で済ませる。言葉は、出したぶんだけ、だれかのなかに残る。残したくない。

現像の薬品を店で買う。木の引き戸を開ける。鈴が、ちい、と鳴る。ちい、と鳴って、それから、音が店の奥まで沈んでいく。床の板が、足の下で、きし、と鳴る。絹は入り口から二歩のところで、止まる。それより奥へは、入らない。それが、絹と店とのあいだの距離だった。店主が絹を見て、一歩下がる。下がったぶん、店の奥のほうで、瓶の影がゆれる。今日も変わらず、と店主が言う。絹はうなずくだけだ。うなずきは言葉より遠くまで届かない。届かないから、ちょうどいい。

絹は黙って、棚の瓶を指さす。現像液を一本、定着液を一本。指さした指先の、その先に、瓶が二本、棚のうえですこし光っている。店主がそれを紙で包む。包む手がすこし震えている。紙の折り目がすこしずれている。瓶が二本、紙のなかで、かち、と、すこしぶつかる。絹はそれを見ない。代金を置く。釣りを待たない。店主が釣りを差し出す。硬貨が掌にすこし冷たい。その冷たさが、暗室の液の冷たさとおなじだった。絹はそれを受け取って、店を出る。ありがとう、とも言わない。言わないほうが相手を楽にする。絹はそう知っている。

絹は帰り道を歩く。包みを片手に持つ。包みの紙の、かさ、という音が、歩くたびに、すこしする。夕方の光が長い。絹の影が、道にすこしだけ長い。誰も絹と目を合わせない。絹も合わせない。すれ違う者はみな、目を伏せる。目を伏せる早さが、みな、おなじだった。この距離がいつから始まったのか、絹は思い出せない。思い出せないことだけがこの距離を正しく保っている。
