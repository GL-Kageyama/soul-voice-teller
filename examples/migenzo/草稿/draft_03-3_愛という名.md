# 愛という名

絹は現像を仕事にしている。人の、撮らなかった瞬間を現像して崩壊させる。それが絹の仕事だった。

けれど、娘の一枚だけは現像しない。絹はそのことを、愛、とは呼ばない。呼べない。呼んでしまうと、なにかが違ってしまう。

絹はただ、現像しない。現像しないということを二十年、してきた。現像は崩壊だ。ならば、現像しないということは崩壊させないということだ。絹はその逆さの計算を二十年守っている。

絹は今日も現像する。人の、拒んだ瞬間を。そして娘の一枚だけを現像しない。現像しないことだけが絹のなかに残る。現像するという仕事の向こう側に。

絹はその、現像しない一枚のことを考える。考えるのではなく、持っている。持っているということだけが、絹の二十年のなかでいちばん確かだった。
