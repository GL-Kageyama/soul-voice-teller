# 愛という名

絹は現像を仕事にしている。人の、撮らなかった瞬間を現像する。現像するたび、絹のほうから何かが一つ抜ける。抜けたものが脂となって像に残る。それが絹の仕事だった。二十年、絹は、その抜けていくもののいちいちを数えないできた。数えたら、仕事ができなくなる。

けれど、娘の一枚だけは現像しない。絹はそのことを、愛、とは呼ばない。呼べない。呼んでしまうと、なにかが違ってしまう。言葉にすると、娘の一枚が、言葉の大きさになってしまう。

絹はただ、現像しない。現像しないということを二十年、してきた。現像すれば、なにかが浮かぶ。浮かんだら、娘はもう無限ではなくなる。だから絹は現像しない。しないほうを二十年、選んできた。逆さの計算を二十年、守っている。人には、現像するという仕事を。娘には、現像しないという仕事を。絹は、その逆さを、両手に二十年、持ってきた。右手に、人を現像する仕事を。左手に、娘を現像しない仕事を。

絹は今日も現像する。人の、拒んだ瞬間を。そして娘の一枚だけを現像しない。現像しないことだけが絹のなかに残る。現像するという仕事の、いちばん底に、それが、静かに残っている。

絹はその、現像しない一枚のことを考える。考えるのではなく、持っている。持っているということだけが、絹の二十年のなかでいちばん確かだった。
