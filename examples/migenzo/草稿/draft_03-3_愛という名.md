# 愛という名

絹は、現像を、仕事にしている。人の、撮らなかった瞬間を、現像して、崩壊させる。──それが、絹の仕事だった。

けれど、娘の一枚だけは、現像しない。──絹は、そのことを、愛、とは呼ばない。呼べない。呼んでしまうと、なにかが、違ってしまう。

絹は、ただ、現像しない。現像しない、ということを、二十年、してきた。──現像は崩壊だ。ならば、現像しないということは、崩壊させない、ということだ。絹は、その逆さの計算を、二十年、守っている。

絹は、今日も、現像する。人の、拒んだ瞬間を。──そして、娘の一枚だけを、現像しない。現像しないことだけが、絹のなかに、残る。現像する、という仕事の、向こう側に。

絹は、その、現像しない一枚のことを、考える。考えるのではなく、持っている。──持っている、ということだけが、絹の二十年のなかで、いちばん確かだった。
