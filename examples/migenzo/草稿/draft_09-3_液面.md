# 液面

暗室には、単一の赤い光が、ある。──その光が、トレイの液面を、照らしている。液面は、静かだった。二十年ぶりの、静けさだった。

絹は、液面を、見る。──液面は、絹を、映さない。現像液の琥珀が、光を吸って、なにも映さない。絹の顔も、映らない。

絹は、フィルムを、液面の上に、かざす。──かざして、とどめる。沈めない。沈める、という選択が、まだ、絹の手のなかに、ある。

絹は、娘のことを、思う。──娘は、死の瞬間、なにをしたのか。二十年、絹は、その瞬間を、現像しなかった。現像しなければ、その瞬間は、無限のまま残る。──残る、ということが、今夜、ここで、終わろうとしている。

絹は、液面を、見る。──液面の静けさが、二十年の静けさと、同じものだった。──同じもののはずが、今夜は、すこし、ちがう。液面が、絹の、沈める、という手を、待っている。
