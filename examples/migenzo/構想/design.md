# design —— 設計書

## 必須構想（fast-draft が書く前に確定しているべきもの）

### ログライン

現像とは崩壊である。——その世界で、女は娘の一枚だけを現像せずに生かしてきた。現像した瞬間、浮かんだのは娘の顔ではなく、レンズを内側から押さえる小さな手だった。

### 語り

- 視点: **三人称・制限（絹の内側に寄り添う内的焦点化）を基調**。第10章の「現像された像」だけ見る側→見られる側へ反転。キャッチコピーと最終頁の白のみ**二人称「あなた」**。
- 時制: **現在形基調**。娘の死の瞬間だけ、像の浮上として現在形に割り込む（過去を語らず、現像の像として返す）。
- 語り手: **暗室の地の声**。白の意味を決めない（娘の意志を最後まで知らない＝読者の無知と同期）。

### 文体の方向

- **像が浮かぶ順（輪郭→眼→口元）を、文の順序でなぞる**。説明ではなく、白い紙に像が滲む過程をそのまま文にする。
- **ネガから正像への反転を、語順の反転で**。光と影、能動と受動が、現像の場面でだけ入れ替わる。
- **説明しない**。三則＋第四則も「現像＝崩壊」も、現像の行為で滲ませる。
- **感傷にしない**。娘への愛は名指ししない。脂痕（レンズの指紋・手の脂）に、失われた記憶を宿す。悲しみの通路は脂痕だけにしない——失われた声・鼻歌・手の感覚にも記憶を宿す。
- **余白を埋めない**。白の三義、娘の顔、愛か暴力か——最後まで決めない。
- **声はソリッドに、短くリズミカルに**。刻むのは要の一打（像の浮上・白の一瞬）だけ。

### 反応軸

- **恐怖一次**（四工程：安全の担保 → 脅威の提示 → 逃げ場を塞ぐ → 解放）・**感嘆二次**（誘導 → 超出 → 必然 → 頂点）。
- 恐怖の三種（ゾクッ・ヒヤッ・ぞわり）が中盤を、感嘆の三種（へえ・なるほど・うまい）が結末の超出を撃つ。恐怖の「解放」はカタルシスでなく、白を決めない余白として訪れる。

### 読者像と読者への約束

- **誰に**：見られることに疲れ、それでも見られることをやめられない者。自分の像へ固定されていく息苦しさを知る者。
- **約束する体験**：
  - **掴む**（場面1-2）：暗室の仕掛けと盗難で、サスペンスに乗せる。
  - **置かせる**（場面3-4）：絹の加害性と、愛＝留置の二面性を滲ませる。「私も、誰かを現像しないことで生かしたつもりだった」と内省へ導く。
  - **解放する**（場面5-6）：崩壊を受け取り、白を決めないまま閉じる。読者は「現像される側」に立たされ、白に自分の顔を見る。

## 設計ループ（照合）

必須構想の初稿を、premise（約束・反応軸・核心の問い）＋ persona（声・美意識・禁じ手）に照らして改訂した記録。

- **語りを一人称にしない**。一人称は「現像する側」の内面を説明して白を決めてしまう。三人称・制限（内的焦点化）は絹の無知を読者の無知と同期させ、第10章の反転（見る側→見られる側）まで白を保てる——persona の「余白を埋めない」に照らして守る選択。
- **解放＝カタルシスを退けた**。恐怖一次の四工程を「読者を泣かせて閉じる」で終えるのは誰でも書ける。premise の約束（白は最後まで決めない）に照らし、解放を「白を決めない余白」として再定義した。
- **語りの途中反転・二人称 `?`**：基調（三人称・制限）を、第10章（見る側→見られる側）と最終頁・キャッチコピー（二人称「あなた」）で破る。premise に無い逸脱だが、核心（見る／見られるの反転）を語りの様式そのもので実装する singular な選択——**深める**ので設計に残す。
- **感動の軸外侵入 `?`**：反応軸は恐怖一次・感嘆二次だが、第7章だけ感動（じんわり）を撃つ。愛と暴力の表裏を体で知らせるので**深める**が、涙でなく「区別の溶ける痛み」として一度だけ・抑制して差す（全体は恐怖と感嘆に譲る）。
- **評議会評価の反映（2026-09-05）**：novel-council の指摘（character-depth 53＝脇役・娘の機能性、character-role＝中盤の受動、emotional-power＝悲しみの通路が脂痕のみ）に照らし、(1) 盗人の自己欺瞞と娘の手の迷い・群像の個別の能動（血肉化）、(2) 中盤（第6章）の本人起点の能動、(3) 「沈める」選択の別の残骸、(4) 手の開示を「娘の意志の解放」として先に着地させる順序、(5) 悲しみの通路を声・鼻歌・手の感覚にも、を必須構想へ反映した。維持すべき「現像＝崩壊の世界法則」「手の反転」「愛を名指ししない抑制」は崩さない。
