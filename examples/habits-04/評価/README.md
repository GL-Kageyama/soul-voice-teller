### 匿名化について（実測）

`utils/anonymize.py` に `--title "ハビッツ！！！"` と `--title "ハビッツ"` を渡して実行。**赤字0件**であり、**前後はバイト単位で同一**（100,026 = 100,026）。**作品名は本文に一度も現れない**——ゆえにこの入力では、第一の盲は入力そのものが満たしている。
