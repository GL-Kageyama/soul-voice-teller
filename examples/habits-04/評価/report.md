> 第四巻の設計は、巻一・巻二・巻三と同型の分類（innovation）に、これまでで最も深い溝を伴って落ちた。current_value_score 58.33、hidden_potential_score 69.33。構造の次元——quality 76・theme-resonance 73・narrative-originality 72・world-building 67・admiration 67——が高く、人物の二次元が 29・29 で、四巻のうち最も低い。巻三の 41・36 からさらに 12 と 7 下がった。ただし下がり方は、巻三までの「設計が人物を書いていない」とは質を異にする。character-depth は自ら「人物が薄い」ではなく「人物が別の場所に置かれている」と書き、character-role は「引き受ける位置が、初めから空けられている」と書いた。すなわちこの巻は、人物の設計を怠ったのではなく、行為者の位置を名の書かれた物と手へ明け渡すことを選んでいる。同じ選択が、上位の次元を支えてもいる——形式の逸脱（narrative-originality の meaningfulness_of_deviation 78）と、抑制の徹底（theme-resonance の restraint 84）は、どちらもこの明け渡しの上に立っている。したがってこの報告の中心的な問いは「人物をもっと書くべきか」ではない。「行為者の位置を紙へ明け渡したまま、読者が感情と関心を預ける先をどこに作るか」である。その一点について、hook は「十八件の話末の引きが未決定のまま」を断線として上げ、emotional-power は「余白が変位になるか空無になるかは読者に委ねられている」と書き、admiration は「初読での着地は保証されない」と書いた。三体が別の入口から同じ賭けに触れている。

## 🤝 一致点

十体の一致は四点にある。第一に、この巻の設計は散文を一行も持たないにもかかわらず構造が主題を担っているという判断が全員に共通する——quality 76（anti-generic）・theme-resonance 73・narrative-originality 72 が高く、いずれも「前提から形式が演繹されている」という同じ筋で点を与えている。第二に、「名を目で読む者」の配分——主役から読む手へ、読む手から欄の空きへ、そして読む手の不在——が形式の骨格であることを、narrative-originality（form_deviation 75）・plot-architecture（disclosure_timing 70）・theme-resonance（restraint 84）・hook の四体が別々の語で指した。第三に、第十八話の宛名欄の空きと一行の余白が結びとして働いていることを、theme-resonance・emotional-power・hook の三体が一致して評価した。第四に、そして最も重い一致は、この巻の人物が動く主体の位置から外されているという判断である——character-depth 29 と character-role 29 が揃って最下位に落ち、emotional-power も「読者が感情を預ける主体が不在」と書き、hook も「乗り移りの先が人物の運命ではなく、読者自身が反復する読む行為そのものである」と書く。四体が四つの語彙で同じ空白を指した。

## 🎯 推奨アクション

1. 十八件の「話末の引き」のうち、少なくとも巻の前半九話ぶんについては、その話の記名の紙が次の話の記名へどう繋がるかを一行で決めよ。hook の赤旗「断線」と plot-architecture の弱点五が同じ箇所を指しており、この巻で最も具体的な修正可能点である。止まることを保ちながら、止まったあとに開く問いを一行だけ置く設計は、各話では解放しないという巻の規律と衝突しない。
2. 人物が何かを手放す（あるいは手放し損なう）一手を、動作の順序だけで各話に一つずつ置け。character-role の提案が最も具体的である——四針目で止まる話と、ほどいた糸を捨てずに箱へ入れる話は、犠牲の有無を分ける位置にある。内面を書かない規律は破られない。
3. 台帳にしかない動機の一行を、説明せずに本文へ置ける形（物の位置、手の止まり方、反復の位置のずれ）として各話に一つずつ設計せよ。character-depth の指摘——「動機の真実味が『台帳に一行がある』という外部参照で担保されており、評価対象の文書自身がその一行を提示しない」——は、四巻を通じて一度も閉じられていない構造上の穴である。
4. 二度目に立つ六話で、二度目を一度目の帰結として着地させよ。間の出来事を書かずとも、同じ癖が別の結果に届けば、選択が出来事を生む最小の形が立ち上がる（character-role）。同時に、二度目の重さを全員について「いちばん小さい動作」に均すことをやめ、誰の二度目が最も軽く、誰の二度目が最も重いかを決めよ（anti-generic-story-filter の赤旗「等価な扱い」）。
5. 各話の「止まる」に強弱の段階を設計せよ。感情の勾配が全話でほぼ一定であることは、emotional-power が挙げた弱点のうち最も直しやすいものである——止まる位置と、止まる直前に対象へどこまで接近するかを話ごとに変える（触れる／触れずに止まる／触れて離れる）。
6. 第十八話の宛名欄の空きの手前に、読者が持ち帰る一つの未決を一行だけ置け。hook の提案であり、admiration の弱点五（頂点の一文を場面表に置かないため、着地が実行に全額委ねられている）とも噛み合う。返却のあとの一章に引く力を残すことは、余白の決定を弱めない。
7. 名の存在論に限界・代償・失敗例のうち一つを置け。world_building の指摘——「何が起きないかは十八話ぶん定められるが、何ができないかがどこにも定められず、世界の輪郭が外側へ閉じない」——は、五巻を置かないと決めた以上、この巻の中で閉じるしかない。呼べば減る／置けば増える／書けば移るのうち一つでよい。
8. 基礎ルールを読者へ渡す場所を一話だけ定め、説明ではなく物の挙動として置け。world_building の赤旗であり、narrative-originality の弱点二（「閉じられていることを読者が数える手がかりが本文の側に置かれないため、禁が守られていても破られていても、読者には同じ平坦さとして届く」）と同根である。禁を数える装置を一つ置けば、欠けは不在ではなく設計として読まれる。

## 🔧 次回の修正方向（`逐次確認（confirm）`）

> 第四巻は、四巻のうちで最も深い明け渡しを行った巻である。行為者の位置が人物から、名の書かれた物と、それに触れた手へ移され、その一点から形式の逸脱（narrative-originality 72）と抑制の徹底（restraint 84）が同時に立ち上がっている。代価は人物の二次元（29・29）であり、これは巻三の 41・36 からさらに下がった。ただし下がったのは「人物が書かれていない」からではなく、「人物が別の場所に置かれている」からである。したがって次に動かすべきは人物の内面ではなく、明け渡した位置の外側に、読者が預ける先を一箇所だけ作ることである。具体的には、話と話のあいだ（話末の引き）と、人物が手放す一手と、ルールを読者へ渡す場所の三点。いずれも巻の規律——内面を置かない・解放しない・運搬は運ばない——と衝突しない形で置ける。

**上げる／変える**:
- 十八件の話末の引きのうち、少なくとも前半九話ぶんを一行ずつ定義する（止まることを保ちながら、開く問いを一つ置く）
- 人物が何かを手放す（手放し損なう）一手を、動作の順序だけで各話に一つ置く
- 台帳にしかない動機の一行を、説明せずに本文の構造として各話に一つ置く
- 二度目の六話を一度目の帰結として着地させ、二度目の重さを話ごとに差のあるものにする
- 「止まる」に強弱の段階を設計し、十八話の感情の勾配を一定でなくする
- 第十八話の空きの手前に、読者が持ち帰る一つの未決を一行置く
- 名の存在論に限界・代償・失敗例のうち一つを置き、世界の輪郭を外側へ一度閉じる
- 基礎ルールを読者へ渡す場所を一話だけ定め、禁を数える手がかりを本文の側に置く

**維持すべき**:
- 語り手を人ではなく頁に置き、頁は読まないとする一行から全形式を導く構成（narrative-originality・theme-resonance・plot-architecture が一致して最高点を与えた）
- 一人称・二人称・内面・回想・記憶の四つの通路を閉じ、書けないのではなく欄がないと言い切る規定（theme-resonance が restraint 84 を与えた中心）

- 返却を第十七話に置き、そのあとに全六十三話で最も長い第十八話を敷く構成（admiration・hook・plot-architecture が評価）
- 「口は、訊く形に動いて、音にならなかった。」を場面表に置かない決定（emotional-power が「感情の最大点を演出の外へ守っている」と評価）
- 宛名欄の空きとその下の一行の余白で閉じ、第五巻を置かないと定める結び（theme-resonance・emotional-power・hook が一致して評価）
- 名の持ち主を四巻を通じて回収しない規則（pain ではなく設計として三体が支持）
- 六名の担い手と六つの市区を、主役回と二度目で一字も違わず対応させる索引（world_building が internal_consistency 76 の根拠とした）

## ⚠️ 注意点

- content_type: plot のため prose-style, narrative-technique, reader-experience の三体は未招集（次元が不適合）。それぞれの次元は story_vector 上で null とし、集計から除外した（0 としては数えていない）。
- full mode のため、各次元は単一の評価者が採点しており、次元ごとの分散はすべて 0.0 である。実質的な不一致は disagreement_map に記録した。render_report.py は分散 0 を「不一致なし」と表示するため、不一致の所在は本 JSON の disagreement_map を直接読む必要がある。
- character-depth の出力は value_vector_contribution の 13 鍵のうち character_role を欠いていたため、欠落鍵を null として補完した。他の 12 鍵と primary_score（29）は評価者の出力どおりであり、意味の変更は行っていない（Phase 2.5 の検証は構造のみを見るため、この補完は検証を通過した後に行った）。
- plot-architecture の narrative に一字の転記ゆれ（「代価」）があり、書き込み時に修正した。語の選択は評価者の出力と同一である。
- 個々の評価者レポートは評価者エージェントの応答を転記して保存したものである。validate_output.py は構造のみを検査するため、長い自由記述欄の語句の揺れは検出できない。転記は Write ツールで行い、heredoc 経由の揺れは避けた。
- Phase 2.5 の検証では、十体すべてが一度で valid=true を返した。再生成（最大3回）および手修正は一件も発生していない。excluded_evaluators は空である。
