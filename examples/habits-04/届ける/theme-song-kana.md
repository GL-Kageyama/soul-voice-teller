# 歌詞——かな版（Suno の読み違いを減らす）／第四巻『書いていない名』

> 出所: [`theme-song.md`](theme-song.md) §2 の歌詞。**語も行も読点も、そのまま**——変えたのは、**漢字をかなに開いたことだけ**である。**Suno に渡すのは、下の歌詞欄だけ**（情景・註は渡さない）。曲名・曲調・声・置き場は `theme-song.md` のまま動かさない。
>
> **もう一つの候補**——[`theme-song-mix.md`](theme-song-mix.md)＝**危ない語だけ開き、常用漢字は境界の杭として残す版**。三つ（漢字・かな・混ぜ）の聞き比べ方は [混ぜ版 §三つを、どう比べるか](theme-song-mix.md) にある。

## 読みの決め方（迷う語だけ）

| 語 | 読み | なぜ |
|---|---|---|
| 行 | **ぎょう** | 紙の上の一行。**いき・ゆき ではない**——この歌の「行」は、名の並ぶ行そのものである |
| 頁 | **ページ** | この作品は頁を「ページ」と読む。カタカナのまま置いた |
| 端 | **はし** | 紙の端。**そば ではない** |
| 指の腹 | **ゆびのはら** | 腹を ふく と読ませない |
| 五本 | **ごほん** | 数字を使わない |
| 余白 | **よはく** | — |
| 埃 | **ほこり** | — |
| 側 | **そば** | 紙の側（かたわら）。**がわ ではない** |
| 二枚目 | にまいめ | 数字を使わない |
| 一枚 | いちまい | 同上 |

## ⚠ これで直ることと、直らないこと

**直ること。**

- **漢字の読み違いは、起こらなくなる。** 「行」を いき と読む、「側」を がわ と読む、「腹」を ふく と読む類の事故は、この版では起きない。
- **「名」を「な」と開いたことで、この歌の寸法の語が揃う**——**おおきさ・ながさ・はし**。名は な であり、**大きくも小さくもない一音である。** これは偶然ではなく、この歌が名を名指さずに寸法だけを歌うことの、音の側の帰結である。

**直らないこと。**

- **区切りと息継ぎは、かなでも指定できない。** 「なのしたのよはくは」「おなじおおきさで」のような連なりは、区切りの推測を誤りうる——ただし、誤っても音は同じである。
- **アクセント・長音・促音の伸ばし方は、保証されない。**
- **旋律・テンポ・声は変わらない。** それらは `theme-song.md` §3・§4 の担当である。

**この版を使うときに、数え直さないこと。**

- `theme-song.md` の**「名」9・「誰」0・「声」1・「頁」1** などの**文字の実測は、漢字版のものである。** かな版では「名」が「な」になるので、**同じ数え方はできない。** 検品の表は、**漢字版に当てる**。
- **モーラは変えていない。** サビの 14・14・13・15・7・7、フックの 7 は、この版でも同じである。

**⚠ まだ試していない。** この版で Suno が実際にどう歌うかは、**一度も生成していない。** 漢字版と聞き比べて、**読み違いが減ったかどうかを、耳で確かめるほかない。**
