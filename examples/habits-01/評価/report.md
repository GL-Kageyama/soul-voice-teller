## 🤝 一致点

十名の有効評価者が以下で一致する。(1) 「名は呼ばれた回数でできている。ゆえに呼ばれない名は消えない——置かれる」という一条の存在論が、十四話すべての記名の現場と「名を目で読み、手が止まる」一拍を駆動している（narrative-originality, theme-resonance, world-building, emotional-power, anti-generic-story-filter, hook）。(2) 動きが全話「紙を一枚めくる手前で止まる」と定められ、運搬が一度も完了しない——この反復が巻の律動そのものになっている（hook, character-role, theme-resonance, anti-generic-story-filter, admiration）。(3) 記名の「紙の配当」——同じ出席簿の同じ転出欄でも、開く欄を話ごとに一つに限定し、巻をまたいで重複を禁じている整合の統制は、この規模の設計として稀な水準にある（world-building, narrative-originality）。(4) 助詞一つが第一話では文頭に置かれ第十三話で文末に落ちること、地の文に呼びかけが一度も出ないこと——主題が内容ではなく文法の水準に置かれている（theme-resonance, admiration, narrative-originality）。(5) 頂点の第13話が「その字、誰の字。」という一つの行為に絞られ、返却のあとに第14話を残す配置が、解決で締める型を意図的に拒んでいる（admiration, hook, emotional-power, plot-architecture）。一致は構造の達成（前提と形式の一致・紙の配当・文法水準の仕掛け・非解放）に集中し、不一致は「反復を形式と読むか手順と読むか」「止まることを能動と読むか凍結と読むか」に集中する。

## 🎯 推奨アクション

1. 人物の次元（character-depth 42・character-role 45）が十名中最低の二席であり、しかも構造の次元（theme-resonance 73・narrative-originality 72）と40点近く開いている。改稿の優先順位は構造ではなく人物に置くべきである——構造の側は既に十名の過半が達成として認めている。
2. 「この巻では超えない、掴ませるだけである」という反応軸の決定を、一度だけ破ることを検討する。admiration の43はこの一行を減点の根拠に挙げており、超出が一巻の中に一度も放電しない設計は、連載の設計としては正当だが、一巻を単独で読む読者には何も返さない。
3. 第十四話の書き直しが第八話の「一年で消える」という決まりをどう書き換えるかを、`?` のまま残さず一行だけ決める。admiration と theme-resonance が独立に、ここが巻内で唯一「なるほど」を得られる位置だと指摘している。
4. 地の文に呼びかけが一度も出ないという仕掛けを、初読の読者にも身体的な違和として届かせる工夫を検討する。hook の68は、気づかれない欠けは引く力にならず、これは再読の装置であって初読のフックではないと指摘した。
5. 各話の話末の引き十四件を、すべて「紙がどこへ置かれるか」の一点に揃えず、置き場所・読む者・残る時間のいずれかを話ごとに選ぶ。hook は、すべての継ぎ目が同じ問いを立てるとき、その問いは未知ではなく型になると述べている。
6. 第二の主要人物の初出が第十二話と第十三話に二話続いている点を、どちらか一方に寄せる。hook が、頂点の会見が持つ未知を一話分先に消費していると指摘した唯一の間合いの粗である。
7. 巻末の最大の分岐で採らなかった側（人称が失われる側）が、この作品に何を失わせたのかを一行だけ書き残す。anti-generic-story-filter は、採らなかった側の損失が記録されていないため選択が最適化として読まれると指摘した。
8. 人物の深さを「説明の量」ではなく「名をめぐる席に立っている時間の長さ」で配分している非対称を、設計の意図として明記するか、主役回の六話に均等配分を崩す差を与えるか、どちらかを選ぶ。両方を曖昧にしたままでは、均等そのものが検算の美点として報告され続ける。

- 名を読む一拍の反復に強弱をつける（一拍の長さが最短の話と最長の話を巻の前後半に一つずつ明示的に置く）

- 語り手の七つの癖を、名を読む・止まるという同一の能動の原理の変奏として一行で束ねる

**維持すべき**:
- 「名は呼ばれた回数でできている」という一条の存在論と、記名の現場を毎話一つ置く形式

- 会話のない話を五話置く配分と、音を呼び声ではなく紙と手の音にする手触り

## ⚠️ 注意点

- content_type: plot のため prose-style・narrative-technique・reader-experience の三名は未招集（次元が不適合）。散文は一行も存在せず、文体・語りの技法・読書体験は本評価の対象外である。三名が担当する次元は story_vector 上 null であり、集計から除外される（0として数えない）。
- 入力は執筆前の設計文書であり、`?` は著者が意図的に残した未決定の印であって欠落ではない。したがって本評価が測っているのは実現された価値ではなく、設計が約束する価値である。実装によって主題が痩せる危険は、theme-resonance が自ら減点材料として挙げている。
- full mode では各次元を単一の評価者が採点するため、次元内分散は構造的に0となり、形式上の disagreement_map は空になる。実質的な不一致は本節の disagreement_map に評価者間の言明として保存した（評議会の記憶にある既知の挙動: full mode の実質的不一致は disagreement_map を見る。renderer は「不一致なし」と表示する）。
- 十名すべてが individual classification で discovery_target を付けたが、議長の集計（current 58.0 / hidden 70.33）は innovation となる。この差は、各評価者が担当次元の内側で厳しく採点する一方、集計が次元をまたいで平均するために生じる。個々の席の判断は individual_reports を参照すべきである。
- current_value_score は45以上の閾値にあるが、内訳では人物の次元だけが閾値未満である（character-depth 42・character-role 45）。この偏りは「構造は実装されており、人物は設計されていない」という一つの読み方を支持する。
- 採点は意図的に厳しい基準（「読める」では50未満）に従っている。絶対値は低めに付くため、閾値は相対的な道標として読むべきである。
- anti-generic-story-filter は quality 次元を担当するため、本巻に対する「文学的な平均への最適化」という警告（58）は current_value_score の構成要素そのものである。
- 評価者十名の出力はすべて validate_output.py の検証を通過した（excluded_evaluators は空）。
