# 歌詞——混ぜ版（Suno の読み違いを減らす・危ない語だけ開く）／第一巻『残った名』

> 出所: [`theme-song.md`](theme-song.md) §2 の歌詞。**語も行も読点も、そのまま**——変えたのは、**読みを外しやすい語だけを、かなに開いたこと**である。**Suno に渡すのは、下の歌詞欄だけ。** 曲名・曲調・声・置き場は `theme-song.md` のまま動かさない。
>
> **⚠ これは仮説の版である。** 「Suno が読みを外すのは、複数読み・珍しい読みの語に偏る」という見立てに立っている。**まだ生成していない。** 全部かなの版（[`theme-song-kana.md`](theme-song-kana.md)）と聞き比べて選ぶための、三つ目の候補である。

## 開いた語（これだけ）

| 語 | 開いた形 | なぜ開いたか |
|---|---|---|
| 六つ・二つ | むっつ・ふたつ | **数字**。Suno が ろくつ・につ と読みうる |
| 端 | はし | **複数読み**（はし／はじ／たん） |
| 行 | ぎょう | **複数読み**（ぎょう／いき／ゆき／こう） |
| 出席簿 | しゅっせきぼ | **珍しい複合語** |
| 転出欄 | てんしゅつらん | **珍しい複合語**。てんしゅつば と読みうる |
| 名札 | なふだ | めいふだ と読みうる |
| 三文字 | さんもじ | さんもんじ と読みうる |

## 漢字のまま残した語（境界の杭）

**机・椅子・扉・棚・段・幅・両手・名・欄・手前・手・声・字・紙・表紙・字・胸・印刷・毎朝・今日・読む・書く・呼ぶ・閉じない・浮く**——**常用の読みしか持たない語、または文の骨格になる語**である。**日本語は分かち書きしないので、これらの漢字が語の切れ目を教える。** 全部かなにすると、この杭が全部抜ける（[`theme-song-kana.md`](theme-song-kana.md) の側の弱点）。

## 三つを、どう比べるか

1. **同じ条件で三つ作る。** Style・Vocal・Exclude は `theme-song.md` §3・§4 のまま**一字も変えない**。変えるのは Lyrics 欄だけ。
2. **まずサビだけで試す**（短く、回数が少なく済む）。`[Chorus]` の四行＋「閉じない。」二行を、**漢字版・かな版・混ぜ版**の三つで一回ずつ。
3. **聞く点は三つ**——**読み**（事故が消えたか）・**区切り**（息継ぎが不自然でないか）・**旋律**（変わっていないか）。
4. **決め手は通しで二本。** サビで差が付かなければ、漢字版と混ぜ版を、通しで一本ずつ。

## ⚠ この版の弱点

- **開かなかった語が、外れる可能性は残る。** 常用漢字でも Suno の辞書が外すことはある——**この版は、その危険をゼロにしない。** 全部かなの版だけが、それをゼロにする（代わりに区切りの危険を負う）。
- **開いた語の境目が、新しい曖昧さになる。** 「そのぎょうは」「しゅっせきぼは」のように、かなと漢字が混ざる位置は、Suno にとって区切りの手がかりが減る。**ただし、漢字が両側に残っているので、全部かなよりは情報が多い。**
- **まだ試していない。** この版が三つの中で最も良いという保証は無い。**耳で決めるほかない。**

## 数え直さないこと

`theme-song.md` の文字の実測（「名」4・「誰」0 など）は、**漢字版のものである。** この版では一部がかなになっているので、**同じ数え方はできない。** モーラは変えていない（サビ 9・10・10・10、フック 4）。
