# package：読者への包み

> 対象読者: 疾走感とユーモアを好む。笑ったあとに何かが残る短編を読む。職人の意地と、言い出せなかった関係に心当たりがある人。
> すべての包みは、この読者の第一印象に照合する。嘘をつかずに釣り、届けるものを約束し、開示の手前で止まり、余白を残す。

## タイトル＋サブタイトル

**きつねそば、湯気のうちに**
五十年、一度も届けなかった家へ

- 主タイトルは作品の名をそのまま（置き換えない）。きつねそば＝魂の物、湯気のうちに＝時間の約束。
- サブタイトルは前提のフック。「一度も届けなかった」が問いを立てる（なぜ？ 誰の家？ 今夜どうなる？）。名を説明しない。

## キャッチコピー（帯）

> 五十年ぶりの出前。湯気は、まだ、立っている。

- 「五十年ぶりの出前」で事実のフックを立て、帯は本文のリフレイン「湯気は、まだ、立っている」そのもの。読者はこの行を帯びて頁を開き、最終行で再会する（魂の先送り）。感情は名指さない。

## あらすじ

### 背表紙用（短）

雨の秋の夕暮れ。そば屋「一力」の職人・源三は、風邪で倒れた息子の代わりに、五十年ぶりに一人で出前に出る。注文は「きつねそば」。それは源三が初めて打ったそばで、メニューにもない。届け先は、五十年、一度も出前を届けたことのない、ただ一軒の家。湯気が立つうちに、届くか。

### web 用（中）

雨の秋の夕暮れ、そば屋「一力」。店主の息子・祐一は風邪で寝込み、店に残ったのは職人の源三だけ。六十四歳、出前を一人で走るのは五十年ぶりだ。

電話が鳴った。注文は「きつねそば」。一力のメニューに、そんなそばはない。それは源三が五十年前、初めて打ったそばで、褒めたのはたった一人だけ。それ以来、一度も打っていない。

そして宛先。坂の上の、蔦のある家。源三が五十年、一度も出前を届けたことのない、ただ一軒の家だった。

雨の商店街を、源三は走る。そばが冷めないうちに、湯気が立つうちに。工事の封鎖、強まる雨、水の川。町の人々の手を借りずに、源三は坂を上る。

湯気が消える前に、届くのか。ドアの向こうで、誰が待っているのか。

## 画像生成プロンプト

### 表紙

昭和の雨の夕暮れ、秋。商店街の坂道を、老職人が前かがみに走る。頭に風呂敷で包んだ丼を載せ、前掛けと草履、濡れた背中。丼から白い湯気が一本立ち上る。街灯と店のネオンがぬれたアスファルトに映り、空は深い藍色、雨の筋。構図：後ろ姿をやや低い位置から、奥に坂と灯り。画風：日本の昭和ノスタルジーの絵画風イラスト。柔らかい光、大きな余白、疾走感。寂しさと温かさ。

### キー場面（ドア・感嘆の間）

雨の夜の玄関。開いたドアのあたたかい光を背に、白い髪の痩せた老人が立つ。その向かいで、うつむいた老職人が両手で丼を差し出す。二人の間に、立ち上る湯気。構図：二人を横から、間の湯気を中心に、静かな間を大きく取る。画風：表紙と同系の画風。藍と暖色の対比、影と光。派手にせず、静けさで受ける。

## 検品（包みの四則 × 一つの魂）

| 四則 | 判定 |
|---|---|
| 嘘をつかずに釣る | フックはログラインと本文の実在だけから（五十年・一度も届けなかった・きつねそば・湯気）。流行ジャンルの定型はつけない |
| 届けるものを約束する | 疾走×ユーモア×静かな余白。本文が実際にすることを置く。派手さは約束しない |
| 正体開示の手前で止まる | あらすじは「ドアの向こうで、誰が待っているのか」で止める。**兄・宗一・きつねそばの意味は明かさない**（場面5の感嘆を温存） |
| 抑制は包みにも及ぶ | 帯・あらすじに感情の名指しなし。「届けたい」も「再会」も書かない。余白は「湯気は、まだ、立っている」に預ける |

一つの魂、多くの扉。タイトル（きつねそば×湯気）・サブタイトル（届けられなかった家）・帯（湯気のリフレイン）・あらすじ（雨の疾走と間合い）・絵（走る背中／ドアの間）は、すべて「五十年の未決着が、湯気の立つうちに走る」という一つの魂に開く。扉は違えど、約束・調子・声は同じ作品に一致している。
