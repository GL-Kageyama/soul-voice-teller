## この話で、動かさないもの

- **名の欄を、作らない。** 値引きシールには、**名を書く場所が用意されていない**（台帳）。**欄を足す行を、置かない。**
- **「ゆみ」の字を、置かない。** 誰にも呼ばれない名である。**記名の紙に、その名は書かれ得ない**（台帳。同じ run の二十三番からの混入が、訂正済みである）。
- **パートは、何も言わない**（台帳の規律）。**言い合うのは、第3話である**——この巻で「言い合う」のは、傘の数の回だけである。
- **主役は、読まない。** 名を目で読む者は**暮林蒼**である（[`../話割り.md`](../話割り.md) の決定 2026-09-16）。**高橋由美は、名のそばに立つ**——**置き直す手が、その位置である。**
- **暮林蒼が、この現場に居る理由を、書かない。** `?` のまま（[`../話割り.md`](../話割り.md) の「この巻に残る `?`」）。

**惣菜部門の夕方——この話の設計上の判断。** 出典は「貼る前に、一度置き直す」（run-09）と、動き・会話（run-10 第2話）までしか言わない。**時刻を書いていない。この話の三場面を、川口市の一つの夕方に置く**——**値引きシールが貼られる時間帯である。** **三場面は、同じ台のまわりで起きる**——**移るのは、パックだけである。**〔設計〕

## 検算

- 1,300＋1,800＋1,300＝**4,400**——話割りの字数と一致する。
- **内面の欄は〔実測〕である**——[`../../草稿/draft_02-02_名の欄がない.md`](../../草稿/draft_02-02_名の欄がない.md) の三節を読んだ。**第一場面＝B**（02-02:19「時刻は、店ごとに、少し、違う。この仕事では、その、時刻を、覚える。」）／**第二場面＝A**（02-02:113「僕の、目が、その、面に、入る。」）／**第三場面＝C**（02-02:285「私は、この、あいだに、口を、出しません。」）。**⚠ 執筆の前に決めた値ではない**——**書かれた本文から読んだ値である**（同 §5g）。**✅ 2026-09-21——本文から読んだ値は、三節とも〔設計〕の値と一致した。**
- **✅ 2026-09-21——この行は〔設計〕のものである。** **本文を書く前に決めた値と、その理由づけである**——**いまの欄の値は、上の〔実測〕の行に在る**（C-18 の実施細目1。[`../../../habits/構想/内面の規律_破棄と置き換え.md`](../../../habits/構想/内面の規律_破棄と置き換え.md) §5g）。**第一場面＝B**（**この仕事ではこうである**——**値引きの時刻であり、「貼る前の一度」という作法が置かれる節である**。四人が居る場でもある）／**第二場面＝A**（**一拍の位置。「台の縁に置き直す」「暮林蒼の目が、シールの面に入る」——身体に起きたことの報告が、一拍の中身そのものである**。**⚠ この節は「名の欄を見つけたかどうかを、書かない」と定められている**——**発見を名指しできない節では、A の形（感覚の報告）だけが、発見の代わりに立つ**。**⚠ この節に C を置けない**——**この節の記名には、名の欄が無い**——読む対象がまだ無く、「読まない」も「声に出さない」も、何も指さない）／**第三場面＝C**（**「読むだけで、声に出さない」——台帳の規律が、そのまま為まいの宣言になる**。**四人の沈黙を破らないことが、反応軸の「解放しない」である**）。
- **⚠ この話の順序も、書けた三話の実測から、一つずれている。** **三話とも、第二場面が C である**（02-08・02-09・02-10）。**この話は第二場面に A、第三場面に C を置く**——**第1話と同じ順序である**（第1話も B・A・C）。**⚠ `n=3` の一致は規則ではない**（同 §5g）。**⚠ 第1話と第2話で二度続いたことは、三話目の一致に何も足さない**——**それも、`n=3` の側は動かない。**
- **機構2（ずれの自覚）の置き場は、この話では決めていない**——**未決である**（同 §9 の未決9）。**⚠ 置き場が何を指すかは、二つに読める**——**(い) 節の内面に「気づいているが、決まらない」が現れる場所**／**(ろ) その巻で、それを誰に与えるか**。**裁定5 が定めるのは (ろ) だけである**（**与えるのは中核四人のみ**）。**⚠ この話は主役回である**（高橋由美——[`../../../habits/台帳/人物/サブ/03_高橋由美.md`](../../../habits/台帳/人物/サブ/03_高橋由美.md)）——**ゆえに、この話の主題はサブの側の人物にある**。**⚠ ただし、この場面表の「内面」の欄が、誰の内面を指すかは、実施細目が定めていない**——**書けた三話では、いずれも語り手（暮林蒼）の側から読んだ値である**（02-08・02-09・02-10。同 §5g）。**ゆえに (い) の読みでは、主役回であることは、置き場を禁じない。** **⚠ 禁じるのは (ろ) である**——**サブの人物に機構2 を与えること。** **この区別は、2026-09-20 に私が潰していた**（同 §9 の未決9）。**⚠ 欄が誰のものかは、決まっていない**——**未決9 の側に含まれる。**
