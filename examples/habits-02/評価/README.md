### 規則——本文評価を回すときは、直前に写しを取る

**⚠ 五単位（系列1＋巻4）は `input-anonymized.md` の写しを持っている。本文評価だけが、その作法から外れていた**——**生きた草稿をそのまま入力にした。**

**以後、本文評価を回すときは、入力の直前に写しを取り、評価ディレクトリに置く。** **⚠ 評価の後で本文が動いた場合、写しは動かさない**——**差は申し送りに逐語で書く**（**M-1 がその先例である**）。

**⚠ 第8話の写しは、この規則より前の回なので、起こさない。** **後から作った写しは「評価者が読んだ本文」ではなく、一字を戻した再構成物である**——**その区別がつかなくなるほうが、再現性より高い代償である。**
