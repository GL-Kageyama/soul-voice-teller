## ⚠️ 注意点

- 【評価者の起動方法の逸脱】評価者定義（agents/*-ja.md）は frontmatter で tools: [] を持ち、本文の Output Format にも「ツール呼び出し・ファイル読み込みは一切禁止」とある。したがって評価者エージェントを直接起動して本文パスを Read させることはできない（実際に13体すべてが tool_uses: 0 で崩れた）。本実行では general-purpose のラッパーに評価者定義ファイルと本文を Read させて評価させた。人格・評価基準・出力形式は定義ファイルをそのまま読ませているが、起動方式は定義の想定（本文をメッセージで受け取る）と異なる。この逸脱は本実行の全評価者に共通である。
- 【議長の文脈に本文を読み込んでいない】評価者には本文のファイルパスを渡し、Read させた。議長（統合側）は本文を読んでおらず、統合は評価者の報告のみに基づく。
- 【full mode の構造的限界】十三名を招集したが、各次元を採点したのは各一名である。したがって story_vector の per-dimension 分散はすべて 0 であり、disagreement_map は分散の閾値（100/400）によってではなく、評価者間で実際に割れた読みと expected_disagreement_points に基づいて構成した。variance フィールドは null としてある——0 と書けば「一致」を意味してしまうため。
- 【一件の再生成】prose-style の初回出力は JSON 構文エラー（文字列内の生の制御文字）で validate_output.py が INVALID を返した。方針どおり手で直さず再生成し、二度目は VALID。再生成でスコアが 72 から 77 へ動いた（rhythm 68→80、voice 73→83、sensory_texture 72→74、verbal_precision 78→71）。同一本文・同一評価者でこの幅が出たことは記録に値する。他の十二名は一発で PASS した。
- 【評価者は設計を知らない】評価者に渡したのは本文と一行のメタ（連作の約束・この一話だけを読んでよい旨）のみである。設計文書は一切渡していない。ゆえに「一枚で止まる理由が書かれない」「暮林蒼がこの現場に居る理由が書かれない」という指摘は、それが設計上の決定であることを知らないための所見でありうる。
- 【単位の切り方】これは一話単体の評価である。連作の約束（名の書かれた紙・扱う癖・一拍）は検証していない。単体の読者と連作の読者では、同じ一行の値が変わる——この差は本レポートのどこにも反映されていない。
- 【測っていないこと】他話との比較、第二巻の中での第9話の位置、第三巻への伏線（段差）、映像・ビジュアル層との整合は、いずれもこの評価の担当外である。
