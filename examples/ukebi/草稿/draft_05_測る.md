# 第5章「測る」／器官・耳

境には秤があった。魂の重さを測るための。転生先を決めるために。

送り火は、耳を動かす。八つの器官の、五つ目。針の傾きを聞く。魂の重さで送り先が決まる。重い魂は遠くへ、軽い魂は近くへ。針の傾く音を聞く。傾く音で重さを知る。それが境の営みだった。

魂が秤にかかる。皿がわずかに沈む。針が傾く。重い魂ほど、針は遠くへ傾く。軽い魂ほど、針は小さく揺れる。送り火は、耳を澄ませる。針の軋む音を聞く。目では見ない。耳で測る。重さというものは、音になって耳へ届く。

送り火は、これまでいくつもの魂を、この秤で測ってきた。測れる魂だけを測ってきた。測れない魂は、この境には来なかった。

少女の重さは、秤の針を振らせなかった。

該当なし。

針は振れなかった。皿は沈まなかった。彼女はどこにも送られない。重くも軽くもない。値のつかない魂が、秤の皿の上に立っている。針はまっすぐ真上を指している。動かない。音がない。測るための耳は、測るべき音をひとつも聞かない。

送り火は、これまでいくつもの魂を、この秤で測ってきた。測れる魂だけを測ってきた。測れない魂は、この境には来なかった。少女が来るまでは。

少女が秤を降りる。

そして手を伸ばす。彼の腕に触れる。秤ではない。手で測る。指が彼の手首をかるくつかむ。重さのない者が重さを問う。

手首をつかまれて、送り火は、初めて自分の重さを知る。手首の骨のかたさを知る。測るはずの耳は、いま測られていた。手で。

境で、誰も彼を測ったことがなかったのに。少女だけが、彼を測ろうとした。

耳が、止まる。

「あなたの重さは」

この魂は、まだ誰にも名付けられていない。
