# 第2章「綴じる」／器官・指

境には、台帳があった。送り火は、魂を送る前に、名を、一頁に綴じる。それが、二つ目の器官の、仕事だった。台帳の紙は、乾いていて、頁をめくるたびに、かさりと、音がした。境には、音が、ない。だから、紙の音だけが、聞こえる。

一冊も読まれなかった作家の魂火が、届く。結城文、という。手の指に、ペンだこがある。書いて、書いて、一度も読まれなかった指が、青白い火になって、台帳の前に浮かんでいる。火は、頁を、めくりたがるように、揺れていた。火のなかには、書かれたのに読まれなかった頁が、何枚も、入っている。送り火には、それが、見える。

彼は、生涯、いくつの頁を、書いたのか。その頁は、どれも、閉じたままだった。読まれることを、待って、待って、白いまま、誰かの本棚で、埃をかぶった。それでも、書くのを、やめなかった。読まれなくても、書いた。読まれるためにではなく、書くことが、彼の呼吸だった。その指の、ペンだこが、それを、語っている。ペンだこは、火のなかで、硬く、光っている。送り火には、そのだこが、見える。

送り火は、指を動かす。八つの器官の、二つ目。台帳を開き、魂を、一頁に綴じる。指が、頁を、押さえる。ペンが、名を、記す。結城文という名は、頁の上に、一行、記される。紙は、乾いている。墨は、紙に、すうっと、吸われていく。それで、終わりのはずだった。送り火は、これまで、いくつもの名を、この台帳に綴じてきた。綴じる。綴じて、送る。それが、境の、営みだった。綴じられた頁は、閉じられる。閉じることが、綴じることだった。誰にも、開かれない。

指が、台帳の、最初の頁に、触れる。

頁は、白紙だった。

「読んで」

結城文の魂火が、言う。

送り火は、頁を読もうとする。読めない。綴じる指は持っていても、読む指は、持っていなかった。誰かの頁を、読んだことが、なかった。誰かに、読まれたことも。白い頁は、白いまま、彼の指の下で、じっとしている。文字は、ない。それなのに、頁は、読んでほしいと、震えている。紙の、かさり、という音が、震えているように、聞こえる。綴じる指が、初めて、読む、ということを、知りたがる。

指が、止まる。

白い頁が、一枚、彼の指の下で、まだ、震えている。

この魂は、まだ誰にも名付けられていない。
