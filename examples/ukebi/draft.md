# 序章「迎え火」

あなたは、踏切に立っている。

線路は、どこにも続いていない。駅にも、町にも。レールの錆だけが赤く光って、踏切を誰も渡らない。遮断機は上がったまま、ずっと動かない。雨は降っていない。けれど空気は濡れていて、音はみな、遠い。自分の足音も、息の音も、遠い。ここには、誰も来ないはずなのに、あなたは、立っている。いつから立っているのかも、わからない。それでも、この踏切を、渡れない。

渡った先に、何があるのか。あなたは、知らない。知りたいとも、思わない。ただ、遮断機の上がった踏切の上で、あなたは、立っている。立っていることが、仕事のように。

線路の向こうから、火がひとつ、流れてくる。

青白い。魂火。誰にも教わっていないのに、あなたはそれを知っている。火は、レールの上をすうっと滑ってきて、あなたの前で、止まる。まるで、あなたの顔を、確かめるように。火のなかには、誰かの一生が、入っている。生まれて、生きて、死んだ。それだけのものが、青白く燃えて、あなたを見ている。

たとえば、歩き疲れて斃れた旅人の火には、土の色がついている。読み手のいなかった書き手の火には、ペンだこの形が、残っている。抱き上げられたことのない子の火には、伸ばした両手が、見える。火は、どれも、人のかたちをしていない。それなのに、火を見ると、その人の死に方が、わかる。

火の後ろから、名のないものが来る。

魂たちは、それを「送り火」と呼ぶ。八つの器官を、ひとつずつ、淀みなく動かして、魂を転生へ送る。手が火をすくい、指が台帳の頁をめくる。喉が上下し、腕が火を抱える。耳が傾き、目が火を透かす。声が低く響き、背が火を見送る。どれにも、淀みがない。今日も。昨日も。最初から、ずっと。ひとつの魂を、ひとつの器官で、ひとつの動詞で、処理する。それが、境の、営みだった。

送り火は、あなたの前を通り過ぎる。

そのとき、見えてしまう。喉の奥に、何かがひとつ、留まっているのが。どの器官も、それを処理できない。どの動詞も、それを動かせない。八つの器官のどれにも当てはまらない何かが、喉の奥で、静かに、燃えている。最初から、あったもののように。ずっと、燃やし続けてきたもののように。

送り火は、それに、気づいていない。

あなただけが、見えている。

この魂は、まだ誰にも名付けられていない。


# 第1章「送る」／器官・手

境には朝がない。けれど、仕事の始まる時刻だけは、あった。送り火は、線路の上に立ち、向こうから来る火を待つ。今日も、昨日も、最初から、そうしてきた。待つことと、送ること。それだけが、彼の一日だった。

旅路で斃れた女の魂火が、届く。幸恵、という。土の、色を、している。歩き疲れて、道の傍らで動かなくなった魂が、青白い火になって、線路の上を滑ってくる。行く先を、見失った火のようだった。火のなかには、歩き続けた足と、乾いた喉と、届かなかった場所が、入っている。送り火には、それが、見える。

彼女は、どこへ行こうとしていたのか。その足は、いくつの国を、越えてきたのか。送り火には、わからない。ただ、火のなかの足が、まだ、先へ進もうとしているのが、見える。乾いた喉が、まだ、水を求めているのが、見える。届かなかった場所が、まだ、彼女を待っているのが、見える。送り火は、それらを、見るだけだ。見て、そして、送る。

送り火は、手を動かす。八つの器官の、最初のひとつ。手は、魂火を取り、掲げ、流れへ送る。転生先へ。異世界へ。すくう手は、淀みなく、火を包む。火は、抵抗しない。どの魂も、抵抗しない。送られることを、待っていたように。手のひらの上で、青白い火が、ほんの少し、明るくなる。幸恵という名は、台帳の一行に記され、火は、レールの先へ流れていく。この仕事に、淀みはない。今日も、昨日も、最初から、ずっと。魂が送られるたび、線路の向こうが、少しだけ、明るくなる。

「あなたは、誰に送られるの」

女の魂火が、声を上げる。

火は、もう、手のひらから離れていた。それなのに、声は、戻ってきた。レールの先へ流れていったはずの火が、送り火の、手のひらへ、問いを、置きに来る。

送り火は、答えない。答えというものを、持っていなかった。誰にも、問われたことが、なかった。彼は、送る。送られる、ということが、どういうことなのか。誰かに手を取られて、向こうへ渡されるということが、どういうことなのか。それを、知らない。すくう手を持っていて、すくわれる手を、持ったことが、ない。

手が、止まる。

送るだけだった手は、いま、何かに、掴まれることを、知る。

この魂は、まだ誰にも名付けられていない。


# 第2章「綴じる」／器官・指

境には、台帳があった。送り火は、魂を送る前に、名を、一頁に綴じる。それが、二つ目の器官の、仕事だった。

一冊も読まれなかった作家の魂火が、届く。結城文、という。手の指に、ペンだこがある。書いて、書いて、一度も読まれなかった指が、青白い火になって、台帳の前に浮かんでいる。火は、頁を、めくりたがるように、揺れていた。火のなかには、書かれたのに読まれなかった頁が、何枚も、入っている。送り火には、それが、見える。

彼は、生涯、いくつの頁を、書いたのか。その頁は、どれも、閉じたままだった。読まれることを、待って、待って、白いまま、誰かの本棚で、埃をかぶった。それでも、書くのを、やめなかった。読まれなくても、書いた。読まれるためにではなく、書くことが、彼の呼吸だった。その指の、ペンだこが、それを、語っている。送り火には、そのだこが、見える。

送り火は、指を動かす。八つの器官の、二つ目。台帳を開き、魂を、一頁に綴じる。指が、頁を、押さえる。ペンが、名を、記す。結城文という名は、頁の上に、一行、記される。それで、終わりのはずだった。送り火は、これまで、いくつもの名を、この台帳に綴じてきた。綴じる。綴じて、送る。それが、境の、営みだった。綴じられた頁は、閉じられる。閉じることが、綴じることだった。誰にも、開かれない。

指が、台帳の、最初の頁に、触れる。

頁は、白紙だった。

「読んで」

結城文の魂火が、言う。

送り火は、頁を読もうとする。読めない。綴じる指は持っていても、読む指は、持っていなかった。誰かの頁を、読んだことが、なかった。誰かに、読まれたことも。白い頁は、白いまま、彼の指の下で、じっとしている。文字は、ない。それなのに、頁は、読んでほしいと、震えている。綴じる指が、初めて、読む、ということを、知りたがる。

指が、止まる。

この魂は、まだ誰にも名付けられていない。


# 第3章「呑む」／器官・喉

どの家にも吐き出された、名なしの胎児の魂火が、届く。小さい。青白い火が、揺れている。名前のつく前に捨てられた魂が、線路の上を、ころがるように滑ってくる。火のなかには、誰かの腕と、誰かの声と、与えられるはずだった名が、入っている。送り火には、それが、見える。

火は、小さい。どの火よりも、小さい。手で、すくうまでもない。息で、吹けば消えてしまいそうな火が、線路の上を、ころがる。ころがって、送り火の、足元に、止まる。名もない火は、名もないまま、ここへ来た。名前のつく前に、捨てられた。だから、台帳の、どの頁にも、その名は、ない。送り火には、それが、見える。

送り火は、喉を動かす。八つの器官の、三つ目。魂を、呑む。転生先へ送るのではなく、いったん喉の奥へ、しまう。消化して、流れへ戻す。喉が、上下する。火が、喉の奥へ、沈んでいく。それで、終わりのはずだった。呑んで、消化して、流れへ戻す。名もない火を、名もないまま、流れへ戻す。それが、境の、営みだった。

喉が、動かない。

魂は、喉に、残る。どの器官も、それを、引き受けられない。どの動詞も、それを、動かせない。送り火の、完璧だったはずの八器官が、初めて、止まった。呑み込んだはずの火が、喉の奥で、静かに、燃え続けている。吐き出すことも、消化することも、できない。名のない火が、名のないまま、喉を、塞いでいる。

台帳の、一番下の欄に、印が、ひとつ、浮かぶ。

該当なし。

その席に、誰かが、座っている。

少女が、いた。制服を着ている。雨に、濡れていない。彼女は、台帳の「該当なし」の席に、腰を下ろして、送り火を、見ていた。名もない魂を送り損ねた装置を、静かに、見ていた。少女は、何も言わない。けれど、その目は、送り火を、見つけていた。境で、誰も彼を、見たことがなかったのに。少女だけが、彼を、見ていた。

この魂は、まだ誰にも名付けられていない。


# 第4章「預かる」／器官・腕

引き取り手のない孤児の魂火が、届く。コダマ、という。手の、ひらを、上に向けている。抱き上げてもらうのを、待つように。青白い火が、送り火の胸の前で、じっと、止まっている。火のなかには、抱かれたことのない夜と、呼ばれたことのない名と、伸ばされたままの両手が、入っている。送り火には、それが、見える。

その両手は、ずっと、伸ばされたままだった。抱き上げられるのを、待って、待って、待ち疲れて、それでも、下ろすことができなかった。下ろしてしまったら、もう、抱かれないと、わかっていたから。火のなかの両手は、いまも、上を向いている。誰かの腕を、待っている。送り火には、その手が、見える。

送り火は、腕を動かす。八つの器官の、四つ目。魂を、預かる。転生先が決まるまで、腕の中に、しまっておく。火を、抱える。胸の前で、じっと、止まっていた火が、送り火の腕に、収まる。火は、小さく、震えた。抱かれたことのない火が、初めて、抱かれた。それで、終わりのはずだった。送り火は、これまで、いくつもの魂を、この腕で、預かってきた。預かる。預かって、送る。それが、境の、営みだった。

「あなたは、誰かに、預けられたことがあるか」

コダマの魂火が、言う。

送り火は、答えない。預けられたことなど、なかった。預かるばかりで、預けられたことは、一度も。抱える腕を持っていて、抱かれる腕を、持ったことが、ない。伸ばされた両手を、受け取ることはできても、自分の両手を、誰かに伸ばしたことは、なかった。

腕が、止まる。

「代わりに、あんたを、預からせて」

少女が、言う。

彼女は、送り火の腕から、コダマの魂火を、そっと、下ろした。そして、送り火を、膝から、下ろした。少女の膝の上に、送り火が、置かれた。抱えるはずの腕は、いま、抱えられていた。境で、誰も彼を、預かったことがなかったのに。少女だけが、彼を、預かった。

預かるはずの腕は、いま、預けられていた。

この魂は、まだ誰にも名付けられていない。


# 第5章「測る」／器官・耳

境には、秤があった。魂の重さを、測るための。転生先を、決めるために。送り火は、耳を動かす。八つの器官の、五つ目。針の傾きを、聞く。魂の重さで、送り先が、決まる。重い魂は遠くへ、軽い魂は近くへ。針の、傾く音を、聞く。傾く音で、重さを、知る。それが、境の、営みだった。

魂が、秤に、かかる。皿が、わずかに、沈む。針が、傾く。重い魂ほど、針は、遠くへ、傾く。軽い魂ほど、針は、小さく、揺れる。送り火は、耳を澄ませる。針の、軋む音を、聞く。目では、見ない。耳で、測る。重さというものは、音になって、耳へ、届く。送り火は、これまで、いくつもの魂を、この秤で、測ってきた。測れる魂だけを、測ってきた。測れない魂は、この境には、来なかった。

少女の重さは、秤の針を、振らせなかった。

該当なし。

針は、振れなかった。皿は、沈まなかった。彼女は、どこにも、送られない。重くも、軽くも、ない。値のつかない魂が、秤の皿の上に、立っている。針は、まっすぐ、真上を、指している。動かない。音が、ない。測るための耳は、測るべき音を、ひとつも、聞かない。送り火は、これまで、いくつもの魂を、この秤で、測ってきた。測れる魂だけを、測ってきた。測れない魂は、この境には、来なかった。少女が来るまでは。

少女が、秤を、逆さに向ける。

「あなたの、重さは」

耳が、止まる。

測るはずの耳は、いま、測られていた。重さのない者が、重さを、問うていた。境で、誰も彼を、測ったことがなかったのに。少女だけが、彼を、測ろうとした。

この魂は、まだ誰にも名付けられていない。


# 第6章「値付ける」／器官・目

生涯「無価値」と値踏みされた女の魂火が、届く。折笠千代、という。目を、伏せている。値踏みされ続けて、自分の値に、目を伏せるようになった魂が、青白い火になって、送り火の前に、浮かんでいる。火のなかには、値をつけられなかった日々と、伏せられたままの目と、認めてもらいたかった夜が、入っている。送り火には、それが、見える。

彼女は、生涯、値踏みされ続けた。誰かに、値をつけられて、安いと、言われて、それでも、目を伏せて、生きてきた。伏せた目の、奥で、認めてもらいたかった夜が、ずっと、燃えていた。誰かに、値をつけてほしかったのではなく、値の、つかないものとして、見てほしかった。けれど、誰も、それを、見なかった。誰もが、値をつけた。送り火には、その伏せられた目が、見える。

送り火は、目を動かす。八つの器官の、六つ目。魂を、透かして、値付ける。転生先の、値段を、決める。折笠千代という名の横に、値が、記される。目が、火を、透かす。火の、値が、浮かび上がる。それで、終わりのはずだった。送り火は、これまで、いくつもの魂を、この目で、値付けてきた。値付ける。値付けて、送る。それが、境の、営みだった。

少女には、値が、なかった。

該当なし。

値のつかない魂に、判は、押せない。送り火は、判を、下ろそうとして、下ろせない。生まれて初めて、値付けを、止めた。透かす目が、透かし切れない。値の、ない火が、目の前で、静かに、燃えている。値をつける、ということが、初めて、できなくなった。

少女が、判を、奪う。

送り火の、額に、判が、押される。

該当なし。

境で、誰も彼を、値付けたことがなかったのに。少女だけが、彼を、値付けた。該当なし、と。値のない者に、値のない者として、判を、押した。

この魂は、まだ誰にも名付けられていない。


# 第7章「悼む」／器官・声

独り死んで、誰にも悼まれなかった兵の魂火が、届く。早瀬甚吾、という。誰にも見送られなかった、死体の重さを、している。青白い火が、声の器官の前に、静かに、置かれる。火のなかには、誰にも読まれなかった手紙と、誰にも聞かれなかった最期の声と、独りで死んだ夜が、入っている。送り火には、それが、見える。

彼は、独りで、死んだ。誰にも、見送られずに。最期の声は、誰の耳にも、届かなかった。書いた手紙は、誰の手にも、届かなかった。それでも、彼は、死ぬ前に、声を出した。手紙を書いた。届かないと、わかっていても。独りで死ぬ、ということが、どういうことなのかを、誰かに、知らせたかった。けれど、誰も、いなかった。送り火には、その、届かなかった声が、見える。

送り火は、声を動かす。八つの器官の、七つ目。魂を、悼む。低い声で、名前が、呼ばれる。早瀬甚吾。死んだ者の名が、声に、乗せられる。悼む、ということは、名を、声に乗せることだった。それで、終わりのはずだった。これまで、いくつもの魂が、この声で、悼まれてきた。悼む。悼んで、送る。それが、境の、営みだった。

「あなたを、悼む声が、ない」

少女が、言う。

声が、止まる。

死んでいないのに、悼まれてきたのは、どちらだったか。誰かを悼む声を持っていて、悼まれる声を、持ったことが、ない。境で、誰も彼を、悼んだことがなかったのに。少女だけが、彼を、悼んだ。死んでいない者を、少女は、悼んだ。

送り火は、悼まれた。

この魂は、まだ誰にも名付けられていない。


# 第8章「捨てる」／器官・背

最後の器官は、背だ。最初に、自分を捨てた記憶から、作った器官。

送り火は、八つの器官を、使い切ろうとしている。魂を、送り、綴じ、呑み、預かり、測り、値付け、悼み、そして、捨てる。八つ目の器官が、終わりのはずだった。これまで、いくつもの魂が、この背で、捨てられてきた。捨てる。捨てて、送る。それが、境の、営みだった。背を、向ける。向けた先に、流れが、ある。魂は、その流れへ、捨てられる。捨てられて、送られる。

少女を、捨てる。彼女を、流れへ、捨て返そうとする。彼女がいるせいで、装置は、止まり続ける。彼女がいるせいで、彼は、問われ続ける。見られ、預かられ、測られ、値付けられ、悼まれた。すべては、彼女が来てからだった。だから、捨てる。彼女を、捨ててしまえば、装置は、また、動き出す。それまで、ずっと、そうだった。捨てることで、動いてきた。だから、今回も、捨てる。

送り火は、背を動かす。花を、流れへ、捨て返そうとする。

背を、向ける。

背の向こうに、最初に捨てたものが、いた。

篠宮花、という。

制服を着て、雨の踏切に、立っている。最初に捨てた、自分。捨てたはずの、自分。忘れたはずの、自分が、背の向こうで、彼を、待っていた。境で、誰も彼を、待ったことがなかったのに。少女だけが、彼を、待っていた。背を向けて、捨てようとした、その先に、捨てたはずの自分が、立っている。

背が、止まる。

捨てられない。

この魂は、まだ、誰にも、名付けられていない。


# 終章「該当なし」

八つの器官が、ひとつも、残らない。

送り、綴じ、呑み、預かり、測り、値付け、悼み、捨てる。どれも、動かない。装置は、止まる。止まって、静かになって、ただの男が、線路の上に、立っていた。境で、はじめて、音が、した。

八つの器官を、動かすための、八つの動詞が、尽きた。送ることも、捨てることも、できない。ただの男は、線路の上に、立って、静かになった。静かな自分を、初めて、知った。動かない、ということが、どういうことなのかを、初めて、知った。

少女が、彼の前に、立つ。

「あんたは、なんと呼ばれたい」

彼は、問われた。
