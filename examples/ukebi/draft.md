# 序章「迎え火」

あなたは、踏切に立っている。

線路は、駅にも続いていない。雨は降っていない。踏切を、誰も渡らない。

線路の向こうから、火がひとつ、流れてくる。魂火。誰にも教わっていないのに、あなたはそれを知っている。

火は、あなたの前で、止まる。

向こうから、名のないものが来る。魂たちは、それを、「送り火」と呼ぶ。八つの器官を、ひとつずつ、淀みなく動かして、魂を転生へ送る。今日も。昨日も。最初から、ずっと。

送り火は、あなたの前を、通り過ぎる。

その喉に、何かが、ひとつ、留まっている。どの器官も、それを、処理できない。最初から、あったもののように。

この魂は、まだ誰にも名付けられていない。

# 第1章「送る」／器官・手

旅路で斃れた女の魂火が、境に届く。幸恵、という。

送り火は、手を動かす。八つの器官の、最初のひとつ。手は、魂火を取り、掲げ、流れへ送る。

「あなたは、誰に送られるの」

女の魂火が、声を上げる。

手が、止まる。

送るだけだった手は、いま、何かに、掴まれることを、知る。

この魂は、まだ誰にも名付けられていない。

# 第2章「綴じる」／器官・指

一冊も読まれなかった作家の魂火が、届く。結城文、という。

送り火は、指を動かす。台帳を開く。魂を、一頁に、綴じる。

指が、台帳の、最初の頁に、触れる。

頁は、白紙だった。

「読んで」

結城文の魂火が、言う。

指が、止まる。

この魂は、まだ誰にも名付けられていない。

# 第3章「呑む」／器官・喉

どの家にも吐き出された、名なしの胎児の魂火が、届く。

送り火は、喉を動かす。魂を、呑む。

喉が、動かない。魂は、喉に、残る。消化されない。

台帳の、一番下の欄に、印が、ひとつ、浮かぶ。

該当なし。

その席に、誰かが、座っている。

少女が、いた。

この魂は、まだ誰にも名付けられていない。

# 第4章「預かる」／器官・腕

引き取り手のない孤児の魂火が、届く。コダマ、という。

送り火は、腕を動かす。魂を、預かる。

「あなたは、誰かに、預けられたことがあるか」

コダマの魂火が、言う。

腕が、止まる。

「代わりに、あんたを、預からせて」

少女が、送り火を、膝から、下ろす。

預かるはずの腕は、いま、預けられていた。

この魂は、まだ誰にも名付けられていない。

# 第5章「測る」／器官・耳

魂の重さが、秤にかかる。転生先を、決める。

送り火は、耳を動かす。魂の重さを、測る。

少女の重さは、秤の針を、振らせなかった。

該当なし。

少女が、秤を、逆さに向ける。

「あなたの、重さは」

耳が、止まる。

測るはずの耳は、いま、測られていた。

この魂は、まだ誰にも名付けられていない。

# 第6章「値付ける」／器官・目

生涯「無価値」と値踏みされた女の魂火が、届く。折笠千代、という。

送り火は、目を動かす。転生先を、値付ける。

少女には、値が、なかった。

該当なし。

少女が、判を、奪う。

送り火の、額に、判が、押される。

該当なし。

この魂は、まだ誰にも名付けられていない。

# 第7章「悼む」／器官・声

独り死んで、誰にも悼まれなかった兵の魂火が、届く。早瀬甚吾、という。

送り火は、声を動かす。魂を、悼む。

「あなたを、悼む声が、ない」

少女が、言う。

声が、止まる。

送り火は、悼まれた。

この魂は、まだ誰にも名付けられていない。

# 第8章「捨てる」／器官・背

最後の器官は、背だ。最初に、自分を捨てた記憶から、作った器官。

送り火は、背を動かす。花を、流れへ、捨て返そうとする。

背を、向ける。

背の向こうに、最初に捨てたものが、いた。

篠宮花、という。

背が、止まる。

捨てられない。

この魂は、まだ、誰にも、名付けられていない。

# 終章「該当なし」

器官が、ひとつも、残らない。

少女が、彼の前に、立つ。

「あんたは、なんと呼ばれたい」

彼は、問われた。

花は、花に、名付けられた。

彼は、異世界ではなく、読者の世界へ、送られた。

この本が、彼を送る、受け火になる。

# 最終空白頁「あなたの名」

あなたは、最後の頁を、開く。

頁は、白い。ただ、一行だけ、文字がある。

彼は＿＿＿に受け取られた。

あなたは、主人公の名ではなく、あなたの名を、書く。
