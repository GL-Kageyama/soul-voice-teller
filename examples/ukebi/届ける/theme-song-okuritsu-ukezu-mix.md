## 4. 「それでも聞こえたら」

| 聞こえた読み | 次に開く形 | 備考 |
|---|---|---|
| 「たはすくひ」と歌った（助詞の「は」） | 「た わ すくひ」→「た わ すく ひ」 | まず空白を一つ足す。語は削らない |
| 「わは」と歌った（「わ」＋助詞） | 「わ わ」→「わ わ うけず」→「わ わ うけ ず」 | 「わ」を二つに割る |
| 「をみな」と歌った | 「おみな」→「お みな」 | 「を」を「お」に開く |
| 「こゑ」と歌った | 「こえ」→「こ え」 | ゑ→え |
| 「とぢ」と歌った | 「とじ」→「と じ」 | ぢ→じ |
| 「あづけ」と歌った | 「あずけ」→「あ ず け」 | づ→ず |
| 「あたへ」と歌った | 「あたえ」→「あ た え」 | へ→え |
| 「うけらよ」と歌った | 「うけらゆ」→「うけら ゆ」 | **最も弱い一語。** それでも直らなければ「うけられつ」に替える（上代語の純度を犠牲にする） |
| 「のめどお」と歌った | 「のめど」→「のめ ど」 | 已然形＋ど |

## 5. 比べ方

1. **同じ条件で二つを生成する。** Style of Music・Exclude Styles・Vocal Gender・Duration・Weirdness・Style Influence・Max Mode をすべて同じにする。**変えるのは Lyrics 欄だけ。**
2. **一度に一つ。** 正典 `theme-song-okuritsu-ukezu.md` §2.1 と、この混ぜ版を同時に貼らない。**別々の生成で聞き比べる。**
3. **聞く点**:
   - **読み**——「た」「ま」「せ」「かひな」「おみな」「うけらゆ」が、狙った音で歌われているか。
   - **区切り**——語の境目が聴こえるか。特に「わが た わ すくひ」「わ わ うけず」「わ わ うけらゆ」。
   - **旋律**——空白が増えたことで、メロディが割れていないか。**割れていたら、空白を減らす。**
   - **声の数**——コーラス・ハモリ・多重録音が混ざっていないか。混ざっていたら、Lyrics ではなく Exclude と Vocal 指定を直す。
4. **選び方**:
   - 正典 §2.1 が読めたら、**正典を採る**（語の区切りが残り、旋律が割れにくいから）。
   - 正典が外れたら、**この混ぜ版を採る**。
   - 両方外れたら、**このファイルの「それでも聞こえたら」を一つずつ開く**。それでも直らなければ、**全部かなのこの版を採り、字面の意味は §2.2 の表で補う**。

## 6. 弱点

1. **かなは字面の意味を失う。** 「手」「目」「声」「魂」「火」「名」の漢字が持つ視覚的な意味は、この版にはない。**歌詞カードには §2.2 の古語表記を併記する**（歌詞カードは読むもの、Suno は歌うもの）。
2. **かなを増やすほど、語の境目が減る。** この版は**最終手段**——全部を開いた fallback である。空白で境目を補っているが、空白が多すぎると旋律が割れる。**通常は正典 §2.1 の最小限の開口から始め、外れた語だけをこの版で開く。**
3. **古語の文法は、聴き手には届かない。** 「のめど」「うけらゆ」「とひき」は、現代人には意味が取れない。**それは設計である**——意味は §2.2 の現代語訳にあり、歌は音として運ぶ。
4. **「うけらゆ」は、この歌で最も確証の弱い一語。** 上代の受身「らゆ」の接続規則に従ったが、「受く」に付した確例は確認できない。**Suno が不自然に歌うなら「うけられつ」に替える**——その場合は上代語の純度を犠牲にする。
5. **十六楽器は、この版では直らない。** Suno がすべてを鳴らす保証はない。**Lyrics を変えても、楽器の再現は変わらない。** Style 欄の語順で調整する。
6. **`no backing vocals` は無視されることがある。** 声が重なったら、Exclude を強め、Lyrics の行を短くする——**行を足さない。**
7. **158 BPM の Eurobeat でも、古語の一語一語が聴き取りにくい。** 速さは 200 BPM より落ちたが、**楽太鼓の四つ打ちと楽琵琶の裏拍が語の境目を隠す**。これはこの曲の設計（装置の軽さ）でもある。**歌詞カードと §2.2 の表が、聴き手のための第二の扉**になる。
