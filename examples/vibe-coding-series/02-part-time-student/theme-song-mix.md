## 開いた語

| 語 | 開いた形 | なぜ開いたか |
|---|---|---|
| 千二百円 | せんにひゃくえん | **数字。** この曲の主題語。読みを固定する |
| 二十三時 | にじゅうさんじ | **数字＋時。** 二十三 を にじゅうさん と読ませる |
| 四時間 | よじかん | **四 の読みが割れる**（よ／し） |
| 八円 | はちえん | **数字。** この曲の反転点 |
| 初月 | しょげつ | **ういづき** と読ませない。初月の売上 |
| 自販機 | じはんき | **辞書が外しやすい複合語。** 八円との比較の軸 |
| 規約 | きやく | **きそく** と混同されうる |
| 一度 | いちど | **ひとたび** と読ませない。改訂で追加した一行 |
| 千二百（円なし） | せんにひゃく | 「次は 千二百」「千二百は 一度」の二行。**円を付けると行が変わる**ので、語尾を落とす |

**八語と、円なしの一形。** 数字を全部開いたのが、この版の性格である。**千二百円は十一回出る**ので、ここを固定する価値が最も高い。

## 漢字のまま残した語

- **送り仮名が読みを決める語**——終わり・閉めて・食って・漕ぐ・叩く・光る・頼んで・待って・出てきた・動いた・貼れない・読む・出してた・**直せる**（なおせる）。**活用が読みを一つにする。**
- **読みが一つの常用語**——講義・鞄・画面・時給・今日・計算・入金・口座・端末・問い合わせ・広告・通知・売上・笑う・明日。
- **カタカナ語**——シフト・アパート・キーボード・レビュー・スクショ。**開くと不自然。**
- **「バイト」「一時間」はそのまま。** バイトはカタカナ、一時間は いちじかん で一意。
- **円の付かない「千二百」は、せんにひゃく。** 「次は 千二百」「千二百は 一度」の二行で、**円の付く行とは語尾が変わる。**

## 二つを、どう比べるか

1. **同じ条件で二つ。** Style・Vocal・Exclude は変えない。Lyrics 欄だけ。
2. **まずサビ。** 「せんにひゃくえん」の十一回が、**同じ速さで転がるか**。数字が歌として重くならないか。
3. **次に Bridge。** 「はちえん」の落差が、**笑いとして聞こえるか**。ここがこの曲の要。
4. **聞く点**——読み・区切り・旋律。**「せんにひゃくえん」が長すぎて拍から落ちないか**を、特に。

## ⚠ この版の弱点

- **「せんにひゃくえん」は七モーラ。** 漢字の「千二百円」より、**字面の情報量が落ちる。** 歌では聞こえれば同じだが、**画面の歌詞としては読みづらい。**
- **数字を全部開いたので、かなの比率が上がった。** 語の境目が減っている。**息継ぎが不自然になったら、開くのを減らす。**
- **「しょげつ」は耳で意味が取りにくい。** 初月を「ういづき」と歌う選択もある。**意味を取るなら ういづき。**
- **まだ試していない。** 耳で決めるほかない。
