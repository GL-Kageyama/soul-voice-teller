# バイブコーディングの歌シリーズ

> 1曲目「荒くれITエンジニア編」＝ [`vibe-coding/`](../vibe-coding/)。
> ここは、その後に続く**11編**の独立した曲を置く場所である。

## 前提

- 11本はそれぞれ独立した曲。タイトル・ジャンル・声・人物は編ごとに変える。
- 共通する主題は「**バイブコーディングを実施する人の歌**」だけ。
- 物語の芯は **AIと人間の協調が効果を生む（時には失敗する）**。全編A。
- 各曲に、**小さな失敗か誤報を一つ**入れる。Aの芯は変えない。
- **Style of Music に固有名詞を入れない。** 参照した名前は選定の記録に留める。
- 歌詞は**読点ゼロ・括弧ゼロ**。区切りは空白。相手は「あなた」。

## 各フォルダの中身

- `theme-song.md` — 6点セット（曲名／歌詞／曲調／声／楽曲説明／置き場）
- `theme-song-mix.md` — Suno の読み違いを減らす、かな開き版。**歌詞欄だけ差し替える。**
- `council-report.md` — 5人の評議（修正の材料）。`council-report.json` はその生データ
