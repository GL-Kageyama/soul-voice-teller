## 4. 割れたこと（平均しない）

### ① 骨格（データ対勘・寡黙な父・三世代）は既製品か、丁寧に避けられた型か

**5人は骨格が既製であることに、ほぼ同意している。争いは、それがどれだけの値段なのかだけである。**

- **anti-generic（44, cliche_density 50 / formulaic_structure 38）**：「この配置は現代日本語歌詞の既定路線であり、登場人物が役割の枠から出ていない。**父は人物ではなく「読めない天気」の人格化に近い**」「**抑制の対象が古いのに抑制だけが巧いとき、それは洗練ではなく匿名性である**」
- **emotional-power（72）**：「骨格そのもの——老いた農夫、端末、データと空——は既視感が強く、**抑制がかろうじて支えているに過ぎないとも言える**」——同じことを認めて、減点は限定的
- **admiration（66）**：「世代対立の和解という定型を、**父を改宗させないことで部分的に裏切っている**」——骨格は定型、処理は定型でない
- **theme-resonance（72, coherence 83）**：「主題は後付けではなく、**反復される所作の配列そのものから立ち上がる**。構造の一貫性はこの作品の最も強い点」
- **prose-style（65）**：「一語一行の組版自体は日本語詞の既存の様式であり、**様式が声を支えているのか声が様式を必要としているのか、境界は微妙**」

**44と72の差は、44点の側が「骨格が古い」を減点の中心に置き、72点の側が「骨格が古い」を認めたうえで処理を測ったことにある。** 同じ事実を、一人は減点の根拠に、一人は減点しない前提に使った。

### ② Bridge の「理由 は／言わない」——唯一の「おおっ」か、免罪符か

- **admiration（66, admiration_peak 66 / inevitability 74）**：「橋で『父 が 見る』という繰り返し句が再文脈化される」「**動詞は一つも変わっていないのに、対象がすり替わっている。驚きと必然が同じ場所で噛み合っている、稀な一撃**」
- **anti-generic（44）**：「和解が**定型の位置に、定型の画像で、時間通りに**訪れている」「『理由は言わない』という一言が、その甘さを**免罪するための免罪符**になっている」
- **prose-style（65）**：「**言わないことを言葉で説明しており、この文体が掲げる抑制を語で裏切っている。抑制は演じるもので、報告するものではない**」
- **theme-resonance（72, restraint 82）**：「語らないこと自体を名指しており、**余白がわずかに自己言及的になる**」——改善提案で削除を勧めた
- **emotional-power（72）**：「理由をあえて明かさないことで、**説明すれば壊れる感情を守っている**」

**5人中3人がこの一行を疑い、2人が頂点に置いた。しかも疑い方は三通りに違う**——甘すぎる（anti）、説明しすぎる（prose）、自己言及する（theme）。**同じ一行について、三つの異なる欠陥が指摘された。** これは珍しい。ふつう争点は「良いか悪いか」に割れるが、ここでは「悪いなら、どう悪いか」が割れている。

### ③ 「俺 は／両方 を／記録 する」——第三の着地か、整いすぎた総合か

- **theme-resonance（72）**：「**総合の位置がやや整いすぎており、対立を解いて見せる設計図の線が見える。三者のうち話者の立場だけが明示的に正しさを得てしまう**」
- **anti-generic（44）**：「三つの立場が等しく尊重され、等しく軽い。**等価な扱いの歌は、誰の歌でもない**」
- **emotional-power（72）**：「データと身体知のどちらにも軍配を上げず、記録という第三の行為に着地させることで、**和解を感傷ではなく手続きにしている**」
- **prose-style（65, voice 64）**：「『俺』の位置が、断定ではなく**記録という動詞**で示されている」
- **admiration（66）**：「折衷は語り手の『俺は両方を記録する』にだけ起こる」——**父を改宗させないことの証拠**として強みに数えた

**2対3。** 整いすぎると読む側（theme・anti）と、正しい着地と読む側（emotional・prose・admiration）。ただしその理由は逆向きである——theme は「話者だけが正しさを得る」ことを問題にし、admiration は「父が正しさを譲らない」ことを評価している。**同じ行を、片方は和解の過剰、片方は和解の欠如として読んだ。**

### ④ 「袋 の 重さ／それだけ」——還元の成功か、主題の名指しか

- **anti-generic（44）**：「収穫という主題を単一の尺度に還元する。**歌詞として強い選択**で、感傷を数値で押さえ込んでいる」——強み
- **prose-style（65）**：「収穫という出来事を一つの測定量に還元し、場面全体を再文脈化している」——ただし「**この歌が父の尺度に降参しかけている場所**」とも
- **emotional-power（72）**：「収穫を祝祭ではなく計量として差し出し、労働の実感を感情の誇張なしに伝えている」——強み
- **admiration（66）**：「**袋の重さだけが共通項だという結論を、句そのものが名指ししてしまっている。余白に預けられたはずの主題を、言葉が回収している**」——弱み
- **theme-resonance（72）**：「抽象が許されるのは『袋の重さ／それだけ』の**一行だけ**」——名指しを問題にせず、唯一の抽象として許容

**4対1。** admiration だけが「言いすぎ」と読んだ。興味深いのは、同じ admiration が「Bridge は言わないことで頂点になった」と書いていることだ。**この歌で最も抑制が効いた場所と、最も抑制が破れた場所を、彼は同じ尺度で測っている。**

### ⑤ 評価者間の主点と、11曲で最大の分裂

anti-generic 44 から theme-resonance／emotional-power 72 まで、**範囲 28・分散 106.56**——11曲で最大（次は⑩の48.24）。

## 5. 各評価者の修正材料

### anti-generic-story-filter（44）
- **強み**: 田んぼの番号・水位センサー・鎌を研ぐ音だけ・袋の重さ——作業の具体物が感情の説明を介さずに置かれている／省略の反復が歌の核として機能／雨で破綻させず「品質は少し落ちた」で流す抗クライマックス／「それだけ」の還元。
- **弱み**: データ対勘・寡黙な父・アプリと手・三世代という既定路線／父が人物ではなく天気の人格化／Bridge の和解が定型の位置に定型の画像で／誰も損をしない／「夕方 空 赤い」「また明日」が循環を閉じる定型句。
- **提案**: **父にアプリを渡さない版**を一つ書く／**収穫を実際に失敗させる**、あるいは「それだけ」を損失に向ける／「まあいい」に父が何を諦めたかを一文だけ滲ませる。

### emotional-power（72）
- **強み**: 「父は空を見る」と「俺は両方を記録する」の対置で和解を手続きにした／「これ どう やる」から「理由は言わない」への運び／合唱の平坦さ／「空」の三段階の変容（明るい→見る→赤い）が権威の移動を説明なしに示す。
- **弱み**: 老農と端末の図像が既視感／「あなた」に内面がなく共感の三角形が二等辺で止まる／行分けが一〜三語で統一され律動の変調が乏しい／合唱の反復が三回ほぼ同一で感情の進展が一語の置換に依存。
- **提案**: 「あなた」に数える・予報する以外の感覚的行為を一つ／橋か結びで律動を一度崩す／語り手の身体（手、土、腰）を名指さず一箇所。

### theme-resonance（72）
- **強み**: 主題が宣言されず所作の配列から浮かぶ／三者の位置が台詞の持ち方だけで区別される／父の変化が「アプリを開く」の一動作に宿る／末尾が「また明日」で意味を確定しない。
- **弱み**: 軸が「データ対空」の二項に収まり単層／「両方を記録する」の総合が整いすぎ、話者だけが正しさを得る／「理由は言わない」が余白を名指ししている／合唱の反復が新しい意味を蓄積しない。
- **提案**: 「あなた」に一度だけ固有の身体を与え、また匿名に戻す／「理由は言わない」を削り、画面を見る指だけで終える／**第二の軸を一つだけ植える（十二の番号のうち一つに触れない）**。

### prose-style（65）
- **強み**: Intro の五打が夜明けの速度とクランクの速度を一致させる／Pre-Chorus の応酬が打音を崩して速度を上げ「空 を 見る」で着地／「まあ いい」の三語／「音 だけ」「指が太い／画面が小さい」の経済／Intro と Outro の円環。
- **弱み**: 一行一語の刻みが全編で同じ強度で、定規になっている／「理由は言わない」が抑制を語で裏切る／Chorus の空白がフックの流れを細切れにする／「品質は少し落ちた」が報告文の語彙で精度から落ちる。
- **提案**: **Chorus だけは空白を外すか間隔を詰める**／「理由は言わない」を父の動作に置き換える／「品質は少し落ちた」を米の状態（色、粒、乾き）に。

### admiration（66）
- **強み**: 「父 が 見る」の再文脈化（野から画面へ）／父を改宗させないこと／データを勝敗にしない着地／「指が太い／画面が小さい」／一日の枠に一年を畳む収束。
- **弱み**: マクロの弧（雨→遅れ→品質低下→間に合う→来年の学び）が読める／最終コーラスが頂点を更新しない（「山は一つで、その後に尾根がない」）／「それだけ」が主題を名指ししている／Pre-Chorus の発話者帰属が揺れる。
- **提案**: 最終コーラスで「父 が 見る」の対象をもう一度ずらす／「それだけ」の一方を具体（重さを計る手、袋を縛る動作）に／雨の三日間を一行だけ具体に。

## 6. 書き直しの方向

**最初に決めること**: 骨格を替えるか、処理で勝つか。5人は骨格が既製であることにほぼ同意している。したがって道は二つしかない——**データ対勘という骨格そのものを外す**（anti-generic の「父にアプリを渡さない版」）か、**骨格は残して処理を一段深くする**か。前者は別の歌になり、後者はこの歌の上限を上げる。どちらを選ぶかで、残す行が変わる。

**処理で勝つ場合の一点目**: **この歌に、一度も自分を破らない時間を与えること**。prose-style は「Chorus だけは空白を外すか間隔を詰める」、emotional-power は「橋か結びで律動を一度崩す」と書いた。2人が独立に、しかも**逆の位置**を指した。どちらを選ぶかが、この歌の山をどこに置くかの判断になる。prose-style の「あの八行が、この歌でいちばん歌らしい」という言葉が、最も具体的な手がかりである。

**一点目（全員が触れた行）**: 「理由 は／言わない」。3人が疑い、2人が頂点に置いた。**削るのではなく、動作に置き換える**のが最も安全である——父が画面を見ている指、押す前のためらい。prose-style の「抑制は演じるもので、報告するものではない」が、この判断の基準になる。

**残す**: 「田んぼ に／番号 を 振る／一 から／十二」／「鎌 を／研いで いる／音 だけ」／「データ では／俺 が 言う／父 は／空 を 見る」の応酬／「父 は／まあ／いい／そう 言う」／「品質 は／少し 落ちた／それでも／間に合った」／「指 が／太い／画面 が／小さい」／「袋 の 重さ／それだけ」／朝の軽トラと夕方の赤い空の円環／「また 明日」／読点ゼロ・空白区切りの表記。

**動かす（慎重に）**: 「理由は言わない」／Chorus の空白／「あなた」の身体／雨の三日間の具体／「それだけ」の一方。

**声明**: この歌は、11曲で最も評価が割れた歌である。44と72のあいだには、評価の差ではなく、**何を歌の手柄と数えるかの差**がある。修正は、どちらかの側に寄せることではなく、**両方が認める一点**——刻みが一度も破れないこと、そして「あなた」が機能のままであること——から始めるのがよい。
