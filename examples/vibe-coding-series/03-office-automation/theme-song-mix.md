## 開いた語

| 語 | 開いた形 | なぜ開いたか |
|---|---|---|
| 三十分 | さんじゅっぷん | **さんじゅうふん** と割られる。この曲の主題語 |
| 九時五分 | くじ ごふん | **きゅうじ** と読ませない |
| 月次 | げつじ | **つきじ** と読ませない |
| 三十二枚 | さんじゅうにまい | 数字。**枚 の前で区切る** |
| 十八時十分 | じゅうはちじ じゅっぷん | 数字＋時。**電車の時刻は歌の証拠** |
| 上長 | じょうちょう | **うえちょう** と割られうる |
| 時刻 | じこく | **とき** と読ませない |
| 十分 | じゅっぷん | Bridge の「十分 戻る」。**じゅうぶん** と読むと意味が変わる |
| 開く | ひらく | **ひらく／あく** で割れる。ここは人が開く（Intro と Bridge の二箇所） |
| 一度 | いちど | **ひとたび** と読ませない。Bridge の「もう いちど」 |

**十箇所。** 数字と、読みが割れる漢字に絞った。

## 漢字のまま残した語

- **送り仮名が読みを決める語**——違う・変えて・覚えて・整えて・飲む・戻る・見る・空いた・混んで・温かい。
- **読みが一つの常用語**——席・表・報告・先月・数字・手順・列・全部・形・時計・指・電車・色・合計・中身・確認・本当・目・窓・外・明かり。
- **カタカナ語**——コピー・エレベーター・コーヒー。
- **「時短」はそのまま。** じたん で一意。**ただし歌では、この語を一度しか使わない。**

## 二つを、どう比べるか

1. **同じ条件で二つ。** Style・Vocal・Exclude は変えない。
2. **まずサビ。** 「さんじゅっぷん」が、**機械の速さで転がるか**。長すぎないか。
3. **次に Pre-Chorus。** 「この 列を／全部 集めて／はい」の**間**が、指示と返事になっているか。
4. **聞く点**——読み・区切り・旋律。**「じゅうはちじ じゅっぷん」が、歌の最後で急に説明的に聞こえないか**を、特に。

## ⚠ この版の弱点

- **「さんじゅっぷん」は六モーラ。** サビで十一回歌うと、**言葉が重くなる。** 漢字版の方が軽い可能性がある。
- **「じゅっぷん」は二箇所。** Bridge の「十分 戻る」は、**じゅうぶん** と読まれると意味が反転する。ここは開く価値が高い。
- **数字を開きすぎた。** かなの比率が上がり、**語の境目が減っている。**
- **まだ試していない。** 耳で決めるほかない。
