## 3. 一致したこと

1. **「しきい値 を／直す」が、この歌の要。5人全員が挙げた。** prose-style は「この作品の要」「最良の一手」と書き、theme-resonance は「必要が人を起こすのではなく、必要を測る仕組みが人を起こす」と主題の核心に置いた。emotional-power は「Bridge の反転が全曲で最も強い」とし、admiration はその機構を最も正確に言い当てた——**既出の動詞〈直す〉の目的語を差し替えること**。anti-generic だけは「魅力的な異物だが、一度しか機能しない」と留保した。
2. **「あなた が 数え／私 が 直す」が、関係の力学を説明なしで運ぶ。4人。** prose-style「訂正の応酬が文体のリズムとして反復され、関係の力学を説明なしで運ぶ」、theme-resonance「名目的な記録を持つ者と実際の真実を負う者の静かな非対称」、emotional-power「精度を半分ずつ持つ二人の台帳」、anti-generic「記録の主導権をめぐる交渉」。**この曲の夫婦は、愛ではなく台帳で結ばれている。**
3. **Bridge の「起こして／ごめんなさい／あなた が 言う」の反転。5人。** 世話が誤作動を生み、世話される側が謝る。emotional-power「四行で温かさと痛みを同時に置き、説明を一切しない」、anti-generic「赤ちゃんは寝ているのに謝る倒錯が、予定調和の感情曲線を拒んでいる」、prose-style「苦笑いから寝落ちまでを三語で処理している」。
4. **弱点は4人が同じ場所を指した。最終サビが差分を持たない。** theme-resonance「三度目は単調さとして響く危険」、emotional-power「反復が侵食ではなくループとして処理されている」、prose-style「反復の設計が最後に一段上がらない」、anti-generic「楽曲の反復に支えられて初めて機能する」。**ただし admiration だけは、この反復を罠として高く評価した**（→ 4-③）。

## 4. 割れたこと（平均しない）

### ① 頂点の平坦さ——抑制の達成か、感嘆の不足か

- **admiration（64, admiration_peak 50）**：「頂点が意図的に平坦化されているため、**認知的驚きが身体的反応へ変換されない**。抑制は主題的に正しいが、感嘆の強度としては回収し切れていない」「**これは顎が落ちる瞬間ではなく、目が開く瞬間である。巧みだが、声は漏れない**」
- **theme-resonance（78, restraint 88）**：「赦しとも諦念とも決めない。道徳も総括も置かず、読者の解釈の余地を閉じない。**沈黙そのものが意味を担っている稀な例**」
- **emotional-power（72）**：「**72という点は、感傷への警戒ではなく、届く範囲の狭さに対する評価だ**」——抑制そのものは減点していない
- **prose-style（74）**：「78bpm のピアノポップに対して、この行送りはメトロノームより少し遅い。**遅いことが正しい**」
- **anti-generic（65）**：平坦さを強みとも弱みともせず、別の角度（作法の様式化）から問題にした

**4対1。だが、この1は評価の低さではない。** admiration は設計そのものが正しいと認めている。**位置は正しい、大きさだけが足りない。** これは8曲で最も細かい争点である——「やるべきことをやったか」ではなく「やったことが届いたか」を争っている。そして §3 の「Bridge で音が一度止まる」が実行されれば、admiration の50は動く可能性がある。

### ② 「左 三分／右 五分」——未回収の失敗か、翻訳の方法か

- **admiration（64）**：「最も具体的で非対称な仕込みが、**以後どこにも回収されない。読者はこの数字に意味を予測するが、支払われない**」——red flag
- **emotional-power（72）**：「身体を分の単位に翻訳しており、**それは主題に忠実**だ。だが翻訳されない一回の感覚があれば、**翻訳の残酷さがより強く立つ**」——方法であり、不足は隣にある
- **prose-style（74, sensory_texture 64）**：「計測の対句」としてリズムの核に置きつつ、「**抱いた子の重さ・温度・肌の感触がゼロに近い**。授乳という題材の中心的な触覚が抜けている」
- **anti-generic（65）**：「左右の分数」を**置き換え不可能な細部**として green flag に挙げた——回収の要否を問題にしていない

**1対3、だが三つは別のことを言っている。** admiration は「伏線が未回収」、emotional-power は「翻訳という方法」、prose-style は「その隣に触覚がない」。**同じ一行が、仕掛けと方法と欠落の三つに見えている。** この三つは両立する——数字は方法であり、回収されず、その隣に身体がない。

### ③ 「三十分」の反復——罠か、単調か

- **admiration（64, expectation_guidance 72）**：「『三十分』の四連で**単調な夜の循環を予測として植え付ける**」——反復は反転のための罠であり、**機能している**
- **theme-resonance（78）**：「三度目は形式の強度よりも**単調さ**として響く危険がある。反復に内的な変化が欲しい」
- **emotional-power（72）**：「反復が**侵食ではなくループ**として処理されている」
- **prose-style（74）**：「Final Chorus が…**反復の設計が最後に一段上がらない**」
- **anti-generic（65）**：「**歌詞カードの上では作業メモとの区別がつきにくい**」

**1対4。** admiration だけが、反復を「退屈させるため」の設計として読んだ。他の4人は、反復を「変化させるため」の設計として読んでいる。**この二つは排他ではない。** 罠として機能しながら、最後に一段上がることはできる。4人が求めているのは、罠を壊すことではなく、罠の出口を作ることである。

### ④ 脱感傷の作法と題材の表面——固有の声か、流通する様式か

- **anti-generic（65）**：「単語間の空白と体言止めの連鎖が、**内容ではなく表記の様式として先に立つ**。この書法は現在かなり流通しており、声の個別性を担保しない」「凡庸を避ける作法のあまりに整った慎ましさが、**いまや『脱感傷』という別のテンプレートとして流通している**」
- **theme-resonance（78）**：「主題の表面（育児×アプリ／データ）が現時点の関心に近く、**扱いを誤れば風俗的な記号として消費されうる**。作品自体はその罠を避けているが」
- **emotional-power（72）**：「同じ夜を生きた読者には刺さるが、**そうでない読者には精密な観察として届いて終わる**」——様式ではなく到達範囲
- **prose-style（74）**：「この乾きは誰にでも書ける平板ではなく、**選ばれた抑制**である」
- **admiration（64）**：作法を問題にせず、反転の距離だけを問題にした

**2対3。** 二つの批判は別方向を向いている——anti-generic は**書き方**が、theme-resonance は**題材**が、それぞれ「いま流通しているもの」に接近していると言う。どちらも「作品そのもの」ではなく「作品が受け取られ方」への警戒である。prose-style の「選ばれた抑制」は、作品の内側から見た反論になっている。

### ⑤ 主点の散らばりと、現在値・潜在値の差

admiration 64 から theme-resonance 78 まで、**範囲 14・分散 28.64**。②（12）に次いで小さい。**しかし、この揃い方は「評価が揃った」のではない。** 現在値 68.8 に対し潜在値 75.0、その差 6.2 は⑤と並ぶ最大である。

内訳を見ると理由は明快だ。theme-resonance が78（coherence 86・restraint 88）、prose-style が74、emotional-power が72。**主題・文体・感情のどれも高い。** 低いのは quality（65）と admiration（64）——**「新しいか」と「声が漏れるか」**である。この歌は、良く書けているのに、驚かれていない。

## 5. 各評価者の修正材料

### anti-generic-story-filter（65）
- **強み**: 「あなたが数え 私が直す」の主導権の分担／「通知が鳴る 本当に泣く」／赤ちゃんが寝ているのに謝る倒錯／「私も寝る」で平板に閉じる／左右の分数・抜ける記録・しきい値・干していない洗濯物。
- **弱み**: 空白表記と体言止めが様式として先に立つ／サビの反復が楽曲依存／時刻が等価に並び、夜の長さが描かれない／「しきい値を直す」が一度きり。
- **提案**: 時刻に強弱をつけ、一夜の一度だけを決定的な重みで描く／「しきい値を直す」を二度目に召喚する／空白表記に依存しない強度を一箇所試す。

### emotional-power（72）
- **強み**: 感情を手続きに置換した抑制／「わかりました／また直す」の同意なき服従／Bridge の謝る側の逆転／「本当に泣く」の主語の不在／「たぶん」で閉じる。
- **弱み**: 全編が同一レジスタ／反復が侵食にならない／相手が機能としてしか描かれない／赤ちゃんが時刻表のまま。
- **提案**: 抽象化を解いた身体の感覚を一行／三度目の合唱に語彙でない変更を一つ／相手に機能と無関係な細部を一つ／赤ちゃんに時刻表でない細部を一つ。

### theme-resonance（78）
- **強み**: 計測語彙と身体語彙の対置／「数え」と「直す」の非対称／Bridge の「制度が人を起こす」／Intro と Outro の枠取り／「たぶん」の誠実な不確かさ／形式と主題の一致。
- **弱み**: 後半の振幅が一定／相手が報告の声のみ／題材の表面が記号化しうる／「しきい値」が Bridge 初出の一度きり／洗濯物やグラフが後の像に回収されない。
- **提案**: 「しきい値」を前半に予兆として落とす／反復の内部に「数えられない時間」を侵入させる／相手の具体の行為を一つ／反復の単位を一度だけ崩す。

### prose-style（74）
- **強み**: 分かち書きの空白が「寝た 隙間」の写像になる／「しきい値を直す」の一語／「あなたが数え／私が直す」の対句／「笑う／笑って／また寝る」の活用の段差／光が落ちてから人が落ちる順序／「当たる」の受動性。
- **弱み**: 光と音に偏り、触覚がほぼない／Final Chorus が差分を持たない／「昨日と今日が似ている」が説明に落ちる／Pre-Chorus 2 が緊張をほどく方向にしか働かない／「記録」「直す」「数え」の飽和。
- **提案**: 腕のしびれや襟の濡れのような局所の身体を一行／Final Chorus に一語だけ差し替え／「似ている」をグラフの具体的な形に／Pre-Chorus 2 と Bridge の落差を整えすぎない。

### admiration（64）
- **強み**: 〈直す〉の目的語の差し替えという文法操作／通知を泣き声の予告として植えた反転／「たぶん」への最小差分／Intro の画面まで遡って読み返させる必然性（78）。
- **弱み**: 「左三分／右五分」が回収されない／反転が Bridge の定位置に収まり距離が短い／頂点が平坦で身体的反応に変換されない／反転の後に二段目がない。
- **提案**: 左右の分数を終盤で一度回収する／Final Chorus の前に一行だけ別の語に差し替えておく／しきい値を直した代償を一つ置く。

## 6. 書き直しの方向

**最初に直す一点**: **抽象化を解いた身体の感覚を、一行だけ置く。** prose-style は「腕のしびれや襟の濡れのような局所で」、emotional-power は「翻訳されない一回の感覚」、theme-resonance も「中盤に一度、手続きの外にある身体感覚」を挙げた。3人が独立に同じ手を指している。**この一行が、「左三分／右五分」の未回収（admiration）と、触覚の不在（prose-style）を同時に解く。**

**次に直す一点**: 反復の内部に一度だけ段差を入れる。案は割れている——**「三十分」を別の単位に崩す**（theme-resonance・emotional-power）／**Final Chorus で一語だけ差し替える**（prose-style）／**しきい値を直した代償を置く**（admiration）。どれでもよい。4人が指した唯一の共通弱点で、行数は一行で済む。

**残す**: 「しきい値 を／直す」／「あなた が 数え／私 が 直す」／「起こして／ごめんなさい／あなた が 言う」／「笑う／笑って／また 寝る」／「三十分／三十分／寝た 隙間／三十分」／「本当 に／泣く」／「明日 も／当たる／たぶん」／「画面 の 明かり／最小 に」〜「画面 が／暗く なる」の枠取り／読点ゼロ・空白区切りの表記。

**動かす（慎重に）**: 身体の一行／反復の段差／「左 三分／右 五分」の回収／相手の細部／「しきい値」の予兆。

**触らない**: Bridge の四行。5人全員がこの曲の核心と読んでいる。**足すのは、Bridge の前か後である。**

**声明**: この歌に足りないのは、主題でも声でもない。**翻訳されない身体が一行**と、**反復の一段差**である。現在値と潜在値の差 6.2 は、テーマが立っていないのではなく、届いていないことを示している。修正は「情感を足す」方向にだけは向けないこと——この歌の正しさは、泣かせないことにある。
