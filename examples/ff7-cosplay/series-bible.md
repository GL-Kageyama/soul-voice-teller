# 三日間のセフィロス — work bible

> 独立短編（約1,900字）。連載なし → 連載記録は N/A。
> この台帳は whole-work-review の検品基準（伏線の置き・回収の保証）として機能する。
> 未回収の項は意図的な「開き」として明示する（3-12 set-aside）。

## 設定記録（dictionary）

| 種別 | 項目 | 記録 |
|---|---|---|
| 固有名 | セフィロス | 男が演じる役。白い顔・銀髪・マサムネ。母に愛された子。ゲームの敵役にして男の「救いたい本物」 |
| 固有名 | クラウド | 少年の衣装。金髪・バスターソード。初日は安物（艶のないウィッグ・発泡スチロールの剣） |
| 固有名 | マサムネ | 背の太刀。男が20歳のとき最初のコンテストのために包丁鍛冶に三日通い自ら鍛造 |
| 固有名 | マコ | セフィロスの瞳の緑。特注コンタクトで「正確に再現」する |
| 固有名 | 初版／リメイク | 男は全バージョンの正解を知る。部屋に初版ソフト（未開封）・全種フィギュア・映画・リメイク |
| 人物 | 男 | 本名は読者へ非開示。20年、セフィロスの姿のみで生きた。母は故人 |
| 人物 | 少年 | 本名不明。安物クラウド→三日目は体操着。相手の目を見る。異常な理解者（正体は開示しない＝幹） |
| 人物 | 母 | 故人。毎晩「大丈夫。あなたは特別な子だから」と語った。男の背後の源（源は語らない） |
| 舞台 | 3日間の同人イベント | 初日=会場入り口／夜=ホテル／二日目=控え室前／三日目=コンテスト／エピローグ=会場外 |

## 伏線記録（置き→回収）

| 伏線 | 置き | 回収 | 開示度 |
|---|---|---|---|
| 未開封の初版ソフト | 初日「部屋にも、未開封で、一本ある」 | 二日目「開けられなかった」→エピローグの擦り切れた箱（開かれ愛された箱の贈与） | 一部開示（男が自身の箱を開くかは開き） |
| 母の言葉「特別な子」 | 夜「毎晩、こう言った」 | エピローグ「おじさんは、ちゃんと、特別な子だよ」 | 回収 |
| セフィロスは苦しまない | 初日「本物はね」 | 三日目、男自身の名前を口にする（本物＝セフィロスをやめる） | 回収 |
| 無敗／太刀 | 初日「一度も負けたことがない」 | 三日目「太刀を下ろしたことがなかった」→下ろす | 回収 |
| 少年の正体 | 初日「カメラではなく、相手の目を見ていた」 | 最後まで開示しない（幹の温存） | 未開示（意図的） |
| 男の本名 | 初日「本名を、呼んだものは、二十年、一人もいない」 | 三日目、名乗るが読者には非開示 | 未開示（意図的・読者への余白） |

## 約束の返却

- 冒頭の約束＝「本物」の男が、その「本物」を脱ぐまで。三日目のマスクオフで回収し、エピローグの箱で「開かれた箱」への誘いとして開きに返す。
