# 灵魂之声的声音库（voice-ledger · 演示用）

> 真实的 ledger 存于 `SOUL_VOICE_HOME`。这是本流程的演示样本，格式依 [声音.md](../../../references/zh/声音.md)。
> 格式：日期 · 作品 · 场景 ／ 听见的声音（照原文，不概括）／ 语境（A/B/C 哪个问句）／ 已用·未用

- [x] 2026-08-15 / 守塔人 / 构思（B-1）
  声音：这个守塔人不是「怕海」，而是「怕海，却只能从海上等」。恐惧和等待，是同一片水。
  语境：B-1（这素材如何回应写作者「反复书写的问句」——人为何一直等待不会到来的东西？）
  已用：premise 的主题。

- [x] 2026-08-15 / 守塔人 / 第 3 场 · 黎明
  声音：他不是「熄了灯就结束」，他是「又泡两杯茶」。空船来了，等待没停。
  语境：C-1（这个动作出自计划的要求，还是出自人物自身？→ 人物自身）
  已用：第 3 场的结。以热气而非结论收束，守「不闭合」的约。

- [x] 2026-08-15 / 守塔人 / 第 2 场 · 空船
  声音：来的不是客人，是一只空船。桨横在舱里。没有人。
  语境：C-1（B-4 的摇晃在草稿里应验——「唯一从海上而来的客人」，「人」错开成「物的空」）
  已用：第 2 场的转折。海归还的是「空」。

- [ ] 2026-08-15 / 守塔人 / 第 1 场 · 黄昏
  声音：泡两杯茶。一杯放窗台，一杯自己端着。窗台上那杯，凉了。
  语境：A-3（对照具体句锚点「为不会来的客人泡的茶，正渐渐冷去」——这一场乘上了锚点那种观察的质地）
  已用：第 1 场。锚点化为两杯茶的仪式，未原句复述。

- [ ] 2026-08-15 / 守塔人 / 触及禁忌的瞬间
  声音：想写「他想念海那边的人」。没写。改成了——他抬头，朝海望了一眼，又低下头。
  语境：A-4（绝对不写的：点名情感、感伤。险些破，改为行动）
  已用：贯穿三场——情感全以「背对窗」「搓手」「望一眼又低头」示之，不点名。
