## 作る順

1. 送り火の参照画像（第1話）。暗い藍のコート、短い髪、大きい手、直立、表情なし。
2. 花の参照画像（第4話）。暗い藍の制服、長い髪、目だけが動く。
3. キービジュアル。二人を同じ踏切に置く。
4. キー場面（第9話）。振り返る背中と、背の向こうの花。

## 検品（絵を見る）

- 読める文字が無いか。看板・標識・名札・字幕・ロゴ・数字。
- 光源が魂火ひとつだけか。bloom、lens flare、グローが無いか。
- 空に太陽・月・星が無いか。
- 雨が降っていないか。濡れた砂利と水たまりだけか。
- 三人以上の人・群衆が無いか。
- 送り火と花のシルエットが、台帳の同一性と合っているか。
- 人物名をローマ字で描いていないか（プロンプト側の指示）。

## 参照画像の扱い

- 送り火と花のシルエットは全話で固定する。参照画像を1枚ずつ持つ。
- ゲストは1話1人。記憶の中の人物も、その話のゲスト1人だけ。
- 台帳・秤・判・遮断機の形を固定する。
