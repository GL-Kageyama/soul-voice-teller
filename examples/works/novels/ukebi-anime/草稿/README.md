## 全10話の申告

- 定型句は第1〜9話の9回。第9話だけ読点で刻む。第10話には置かない。
- 「該当なし。」の宣告は第6話に一度だけ。第10話の題は同じ語だが、宣告ではない。
- 花の台詞は4つ（第5・6・8・10話）。増やさない。
- 第9話まで、地の文は彼女を「少女」と呼ぶ。名「花」は第10話で彼の声から出る。
  設計の開示表（第10話で名付け）に合わせた。第9話で明かすのは「最初に捨てた半身」まで。
- 画面に読める文字は無い。台帳の印は火の跡、秤に目盛りは無く、判の面は白い。
- 記憶に台詞は無い。第6話に記憶は無い。
