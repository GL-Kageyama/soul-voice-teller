# 届ける

読者・視聴者へ渡す層。作品の魂を、二つの扉から開く。

| ファイル | 中身 | 状態 |
|---|---|---|
| [package.md](package.md) | 題・帯・あらすじ・画像プロンプト・タグ・文字を出さない言い換え・最終頁 | ✓ |
| [theme-song.md](theme-song.md) | Suno 用の主題歌一式（曲名・歌詞・曲調・ボーカル・画面の置き方） | ✓ |

## 二つの扉

- package は「送られたことがなかった」と言う側から扉を押す。
- 歌は「名付けられていない」と言う側から同じ扉を押す。
- どちらも、第9話の正体と第10話の答えには触れない。
