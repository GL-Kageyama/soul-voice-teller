## 1. 異世界寄りの日本

### 調べたこと

- `premise.md` のジャンルの約束は「異世界転生モノの装いを借りて、じつは現代の実存の話」。
- `persona.md` の舞台嗜好は「日本・現代、一部海外」。ただし嗜好であって禁じ手ではない。
  `premise.md` はすでに「題材の逸脱」として異世界の装いを記録している。
- 核心の問い（魂は送られるときに終わるのか、受け取られるときに始まるのか）は、
  時代にも地名にも依存しない。
- 現在の本文で「現代」を担っているのは、踏切・線路・制服・台帳・秤・判。
  これらは形を保ったまま、由来だけを異世界へ移せる。
- 「生活」の手触りを担っているのは、回想の中だけ。ここを日本的・現代的に保てば、
  実存の質感は落ちない。

### 推奨

採用。ただし約束の文面から「現代」を外す。本文の手触りは回想で保つ。

### 採否

**採用。** 約束を「異世界転生モノの装いを借りて、じつは魂の行方を問う実存の話」に書き換える。

## 2. 最終頁

### 調べたこと

- 現在の最終頁の行為は「あなたが書く」。文字のない世界では成立しない。
- 主題歌『まだ、誰にも名付けられていない』は「書く」を一度も歌っていない。
  歌詞は「名付けられていない」で止まる。ゆえに歌は影響を受けない。
- 代替の行為は3つ。書く（不可）／閉じる／受け取る。
- 「閉じる」は物理的だが、主題の動詞でない。「受け取る」は主題そのもの。

### 推奨

「受け取る」。頁は白いまま。声が一行を言う。あなたは何も書かない。

### 採否

**採用。** 末文は「受け火は、あなただった」を残す。

## 3. 定型句

### 調べたこと

- 定型句「この魂は、まだ誰にも名付けられていない。」は9回（序＋第1〜8章末）。
- 主題歌の曲名とサビの最終行が、この一句から来ている。
- 語りを全部削ると、定型句も消える。曲名の根拠が消える。
- 残す場合でも、ナレーションは1話1行まで絞れる。

### 推奨

残す。地の文は極限まで削り、定型句だけを毎話の最後に置く。第10話では消える。

### 採否

**採用。** 第1〜9話の最後に9回。第10話には置かない。消えることが解消になる。

## 4. 記憶6本

### 調べたこと

- 現在の各章は、ゲストの生前を2〜4行で火の中に見せている。これを2〜3分に伸ばす。
- `design.md` の world-iceberg は「名前・飢え・生前の一つの具体」だけを資料化している。
  2〜3分には、一つの事件を足す必要がある。
- 6本×2〜3分＝12〜18分。全体70分の17〜26%。
- 危険は2つ。記憶が「説明」になること。単一舞台が壊れること。

### 推奨

採用。ただし規則で縛る。

1. 記憶は火の中にだけ現れる。カメラは踏切を出ない。
2. 一つの事件だけを見せる。生涯を要約しない。
3. 記憶に台詞はない。音は息と、その場の音ひとつ。
4. 器官が動くと切れる。
5. 長さを揃えない。胎児は30秒。
6. 第6話（測る）には置かない。無い話が一本あると型が緩む。

### 採否

**採用。** 記憶の長さは 2:00 / 2:30 / 0:30 / 2:00 / なし / 2:30 / 2:30 / 3:00。

## 5. 名前

### 調べたこと

- 現在、草稿は「幸恵」、聖典と主題歌は「サチ」。すでに食い違っている。
- 名は声だけで運ぶので、漢字は決めなくてよい。音が肝。
- 聖典は、5人の名が「それぞれの受動の飢えと響く」と定めている。

### 推奨

「死んだ者は、ひとつの語で呼ばれる」を世界律にする。

| 名 | 語 | 飢え |
|---|---|---|
| 送り火 | 送る火（名でない） | 送られたい |
| 花 | 花（物の名。姓を落とす） | 名付けられたい |
| サチ | 幸 | 祝福されなかった |
| フミ | 文 | 読まれなかった |
| コダマ | 木霊 | 応えられなかった |
| トワ | 常 | 値をつけられなかった |
| ナギ | 凪 | 悼まれなかった |

### 採否

**採用。** 篠宮は落とす。ゲスト5人の姓も落とす。漢字は本文に書かない（かなで書く）。

## 6. 該当なし

### 調べたこと

- 語は4箇所。終章の章題、第3章の席、第5章の宣告、`package.md`。
- 文字を外すと、席の札と package の表記は消える。宣告は声なので残せる。
- 中空の印だけでも意味は通るが、語が一度も出ないと、章題が宙に浮く。

### 推奨

第6話（第5章・測る）で一度だけ、地の文が宣告する。視覚は中空の印。章題は残す。

### 採否

**採用。**

## 7. 試作の未決4点（2026-11-11）

第2話の7分試作 `草稿/第2話_送る_試作.md` の未決を、次のとおり決める。

1. **火の問いの声は、境の声。** サチの残り火の声にしない。
   問いは彼に向けられたシステムの問いで、個人の情に寄せない。
   定型句と同じ声にすると、第2話の二つの声が一人の声になる。
2. **第2話の彼方の光は、乾いた白。** サチの渇きと、届かなかった場所の色。
   青赤の火と対になる。話ごとに変える前提で、第2話の色だけを決める。
3. **サチの器は、片手の窄口の壺。** 片手が空くので歩幅が変わらない。
   傾けて音が鳴り、一滴も出ないことが一度で分かる。
4. **定型句の読みは、平坦で低い声。囁かない。** 囁くと慰めになる。
   この話は慰めない。火の問いと同じ声で読む。
