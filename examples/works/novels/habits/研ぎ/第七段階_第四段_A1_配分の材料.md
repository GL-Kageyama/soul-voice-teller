## 1. 物差し——**反応軸は、二つの縮尺で走る**

出典＝[`references/ja/6つの反応軸.md`](../../../references/ja/6つの反応軸.md)。

> 各軸の正体は**四工程**へ展開する。それは**二つの縮尺**——**全体の弧**と**場面の弧**——で走る。

| 軸 | 全体の弧（巻・作品の縮尺） | 場面の弧（場面の縮尺＝**三種**） |
|---|---|---|
| 感嘆 | 誘導 → 超出 → 必然 → 頂点 | **へえ・なるほど・うまい** |
| ユーモア | 真面目の土台 → ズレの仕込み → 安全な回収 → 笑いの頂点 | **クスッ・ニヤリ・ぷっ** |
| 感動 | 同一化の土台 → 価値の提示 → 代償の支払い → 抑圧の頂点 | **じんわり・胸が熱い・こみ上げる** |
| 楽しい | 情動の種 → **流れの設計** → スケールの超出 → 爽快の頂点 | **心地よい・ワクワク・ぞくぞく** |

そして——**「三種のどれも渡さない場面は、読者を失う場面である。」**

### 1-1. 設計自身の二行

`design.md:138`（**§4 の裁定 A1 が根拠として引いた行**）——

> **主軸（感嘆）が全体の弧を担い、個々の話は感動・楽しいを混ぜて飽和を避ける。**
> 恐怖とかわいいは使わない。ユーモアは軸にせず、声に置く。**話ごとの軸は各巻の話割りに置く。**

⚠ **この一行は、二つの縮尺をそのまま言っている。** **感嘆＝全体の弧。個々の話＝感動と楽しい。** 「混ぜて**飽和を避ける**」——**飽和とは、全体の弧の軸が、話の既定になることである。**

`design.md:189`（**A3 で当てた行の、同じ段落**）——

> 各話で時間をどこで掴み・置かせ・解放するか——**掴む**のは話の入口（**多くは楽しい・心地よい**）。

⚠ **掴む は第一場面である。** 設計自身が、**話の入口の軸は、多くは楽しい**と定めている。

### 1-2. 各巻に割り当てられた「全体の弧」

`design.md:130-136` の章立て表——**感嘆の四工程は、一巻に一つずつである。**

| 巻 | 感嘆（主軸＝全体の弧） | 感動（副軸） |
|---|---|---|
| 一『残った名』 | **誘導** | 同一化の土台 |
| 二『重なった名』 | **超出** | 価値の提示 |
| 三『書き直した名』 | **必然** | 代償の支払い |
| 四『書いていない名』 | **頂点** | 抑圧の頂点 |

⚠ **楽しいの全体の弧（情動の種→流れの設計→スケールの超出→爽快の頂点）は、どの巻にも割り当てられていない。** **ゆえに楽しいは、この作品では場面の縮尺でだけ走る**——**それは欠陥ではない。選択である。** ただし、**選択であるなら、場面の縮尺でちゃんと走っていなければならない。**

## 3. 二つ目の食い違い——**三種の名が、正典に無い**

「**三種のどれも渡さない場面は、読者を失う場面である。**」——**ゆえに名は、三種のどれかでなければならない。** どれでもなければ、**届いたかを、設計からも検品からも、検められない。**

実際に置かれている名を、正典の三つと突き合わせた（走査した集合＝場面表63枚の反応軸の欄）。

| 軸 | 正典の三種 | **正典に無い名**（話） | 場面 |
|---|---|---|---:|
| 楽しい | 心地よい・ワクワク・ぞくぞく | **速い**（`2-01`）・**うまい**（`2-04`）・**丁寧**（`3-01`） | 9 |
| 感動 | じんわり・胸が熱い・こみ上げる | **あたたかい**（`2-09`・`4-07`）・**胸が痛い**（`3-07`・`4-11`）・**静か**（`3-09`・`4-14`）・**余白**（`4-18`） | 18 |
| 感嘆 | へえ・なるほど・うまい | **静か**（`4-01`・`4-08`） | 6 |
| | | **計** | **33** |

⚠ **楽しいの4話のうち、正典の三種を使っているのは1話だけである**（`1-01` の 心地よい）。
⚠ **`2-04` の「楽しい・うまい」——うまい は感嘆の三種である。** 軸と三種が、食い違っている。

⚠ **これは、欠陥だという主張ではない。** `胸が痛い`・`静か`・`余白` が意図である可能性がある（第三巻の「静か」、第四巻の「余白」は、巻の語である）。**だが意図であるなら、正典の三つとの関係がどこかに書かれていなければならない。**
**いま、書かれていない**——走査した集合＝`habits/構想/` 配下。⚠ **`胸が痛い`・`あたたかい`・`丁寧`・`速い` を含む文書は、その語を置いた場面表のほかに無い**（走査した集合の外＝リポジトリ全体ではない。**私は `habits/構想/` と `references/` しか見ていない**）。

**ゆえに、これは「裁定を要する一件」ではなく、「配分を開くときに、いっしょに閉じる一件」である。**

## 5. 推奨——**二つのてこ**

### てこ①——**掴む（第一場面）を、楽しいへ**

**根拠**＝`design.md:189`「掴むのは話の入口（**多くは楽しい・心地よい**）」。**新しい規則ではない。書いてある一行を、満たすだけである。**

**動かす先**＝第一〜三巻の **41場面**（45話の第一場面のうち、既に楽しいである4つを除く）。⚠ **第四巻18場面は動かさない**（下 §7-1）。

**三種の名**＝正典の三つ（**心地よい・ワクワク・ぞくぞく**）から選ぶ。⚠ **いまの4話の名は 心地よい・速い・うまい・丁寧 であり、三つが正典の外にある**（§3）。**「速い」は「ぞくぞく」、「丁寧」は「心地よい」の位置である**——**ただしこれは私の読みであり、著者が決めてよい。**

### 7-2. 場面表の「検算」の欄に、触れるものがある

⚠ **場面表の検算は、第一場面の軸を、内面の欄の根拠に使っている。** 実例——[`habits-01/構想/各話/01_消さなかった一行.md`](../../habits-01/構想/各話/01_消さなかった一行.md) の検算は「**第一場面＝`B`**……**入口の反応軸は、この知識の手つきから出る**」と書く。

**ゆえに、第一場面の軸を動かすと、その一行と食い違う話が出る。** **当てる前に、63枚の検算を走査し、食い違う話を数える**（この文書では数えていない）。

### 7-3. 話割りの「反応軸の配分」の行

⚠ **配分の行は、いま実測と一致している**（感嘆38・感動21・楽しい4。**第一巻だけ「第9話は感嘆と感動の両方」と注記がある**ゆえ、内訳の合計は話数より1多い）。**てこ②を当てたら、四つの行を書き換える。行数は動かない**（同じ行の中身を差し替える）。**てこ①は、配分の行を動かさない**（話の軸は動かないため）——**場面表の反応軸の欄と、その話の§内の「反応軸」の欄だけが動く。**

## 9. この文書が言っていないこと

- **一件も当てていない。** 本文・設計・場面表のいずれも、一行も動かしていない。
- **配分を決めていない。** §5 は**推奨**であり、案A1-1 の文面は「**具体的な配分は著者が決める**」と書いている。
- **面白くなるとは言っていない。** **配分は、場面の弧の軸を決めるだけである。** それが届くかは、**第三段の案が、その三種を実際に置くかどうか**で決まる。
- **§5 の5話は、私が区分けの一行から読んだものである。** **本文は一行も読んでいない。**
- **§3 の「書かれていない」は、走査した集合の話である**（`habits/構想/` と `references/`）。**リポジトリ全体を走査したとは言っていない。**
- **第四巻は、この文書でも動かしていない。**
