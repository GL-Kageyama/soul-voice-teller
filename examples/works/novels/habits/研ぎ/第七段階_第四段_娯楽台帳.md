## 3. 見つけたこと

### 3-1. 設計は、ユーモアの軸を、一場面にも配っていない

**設計が各場面に配った反応軸**（`反応軸` の欄。189 場面で数える）——

| 軸 | 場面 | 割合 |
|---|---:|---:|
| 感嘆 | 113 | 60% |
| 感動 | 64 | 34% |
| **楽しい** | **12** | **6%** |
| **ユーモア** | **0** | **0%** |
| 恐怖・かわいい | 0 | 0% |

**ユーモアは、63 話 189 場面のどこにも無い。** ⚠ 設計自身が
「**ユーモアは軸にせず、声に置く**」と決めている（`構想/design.md:79`）ゆえ、これは**設計の内訳どおり**である。
**だが、その声を、設計は禁じている**（`design.md:87`「読むだけで、誰も声に出さない」）。
**ゆえに、ユーモアの棲家は、設計の中で二重に閉じている。**

**楽しいの 12 場面は、4 話ぶんである**——`01-01`（心地よい）・`02-01`（速い）・
`02-04`（うまい）・`03-01`（丁寧）。**いずれも、その話の三場面すべてが楽しい**（話まるごと一本）。
**第四巻の 54 場面には、楽しいが一つも無い。**

### 3-2. 設計は、六軸の語彙に無い三種の名を、自分のために作っている

三種の名を正本（`6つの反応軸.md`）と突き合わせると、**正本に無い名が三つ**ある——

| 話 | 設計の軸 | 設計の三種 | 正本の楽しいの三種 |
|---|---|---|---|
| `02-01` | 楽しい | **速い** | 心地よい・ワクワク・ぞくぞく |
| `03-01` | 楽しい | **丁寧** | 同上 |
| `04-18` | 感動 | **余白** | （感動は じんわり・胸が熱い・こみ上げる） |

**それぞれ、その話の三場面すべてに同じ名が置かれている。** ⚠ これは**欠陥ではなく、設計の記述である**
——**検品の物差し（三種のどれか）が、この三話には掛からない。** 記録として残す。

### 3-3. 場面の型は、63 話とも三場面である

`位相` の欄——**掴む 63・置かせる 63・解放しない（または止める）63**。一話の場面数は
**63 話すべてが 3**。ゆえに型は 63 回反復している（計画の症状 C の実測）。

### 3-4. 入口は、設計が名指した句を**持っている**——だが、**第一段落には無いことが三分の一ある**

「第一場面の第一文——」と名指された句を持つ場面表は **63 / 63 枚**。

| 判定 | 話 |
|---|---:|
| **在**（②が八割以上） | 42（67%） |
| **後ろ** | 21（33%） |
| **無し** | **0** |

⚠ **「無し」が零であることが、この測定の要である**——設計が名指した字は、
**63 話すべてで、本文の第一場面に在る。** 無いのは**位置**である。

**巻ごとの②（第一場面が持っている字の、何割が第一段落にあるか）**——

| 巻 | ①設計の字を章が持つ | ②そのうち第一段落にある |

### 3-4a. 「後ろ」は、一つの症状ではない——三つに割れる

[`配置を組む.py`](配置を組む.py) が、第一〜第四巻の「後ろ」を**理由で割った**（21 話）——

| 理由 | 話 | 意味 |
|---|---:|---|
| **一点に寄らない** | **11** | どの段落も、設計の字の八割に届かない。**動かす先が無い** |
| **僅差** | **3** | 最良が、いまの入口より**二字以上多く持たない**（`03-10` は 3→4 字） |
| **一点に寄っている** | **7** | ある段落が八割以上を持つ。**これは、動かせる** |
| | **21** | ＝「後ろ」の総数（`場面表を検める.py` の 21 と一致） |

⚠ **いちばん多いのは「一点に寄らない」である。** `02-03` の入口は
「傘立ての前に立ち、数を確かめる」＝**漢字五字**で、**どの段落も三字まで**。
**これは「入口が遅い」ではなく「設計の数文字が、段落に散っている」である。**
⚠ **ゆえに、前回の診断「設計の要素は本文に在るが、位置が後ろ」は、少なくとも第一〜第三巻では、
成り立たない**——**位置が問題になるほど、字が固まっていない。**

### 3-5. 第四巻の入口は、**家具の目録**である

第四巻の 18 話の第一段落を読むと、**物の在庫を並べるところから始まっている**——

```
04-11 / 04-12 / 04-13 の第一段落——「机がある。机の脚が床に着いている。机の面が平らである。」
04-09 / 04-16 の第一段落——「紙がある。紙は平らである。紙は白い。紙は一枚である。」
04-02——設計の句は 25 段落目／04-13——19 段落目／04-12——13 段落目
```

**設計の入口は、段落 2〜25 に散っている。** ⚠ そして**第四巻は、本文に色語を一つしか持たない**
（`04-13:47`「影は青い。」の一色）——**物の名は書かれ、物の色は書かれない。** ゆえに入口の目録は、
**形と数だけの目録**である。

## 4. ⚠ この段で見つけて、直した器の欠陥

**`台帳を検める.py` が、第四巻の規則を、全巻へ掛けていた。**

この器（第三段の案を当てる前に検める器）は、八つを見る。うち**三つは第四巻の規則である**——

> **色語**（青・緑・黄・茶・灰・銀・紫・桃・橙）と**匂いの語**……を、**新しく持ち込まない**
> （**第四巻は、この二つが既に閉じている**）
> —— [`第七段階_第三段_prose_指示書.md:222-224`](第七段階_第三段_prose_指示書.md)
>
> **第四巻では**、「〜は、答えない。」「その、ままである。」を使わない（同 §4-4）
> —— 同書、および [`第四巻_締めの連_差し替え指示.md:68`](第四巻_締めの連_差し替え指示.md)

**⚠ 実測——本文で色語を持つ行は、一巻 17・二巻 43・三巻 5・四巻 1。**
第一〜第三巻の地の文は、色を普通に使う（`01-01:87`「罫が引いてある。薄い緑である。」／
`02-01:93`「二つとも青である。」）。**`README.md` の禁則（八つの語群）に、色語は入っていない。**
ゆえに、これは**全巻の禁則ではない。**

**掛け直した結果**——`CLOSED_VOLUMES = {"04"}` を置き、この三つを第四巻にだけ掛ける。
⚠ **掛けなかったことを、ヘッダが名乗る**——黙れば「空の検査はOKと言う」の型になる
（**検査が走っていないことが、合格に見える**）。

**踏んで確かめた**（一巻＝黙る／四巻＝鳴る）——

```
■ 01-02:5  ✅ 機械で見える範囲では、問題なし
   ＋ ……子の背の高さである、緑である。          ← 一巻。色語を新しく持ち込んでも、鳴らない
■ 04-10:5
   ＋ 机がある。点呼簿が机の上に開かれている、緑である。
   ⛔ 色語を、新しく持ち込んでいる: 緑              ← 四巻。鳴る
⚠ 色語・匂い・閉じた形の検査は、**巻 04 にだけ掛けた**。巻 01 には掛けていない。
   **ゆえに、この三つについて、巻 01 の ✅ は「合格」ではない。**
```

⚠ **`一案を検める.py`（第四巻に固定された旧い器）は、これで置き換えられる。**
計画は「`一案を検める.py` を四巻へ一般化する」としていたが、**一般化された器は既に在った**
（`台帳を検める.py`）。**足りなかったのは、その中の三つの検査の、巻の切り分けだけである。**
**ゆえに、同じことをする器を二つ持たない**——`一案を検める.py` は残すが、第三段以降は使わない。
