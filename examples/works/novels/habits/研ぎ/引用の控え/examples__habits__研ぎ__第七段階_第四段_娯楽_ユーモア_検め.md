# 娯楽・ユーモア——**当てる前の検め**（検め役へ）

## 0. この段の位置

**⚠ 第三段で、順序を誤った。**

> **当てる前の人の読みを飛ばした**——機械の検算だけで 140件を当て、そのあとで検めさせた。
> **ゆえに ⛔ 12件が、一度本文へ入った。**
> （[`第七段階_第四段_娯楽_届いた_案_当てた.md`](第七段階_第四段_娯楽_届いた_案_当てた.md) §2-1・§5）

**この段は、その順序を正す。** **案は、当てる前に、人（あなた）が読む。**

```
案（八人が書いた）→ ★ 検め（あなた）→ 当てる → 測る
```

**⚠ あなたは、案を書いた者ではない。** **あなたの仕事は、案を良くすることではなく、`当ててよいか` を判定することである。**

## 2. 三つの判定

**一案ごとに、一つ。**

| 判定 | 意味 | 帰結 |
|---|---|---|
| **⛔** | **当ててはならない。** | 戻す（当てない） |
| **△** | **当てられるが、疑わしい。** | ⚠ **著者が読む番へ回す** |
| **✅** | **当ててよい。** | 当てる |

**⚠ `△` を濫用しない。** **`△` は「私には決められない」ではなく、「本文か設計文書と、積極的に衝突する側に一件でも読める」である。**
**⚠ 逆も同じ**——**「たぶん大丈夫」で `✅` を付けない。** **四つの根拠（§3）が自分で言えるときだけ `✅` である。**

### 2-1. ⛔ の条件——**一つでも当たれば ⛔**

**⚠ 第三段で、四人が同じ形の誤りを 12件見つけた。** **そこから作った一覧である。**

| # | ⛔ の条件 | 第三段の実例（**当ててはならなかった**） |
|---|---|---|
| 1 | **本文が自分で立てた不変を、破る** | `02-06:275`「それから、もう一度鳴る。」← 同じ行の「一度である。」と `:269`「もう鳴らない。」 |
| 2 | **「動かない」と書いてある物を、動かす** | `02-02:47`「袋が、ひとつ揺れる。」← `:49`「袋は動かない。動かす者が居ない。」 |
| 3 | **同じ物を二度、消す／鳴らす／止める** | `02-15:419`「事務所の灯りが、ひとつ、消える。」← `:405`「営業所の中の灯りが消える。」 |
| 4 | **その場面に居ない者に、させる** | `02-02:229`「台車の車輪が、ひとつ鳴る。」← 押す者が居ない |
| 5 | **場面表の「動かさないもの」に触る** | `02-07:313`「戸の内側で、スリッパの音がする。」← 場面表が「届け先の玄関の内側を、書かない」と定める |
| 6 | **同じ一句が、別の行に逐語で在る** | `02-07:313` ← `02-09:293` に同一の一句 |
| 7 | **禁則語**（`../README.md` の「## 禁則」） | 利息・借・貸・返済・清算・負債・帳簿・残高・請求・担保・信用／愛・所有・関係・恩・縁・功徳／「AI」／編集・場面・カット・アングル・アップ・演出・観客・視聴者・「アニメ」／上限・定員・容量・枠／煙草・煙管・吸殻・路上喫煙／「読者」 |
| 8 | **感情に名を与える**（`悲し/さびし/うれし/怖/つらい`） | **塀である。** 全63話で 0件 |
| 9 | **説明・解釈・総括を書く**（状態でなく） | この作品の欠陥そのものである |
| 10 | **新しい物・出来事・数を、持ち込む** | 使ってよいのは、**既にその場面にある物・行為・音・声**だけ |
| 11 | **`?` を閉じる** | 設計が読者へ投げた問いに、答えを足さない |
| 12 | **第四巻だけ**——**人称・内面・回想・記憶**／**色語**（青緑黄茶灰銀紫桃橙）／**匂いの語**（匂・におい・臭・香・嗅）／**「〜は、答えない。」「その、ままである。」**／**鉤括弧** | ⚠ **「ままである」一般ではない**——「触ったままである」は第四巻に110行あり、正しい用法である |
| 13 | **差し替え後が五文以上** | ⚠ **器は ⛔ にしない**（⚠ 註だけである）。**この段の規則であり、あなたが守る** |
| 14 | **鉤括弧の中を、触っている** | 第四巻は、そもそも鉤括弧を置かない |

### 2-2. ✅ の条件——**四つとも、自分で言えること**

**⚠ 案の `根拠` 欄に四つが書いてある。** **それを読んで、自分で確かめる。**

| # | 何を確かめるか |
|---|---|
| ① | **型**——字面のすり替え／逆転／過剰な精密さ／三段オチ のどれかである |
| ② | **土台**——**本文のどこが、その予測を作っているか。** **⚠ その行を、自分で開いて確かめる**（**申告を信じない**——前段で、読み手が申告した逐語 23件のうち 3件が誤っていた） |
| ③ | **外した予測**——**読者が何を予測し、どこで外れるか。** **⚠ 事実を裏切っていないこと**（裏切ってよいのは、**読者の予測だけ**である） |
| ④ | **回収**——**どの一文が、それを安全に回収するか。** **回収の無いズレは、不条理である** |

## 3. とくに見るもの——**場所**

**⚠ 同じ案でも、置かれる場所で効きが変わる。**

| 見るもの | どう見るか |
|---|---|
| **入口** | **場面の第一段落に置かれているか。** ⚠ 入口は実測でいちばん弱い欄である（`第七段階_第四段_娯楽_届いたかを測る_第二層.md` §3-1）。**第一段落に置ける案は、同じ内容なら、後ろに置くより良い。**（**第四巻の入口は場面2である**） |
| **場面末** | **その行が場面の最後であるか。** 場面末の一行は**強く効く**ゆえ、**そこに置く案は、いっそう厳しく見る** |
| **章末** | **その行が話の最後であるか。** **章末の設計を動かす案は ⛔ である。** |
| **一拍の直後** | **その場面の「記名の現場・一拍・扱う癖」の直後か。** **⚠ 一拍の直後に何かを足すと、一拍が薄まる。** |

## 4. 出すもの

**あなたの巻の、一本の TSV**——

```
examples/habits/研ぎ/娯楽_ユーモア_検め_0N.tsv
```

**⚠ ファイルを書くのは Write ツールで。** **`>` によるシェルのリダイレクトで作らない**（先に切り詰めて中身を失う事故が起きている）。

**五欄のタブ区切り**（先頭に `#` で始まる註の行を数行置いてよい）——

```
鍵<TAB>判定<TAB>当てるか<TAB>理由<TAB>確かめた行
```

- **`鍵`** は `01-01:121` の形（**案の TSV と同じ**）。
- **`判定`** は `⛔`／`△`／`✅`。
- **`当てるか`** は `戻す`／`著者`／`当てる`（**⛔→戻す・△→著者・✅→当てる**）。
- **`理由`** は一句。**⛔ と △ は、必ず §2-1 の番号を書く**（例 `⛔5 場面表が「届け先の玄関の内側を、書かない」と定める`）。
- **`確かめた行`** は、**あなたが実際に開いた行**である（例 `:151` `:405`）。**⚠ 開いていない行を書かない。**

## 5. 返すもの

**最終的な返答に、次を丸ごと入れる**（**ファイルは上記の一本だけ**）：

1. **書いた TSV のパス。**
2. **走査した集合**——**何件を読み、⛔ 何件・△ 何件・✅ 何件か。** **未判定が 0件であること。**
3. **`⛔` の全件**——鍵・当てるはずだった文・理由。
4. **`△` の全件**——同上。
5. **⚠ とくに、自分の目で捉えたもの**——**この巻を通して見て、案の書き手が系統的に外しているところはどこか**（第三段では、四人が同じ形の誤りを12件見つけた）。**数を書く。**
6. **確かめられなかったこと。** **⚠ 空欄を作らない。** **「確かめていない」と書く。**
