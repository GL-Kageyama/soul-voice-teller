**根拠**——[`第七段階_段落化_計画.md`](第七段階_段落化_計画.md)（§2 の規則・§8 の裁定・§11 の試し）。

## 0. 何をするか

**一話の草稿を、一行一文の形から、自然な一行多文の形へ組む。**
**⚠ 字は、一字も触らない。** **⚠ 行の切り方だけを変える。**

**出力は、台帳一本である**——タブ区切り、一行一件。

```
<草稿の絶対パス><TAB><行番号><TAB>組む
```

**⚠ 「切る」は書かない。** **⚠ 既定が「切る」である**（いまの形）。**⚠ 台帳は、例外だけを書く。**
**⚠ 行番号は、いまの（組む前の）行番号である。**

## 1. 規則——`/prose` の 7-E「段落の位置」

**この段の技能は、これ一本である**（[`../../../skills/prose/SKILL-ja.md`](../../../skills/prose/SKILL-ja.md)）。
**⚠ 段落は「決定的な一撃」で切る。** **⚠ 数で切らない**（三文ごと、など）。
**⚠ 短い文を寄せ集めて、余白を潰さない。**

### 判定——その行を、直前の本文行へ繋ぐか、切るか

**⚠ 繋ぐ**（「組む」と書く）——

1. **同じ拍の続きである。** 物・動作・場所・手が、変わっていない。
   - 「窓の外は校庭である。」＋「校庭に人は居ない。」＋「砂が白い。」
2. **列である。** 同じ形の観察が、三つ四つ並んでいる。
   - 「扉が四枚ある。」＋「四枚のうち三枚はしまってある。」
   - 「机が六つある。」＋「椅子が六つある。」＋「椅子はみな机の下に入っている。」
3. **主語を受けて、説明が続く。**
   - 「厚みがある。」＋「一年ぶんである。」
   - 「ボールペンである。」＋「インクが少し濃い。」＋「濃いのは力のぶんである。」
4. **動作が続く。** 一つの身振りの、手順。
   - 「同僚は鞄を机の横に置く。」＋「上着を掛ける。」＋「掛ける場所は毎朝同じである。」

**⚠ 切る**（何も書かない）——

1. **一拍で立つ文である。** **⚠ 繋ぐと、強調が消える。**
   - **「名は書いていない。」**
   - **「入っていないのは私のだけである。」**
   - **「まだ開かない。」**
   - **「閉じない。」**
   - **「はい。」**
   **⚠ 判定は字数ではない。** **⚠ 「その一文が、段落として立つか」である。**
2. **会話（鉤括弧）は、必ず単独の段落である**（下の §2-1）。
3. **場面の最後の一文は、単独で置く。** **⚠ これは規則ではなく、この作品の形である**——**下の註を見る。**
4. **場面の最初の一文は、単独にしない**——**⚠ 繋げられるなら繋ぐ**（**入口は、掴むために要る**）。

**⚠ 註——場面の最後の一文（2026-09-26 に、一度消して、戻した）。**

**⚠ この紙の版は、いったん「場面の最後の一文は単独」を消した。** **⚠ 理由は、承認済みの第一巻第一話が
場面2の最後の行（旧 `:519`「置いた手はまだ紙の上にある。」）を組んでいたためである。**
**⚠ そのあとで、四十二行を数えた**（**第一巻十四話・三場面ずつの最終本文行**）。

## 3. 手順

```
① その話の草稿を、頭から最後まで読む
② 場面ごとに、拍を数える（物・動作・場所・手の変わり目）
③ 台帳を書く——「組む」と書く行だけ
④ 出す前に、自分で数える——本文行数と、組んだ件数と、その割合
```

**⚠ 読まずに作らない。** **⚠ 一話を一つのまとまりとして読む**——
**⚠ 場面3の引きが、場面1の入口とどう対応しているかを見る。**

## 4. 出したあとに、何が起きるか（⚠ 台帳を書く者は、当てない）

**⚠ 当てるのは `段落を組む.py` である。** **⚠ この器が、当てる前に九つ、当てたあとに五つを確かめる**
（**器の docstring に一覧がある**。**読み方——① ファイルがある ② 行がある ③ 本文行である ④ 見出し行でない
