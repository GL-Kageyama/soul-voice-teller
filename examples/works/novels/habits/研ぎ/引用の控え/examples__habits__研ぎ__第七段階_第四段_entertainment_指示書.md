   **「悲しい」「うれしい」「さびしい」を、地の文の内面記述として置かない。**
4. **第四巻に、人称・内面・回想・記憶を持ち込まない。** **さくらは内面を持たない者であり、
   置かないことは、この巻の規則ではなく、この人物である**（決定 C-18・`構想/design.md`）。
5. **禁則語を、持ち込まない。** 第四段の案が持ち込んだ禁則語は、第三段の一件と同じ形で

## 2. この段の線——足してよいのは「具体」だけである

**⚠ `SKILL-ja.md` の手順4——「弱い軸を、その軸の四工程と三種で補う。足すのは具体（行為・映像・音）
だけ」。** **ゆえに、この段の案は、次の三つの形のどれかである。**

| 形 | 何を足すか | 例（この作品の語彙で） |
|---|---|---|
| **行為** | 手・足・口・目の、一つの動作 | **手が止まる／指が行の上にある／振り向く** |
| **映像** | 物の、形・位置・明るさ・影 | **紙の端が、机から出ている／影が、行の上で切れている** |
| **音** | 現場の音 | **戸の音が一度鳴る／頁の音がしない** |

**⚠ 足してはならない形**——説明・解釈・総括・名指し・比喩・新しい物・新しい人物・新しい時刻。

**⚠ 一行を足すことは、行数を動かす。** **この段は、第三段と違って行数不変ではない。**
**ゆえに、この段のあとに第九段の貼り直しが要る**（`NN-NN:NNN「…」` の引用は、挿入の数だけずれる。
**ずれは、一行挿すごとに +2 である**——[`../../進捗表_履歴.md`](../../進捗表_履歴.md) §36 の註）。

**⚠ ゆえに、足す量は、最小である。** **案は、一話あたり一行から三行までを既定とする。**
**それ以上を要する話は、この段ではなく、設計の側の話である**——**そのときは、著者へ諮る。**

### 2-1. 予定字数を、この段の目標にしない

**⚠ 決定（2026-09-21、著者）——予定字数は、目安である。** **`話割り` の字数欄と `design.md` の
合計字数は、書く前の見積もりであり、本文がそこへ着地すべき目標ではない**
（[`構想/design.md`](../構想/design.md)「検算」の末尾）。

**⚠ 実測（2026-09-26）——本文の各場面は、設計の字数を、すべて下回っている。**
**場面1の差の中央値は −236字、場面2は −406字、場面3は −342字である**（六十三話。
**いちばん大きいのは第四巻で、場面2の中央値が −1,500字を超える**）。

**⚠ これは、それ自体では欠陥ではない**（上の決定）。**この表を、この段の目標にしない。**
**この表が言えるのは、一つだけである**——**場面1に、掴むための余地が在る**（**とくに第四巻**）。
**字数を埋めるために具体を足すのではない。****掴めていない入口に、掴むための具体を足す。
その結果として字数が動くだけである。**

## 3. 検品の観点——三つの位相と、二つの弧

### 3-1. 場面1——「掴む」

- **未知が立っているか。** 最初の一、二行が、読者に問いを一つ渡しているか。
- **具体が在るか。** 行為・映像・音のどれかが、最初の数行に在るか。
- **流れが在るか。** 短文の連なりが「切る」のではなく「止まる」になっていないか。
- **⚠ 第四巻の予備調査**——十八話のうち**十五話が「〜がある。」で始まっている**
  （「机がある。」が六話・「紙がある。」が二話・「頁の上である。」が二話）。
  **これが掴むとして働いているかは、本文を読んで判定する**（**物だけで立つことは、
  この巻の設計である。ゆえに、物で始まること自体は欠陥ではない**）。
  **⚠ 判定は、2026-09-26 に出た——この入口は、この段で扱わない**（**`検査/check.py` の実測により、
  これらの行は第四巻の基底語である。** **⚠ 順序の規則も、そこで一本、足した**——
  **案を作る前に、検査器を走らせる**。[`README.md`](README.md) §3-7）。

### 3-2. 場面2——「置かせる」

- **一拍が生じているか。** 誰かが名を目で読み、**運搬が止まる**場所になっているか。
- **読むだけで、誰も声に出さないか。**（`構想/design.md`「文体の方向」）

### 3-3. 場面3——「解放しない」

- **解放していないか。** 総括・名指し・教訓で閉じていないか。
- **話末の引きが、次話への断ちになっているか。**（`?` のまま置く——`残件.md`）

### 3-4. 巻の弧——感嘆の四工程と、感動の四工程

| 巻 | 感嘆 | 感動 |
|---|---|---|
| 一 | 誘導 | 同一化の土台 |
| 二 | 超出 | 価値の提示 |
| 三 | 必然 | 代償の支払い |
| 四 | 頂点 | 抑圧の頂点 |

**⚠ 四工程は、その巻の内側で「誘導 → 超出 → 必然 → 頂点」の一段だけを担う。**
**一段が、その巻の全話に通っているかを見る。**

### 3-5. エンジン——未知×知りたさ

**⚠ 興味は軸ではなく、六軸すべてを貫く次元である**（`references/ja/6つの反応軸.md`）。
**どの軸に乗っていても、興味が切れた瞬間、読者は離れる。**

## 4. 案の作り方と、承認の順

**⚠ 第一段から第三段と同じ順である。**

```
検品 → 案（台帳） → 機械検証 → 著者承認 → 当てる
```

1. **検品**——四巻それぞれに、反応軸の検品を掛ける（六軸の定義と、設計の物差しを読ませる）。
2. **案（台帳）**——弱い軸の実物にだけ、**具体（行為・映像・音）を行番号つきで**作る。
   **案は、その話の本文に既に真であるものを書かない**（`一案を検める.py` が機械で見える分を
   検めるが、**「その案が、その話の本文に既に真であるか」は機械で見えない。人が読む**）。
3. **機械検証**——当てる前に「その行がいまその文であること」、当てたあとに
   「**挿入の位置が、意図した位置であること**」と「**他の行が動いていないこと**」を確かめる。
4. **著者承認**——**案を作るのは AI であり、決めるのは著者である。**
5. **当てる**——`差し替える.py`（置き換え）／挿入は別の器が要る（**この段で作る**）。

**⚠ この段の台帳が空であることは、失敗ではない。** **見つからないときに、案を作らない。**
