## 1. 一手——**設計の三つのうち、長い区間は一つしか持っていない**

**第四巻の規則**（[`../構想/design.md`](../構想/design.md) 決定5）——

> **地の文に置くのは、書かれた名と、それに触れた手と、物の位置だけである。形容は、物にだけ許す。**

**⇒ 三つである——`名`・`手`・`位置`。** **長い目録区間は、`位置`だけを持つ。**

**ゆえに一手をこう定めた**（指示書 §2）——**区間の内側の一行を、「物の報告」から「その物に、体が関わる」行へ。物と状態の情報は残す。行数不変・新しい物と人物なし・鉤括弧なし・感情の名なし。**

**⚠ この一手には、既に一度効いた実例が在った**（§3-27）——`01-14`「退職の日である。午後である。」→「**退職の日の午後、私は棚から出席簿を下ろす。名の書かれた位置に、もう一度立つ。**」

**対象＝場面1の 98 区間 ＋ 場面2・3 で 8 行以上の 24 区間＝122 区間・804 行**（[`目録_対象区間.tsv`](目録_対象区間.tsv)）。

## 3. ⛔ 却下の理由——**44件のうち 42件が、同じ一文の形をしていた**

**足された一文を、機械で並べた。**

| 数 | 足された一文の形 |
|---:|---|
| **28 / 44** | **`私は、その〈物〉に…`** で始まる |
| **39 / 44** | **`私は、…`** で始まる（＋`私の背は…`×1・`私の踵が…`×1・`私も、…`×1＝**42**） |
| 21 / 44 | 知覚の動詞（`目をやる`4・`見る`4・`読む`3・`目を送る`2・`目を落とす`1・`目でなぞる`1・`目を追う`1・`なぞる`3 ほか） |
| 17 / 44 | 手・指の接触（`指を当てる`6・`指にかける`2・`手を置く`2・`手をかける`2・`手を当てる`1・`手を重ねる`1 ほか） |

**⚠ 実物を、四つ挙げる**（第一巻の案のまま）——

| 行 | いまの文 | 案（足した一文だけ） |
|---|---|---|
| `01-01:19` | 取っ手が四つある。取っ手はどれも同じ形である。 | **私は、いちばん上の取っ手に目をやる。** |
| `01-01:23` | 背に年度が書いてある。書いてあるのは年度だけである。 | **私は、その年度だけを読む。** |
| `01-02:9` | 板は二枚ある。上の板には何も無い。 | **私は、その上の板へ指を当てる。** |
| `01-07:105` | （連の内側） | **私は、その目の先を追う。** |

**⇒ これは、一手ではない。** **一つの型である。** **一日で、新しい基底語を作った。**

**⚠ そして——この作品が、それを一番嫌う。** 娯楽の段は、**話をまたいで逐語で現れる段落を 29 → 18 種へ減らすために、まるごと一つの段を費やした**（[`第七段階_第四段_反復_当てた.md`](第七段階_第四段_反復_当てた.md)）。**第九段は、それを 44件ぶん作り直すところであった。**

**⚠ 第二巻ぶんの途中まで作らせていた案も、同じ形をしていた**（足した一文の型が `◯を、◯の◯に◯てる。`・`◯が、その◯へ◯く。` に並ぶ）。**ゆえに、四巻ぶんとも打ち切った。** **第二〜第四巻の案は、書かせていない。**

## 4. 却下の理由は、形だけではない——**そもそも、これは「出来事」ではない**

**⚠ 形を散らせば、直るのか。** **直らない。** **理由を、三つ書く。**

1. **`私は、その取っ手に目をやる。` は、何も起こしていない。** **取っ手は、その前も後も同じである。** **「体を足せば具体になる」は、物に体を向けることではなく、物に**起きること**を書くことであった。** **⚠ この段は、その区別を踏み外した。**
2. **著者の訴えは「説明ばかり」である。** **`私は、その年度だけを読む。` は、説明を一行ぶん足している。** **⚠ 計画の §「治し方の向き」が、いちばん出してはならない案として名指しした形そのものである**——「**説明を足す治し方は、いちばん出してはならない案である。**」
3. **`01-14` の実例と、似ていない。** **あれは「退職の日である。午後である。」という*状況の報告*を、*その日の行為*へ変えた**（昼の報告 → 棚から出席簿を下ろす）。**⚠ 第九段の一手は、*物の報告*の後ろへ、*物への知覚*を継ぎ足した。** **前者は場面の重心が動く。後者は動かない。**

**⚠ ゆえに、この一手は「実行が下手だった」のではなく、**一手そのものが誤っていた**。** **四巻ぶん、198 行を、この形で書き換えるところであった。**

## 5. そこから見えた、もっと大きいこと——**この設計では、1対1の置き換えでは届かない**

**この段が踏んだのは、この作品の「詰まり」の正体である。**

**⚠ 骨格を動かさずに本文へ手を入れる道は、いま、これだけである**——

| 道 | いまの状態 |
|---|---|
| **一行を、別の一行へ**（`差し替える.py`） | **✅ 使える。** **⚠ 但し、目録行の内側で1対1に置き換えられるのは、知覚か接触しかない**（＝§3 の型になる） |
| **行を消す** | ⛔ **使えない。** **引用座標 `NN-NN:NNN` が総崩れになる**——[`README.md`](README.md) §3-21 が、`引用を貼り直す.py` を**当てない**と決めている |
| **段落を組む／文を畳む** | ✅ 使った（段落化・第八段階 流す） |
| **新しい物・人物・会話を足す** | ⛔ 足せない（§3-10 が「**会話は、鉤括弧を足す形では当てられない**」と実測） |
| **第四巻に内面を入れる** | ⛔ **A5-1。著者裁定 2026-10-14。動かさない** |
| **`?` を閉じる** | ⛔ **規則9・「外さないもの」** |

**⇒ ゆえに、著者の言う「面白さが薄い」の残りは、*本文の一手*の問題ではなく、*上の裁定*の問題である。**
**⚠ これは逃げではない。** **娯楽の段は 300 行を超える手を当てて、この壁に当たった**（§3-23——評価者は 13次元中、娯楽を測る次元を持たず、**ユーモアの語が三回・39体で出現 0**）。**第九段は、別の側から同じ壁へ当たった。**
