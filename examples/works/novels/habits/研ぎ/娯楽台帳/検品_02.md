# 娯楽の検品 第二巻（15話・45場面）

判定の物差しは `references/ja/6つの反応軸.md`。各行＝台帳の3欄（行範囲）が指す一つの場面。

## 方法（何を「届いた」に数えたか／数えなかったか）

- 数えたのは、**その場面を読んだ読者に実際に反応が起きるか**。設計にその軸が**在るか**ではない。
- **説明・名指し・総括は「届いた」に数えない。** 「三つのあいだに三年がある」のような地の文の総括は、それを読んだだけでは反応にならない。
- この作品は**感情に名を与えない**。感動は**発露と抑制**——体が実際に動く・止まる具体の側——から読んだ。抑制の一行（「私は……しません」）だけがあり、それが支える発露が本文に無い場面は、届いたに数えていない。
- 敬体一行（第二巻は15話中13話がちょうど一つ持つ。02-09と02-12には無い）は、**地の文の敬体であって発話ではない**。ユーモアの判定では、この一行を「声」として数えていない。
- 迷った場面は弱いほう（なし）へ倒した。**根拠は本文から引いた。推測で埋めていない。**

## ⚠ ユーモアも楽しいも一度も届いていない話

**15話すべて。**（45場面のどこにも、ユーモア＝0、楽しい＝0。二つの軸を持つ場面が一つも無い。）

とくに注意すべきは、**設計が「楽しい」に置いた二話（02-01・02-04）でも、楽しいが一度も届いていない**こと。02-01は三場面とも なし／感動、02-04は なし／感嘆／なし。設計の「楽しい（速い）」は、本文では**動作の速さの描写**にとどまり、読者に**正の情動と流れ**（心地よい・ワクワク・ぞくぞく）を起こしていない。

## この巻でいちばん娯楽から遠い場面（五つ・本文を引く）

いずれも「なし」に落ちた場面である。感情も、笑いも、感嘆も起きず、**手が止まっていることそのものが百行続く**。

1. **02-02 第二場面**（惣菜の値引きシールを凝視する）
   > その指の向こうにシールの面がある。僕の目がその面に入る。面に字がある。……**読むのは目である。** 指は紙に当たっている。当たっているだけである。
   指は動かない。息が浅い。頁の大半が、動かない指と止まった光の記述で埋まる。

2. **02-05 第一場面**（荷台へ箱を積む作法）
   > **この仕事では貼ってある紙はそのまま、運ぶ。この仕事では紙のところを持たない。**
   運搬の規則を地の文が名指しで総括してしまい、読者が自分で掴む超出が残らない。

3. **02-09 第二場面**（箱を置き、写真を撮る）
   > 画面の四角を合わせる。……**僕はその四角を遠くから見ている。** ……**この紙に運ぶ者の欄は無い。**
   日常の作業が淡々と写され、「運ぶ者の欄は無い」という一点だけが残るが、それは総括であって反応にならない。

4. **02-10 第三場面**（四枚目の紙の手前で手が止まる）
   > 指の先が紙の手前にある。触っていない。爪の先が白い。**紙には触らない。読まない。** ……取っ手を握る。指が握りにかかる。親指が上に来る。力は要らない。押せば、動く。**それでも、押さない。**
   止まったままの手が、場面の後半を埋める。場面が終わっても、読者に渡る反応が無い。

5. **02-12 第一場面**（四軒目、同じ番地）
   > **三軒とも置いた。三軒とも写真を撮った。三軒とも声はかからなかった。** この仕事では声をかけられる。一日に何度もである。
   同じ番地・同じ動作の反復が並ぶだけで、場面が読者へ何も投げない。

## 数えた数

分母は45場面。

- **ユーモア = 0場面**
- **楽しい = 0場面**
- **感嘆 = 8場面**
- **感動 = 14場面**
- **なし = 23場面**

（0 + 0 + 8 + 14 + 23 = 45）

掴んでいるかの内訳：○ 8、△ 14、× 23（× はすべて「なし」の場面）。三種の内訳：なるほど 7、じんわり 9、こみ上げる 4、胸が熱い 1、うまい 1、なし 23。

## この文書が言っていないこと

- 場面や作品の**良し悪し・質**は判定していない。娯楽の六軸が届いたかどうかだけを見た。
- 「なし」が**欠陥である**とは言っていない。設計が意図して解放しない第三場面では、なしが設計どおりの結果でありうる。
- **どの軸が正しいか**は判定していない。設計の軸と実物が違う、と並べただけである。
- 台帳の3〜15欄の**数値（字数・段落・文・会話・設計の三種の当否）は検算していない**。行範囲だけを場面の区切りとして使った。
- **第一巻・他巻との比較**はしていない。判定はこの第二巻の45場面の内側だけである。
- 敬体一行（私は……しません／ます。）を、**ユーモアの「声」としても、感動の「発露」としても数えていない**。地の文であって発話でないため。
- 台帳22欄（案）は空のままにした。**案は書いていない。**
- この数の**原因**（なぜ楽しいが届かないか）は分析していない。数と、引いた本文だけを置いた。
- 判定は**一読の判断**であり、読者調査や統計ではない。同じ本文でも、読む者によってこの表は動きうる。
