## 5. 軸3——締めの反復句を、その話に固有の残留物で置き換える

### 5-1. 軸の原文（`axis[3]` 逐語）

> 締めの反復句（「その、ままである」）のうち数箇所を、その話に固有の残留物（紙の目、埃の形、欄の幅）で置き換える。

### 5-2. 実測——前提が、二重に崩れた

**⚠（a）「その、ままである」は、十四話の話末に、一度も無い。** **八件は、すべて本文の内側にある。**

```
03:755  〔## 3〕 指の、形が、その、ままである。
03:787  〔## 3〕 湯は、その、ままである。
04:349  〔## 1〕 その、ままである。
04:923  〔## 3〕 その、ままである。
06:923  〔## 3〕 その、ままである。
07:691  〔## 2〕 その、ままである。
11:777  〔## 3〕 その、ままである。
13:255  〔## 1〕 その、ままである。
```

**⚠（b）話末は、既に四つの型に分かれている**（**§1-3**）。**「〜、ままである」で終わるのは、四話である。**

```
02 閉じた、ままである。
07 名の、欄は、空いた、ままである。
09 呼ばれない、ままである。
10 見えない、ままである。
（05 影が、無い。／06 動かない。／12 指は、動かない。／14 止まらない。＝ 否定の型）
```

**⚠「始業まで、〜、ある。」が三話にある。**

```
01 始業まで、まだ、ある。
03 始業まで、五分、ある。
08 始業まで、十分、ある。
```

**⚠ 三つとも、時刻の残量である**——**ゆえに、これは繰り返しではなく、この巻の時計である**（**反復句として置き換えると、時計が壊れる**）。

### 5-3. 当てるなら

**対象は、軸が名指しした「その、ままである」ではなく、話末の「〜、ままである」四件である。** **そのうち、その話に固有の残留物へ置き換える候補は、二件である。**

- **`02:831`「閉じた、ままである。」**——**第2話の残留物は、名の欄に書かれた名と、閉じた連絡帳である**
- **`09:1027`「呼ばれない、ままである。」**——**⚠ これは残す。** **「呼ばれない」は、川上桜の規律（桜という音を一度も置かない）と結びついた、この話の核である**（**場面表09**）

**⚠「名の、欄は、空いた、ままである。」（`07:1001`）は、場面表07 の第三場面が、そのまま逐語で書いている**——**動かすなら、場面表を先に動かすことになり、設計に触れる。** **ゆえに、候補から外す。**
