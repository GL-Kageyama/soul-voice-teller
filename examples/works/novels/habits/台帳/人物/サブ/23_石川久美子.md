## 呼ばれ方の履歴

**この作品では、これが造形そのものである。**

| | |
|---|---|
| 職場で | **「石川さん」。** 班長十年で、下の名前を職場で使う者はいない（run-09） |
| 家族に | 夫が「おい」、長女が「かあさん」、次男が「かあちゃん」（run-09） |
| 誰にも呼ばれない名 | **「久美子」。** 最後に呼んだのは**平成二十六年の姑**である（run-09） |

**決定（2026-09-13）**——姑は、最後のひと月、彼女を「**くみちゃん**」と呼んだ（run-09、依頼者コメントにより訂正済み）。**久美子から「ゆみ」は導けない。** 同じ run の三番、高橋**由美**（ゆみ）からの混入であった。二十四名の呼ばれ方を全数照合した結果、**ずれはこの一箇所だけで、他はすべてその人の名から正しく派生していた。**

**呼んだ者は、家族ではない。** 夫は「おい」、長女は「かあさん」、次男は「かあちゃん」——**血の続きの三人が、三人とも名を出さない。** 名を出したのは、平成二十六年に死んだ姑である。**そして姑は、名ではなく、縮めた形で呼んだ。**

## 本編での扱い（規律）

- **主役回は第一巻第6話のみ。** **二度目を持たない**——二度目を持つ九名に入らない（[`../README.md`](../README.md)「配属の索引」）。

## テーマとの結びつき〔導出〕

核心の問い「**呼ばれた名は、誰のものか。**」——第一巻の問いは「書かれた名は、書いた者のものか、呼ぶ者のものか」である。

→ 記名＝欠席者の名簿（run-09）。**欠席者の名簿は、来なかった者の名だけが載る紙である。** 癖は「食前に、欠席の子の名を数える」——**名簿の名を、配る前に行き先へ送る。** そして run-10 の会話の一行——**「数と献立のみ」。**

**数は、名の代わりに運ばれる。** 第一巻の問いに、彼女は**「来なかった者」という位置**を足す（書かれる前＝佐藤美咲、呼ばれる前＝片山大翔、読んだ者＝碓氷千夏）。

**そして【独自フック】が、この巻の外へ一本の線を引く**——「二十四名とは、発送され、世界に受け取られ、そして開かれなかった二十四通の荷物である。**呼ばれない名というものはない。取りに来られなかった名があるだけである。**」**欠席調べの名簿は、その二十四通の最初の一枚である。**
