## 📝 総評

> 十三名は、この一話を innovation（現在価値 60.6／潜在価値 67.7）と判定した。世界（76）・主題（74）・凡庸さの回避（74）・散文（72）が高く、感嘆（40）・人物の深さ（42）・引き（52）・読書体験（56）が低い。最大の割れは、不作為が実行される前に規則文として告知される構造で、それを「超出を殺している」と読む席（admiration 40）と「規則の提示」と読む席（plot-architecture 64・narrative-technique 67）が割れる。第二の割れは、本文中に一度だけ現れる一文——「私は、いちばん上の一枚だけを、見ます。」——を、この一話が自らの規則を破る唯一の場所と読む席（narrative-originality 63）と、標識を持たない乱れと読む席（prose-style 72）の対立である。三席が同じ一行に、事件・瑕疵・不作動という三つの名を与えた。

## 🤝 一致点

十三名が一致した点は四点である。第一に、この一話の出来事が不作為そのものであること——読まない・触らない・押さないが行為として置かれ、それ以外に何も起こらない。第二に、宛名票が四枚重なっているという前提が、説明されないまま構造の全体を担っていること。第三に、末尾の「いちばん上は、四枚目である」が、数え上げを反転させる唯一の開示点であること。第四に、最も低い席が人物（character-depth 42・character-role 55）と反応（admiration 40・hook 52）に集まり、最も高い席が世界（world-building 76）・主題（theme-resonance 74）・凡庸さの回避（anti-generic-story-filter 74）に集まること——この一話の重量が、人物ではなく物体と手順にあること。一致はここまでで、末尾の一行を閉じた答えと読む席と、開いた問いと読む席が割れる。また本文中に一度だけ現れる「私／丁寧体」の一文を、形式の唯一の破れと読む席と、標識の無い乱れと読む席が割れる。

## 🎯 推奨アクション

1. 不作為の事前告知（規則文の位置）が、この評議会の中心の争点である。告知を後ろへずらせば admiration の超出は戻るが、plot-architecture の言う「規則の提示」は失われる。この一話では、規則は読者の側に先に渡す設計であり、動かすなら両席の値を同時に測り直す必要がある。評議会は決めない。
2. 本文中に一度だけ現れる「私は、いちばん上の一枚だけを、見ます。」に、三席が三つの名を与えた。この一文がこの巻の値（揺れる私）の実装であるなら、二箇所目を置くという narrative-originality の提案は設計の側の判断になる。一箇所のままなら、この席の言う「判別不能と紙一重」が残る。
3. 四枚の重なりの来歴を物理の層で一度返せ、という提案が narrative-originality・theme-resonance・world-building から出ている。ただしこの巻は「四度とも受け取りに来なかった人がいる」を幹として温存し、答えを出さない設計である。紙のずれの向き・糊の乾き方・埃のつき方という手がかりの層に限るなら設計に触れないが、線の引き方は著者の裁定である。
4. 「様」の側に立つこと、四枚目に送り主の名がないことは、この巻では書かない決定である。改善提案がここへ届いていないかを確認する。
5. 前話までに四枚がどう重なったかを知った上で同じ本文を読むと、末尾の「いちばん上は、四枚目である」の値が動く。今回は連作の約束を一行だけ渡しており、それ以前の話は渡していない。再評価はこの一点に効く。

## ⚠️ 注意点

- 【評価者の起動方法の逸脱】評価者定義（agents/*-ja.md）は frontmatter で tools: [] を持ち、本文の Output Format にも「ツール呼び出し・ファイル読み込みは一切禁止」とある。したがって評価者エージェントを直接起動して本文パスを Read させることはできない。本実行では general-purpose のラッパーに評価者定義ファイルと本文を Read させて評価させた。人格・評価基準・出力形式は定義ファイルをそのまま読ませているが、起動方式は定義の想定（本文をメッセージで受け取る）と異なる。この逸脱は本実行の全評価者に共通である。
- 【議長の文脈に本文を読み込んでいない】評価者には本文のファイルパスを渡し、Read させた。議長（統合側）は本文を読んでおらず、統合は評価者の報告のみに基づく。
- 【full mode の構造的限界】十三名を招集したが、各次元を採点したのは各一名である。したがって story_vector の per-dimension 分散はすべて 0 であり、disagreement_map は分散の閾値（100/400）によってではなく、評価者間で実際に割れた読みと expected_disagreement_points に基づいて構成した。variance フィールドは null としてある——0 と書けば「一致」を意味してしまうため。
- 【検証は一発で通った】この一話の十三名は全員が初回で validate_output.py の PASS を得た（前話では prose-style が一度失敗し再生成を要した）。本レポートはその十三件をそのまま使っている。
- 【評価者は設計を知らない】評価者に渡したのは本文と一行のメタ（連作の約束・この一話だけを読んでよい旨）のみである。設計文書は一切渡していない。ゆえに「四枚の来歴が回収されない」「世界の外側が薄い」という指摘は、それが設計上の決定であることを知らないための所見でありうる。
- 【単位の切り方】これは一話単体の評価である。四枚がどの順に重なったか、前話で何が置かれたかは渡していない。末尾の「いちばん上は、四枚目である」の値は、連作の読者と単体の読者で変わる——この差は本レポートのどこにも反映されていない。
- 【測っていないこと】他話との比較、第二巻の中での第10話の位置、第三巻への伏線、映像・ビジュアル層との整合は、いずれもこの評価の担当外である。
