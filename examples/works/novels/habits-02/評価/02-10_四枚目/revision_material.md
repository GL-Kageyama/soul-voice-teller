## narrative-originality　（primary_score 63）

### weaknesses

- 列挙が原理的に無限であり、止まる根拠が本文にない。終止を担うのは「十分である。」という時計の一行だけで、これは形式の終止ではなく時刻の一致にすぎない。形式そのものが自らを閉じる根拠を持っていない。
- 四枚の宛名票という最強の前提が、回収も増幅もされない。「剥がした跡は、無い」「いちばん上は、四枚目である」という二つの文は、三度の貼り重ねという事実を静かに告げるが、気づかぬ読み手には何も起きず、気づいた読み手にも何も返らない。前提と形式の一致が、意味の生成まで届いていない。
- 人称と文体の破れが、必然か作為かを本文が決めない。二度目に読むと、規則の声・習慣の声・書き手の声のいずれとしても読めてしまい、所属を決める手がかりが本文中にゼロである。異物感は生産的だが、判別不能と紙一重である。

### improvement_suggestions

- 四枚の重なりの由来を、説明ではなく物理の層で一度だけ返す。三枚のずれの向きと、乾いた糊と埃のつき方を、三度の貼り直しの手つきとして読める配置にすれば、前提は回収されずに増幅される。
- 人称と文体の破れをもう一度だけ置き、二つの破れの位置関係によって声の所属を読ませる。一箇所だけでは、意図された逸脱と混入との区別がつかない。
- 列挙の停止を時計から形式へ移す。数える対象そのものが尽きる、あるいは数えられなくなる一点を設け、その消失によってこの一話が閉じるようにする。

### expected_disagreement_points

- **anti-generic-story-filter** :: 内面も事件も会話もなく、人物が行動と物の記述に還元されている。長い区間が手続きの反復として読め、固有の声ではなく汎用の客観描写と区別がつきにくい、として低く出る公算が高い。こちらは同じ反復を形式の制約として読む。
- **plot-architecture** :: 開示の設計が意図的に空である。四枚の宛名票という最重要の情報が置かれながら、回収も転回も伏線の張り直しもされない。情報の出し入れが設計されていない、として低く出る。こちらは開示しないことを形式の選択として読む。
- **narrative-technique** :: 人称と文体の無標の切り替えが、語りの設計として説明されていない。意図か破綻かが本文からは判別できない、と指摘するだろう。こちらはその一点を、この作品が自らの規則を破る唯一の場所として高く見る。
- **reader-experience** :: 読者に渡す情報が極端に少なく、数え上げの反復が続くため離脱の危険が高い、として低く出る。こちらはその希薄さを意図された負荷として読む。

## anti-generic-story-filter　（primary_score 74）

### weaknesses

- 三節がいずれも『観察→名づけの拒否→静止』の同型で、節ごとの差異が配置の差に留まる。反復が方法として明示的に実行可能であり、誰でも再現できる手順に見える箇所がある。
- 等価な扱い：ひびの草、区画の水、電線の鳥、宛名票が同じ韻律の重さで並ぶ。優先順位の不在は意図的と思われるが、その意図は本文の外にしかないため、読者には『決めていない』と見える。
- 抽象の水準が一度だけ上がる（一日あたりの軒数の一般化）。そこだけが世界の説明に寄り、観察の水準から浮く。
- 後半、均質な律が長く続くため、この語り手の選択と自動的な手順の実行を読み分けにくくなる。声の個別性が手順の完全性に食われかける。

### improvement_suggestions

- 三節の反復を維持するなら、三節目に一度だけ律を崩す行（あるいは逆に、他のどの節とも同型でない一行）を置く。反復が『方法』ではなく『癖』として立ち上がり、声が手順から切り離される。
- 数字の一般化（一日あたりの軒数）を残すなら、その抽象を地の文の説明として置かず、数える動作の側へ落とす。この語りの水準からはみ出さない。
- 『——見る。』の同語反復はこの一話で最も強い声であり、同時に最も説明に近い。同じ役割を読点律の内側だけで果たせるか、試す余地がある。
- 等価な扱いを意図とするなら、一度だけ重みの差を本文内に置く（たとえば四枚のうち一枚だけが他の三枚と違う速さで埃をかぶる、といった同一水準内の差）。意図の説明を本文の外に置かずに済む。

### expected_disagreement_points

- **reader-experience** :: 解決も開示も内面も与えないため没入と頁をめくる力が弱く、低評価になりやすい。私が『意図的な拒否』と読むものを、この評価者は『退屈』と読む公算が高い。
- **prose-style** :: 読点律と体言止めの均質さを高く評価する公算が高い。同じ対象を見ながら、私が『方法が声に先立つ』として減点する点を、この評価者は『律の徹底』として加点する。
- **emotional-power** :: 感情を一切名指さない禁欲を抑制の達成と見るか、感情の不在と見るかで割れる。私は抑制の根拠が『読まない』という反復そのものにあり、本文の内側にあると見る。
- **narrative-originality** :: 形式の新しさそのものを測るこの評価者は、三節の同型反復と観察の平坦さを『既存のミニマリズムの範囲内』と読み、私より低くつける可能性がある。

## emotional-power　（primary_score 66）

### weaknesses

- 四百行の大半が「Xは、Yである」の同型であり、感情の手がかりが一つも渡されないため、読者によっては最後まで感情が発生せず、空の手続きとして読了される。抑制が感情を生むかどうかが、読者側の負担に全面的に依存している。
- 四枚の宛名票の来歴、すなわちなぜ四枚重なっているのかが、兆候としても一切与えられない。三枚が下にあるという強い設定でありながら、読者がそれに気づくための足がかりが、ずれの向きと色の違い以外にない。
- 「私」への人称の移動が一度だけ起こり、以後戻ってこない。内的な別の自己が現れる唯一の合図でありながら、構造的な反復になっていないため、読み落とされやすい。

### improvement_suggestions

- 四枚目の前で手が止まる持続のあいだ、時間の経過を示す唯一の時計である影の動きを、あと一段だけ具体的にする。「十分である」の掛詞が、読者の側で十時分の経過として実感されて初めて、この静止はためらいではなく決断として届く。
- 下の三枚の来歴を、情感を名指さずに示す手がかりを一つだけ置く。上の一枚と紙質が違う、印刷の年代が違う、三枚目の端にだけ折れがある、といった程度でよい。想像の負担をわずかに下げるだけで、四つの人生の重なりが読者の側で立ち上がりやすくなる。
- 「私」の声が現れる箇所を、手を引く瞬間にもう一度だけ反復させる。人称の移動が単発の出来事ではなく構造的な回帰となり、内的な別の自己が読み落とされなくなる。

### expected_disagreement_points

- **reader-experience** :: ほぼ何も起こらず、読書速度が極端に遅い。四百行の同型短文は没入ではなく倦怠を生むと判定し、低くつける可能性が高い。私が時間の設計として読むものを、あちらは時間の浪費として読む。
- **hook** :: 未知を作らないことがこの作品の方法であるため、前方への牽引力はゼロに近いと判定されるだろう。読者が知りたくなる前に、知ることを主人公の側が放棄している。
- **prose-style** :: 抑制の徹底を文体の達成として高く評価する可能性がある一方、同型文の反復を作為的・単調と見て低くつける可能性もあり、方向が読めない。いずれにせよ感情の実質には触れない。
- **anti-generic-story-filter** :: この文体と内容は平均から最も遠く、凡庸性の検出にはほとんどかからない。ただし出来事の不在を空虚と見なす設定であれば、低信号と判定されうる。
- **character-depth** :: 内面が一行も書かれていないため、人物が立っていないと判定する可能性が高い。私が内的な別の自己の出現として読む「私」への人称移動を、あちらは雑音あるいは不整合として扱うかもしれない。

## plot-architecture　（primary_score 64）

### weaknesses

- 因果が物理の層に閉じている。重さが腕に来る→足が開くという微細な因果は精密だが、出来事が出来事を呼ぶ物語レベルの連鎖が無い。この一話の中で世界の状態は一度も変化しない（箱が車から台車へ移るだけである）。
- 読者が『読ませたい』と欲する理由＝利害が設定されていない。読むこと／読まないことに帰結が無いため、緊張は好奇心に留まり、投資に到達しない。
- 緊張は張られて回収されない。指が止まり、手が下り、取っ手を握って、押さない。最終行の『いちばん上は、四枚目である』は情報の閉じであって、緊張の解放ではない。
- 伏線の回収が同一話内の近距離に集中している。乾いた糊と埃が数行で『長く貼られている』へ回収されるように、時間を置いた回収が無い。

### improvement_suggestions

- 読むこと／読まないことの帰結を一度だけ置く。内容を明かさずとも、『読めば何かが変わる（あるいは過去に変わった）』という一行があれば、同じ非行為が好奇心から緊張へ移る。
- 時間を置いた回収を一つ。四枚のあいだに経過した時間そのものを伏線にする（二枚目の端の色と四枚目の白さの対比は既に材料として置かれている）。
- 緊張の解放は行為の変更でなくてもよい。影が満了した後に彼が何をするか（押す／降りる／もう一度止まる）を一拍だけ置くと、曲線が閉じる。
- ただし、読ませない設計そのものが意図であるなら、以上の提案はいずれも不要である。この話の非行為は冒頭から末尾まで一貫しており、破綻ではなく選択として書かれている。

### expected_disagreement_points

- **narrative-technique** :: 一度きりの敬体の挿入と常体の観察の切り替えを、距離の操作として高く評価するか、人称の混在として減点するかに割れる。語られた内容より語り方を見る評価者ほど高くつける。
- **reader-experience** :: 十分間の身体描写が決着を持たないことを、保持された緊張として評価するか、停滞として減点するかに割れる。読み進める力が好奇心のみで利害が無いと見る側は、私より低くつける。
- **hook** :: 未知は一つ（四枚目の内容）で、それが分割も更新もされないため『未知はあるが進まない』と見て低くつける可能性が高い。一方、非行為の反復が次の一話を確実に要求すると見ることもできる。
- **prose-style** :: 情報を伏せたまま反復で押す構成を律動として高く評価し、開示の平坦さを問題にしない。次元が交わらないため、同じ本文について私より大きな差で高い点数をつける。

## character-depth　（primary_score 42）

### weaknesses

- 内的葛藤が実在しても、その両極の名が与えられない。読むことを禁じているものが職務規則なのか、失われた誰かなのか、自罰なのかを本文は決定せず、葛藤の重さを読者が全額負担する構造になっている。深さが設計であっても、測定できる形では提出されていない。
- 一話内で人物は変化しない。接近し、停止し、不作為に至るまでで、最終行は事実の反転であって内面の変容ではない。変化弧の評価は話の外に委ねられており、この一話だけでは弧の存在を確認できない。
- 動機が心理と背景から必然的に生じていることを示す材料が、丁寧体で挿入される一行にしかない。規律の声は外部から来ており、それが本人の何を守り、何を傷つけているかが描かれないため、動機の真実味は人物ではなく手順の精度に依存している。
- 道徳の軸が置かれていないため、道徳的複雑さは単純化ではなく不在である。読者が人物をどう評価すべきかを迷うのではなく、評価の対象そのものが与えられない。善悪の外にある人物は深い人物と同義ではない。

### improvement_suggestions

- 内面を説明で足すのではなく、規律の由来を物体か動作の側にもう一つ置く。たとえば四枚のうち一枚だけ紙の質が違う、あるいは下の三枚の角の丸みが上の一枚とだけ揃っている、といった差分を一点加える。読者が動機の系統を推定できる足場が増え、説明を足さずに葛藤の内容へ接近できる。
- 停止した手に代償を一拍だけ滲ませる。読まなかったことによる身体の反応（指を引く速さ、息の置き方、視線の戻り方）を一箇所だけ変える。禁じられている側の重さを、禁じられている内容を明かさずに示せる。
- 変化弧を一話内で動かさない設計を保つなら、話の外の変化を物質に一点だけ残す。前話からの差分が物体の側に堆積していることを一箇所示せば、連作の読者にこの人物が動いていることが伝わり、単独の読者にも弧の存在が示唆される。

### expected_disagreement_points

- **plot-architecture** :: 人物を機能として見る立場からは、四枚の重なりと最終行の「四枚目である」という開示を情報設計の工作として高く評価し、内面の不可視を欠陥として扱わない可能性が高い。同じ材料を、人物の心理ではなく開示の機構として読む。
- **reader-experience** :: 感情移入の手がかりが意図的に与えられていないため、「人物が立たない」「入口がない」という不満に結びつきうる。逆に、精密な反復と空白を強い没入として読む立場もあり、同一の技法を障害と取るか誘いと取るかで判定が割れる。
- **character-role** :: 取っ手を握って押さないという不作為を、動かされていない（自律の欠如）と読むか、押さないという選択（強い自律）と読むかで判定が反転しうる。本評価者は後者に寄るが、これは本文が決定していない分岐である。

## character-role　（primary_score 55）

### weaknesses

- 賭けの内容が一度も名指されない。下の三枚の宛名票が何を意味するか、読まなかったことで何が失われるかは本文の外にあり、守る面の重みが計量できない。
- 挑戦に押し返す相手がいない。向かう先は紙であり、紙は抵抗しない。拮抗する人物も状況も置かれていないため、賭けが具体的な「向こう側」に脅かされる構造に届いていない。
- 自律性が前進の形を取らない。押さないという選択は世界の状態を変えず、次の出来事を生まない。選択が出来事を生むという自律性の中核が、留まるという形に置き換えられている。
- 賭けの対象（箱・紙）と、賭けを守る行為（読まない・押さない）のあいだに、代償が一つも具体化されていない。時間は十分あり、遅れの徴候も、誰かに咎められる気配も描かれないため、犠牲が犠牲として読者に届く手前で止まっている。

### improvement_suggestions

- 挑戦に外部の力を与える。この十分間に、彼の静止を押し返す何か——刻々と減る残り時間、事務所の灯りが示す他者の視線、届け先の側の気配——を一つ置くことで、読まないことが静止ではなく抵抗として構造に現れる。
- 代償を場面の中で一度だけ具体化する。押さなかったことで生じる小さな不利益（次の区画までの距離、手順の狂い）を一箇所に置けば、自律性に価格がつき、賭けが本物であることが読者に計量可能になる。
- 停止のあとに、世界の状態を変える最小の一手を置く。押すこと以外の何か——扉を下ろす、箱の角を直す、手指の跡が消えるのを待つ——が一つでも後続すれば、選択が出来事を生む経路が確保される。
- 下の三枚の意味を、説明せずに一点だけ因果へ接続する。たとえば四枚目の日付だけが読める、糊の乾き方が上の一枚だけ違う、といった物理的な一点を置けば、名指さないまま賭けが物語の出来事と噛み合う。

### expected_disagreement_points

- **character-depth** :: 内面の抑制と反復される所作の精度を人物の生きた厚みとして高く評価し、動きの有無を問わないため、本評価より高いスコアをつけると予測する。深さは動きと直交し、静止した豊かな肖像はこの評価者にとっては高得点になり得る。
- **plot-architecture** :: 読まないという選択を情報開示の設計として読み、四枚の宛名票を未開示の情報として構造的に評価する可能性がある。本評価は因果への接続の有無のみを見るため、開示の巧さは加点しない。
- **narrative-originality** :: 不作為を出来事の中心に置く構成そのものを形式の逸脱として高く評価し、本評価が自律性の欠如として減点した点を、形式の選択として肯定的に読むと予測する。
- **hook** :: 押さない一瞬の後に開かれる問いを興味のエンジンとして高く評価する可能性がある。本評価は問いではなく人物が動くかを見るため、この点で判断が分かれる。
- **reader-experience** :: 反復される細部の記述を停滞として低く評価し、本評価よりも低いスコアをつける可能性がある。読書の時間の使い方と人物の動きは別の軸である。

## prose-style　（primary_score 72）

### weaknesses

- 「ある」と「見える」がほぼ全行に現れ、語彙が選別をやめている。数が意味を持つのは数えられていない語があるからで、あらゆる名詞が同じ「ある」で受けると、数えることの対比が痩せる。
- 「、」で短句を刻む型が全篇でほぼ一定のため、楽章内部では読む速度が変わらない。読者は数十行で拍に馴化し、リズムが聞こえなくなる区間が生じる。
- 「私は、いちばん上の一枚だけを、見ます。」——全篇で唯一の丁寧体かつ唯一の「私」。別の声（規則・規範）が地の文に落ちてきた瞬間だが、「」も導入もなく、引用の標識が一切ない。最も負荷の高い一文が、読みようによっては乱れとして読まれる。
- 「、」の打ち方が、連用中止と後続の動詞を切り離す箇所がある（「〜に、後ろを向けて、止めてある。」など）。息継ぎのつもりが、統語の切れ目として読者の足を止める。
- 感覚の帯域が視覚と触覚に偏り、音は「低い音である」以上に解像されず、匂いと味は一度も来ない。狭さは選択だが、後半の静止部では、動かない紙を前にして新しい感覚の経路が足されないため、描写の解像度が頭打ちになる。
- 環境で唯一動くもの（影）が「影が、さっきより、少し、進んでいる。」と経過を刻むのに、その変位が読む速度に反映されない。時間の進みを数える語が本文にあるのに、それが拍として使われていない。

### improvement_suggestions

- 「私は、いちばん上の一枚だけを、見ます。」の一文に、この作品が許す最小の標識を与える。唯一の他者の声であるこの一文が引用として読めるかどうかで、三節の否定の意味が変わる。
- 楽章内部に一回、句の長さを意図的に崩す箇所を置く。たとえば光が紙に当たる瞬間か、指が止まる直前——人物の注意が切り替わる一点で刻みを変えれば、そこで読者の速度がリセットされ、以後の反復が再び聞こえるようになる。
- 「ある」の一部を、既にこの本文が持っている姿勢・運動の語（立っている／ついている／残っている）に置き換える。数少ない「ある」が重みを取り戻し、数えることの対比が戻る。
- 環境で唯一動くもの（水、影）に一拍を厚く与える。「影が、さっきより、少し、進んでいる。」は時間を刻む語でありながら、現在は速度に反映されていない。ここを速度の変奏に使える。
- 連用中止と後続動詞のあいだに入った「、」を見直す。息継ぎの位置と統語の切れ目が食い違う箇所だけでも直せば、刻みは保ったまま読者の足がつまずかなくなる。

### expected_disagreement_points

- **emotional-power** :: 内面が一度も名指されないため、情感が希薄・無感情な文体と判定し、低くつける公算が高い。私の見立てでは、否定形の反復と残留物だけを見る視線こそが感情の在処であり、抑制が感情の代わりではなく感情そのものになっている。
- **reader-experience** :: 刻みの間隔が一定で反復が多いため、読了までの牽引力は低いと判定するだろう。同調して催眠的と取るか、単調で疲れると取るか、この評価者自身が二つに割れる可能性がある。
- **narrative-technique** :: 「私」「です・ます」への一時的な人称と文体の転換、および三人称的な観察から一人称の行為への地の文の揺れを、未標識の技術的欠陥として指摘する公算が高い。
- **plot-architecture** :: 出来事が「箱を載せ、手を止める」の一点しかなく、開示の設計が薄いと見るだろう。ただし末尾の「四枚目」が数量の意味を反転させる点は、開示としての設計と読める。

## theme-resonance　（primary_score 74）

### weaknesses

- 不読の動機が構造から一義に定まらない。他者への配慮、職業的な規律、自己を守るための距離のいずれの読みも成立し、テキストは構造的な手がかりでどれかを選ばない。余白として強いが、テーマの重心が読み手ごとに散る危険を同時に持つ。
- 一日に、八十から百二十軒である。私は、いちばん上の一枚だけを、見ます。という層だけが、身振りから離れて言語化された説明の露出である。直後に読まないで反転するため致命には至らないが、この一話で唯一テーマが構造の外へ出る箇所である。
- 下三枚の来歴を支える手がかりが黄色いという色の一点に限られ、再読で開く意味の幅は、上の一枚の白との対比の範囲を大きく出ない。
- 主題の射程は匿名の労働と他者への不干渉に絞られ、生の根本問いへは間接的にしか届かない。深さは確かだが、射程は狭い。

### improvement_suggestions

- 下三枚の来歴を、説明ではなく物の状態としてあと一点だけ置く。たとえば四枚の角の丸みが上の一枚だけ新しい、テープが貼り直された跡がある、など。再読の層が謎から深さへ向かう。
- 一般則の層を、規則の声として明確に分離するか、身振りの側へ完全に沈める。説明の層が中途半端に露出すると、構造から浮かぶ原則が弱まる。
- 時間の刻み（十分がある、影が白い線まで来ている）が後半の静止を支えているので、同種の時間指標を前半にもう一つ置くと、この一拍が主題へ直結する。

### expected_disagreement_points

- **plot-architecture** :: 出来事の因果も情報の開示設計もほとんど動かず、四枚の宛名票が何を意味するかを構造が説明しないため、設計の観点からは低く評価される公算が高い。
- **emotional-power** :: 感情が身体の位置としてのみ現れ、名指しの情動が一切ないため、読中の感情の立ち上がりを重視する立場からは低く、抑制の達成として高く、評価が割れる。
- **reader-experience** :: 反復される短文と、読まれない紙という静止した対象により、前へ引く力は非常に弱い。読書体験の観点からは低評価になりやすい。

## world-building　（primary_score 76）

### weaknesses

- 世界の外側が極端に薄い。舞台は駐車場・荷台・台車に閉じられ、この労働がどのような制度・会社・地域・季節に属するのかの手がかりが一切与えられない。世界の地理と社会は一枚の駐車場の面積を超えない。
- 世界の住人が一人しかいない。事務所の窓に灯りが一つついているという一点を除けば、同業者・受取人・灯りの主のいずれも世界の側に現れず、社会としての厚みがほぼ空である。世界は孤独な手順の集積としてのみ立ち上がる。
- 創造性の軸では弱い。要素はすべて現実の物流の道具立ての正確な写生であり、この世界でしか成立しない法則は、宛名票の運用規則という一点に集中している。世界の独創が単一の物体に依存しているため、その物体を取り除けば世界の固有性はほぼ消える。
- 説明の完全な欠如という逆向きの負荷がある。読み手は四枚の重なりの運用規則を自力で再構成しなければならず、世界の理解が読者の推理に依存する。世界が読者を迎え入れる設計というより、読者が世界を掘る設計になっている。

### improvement_suggestions

- 世界の外側を、説明ではなく既に舞台にある物体の中に一語でも二語でも差し込む（この配達が属する制度・地域・季節の手がかり）。駐車場が世界の一部として外へ接続される。
- 四枚の宛名票が既に持っている他人の時間という論理を、舞台の他の物へ広げる。区画の番号、車止めの当たり、隣の区画の落ち葉——他者の痕跡を増やすことで、世界に社会の層が生まれる。
- 宛名票の規則を、この世界の他の手順と交差させる（読む順番、剥がす規則、貼り直しの規則、日付が変わるときの扱い）。一つの規則が他の規則と噛み合うと、手順は体系になり、世界はより強く予測可能になる。
- 反復する物体（水・影・灯り・電線）に、この一話の外の履歴を一度だけ混ぜる（昨日も同じだったという手がかり）。世界の時間が十分という枠を超えて伸び、住む場所としての奥行きが増す。

### expected_disagreement_points

- **character-depth** :: 世界は精密だが、そこに住むのは一人だけで、内面は世界の手順に吸収されている。人物を重視する立場からは、世界が人物を覆い隠している、あるいは人物が世界の付属物になっていると見て、この高評価に反対するだろう。
- **prose-style** :: 細部の厚みは文体の統制（短文と反復）が生んだ効果であり、世界の設計そのものではないと主張しうる。文体評価者は、私が文体の産物を世界の厚みと取り違えていると見る可能性がある。
- **plot-architecture** :: 世界のルールが緊張を生むという私の読みに対し、この一話では出来事が起きず、ルールは開示されても作動していないと見るだろう。世界が前提として物語を駆動しているとは認めない立場である。
- **narrative-originality** :: 設定は現実の写生に留まり、形式の新しさだけが際立つという判断を下すだろう。設定の新しさと形式の新しさを切り分ける私の立場とは、創造性の軸で正面から食い違う。

## narrative-technique　（primary_score 67）

### weaknesses

- 人称標識の不稼働：「僕」は数箇所にしか現れず、三人称に置換してもほぼ損失が生じない。視点の選択が荷重を受けきっておらず、一人称である必然が標識の側からは論じられない。
- 距離の楽器が一つ：遠近の調整が対象の大きさを変えることで行われ、語りのレジスタ自体は最後まで動かない。俯瞰の極が文体として使われておらず、距離の幅が狭い。
- 信頼性の操作が宣言に留まる：「読もうとすれば、読める。読まない。」と明示されるため、読者の認識は揺さぶられない。隠していることの通知が先に立ち、事後の転倒が起こらない。
- 冒頭三行目の焦点操作の帰属が不明：「車の後ろ扉を、僕が開ける。」の「僕が」は語り手自身を新情報として出す不自然な焦点であり、同じ操作が他に無いため、意図的な estrangement か偶発かが本文だけでは判別できない。
- 最終行の反転が一行に依存する：「いちばん上は、四枚目である。」の遡行的な読み替えは強いが、四枚の順序そのものは本文中で一度も操作されず、末尾に置かれている。反転は語りの設計ではなく一行の配置に負っている。

### improvement_suggestions

- 「僕」の標識を、知覚の位置が語り手の身体にしか成立しない箇所（視野の遮蔽・触覚の順序・届く届かないの境界）に集中させ、三人称では書けない一行を数箇所つくる。
- 丁寧体の声を一度きりで終わらせず、対になる位置にもう一度置き、一度目と二度目のあいだで何が変わったかを読者に測らせる（ただし連作の規律として一度きりが定められているなら、採用しない判断が正しい）。
- 「読まない」の宣言を一つ減らし、身体の報告だけを残す。宣言と行為の食い違いを読者に委ねる余地が増える。

### expected_disagreement_points

- **plot-architecture** :: 宛名票の名が最後まで開示されず、四枚の順序も最終行まで伏せられることを、情報開示の空白すなわち設計不足として低く評価する可能性がある。私はそれを語りの規律として読む。
- **prose-style** :: 短文と読点過多の均質なリズムを、単調・作為的として減点する可能性がある。私はその均質さが内部報告を禁じる装置として機能していると見る。
- **reader-experience** :: 出来事が「箱を台車へ移す」ことに尽きるため、没入や引き込みの点で低くつける可能性がある。私は一拍の引き伸ばしを技法の核として読む。
- **character-role** :: 主体が押さない・読まない・触らないと行為を拒否するだけであり、自律性に乏しいと見る可能性がある。私は拒否の反復が規律の提示として働き、手が紙の手前で止まる一節が最も能動的な場面だと読む。

## reader-experience　（primary_score 56）

### weaknesses

- 冒頭の在庫描写に事件も起伏もなく、読者が本を置ける区間が長い。箱に触れる前に読者の忍耐が先に消費される。
- 打拍が全域で均一なため、強調の手段が一点に限られる。長短の対比が無いので、読者の注意に目印がほとんど無い。
- 人称が途中で揺れる。これが設計でなければ没入を破壊するし、設計であれば印が一つ足りない。どちらに読むかで体験が反転する。
- 第三節が第一節の対象をほぼ反復する。反復は一拍のために機能しているが、読者の通過コストを二重に請求する。
- 四枚目という核心が、数え続けた読者にしか届かない。保持を助ける手がかりが本文側に無く、賭けが読者任せになっている。

### improvement_suggestions

- 冒頭の対象列を圧縮する。一拍に必要な数より長く、箱に触れる前に読者の時間が支払われている。
- 第一節か第三節に、リズムの目印を一つだけ足す。現状、読者の注意が止まれる場所は一点しかない。
- 人称の揺れに印を一つ添え、設計であることを読者に渡す。放っておくと整合の破れとして読まれ、没入が切れる。
- 第三節の反復から対象を三分の一ほど落とす。経過を示す印（影・水・灯り）だけを残せば、一拍の効果は落ちない。
- 四枚という数を保持させる補助を一つ入れる。数えていない読者にも反転が届くようにするか、届かないことを覚悟して現状を保つか、どちらかに決める。

### expected_disagreement_points

- **narrative-originality** :: 句読点による打拍と対象のみの視線を実質的な形式の逸脱として高く評価し、私が減点した読解の困難を代価として正当化する。
- **anti-generic-story-filter** :: 平均への最適化から最も遠い対象として高く評価し、均一な打拍を凡庸の反対物として扱う。私が挙げた単調さを見落とすか、美点に数える。
- **prose-style** :: 区切りの連なりをリズムの達成として評価し、私がペースで引いた点を文体上の手柄として逆向きに読む。
- **plot-architecture** :: 開示の設計が薄いと見る。四枚という情報が最後まで動かず、開示の時機が一度しか作られていないと指摘する。

## admiration　（primary_score 40）

### weaknesses

- 不作為を予告してから実行する。「読まない」「はめない」が行為の場面に先行するため、山場は驚きではなく確認として届く。
- 山場と周辺の文体的落差がない。全段落が同じ長さの短句と同じ句点の打ち方で走るため、頂点が構造的に印されない。
- 唯一の亀裂（人称・文体の遷移）が一度きりで、二度目がなく増幅されない。規則の声として機能させるなら、その声が再び現れる場所が要る。
- 四枚の宛名票が何であるかについての予測が読者に立たない。可読性は積み上げられるが、読めば何が変わるのかが示されないため、読まない選択に賭け金がない。

### improvement_suggestions

- 不作為の予告を行為の後に移す。「読まない」の先行提示をやめ、指が止まってから規則を置けば、拒否がまず驚きとして届き、規則がそれを正当化する。超過と必然が同一の点で衝突する。
- 山場を文の刻みで印す。指が止まる一段落だけ、句点の打ち方を変えるか一文を長く取り、前後と落差をつくる。全篇が同一リズムであることが、頂点を不可視にしている。
- 読まない選択に賭け金を与える。可読性だけでなく、読むことが何かを変えてしまうという一点を一行だけ仕込めば、指が止まる場所に重みが生まれ、必然が驚きを支える。

### expected_disagreement_points

- **plot-architecture** :: 四枚の宛名票という未開示情報の配置と、末尾で枚数を数え直す開示のタイミングを機構として高く評価し、私より高い点をつけるだろう。私はその機構が生む反応（驚きの不在）を測る。
- **emotional-power** :: 読まれない宛名票を、抑圧された感情の核として読む。宛名が読者に開かれないことを強度と見なし、私より高い点をつけるだろう。私は同じ沈黙を、感嘆の頂点が印されていない證據として読む。
- **anti-generic-story-filter** :: この話が定型から最も遠い地点にあることに高い点を与える。私もその点には同意するが、感嘆の次元では超出が告知済みである一点で低く出る。

## hook　（primary_score 52）

### weaknesses

- 与えが物に偏り、人に及ばない。読者が所持するのは紙であって人物ではない。行き先も、渡すべき相手も、誰かとの約束も与えられないため、知りたさの乗り移り先が紙一枚に限定される。
- 一話内で幹の問いが一度も分割応答されない。答えが着地しないので、答えから次の問いが生まれる連鎖がほぼ無く、フックは連鎖ではなく同強度の反復で保たれている。
- 「読まない。」「紙には、触らない。」の反復が三度目以降、情報量を増やさない。拒否の強度が変わらないため、読者は同じ未知を同じ濃さで三度受け取り、未知が更新されない。
- 中盤の運搬区間（箱を持ち上げて台車に載せるまで）で幹の問いが長時間停止する。問いへの圧力が抜けた区間を、読者は「保留」ではなく「停止」と読む可能性がある。
- 人称と文体の破れ（「私は、いちばん上の一枚だけを、見ます。」の私・ですます・ダッシュ）が未知を立てる一方、それが誰の声かについて手がかりが一つも置かれない。読者によっては未知ではなく乱れとして処理され、雑音に落ちる。

### improvement_suggestions

- 停止区間に幹の微進を一つだけ入れる。現状、四枚のずれの記述は三枚ぶんで止まっているが、今回の一枚だけずれの向きが他と逆である、といった小さな新事実を一箇所置くと、運搬の区間が先送りでなく進みになる。
- 拒否の強度に段階をつける。一度だけ指が紙に触れかけて止まる、爪が紙の端に当たる直前で止まるなど、拒否が揺れる箇所を作れば、「読まない」の反復が未知を更新する。
- 人称の破れに、説明ではなく位置の手がかりを一つだけ添える。破れが再び現れる位置を揃える、あるいは同じ語が別の人称で反復されるようにするだけで、読者はそれを乱れではなく声として問える。
- 与えを人へ少し延ばす。この人物が誰かに何かを渡す約束を負っている、行き先が一つだけ決まっている、といった一行を置くと、紙に懸かっている知りたさが人物の所持へ乗り移る余地が生まれる。
- 最終行の「四枚目」という数が効くよう、その前に四という数の重みを一度だけ読者に渡す。一枚目から三枚目が過去の配達としてそこに在ることの気配が一行あれば、末尾の再点火は今より強く効く。

### expected_disagreement_points

- **plot-architecture** :: 開示の機構の観点からは、この一話は開示をゼロに留保しており、機構として「遅すぎ」に近い。情報の出し惜しみが読者の理解を妨げると述べ、私より低く採点する可能性が高い。私が「温存」と呼ぶものを、彼らは「未開示」と呼ぶ。
- **reader-experience** :: 没入と読書体験の観点からは、反復と平板な統辞が読む速度そのものを設計しており、彼らはこの停止を「没入の持続」として高く評価しうる。私が連鎖の空白と呼ぶ区間を、彼らは読む時間の質と呼ぶ。
- **emotional-power** :: 抑制の美学の観点からは、感情の名指しがないことを長所として読む。私が「知りたさの乗り移り先が細い」と述べる箇所を、彼らは「余白が読者の感情を立ち上げている」と読む可能性がある。
