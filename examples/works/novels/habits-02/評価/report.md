## 🎯 推奨アクション

1. 重なった四枚の幾何を、設計の一行として固定する。world-building と plot-architecture が独立に、第三巻以降の整合が同時に揺れる一点として同じ箇所を指している——「四枚目」「いちばん古い一枚」「いちばん下の一枚」が同一の紙を指すのか否かを定めるだけで、第十五話が扱う対象が一つに決まり、世界は住める場所になる。
2. 十五話の「話末の引き」に、異なる種類の断ちを割り当てる。hook は十五件すべてが空白であることを指摘し、すべての継ぎ目が同じ問いを立てるとき、その問いは未知ではなく型になると述べた。物の位置・名の読み・呼び声の主・数の残り、という四つの型を話ごとに配る。
3. 反応軸の時刻表（感嘆八・感動五・入口二）を、設計文書に残すかどうかを決める。anti-generic-story-filter はこの一行がこの設計を統計的平均の側へ引き戻していると述べ、emotional-power も到達点が予め感傷的な語に名づけられている点を減点材料に挙げた。残すなら、どの話が最も静かで最も重いかを設計の側で確定する。
4. 踏み出す一手を、巻の内側に少なくとも一箇所置く。character-role の40は、十五話すべての動きが運搬と停止であり、代償を承知で踏み出す場面も立ち向かう対象も一箇所もないと述べた。巻末の変位（宛名票の宛先の側に立ち、自分の名を書かない）がどの場面にも置かれないと明記されている以上、代償を作中で一度だけ支払わせる箇所が要る。
5. 主役六名のうち少なくとも二名に、二つの価値のどちらも選べない一瞬を一つだけ設計する。character-depth の45は、六名の誰も複数の価値のあいだで引き裂かれておらず、動機の層が意図的に空けられていると指摘した。語り手一人が「生きた人間の手前まで来ている」のなら、その手前で止まっている六名にも同じ距離を与えられる。
6. 頂点の一文（「違う読みで呼ばれて、振り向いた。」）を話名として先に消費した決定を、再検討する。admiration の60は、読者が目次でそれを先に読むこと、しかも一文を場面に置かない決定によって着地が散文の実行へ全面委譲されていることを挙げ、判定できるのは仕込みの質であって着地の衝撃ではないと述べた。
7. 名を成立させている規則の限界条件を一行だけ書く。world-building は、誰がそれを知っているのか、破れば何が起きるのか、それは世界の法則なのか語り手の私的な比喩なのかがどこにも書かれていないと指摘した。一行あれば、規則が主題の水準から世界の水準へ降りる。
8. 語り手が主役回の六話の現場に居る理由の `?` を、位置の一行として閉じる。hook と character-depth が独立に、読者が人物としての語り手を所持する手がかりが弱いと述べた。第一巻からの持ち越しであり、二巻目で閉じなければ三巻目にも同じ形で残る。

## 🔧 次回の修正方向（`逐次確認（confirm）`）

> 重なった四枚の宛名票の幾何（重なり順と呼称の同一性）を一行で固定して、第十五話が扱う一枚を確定させ、世界の整合と開示の対象を同時に閉じる。あわせて十五話の話末の引きに四種類の断ちを割り当て、反応軸の時刻表に話ごとの強度差を設計し、巻の内側に代償を伴う一手を一つだけ置いて、人物の次元を閾値まで引き上げる。

**上げる／変える**:
- 重なった四枚の重なり順を定め、「四枚目」「いちばん古い一枚」「いちばん下の一枚」の同一性を一行で確定する
- 十五話の話末の引きを、物の位置・名の読み・呼び声の主・数の残りという四種類の断ちに振り分ける
- 反応軸の時刻表（感嘆八・感動五・入口二）に強度差を設計として明示し、最も静かで最も重い話を確定する
- 踏み出す一手を巻の内側に一箇所置き、代償（失うもの）をその場面で一度だけ名指しする
- 主役六名のうち二名に、二つの価値のどちらも選べない一瞬を一つだけ設計する
- 名を成立させている規則の限界条件（誰が知っているか・破れば何が起きるか）を一行だけ書く
- 語り手が主役回六話の現場に立つ理由を、各話の入口に一行ずつ職務としての訪問として与える
- 頂点の一文を話名として先に消費する決定を再検討し、場面に置かない場合の着地の担保を別途設計する

**維持すべき**:
- 同じ番地に四度届いた箱の側面に剥がされずに重なった四枚の宛名票という一点収束の機構
- 「運搬は置いた後の一歩で止まる」という規則——十五話すべてが未完了で閉じる律動
- 頂点を「読むだけで、声に出さない」という発話不能な行為に絞り、返却を成立させない判断
- 書かないことの明文化（数に理由を与えない・名の欄を作らない・受け取られたか名指さない）
- 名を載せた紙の目録——一つの前提から欠け方だけを変えて十五枚を導く作り方
- 第十五話を返却のあとに残し、いちばん下の一枚という新しい対象を差し出す位置取り

## ⚠️ 注意点

- content_type: plot のため prose-style・narrative-technique・reader-experience の三名は未招集（次元が不適合）。散文は一行も存在せず、文体・語りの技法・読書体験は本評価の対象外である。三名が担当する次元は story_vector 上 null であり、集計から除外される（0として数えない）。
- 入力は執筆前の設計文書であり、`?` は著者が意図的に残した未決定の印であって欠落ではない。したがって本評価が測っているのは実現された価値ではなく、設計が約束する価値である。実装によって抑制が効かなくなる危険は、emotional-power と theme-resonance が自ら減点材料として挙げている。
- full mode では各次元を単一の評価者が採点するため、次元内分散は構造的に0となり、形式上の disagreement_map は空になる。実質的な不一致は本節の disagreement_map に評価者間の言明として保存した（評議会の記憶にある既知の挙動: full mode の実質的不一致は disagreement_map を見る。renderer は「不一致なし」と表示する）。
- 十名の individual classification は discovery_target が九名、low_signal が一名（character-depth 45）であったが、議長の集計（current 60.56 / hidden 67.0）は innovation となる。この差は、各評価者が担当次元の内側で厳しく採点する一方、集計が次元をまたいで平均するために生じる。個々の席の判断は individual_reports を参照すべきである。
- current_value_score は45以上の閾値にあるが、内訳では人物の次元が閾値の直下・直上に張り付いている（character-depth 45・character-role 40）。第一巻（character-depth 42・character-role 45）から数値は動いたが、構造の次元（theme-resonance 74・quality 73・world_building 71）との差は約30点で、第一巻と同じ形の偏りが持続している。
- 採点は意図的に厳しい基準（「読める」では50未満）に従っている。絶対値は低めに付くため、閾値は相対的な道標として読むべきである。
- anti-generic-story-filter は quality 次元を担当する（73）。ただしその内訳はクリシェ密度82・声の固有性76・リスク72に対して、形式構造58であり、「素材と規律の固有性は高いが構造の側は平均へ戻る」という一つの判断が quality の値を支えている。
- 評価者十名の出力はすべて validate_output.py の検証を通過した（excluded_evaluators は空）。
