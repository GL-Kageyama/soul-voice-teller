## 3. 裁定3「文字を物語から外す」の意味

**世界の中の文字を外す。本の文字は外さない。**

- 外すもの：台帳の名、判の「該当なし」、標識、看板、名札、頁の一行。
- 残すもの：書名『受け火』、章題「送る」「綴じる」など、地の文そのもの。
- 地の文が「彼は印を押した」と書くのは文字ではない。世界の中に文字が無いだけである。

この裁定のいちばん強い形は、**「文字のない世界」を世界律にすること**だ。

> この世界には文字がない。紙は白い。印は形。標識はない。名は声にしかない。

これはAIの都合を物語の都合で吸収する、いちばん短い道である。同時に、
「名を持たない」という主題が、世界の法則として最初から置かれる。

例外は記憶の中だけ。書く行為は見せてよい（ペンが動く、頁がめくれる、
手紙が折られる）。だが文字は解像しない。ピントが外れる、指が隠す、火が食う。

## 4. 裁定が引き起こす連鎖

### 4-1. 文字を外すと変わる6箇所

| 章 | いまの文 | 文字を外した後 |
|---|---|---|
| 第1章 | 「幸恵という名は台帳の一行に記され」 | 火が頁に押され、火の形が残る |
| 第2章 | 「ペンが名を記す。結城文という名は、頁の上に一行記される」 | 指が火を頁へ押す。火の形が紙に残る |
| 第2章 | 「白いのは、一番下の欄だけではなかった」 | そのまま（最初の頁にだけ印がない、が成立する） |
| 第3章 | 台帳の「該当なし」の席 | どの欄にも当たらない、空いた席 |
| 第5章 | 「該当なし。」（地の文の宣告） | 針が動かない。音がない。語るなら声で一度だけ |
| 第6章 | 「折笠千代という名の横に、それが記される」 | 火の横に、値がひとつ、浮かぶ |
| 最終頁 | 「一行だけ、文字がある」「あなたが書く」 | 白紙。声が一行を言う。あなたは受け取る |

第2章の開示は強くなる。いまは「書かれた頁の中で、最初の頁だけが白い」。
改稿では「すべての頁が白い。最初の頁だけ、印がない」。前者は記録の欠落、
後者は**記録という行為そのものの不在**になる。主題に近い。

### 4-2. 語りを減らすと、定型句が浮く

定型句は9回、すべて地の文にある。語りを減らすと、いっしょに減る。

提案：**減らす対象から定型句を外す。** 地の文は極限まで削り、定型句だけを
毎話の最後に残す。すると定型句は「説明」でなく「拍」になる。9回の反復が、
10話では9回（序＋8章）のまま残り、終章で消える。消えることが解消になる。

ただし、これは「語りを減らす」の例外を作ることになる。裁定に反するなら、
定型句を声（花の声、または火の音）へ移す。私は地の文に残す方を推す。

### 4-3. 最終頁：「書く」から「受け取る」へ

いまの最終頁の行為は**書く**だ。

> ＿＿＿には名がない。だから、あなたが書く。
> あなたは、主人公の名ではなく、あなたの名を書く。

文字を世界から外すと、この行為が成立しない。代わりに置くのは**受け取る**。

> 頁は白い。
> 彼は＿＿＿に受け取られた。
> ＿＿＿には、名がない。
> あなたは、何も書かない。
> 受け火は、あなただった。

「書く」は読者を作者の席に座らせる。「受け取る」は読者を受け手の席に座らせる。
骨格（読者が宛先になる）は同じで、動詞が能動から受動へ移る。主題と一致する。

失うもの：頁に名を書くという、小説ならではの物理的な誘い。これは大きい。
埋め合わせは、頁の白さと、声のあとの沈黙だけになる。

### 4-4. 名前：花は固有名でなく普通名詞になる

「花だけ残す」を、こう読んだ。

- **花** … 残す。ただし固有名でなく、**物の名**として。名を与えられなかった
  から、花という語で呼ばれる。これが「該当なし」と主題を一度に説明する。
- **篠宮** … 落とす。姓を持つと、彼女が系譜の中の一人になる。彼女は系譜の外にいる。
- **送り火** … 残す。これは名でなく、魂たちが使う普通名詞。
- **ゲスト5人**（幸恵・結城文・コダマ・折笠千代・早瀬甚吾）… 異世界寄りの日本に
  合わせて作り直す。ただし音だけで運ぶので、発音できればよい。漢字は決めない。

これで、世界の固有名はすべて「その世界の名」になり、花だけが「物の名」になる。
花が浮くのは意図である。

注意：画像プロンプトの人名は日本語で書く。ローマ字にしない。読みも振らない。

### 4-6. 記憶場面は火の中に閉じる

2〜3分の記憶を6本入れると、単一舞台が壊れる危険がある。守る規則：

1. 記憶は**火の中にだけ**現れる。カメラは踏切を出ない。
2. 記憶は半透明。彩度は火の色に寄る。別の様式にしない。
3. 記憶に台詞はない。音は息と、その時代の音ひとつだけ。
4. 記憶は器官が動く直前に始まり、器官が動くと切れる。
5. 長さは一定でない。胎児は30秒、作家は3分。
6. 第5章（測る）には記憶を置かない。無い話が一本あると、型が緩む。

これで、尺は伸びるが舞台は一つに留まる。

## 5. 世界「異世界寄りの日本」— 何が残り、何が変わるか

いまの設計は「現世（日本・現代、盆＝夏）＋境」の二層。これを
「日本に似た異世界＋境」へ移す。**現代の実存**という手触りは残す。

### 残すもの（形は同じ、由来だけを変える）

| 物 | 残し方 |
|---|---|
| 踏切 | そのまま。境そのもの |
| 線路 | そのまま。「駅に続かない線路」はすでに異世界的 |
| 遮断機 | 残す。話ごとに一段下りる時計にする（§7） |
| 制服 | 残す。この世界の「最近の時代」の死者の服。名札は無い |
| 台帳 | 残す。白い紙の束。文字は無い |
| 秤 | 残す。骨か錆びた鉄 |
| 判 | 残す。中空の印 |
| 魂火 | 残す。唯一の光源 |
| 盆の習俗 | 機能だけ残す。名は作らない。「送る火／迎える火」の風習 |

### 変えるもの

| 物 | 変更 |
|---|---|
| 文字 | 世界から外す（§3） |
| 地名・駅名 | 作らない。標識が無いので必要ない |
| 現世の家・部屋・電話 | 記憶の中だけ。形は日本的、細部は時代を混ぜる |
| 暦・元号 | 作らない。記憶の時代は色と物で示す |

### 危ないところ

「異世界寄りの日本」は、**現代の実存**という売り文句とぶつかる。
premise のジャンルの約束は「異世界転生モノの装いを借りて、じつは現代の実存」。
世界を異世界へ寄せると、この一文が「異世界の実存」になる。

私は、約束の**中身**（魂は送られるときに終わるのか、受け取られるときに始まるのか）
は動かないと見る。動くのは装いの側だけ。ただし、読者に渡す約束の文面は
書き換えが要る。これは裁定1の副作用として記録する。

## 6. AIアニメの阻害要因と、この改稿での扱い

| 阻害 | 硬さ | 扱い |
|---|---|---|
| 文字が描けない | 硬 | 世界から外す（裁定3）で消える |
| 同一性（人物・小物） | 硬 | 台帳を1対象1ファイルで作り、identity lockを書く |
| 本数（10話×10〜20本） | 硬 | ショット単位で設計する。30秒で割らない |
| 口パク | 中 | 台詞を増やさない。声は主に地の文と記憶の外 |
| 複雑な演技・群衆 | 中 | 記憶も火の中で少人数に留める |
| 単一舞台・単一光源 | 柔 | 記憶の色で変化を作る。光源は増やさない |
| 台詞8行 | 柔 | 10話でも20行程度に抑える。会話劇にしない |
| 同じ型の8章 | 柔 | 遮断機の時計と記憶の位置で差を作る |
| 内面が地の文 | 柔 | 語りを減らし、器官の動きと物に移す |

阻害に見えて強みなもの：静止、限定作画、少人数、小さな所作、単一の舞台。
これは守る。

## 7. 強める部分

1. **遮断機の時計。** 第1話は上がっている。器官がひとつ止まるたび、一段下りる。
   第9話で閉じきる。第10話で、初めて上がる。観客が数を数えられる。
   音は機械の「がこん」、1話に1回だけ。
2. **記憶は火の中。** §4-6の規則。ゲストごとに色・時代・音を変える。
3. **累積する傷。** 線路の錆、台帳の紙の反り、火の暗さ、彼の体の印。
   遮断機ほど数えやすくなくてよい。二つ目、三つ目の時計として置く。
4. **花の能動性。** 説明でなく行為で。彼女も目的と代償を持つ。
   ただし開示の上限（§2）を越えない。
5. **向こう側。** レールの先に、送り先が一瞬見える。話ごとに違う。決して入らない。
6. **台帳を視覚の主人公に。** 白い頁、増える印、最後の空欄。
7. **定型句を毎回同じ音にしない。** 囁き、間、頁の音、火の消え方で変える。
8. **音。** 頁の「かさり」、息、火、遮断機。静けさとの対比。

## 12. 気になるところ

1. **異世界寄りの日本は、売り文句とぶつかる。** premise は「現代の実存」を
   約束している。世界を異世界へ寄せると、約束の文面が変わる。中身は動かないと
   見るが、確認したい。
2. **文字を外すと、最終頁の「書く」が消える。** 「受け取る」に置き換える案を
   §4-3に書いた。小説の物理的な誘いを失う。許容できるか。
3. **定型句は語り。** 語りを減らすなら、定型句も減る。私は例外として残す方を
   推すが、裁定7と衝突する。
4. **記憶6本で12〜18分。** 全体70分の2割前後。単一舞台の作品に、これだけの
   過去が入ると、別の作品になる危険がある。§4-6の規則で縛る前提でよいか。
5. **花の名。** 「花だけ残す」を「篠宮を落とし、花を物の名にする」と読んだ。
   ゲスト5人の名は作り直す。この読みでよいか。
6. **「該当なし」が世界から消える。** いまは第5章で地の文が宣告している。
   文字を外すと、宣告する者も消える。判の形（中空の印）だけで示すか、
   声で一度だけ言うか。
