# 歌詞——かな版（Suno の読み違いを減らす）／第三巻『書き直した名』

> 出所: [`theme-song.md`](theme-song.md) §2 の歌詞。**語も行も読点も、そのまま**——変えたのは、**漢字をかなに開いたことだけ**である。**Suno に渡すのは、下の歌詞欄だけ**（情景・註は渡さない）。曲名・曲調・声・置き場は `theme-song.md` のまま動かさない。
>
> **もう一つの候補**——[`theme-song-mix.md`](theme-song-mix.md)＝**危ない語だけ開き、常用漢字は境界の杭として残す版**。三つ（漢字・かな・混ぜ）の聞き比べ方は [混ぜ版 §三つを、どう比べるか](theme-song-mix.md) にある。

## 読みの決め方（迷う語だけ）

| 語 | 読み | なぜ |
|---|---|---|
| 間 | **ま** | 電話のあいだ。**あいだ でも かん でもない**——「間が、置かれる。」「間は、短い。」 |
| 出は | **では** | 「出は、遅い。」＝出るほうは遅い。**いでは ではない**（送り仮名の「出」だけを拾わせない） |
| 床 | **ゆか** | — |
| 控え | **ひかえ** | — |
| 受話器 | じゅわき | — |
| 一字ずつ | いちじずつ | いちもじずつ ではない。**この巻の本文は「一字ずつ」と書く** |
| 名乗る | なのる | — |
| 鉛筆 | えんぴつ | — |
| 通り | とおり | — |

## ⚠ これで直ることと、直らないこと

**直ること。**

- **漢字の読み違いは、起こらなくなる。** 「間」を かん と読む、「床」を とこ と読む、「控え」を ひかえ 以外で読む類の事故は、この版では起きない。
- **「名乗る」の読みは、なのる に固定される。** のる（乗る）とは音が違う——**歌は、行為の語のまま歌われる。**

**直らないこと。**

- **区切りと息継ぎは、かなでも指定できない。** 「なは、いちじずつでる」のような連なりは、区切りの推測を誤りうる——ただし、誤っても音は同じである。
- **アクセント・長音・促音の伸ばし方は、保証されない。**
- **旋律・テンポ・声は変わらない。** それらは `theme-song.md` §3・§4 の担当である。

**この版を使うときに、数え直さないこと。**

- `theme-song.md` の**「名乗る」7・名詞の「名」2** などの**文字の実測は、漢字版のものである。** かな版では「名」が「な」になるので、**同じ数え方はできない。** 検品の表は、**漢字版に当てる**。
- **モーラは変えていない。** サビの 10・9・7・7・3・8、フックの 3 は、この版でも同じである。

**⚠ まだ試していない。** この版で Suno が実際にどう歌うかは、**一度も生成していない。** 漢字版と聞き比べて、**読み違いが減ったかどうかを、耳で確かめるほかない。**
