# 歌詞——かな版（Suno の読み違いを減らす）／第一巻『残った名』

> 出所: [`theme-song.md`](theme-song.md) §2 の歌詞。**語も行も読点も、そのまま**——変えたのは、**漢字をかなに開いたことだけ**である。**Suno に渡すのは、下の歌詞欄だけ**（情景・註は渡さない）。曲名・曲調・声・置き場は `theme-song.md` のまま動かさない。
>
> **もう一つの候補**——[`theme-song-mix.md`](theme-song-mix.md)＝**危ない語だけ開き、常用漢字は境界の杭として残す版**。三つ（漢字・かな・混ぜ）の聞き比べ方は [混ぜ版 §三つを、どう比べるか](theme-song-mix.md) にある。

## 読みの決め方（迷う語だけ）

| 語 | 読み | なぜ |
|---|---|---|
| 行 | **ぎょう** | 紙の上の一行。**いき・ゆき ではない**——「その行は、まだ、ある。」は行そのものを指す |
| 頁 | **ページ** | この作品は頁を「ページ」と読む。かなに開かず、カタカナのまま置いた（Suno はカタカナを読み違えにくい） |
| 端 | **はし** | 机の端・紙の端。**そば ではない** |
| 出席簿 | しゅっせきぼ | — |
| 転出欄 | てんしゅつらん | — |
| 綴じ目 | とじめ | — |
| 名札 | なふだ | — |
| 三文字 | さんもじ | 「三文字」を さんもんじ と読ませない |
| 六つ・二つ | むっつ・ふたつ | 数字を使わない（Suno が ろく・に と読むのを避ける） |
| インク | インク | カタカナのまま |

## ⚠ これで直ることと、直らないこと

**直ること。**

- **漢字の読み違いは、起こらなくなる。** かなには、別の読みが無い。**「行」を いき と読む、「頁」を けつ と読む類の事故は、この版では起きない。**
- **同音の別語は、問題にならない。** はし（端／橋／箸）は、どれも同じ音である——**Suno が意味を取り違えても、歌は同じ音で歌われる。** 歌に要るのは音であって、意味ではない。

**直らないこと。**

- **区切りと息継ぎは、かなでも指定できない。** Suno はかなの列から語の切れ目を推測する。**「なのらんの」のような連なりは、区切りの推測を誤りうる**——ただし、誤っても音は同じである。
- **アクセント・長音・促音の伸ばし方は、保証されない。** 「まっすぐ」「いっぽ」の詰まりは、Suno の側の判断である。
- **旋律・テンポ・声は変わらない。** それらは `theme-song.md` §3・§4 の担当である。

**この版を使うときに、数え直さないこと。**

- `theme-song.md` の**「名」4・「誰」0** などの**文字の実測は、漢字版のものである。** かな版では「名」が「な」になるので、**同じ数え方はできない。** 検品の表は、**漢字版に当てる**。
- **モーラは変えていない。** サビの 9・10・10・10、フックの 4 は、この版でも同じである。

**⚠ まだ試していない。** この版で Suno が実際にどう歌うかは、**一度も生成していない。** 漢字版と聞き比べて、**読み違いが減ったかどうかを、耳で確かめるほかない。**
