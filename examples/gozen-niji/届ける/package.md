# package —— 公開稿の包み（カクヨム投稿用）

> 作品: 『午前二時に、あなたは誰の時間を生きていますか』（全12話）
> 根拠（読者像）: 15〜25歳。スクリーンタイム通知を見るたび罪悪感を覚える人。「スマホに逃げた時間は無駄だった」と自分を責める人。深夜、布団の中でカクヨムを読む人。
> 約束: 読了後、あなたがスマホに逃げた時間が「誰かに預けた時間」に見えるようになる。
> 包みの規則: 嘘で引かない／届けるものを約束する／開示の頂の前で止まる／抑制を引き継ぐ。全部の扉が同じ作品（預けた時間を宛先へ返す）を開く。

---

## 1. タイトル＋サブタイトル

**タイトル**: 午前二時に、あなたは誰の時間を生きていますか

**サブタイトル**: あなたが誰かに預けた時間の領収書

- タイトルは核心の問い（あなたの時間は誰のものか）を名指しせず立てる。サブタイトルは第3〜4話までに開示される再定義（預けた時間の領収書）で引く。開示の頂（第7話の正体・第12話の自分宛て）には触れない。

## 2. 帯（キャッチコピー）

**主**:
> 身に覚えのない午前二時の記録。それは、あなたが誰かに預けた時間の領収書。宛先に返せたら、幽霊は還って行く。

（余白を残す版・帯がもう一行とれるなら）:
> 午前二時の幽霊は、呪いでも、もう一人の自分でもない。

- 「身に覚えのない記録」=未知で引き、「領収書」=感嘆の再定義で受ける。「返せたら還る」で手触りを約束する。テーマ（時間は無駄じゃない）を名指ししない。抑制5条のまま。

## 3. あらすじ

### 裏表紙（短・約160字）

> 午前二時。真白のスマホに、身に覚えのない記録が残る。眠っていた間に、誰かの指が打っていた。宛先は、自分自身。翌夜、画面に現れた虹色の少女は言う——記録は、あなたが誰かに預けた時間の領収書。幽霊を還すただ一つの方法は、宛先へ言葉を返すこと。真白が避けてきた、三十二人へ。

### サイト用（中・約450字・連載プラットフォーム）

> 高校二年の真白は、深夜、布団の中でスマホをいじるのが癖だった。通知のたびに指が動く。既読を付けたまま返さないトークを、画面上部に残したままにしている。
>
> そんなある夜。午前二時、スマホがひとりでに光る。スクリーンタイムの通知。身に覚えのない記録——午前2時00分〜3時21分、使用時間1時間21分、アプリ・メッセージ。宛先は、自分自身。眠っていた間に、誰かが打っていた。
>
> 　　午前2時00分〜午前3時21分
> 　　使用時間　1時間21分
> 　　アプリ　　メッセージ
>
> その言葉は——「おまえが私にくれた時間、私が生きてるよ」。
>
> 次の夜、画面に現れたのは、真白と同じ顔の、虹色の残像の少女。彼女は言った。スマホに残る記録は、あなたが誰かに預けた時間の領収書。いいねも既読も、返事を打っては消した夜も、全部、誰かの人生へ渡した時間だ——と。そして、幽霊を還す方法はただひとつ。預けた時間を、宛先へ返すこと。
>
> けれど真白は、言えなかった言葉をニジに代わりに届けられて、楽になる。「次は、おまえが届けなよ」。宛先リストは、三十二人。既読無視した後輩に。言えない「ありがとう」の親友に。ずっと見てただけの先輩に。真白は、自分の言葉で、時間を返していく——逃げた時間は、無駄じゃなかった、と確かめるために。

- 開示の頂（第7話の正体・第12話の自分宛て）には触れない。ここまでの設定（領収書・返す・三十二人）は第6話までに開示される範囲。

## 4. 画像生成プロンプト

### カバー（表紙）

```
ラノベ表紙・1枚。深夜の暗い部屋。布団に包まった高校二年の少女（真白）が、布団の中でスマホを顔の前に掲げている。部屋は真っ暗で、画面の光だけが顔を照らす。画面の中に、虹色に滲む少女の残像——真白と同じ顔だが少し幼く、輪郭が虹色に淡く光る。画面の青白い冷たい光と、残像の虹色の暖かい光の対比。手前のスマホに焦点を当て、奥の暗い部屋へ沈む奥行き。少女の表情は、怖い、ではなく、惹かれている、の一歩手前。写実寄りのアニメ塗り。配色は紺・青・虹色を基調に、黒の部屋とのコントラスト。タイトル文字用の余白は上部に確保。
```

### キーシーン（第12話・朝）

```
1枚。朝。窓から差す柔らかな白い光。布団の横のスマホの画面の中で、白い光がゆっくりと虹色を取り戻していく——最初に真白が名前を付けた、あの色に。手前の真白はカーテンを開けかけ、外は晴れている。冷たい夜の青が、朝の白と虹色に溶ける瞬間。希望を名指しせず、色と光だけで示す。余白を効かせた構図。ラノベ挿絵風。
```

## 5. タグ／キーワード

`現代ファンタジー` `ライトノベル` `午前二時` `スクリーンタイム` `幽霊` `スマホ` `SNS` `高校生` `青春` `切ない` `感動` `片想い` `友情` `夜` `成長`

- ジャンル（現代ファンタジー・ラノベ）＋本作固有の語（午前二時・スクリーンタイム・領収書）で、約束（罪悪感→再定義の読後感）が届く読者の住所にする。

---

## 包みの検品（4規則・一つの魂、多くの扉）

1. **嘘で引かない** ✓ —— 全扉が「スクリーンタイム=預けた時間の領収書・宛先へ返す」という本作の実在の設定だけから引いている。幽霊退治や恋愛ものの見せ物を約束していない。
2. **届けるものを約束する** ✓ —— あらすじが約束するのは、静かに宛先へ言葉を返す話。帯もサブタイトルも同じ方向を向く。
3. **開示の頂の前で止まる** ✓ —— ニジの正体（第7・8話）、最後の宛先=自分（第12話）、湊の第2巻（第11話）には一切触れていない。
4. **抑制を引き継ぐ** ✓ —— 帯もあらすじも「時間は無駄じゃなかった」を名指ししない。テーマを説明していない。読者に確かめさせる余白を残す。

**一つの魂、多くの扉** —— 帯（領収書の再定義）→ あらすじ（返す物語）→ 表紙（画面の中の虹色の残像）→ タグ（午前二時・スクリーンタイム）。すべて同じ問い「あなたの時間は誰のものか」を、開かずに指している。
