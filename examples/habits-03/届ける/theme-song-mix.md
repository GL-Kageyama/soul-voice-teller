# 歌詞——混ぜ版（Suno の読み違いを減らす・危ない語だけ開く）／第三巻『書き直した名』

> 出所: [`theme-song.md`](theme-song.md) §2 の歌詞。**語も行も読点も、そのまま**——変えたのは、**読みを外しやすい語だけを、かなに開いたこと**である。**Suno に渡すのは、下の歌詞欄だけ。** 曲名・曲調・声・置き場は `theme-song.md` のまま動かさない。
>
> **⚠ これは仮説の版である。** 「Suno が読みを外すのは、複数読み・珍しい読みの語に偏る」という見立てに立っている。**まだ生成していない。** 全部かなの版（[`theme-song-kana.md`](theme-song-kana.md)）と聞き比べて選ぶための、三つ目の候補である。

## 開いた語（これだけ）

| 語 | 開いた形 | なぜ開いたか |
|---|---|---|
| 受話器 | じゅわき | **珍しい複合語** |
| 紐 | ひも | **珍しい字**。ちゅう と読ませない |
| 間 | ま | **複数読み**（ま／あいだ／かん）。この巻は「ま」 |
| 出は | では | **送り仮名だけの語**。しゅつは・いでは と読ませない |
| 一字ずつ | いちじずつ | **数字＋助数詞**。いちもじずつ と読ませない |
| 名乗る | なのる | **題でもある動詞**。めいじょう と読ませない |
| 床 | ゆか | **複数読み**（ゆか／とこ） |
| 通り | とおり | **複数読み**（とおり／どおり） |
| 控え | ひかえ | ひかえ／ひかえ 以外に読みようが無いが、辞書が外しうる |
| 端 | はし | **複数読み**（はし／はじ／たん） |
| もう一度 | もういちど | **数字**。もうひとたび と読ませない |

## 漢字のまま残した語（境界の杭）

**机・声・線・中・下・先・別・鉛筆・字・書く・手・口・息・先・出る・形・違う・同じ・速さ・静か・音・待ち・短い・戻る・自分**——**常用の読みしか持たない語、または文の骨格になる語**である。**「返る形が、違う。」の「返る」を残したのは、返る（かえる）がこの歌の主題の語であり、字面を保ちたいからである。** ⚠ **同じ「出」でも、「出る」は残し、「出は」は開いた**——**送り仮名が付いた動詞は辞書が外しにくく、送り仮名だけの「出は」は外しやすい**、という見立てである。

## 三つを、どう比べるか

1. **同じ条件で三つ作る。** Style・Vocal・Exclude は `theme-song.md` §3・§4 のまま**一字も変えない**。変えるのは Lyrics 欄だけ。
2. **まずサビだけで試す**（短く、回数が少なく済む）。`[Chorus]` の六行を、**漢字版・かな版・混ぜ版**の三つで一回ずつ。
3. **聞く点は三つ**——**読み**（事故が消えたか）・**区切り**（息継ぎが不自然でないか）・**旋律**（変わっていないか）。
4. **決め手は通しで二本。** サビで差が付かなければ、漢字版と混ぜ版を、通しで一本ずつ。

## ⚠ この版の弱点

- **開かなかった語が、外れる可能性は残る。** 常用漢字でも Suno の辞書が外すことはある——**この版は、その危険をゼロにしない。** 全部かなの版だけが、それをゼロにする（代わりに区切りの危険を負う）。
- **開いた語の境目が、新しい曖昧さになる。** 「じゅわきが」「まが、置かれる」のように、かなと漢字が混ざる位置は、Suno にとって区切りの手がかりが減る。**ただし、漢字が両側に残っているので、全部かなよりは情報が多い。**
- **「では、遅い。」は、形の上では助詞の「では」と同じ字面になる。** 音は同じ（では）なので、歌には影響しない——**意味を読むのは聴き手であって、Suno ではない。**
- **まだ試していない。** この版が三つの中で最も良いという保証は無い。**耳で決めるほかない。**

## 数え直さないこと

`theme-song.md` の文字の実測（「名乗る」7・名詞の「名」2 など）は、**漢字版のものである。** この版では一部がかなになっているので、**同じ数え方はできない。** モーラは変えていない（サビ 10・9・7・7・3・8、フック 3）。
