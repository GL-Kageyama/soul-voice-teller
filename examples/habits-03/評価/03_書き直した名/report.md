## 📝 総評

> 第三巻『書き直した名』十六話を、十三名の評価者が一つの巻として読んだ。総合は現在値 63.08・潜在値 76.33 で、2×2 の高／高——`innovation` に落ちる。ただしこれは平均の位置であって、十三名の個別の判定は discovery_target 9・current_success 3・low_signal 1 に割れている。集計が個々の判断を代表しているわけではない。

一致しているのは、この巻が凡庸の側に一片も落ちていないことである（anti-generic-story-filter 78、cliche_density 88・voice_particularity 90）。そして一致して低いのは、人物が賭けること（character-role 37、challenge 16）と、読む速度が動くこと（reader-experience 49、page_turner 34）と、山場が超出すること（admiration 60、admiration_peak 44）である。三名（prose-style 67・world-building 69・narrative-technique 75）は、反復が成就していると見て `current_success` を選んだ。一名（character-role 37）だけが `low_signal` を選んだ。

この割れは、評価の不一致ではなく、読む契約の不一致である。この巻は、読者に「名を読み、何もしない」という同じ行いを十六話ぶん続けることを求める。その契約を受け取れる読み手には、反復は様式であり成就である。受け取れない読み手には、反復は停滞である。十三名の点数は、この一点で分かれている。

修正の必要があるのは、その契約の内側である——反復の温度（中盤の等速）と、山場の届け方である。契約そのもの（三単位の反復・一拍の位置・未了で閉じること・`?`・話名）は、動かさない。

## ⚠️ 注意点

- 【評価者の起動方法の逸脱】評価者定義（~/.claude/agents/*-ja.md）は frontmatter に `tools: []` を持ち、直接起動すると十三名すべてが `tool_uses: 0` で落ちる（2026-09-21 の第二巻実行で実測）。本実行では一名につき general-purpose のラッパーを一つ起動し、その中で評価者定義ファイルと本文の絶対パスを Read させ、評価者として JSON を出させた。したがって「評価者エージェントを直接起動した」のではなく「評価者の定義を読んだ汎用エージェントが評価者を演じた」という形である。十三名すべてが本文を Read して返っている（content_summary がこの巻の内容を指していることを、実行後に一名ずつ確認した）。
- 【議長は本文を読んでいない】入力が大きいため、議長（オーケストレータ）は本文を自分の文脈に読み込んでいない。評価者にはパスを渡し、Read させてから評価させた。したがってこの報告書の本文に関する記述は、すべて評価者の出力と、設計文書（構想・話割り・場面表・台帳）から来ている。
- 【設計文書の非開示】評価者には設計文書を一切渡していない。渡したのは本文の絶対パスと、一行の context（「これは連作小説の、一つの巻（十六話）の本文である。各話には、名の書かれた紙と、扱う癖と、一拍が、一つずつ置かれる。十六話を、一つの巻として読んで評価してよい。」）だけである。ゆえに、設計が既に決めた事項（話名・`?`・敵役の規律・内面の主語・巻末で解放しないこと）に当たる指摘が、生のまま出ている。それらは disagreement_map の第六群にまとめ、revision_direction には入れていない。
