## 1. 何をしたか

正典の歌詞から、**読みを外す危険のある語**だけを、かなに開いた。開いたのは——

**提灯竿もみまつり → ちょうちんざお　もみまつり（境界の空白を一つ）／古河駅 → こがえき／西口 → にしぐち／矢来 → やらい／灯 → ひ／古河 → こが／雪華 → ゆきばな／古河城 → こがじょう／本丸跡 → ほんまるあと／渡良瀬川 → わたらせ川／篆刻 → てんこく／捺す → おす／渡良瀬遊水地 → わたらせ遊水地／谷中湖 → やなか湖／心 → こころ／形 → かたち**

それ以外の語・行・順・構造タグ・モーラは、**一字も変えていない**。類語への置き換えも、行の追加・削除もしていない。

**今回の最大の危険は「古河」である。** 生成器が「ふるかわ」と読んだら、この歌は古河の歌でなくなる。だから、古河は歌詞の中のすべての箇所で「こが」に開いた。

## 2. 仮説の印

⚠️ **この版は、生成するまで試されていない。** 見立ては次のとおり:

- Suno は `古河` を `ふるかわ` と読む（`こが` ではない）。**これが起きたら、この版の出番である。**
- `提灯竿もみまつり` を `ていとうかんもみまつり` などと読み、祭りの名が崩れる。
- `矢来` を辞書外れの語として読み違える（`しらい`・`やき` など）。
- `灯` を `あかり` と読み、1モーラの `ひ` が3モーラになり、旋律の音数が変わる。
- `雪華` を `せっか` と読み、市のシンボルの語が別の語になる。
- `古河城` を `ふるかわじょう` または `こがしろ` と読み、城の名が崩れる。
- `本丸跡` を `ほんまるせき` と読む。
- `渡良瀬` を `とりょうせ` などと読む。
- `篆刻` を `せんこく` と読む。
- `捺す` を `なつす` と読む。
- `渡良瀬遊水地` を長い複合語として読み違える。
- `谷中湖` を `たになかこ` と読む。
- `心` を `しん`、`形` を `けい` と読み、ブリッジの要の行が崩れる。

**どれも、実際に聞くまで確定しない。** この版は、その危険に対する**二つ目の候補**である。

## 5. 漢字のまま残した語（境界の杭）

| 語 | 残した理由 |
|---|---|
| 十二月 | 日付は `じゅうにがつ` と読まれる見込み。開くと `じゅうにがつ` の区切りが消え、かな過多になる。 |
| 竹 | 文脈（西口・しなって）が `たけ` を助ける。 |
| 灯して | 送り仮名が `ともして` を決める。名詞の `灯` だけを開いた。 |
| 白い息 | 文脈が `しろいいき` を助ける。 |
| 肩 | 文脈が `かた` を助ける。 |
| 朱 | 「朱でおす」の文脈が `しゅ` を助ける。開くと `しゅ` の一字が目立ち、色の像が薄れる。 |
| 石 | 文脈が `いし` を助ける。 |
| 名 | 文脈が `な` を助ける。 |
| 葦 | 「葦が焼けて」の文脈が `あし` を助ける。仮に `よし` と読まれても、意味は通る（葦の別読み）。音数も同じ2モーラ。 |
| 川上 | `かわかみ` と `かわうえ` のどちらでも意味は近い。音数も同じ4モーラ。 |
| 村 | 文脈が `むら` を助ける。 |
| 春 | 文脈が `はる` を助ける。 |
| 真ん中 | 文脈が `まんなか` を助ける。 |
| 帰る・残る・沈んで・焼けて・彫った・笑って | 送り仮名が読みを決める。 |

**境界の考え方**: かなを増やすほど、生成器が聞き取れる語の境目は減る。だから、危ない語だけを開き、文脈が読みを助ける語は漢字のまま残した。**開くのは最小限**である。ただし、今回は固有名詞が多く、どうしても Verse 1・Verse 3・Bridge はかなの比率が上がる。

## 7. 比べ方

1. **同じ条件で作る。** Style・Exclude Styles・Vocal Gender・Duration は正典と同じ。**変えるのは Lyrics 欄だけ。**
2. **一度に一つ。** 正典と混ぜ版を同時に貼らない。まず正典を一本、次に混ぜ版を一本。
3. **聞く点**:
   - **読み**——`古河` が `こが` と歌われているか。`雪華` が `ゆきばな`、`古河城` が `こがじょう`、`本丸跡` が `ほんまるあと`、`篆刻` が `てんこく`、`谷中湖` が `やなかこ` と歌われているか。
   - **区切り**——かなが増えた Verse 1・Verse 3・Bridge で、語の境目が聞こえるか。`ちょうちんざお　もみまつり` の境目が聞こえるか。`こがじょうの　ほんまるあとを` が区切れているか。
   - **旋律**——サビの 8／11／8／9／8／10 モーラが、正典と同じように乗っているか。
4. **選び方**——通しで一本ずつ聞き、**読みが正しく、区切りが聞こえる方**を採る。両方が読みを外すなら、次は Verse 1・Verse 3・Bridge だけ全部かなにする。両方が区切りを失うなら、正典を採り、次の表を開く。

## 8. 弱点

- **かな過多の代償**——開いた語は Verse 1・Verse 3・Bridge に集中している。この三つの節は、正典より語の境目が聞き取りにくい。**読み違いの危険を、区切りの危険に替えただけ**になる可能性がある。特に Verse 1 の第1行は、境界の空白を一つ置いても、12モーラの固有名詞が一息に歌われる。
- **固有名詞の字面の喪失**——`古河`・`古河城`・`渡良瀬川`・`谷中湖`・`雪華`・`篆刻` は、かなに開くと、字面の像が消える。**正典は名を見せ、混ぜ版は音を残す。** どちらを採るかは、聴く場所で決める——表示用の歌詞なら正典、生成用の音なら混ぜ版。
- **`古河` を開くことの大きさ**——この版は、歌詞欄から「古河」の漢字を消している。**町の名の字面を残したいなら、正典で生成し、`ふるかわ` と歌われたときだけ混ぜ版へ。** 混ぜ版は、そのための二つ目の候補である。
- **`谷中湖` のまとまり**——`湖` の字面は残るが、`谷中湖` という三字のまとまりはほどける。`やなか湖` は音としては正しいが、地名の重さが減る。
- **`心` と `形` の字面**——`心` は こころ／しん、`形` は かたち／けい の二つの読みと意味の層を持つ。かなに開くと、その層が消える。**この歌のブリッジは、字面の層を持っている。**
- **未検証**——この版は、実際に生成するまで試されていない。**正典は [theme-song.md](theme-song.md) の歌詞であり、この版はその訂正ではない。**
- **曲名は動かさない**——『おかえり、古河』は、題としては漢字のまま。**題は歌詞ではない**ので、読みの危険は歌詞欄より小さい。Suno のタイトル欄が読みに影響する場合だけ、`おかえり、こが` と書く選択肢を添える。
