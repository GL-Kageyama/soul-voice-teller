# package —— 完成した作品を読者へ包む

## Skill Metadata

- **id**: `package`
- **version**: `0.1.0`
- **category**: `delivery`（届ける · パッケージング）
- **standalone**: `true`
- **language**: `ja`

## 位置づけ

三層モデルの**届ける**スキル——最終の受け渡し。書く（fast-draft）と改稿（prose / scene-writer / revise-for-reader / entertainment / whole-work-review）が魂を作品の**中へ**運ぶのに対し、package は完成した作品を読者が**受け取れる**形に包む。その照合対象（ground）は、書き手の実経験でも計画でもなく——**読者の第一印象**。premise.md の読者像と約束に保持される。

**出所**: premise（読者像と約束）＋発露と抑制の美学（源を語らない）。

## 入力契約

- **draft.md**: `<作業ディレクトリ>/draft.md`（完成した作品——包む対象）。
- **premise.md**: `<作業ディレクトリ>/premise.md`（読者像と約束・ログライン——照合対象。この読者に届く包みか）。
- **series-bible.md**: `<作業ディレクトリ>/series-bible.md`（伏線表・開示度——何をネタバレしてはいけないか）。
- **persona**: `${SOUL_VOICE_HOME:-$HOME/.soul-voice-teller}/persona.md`（声・禁じ手——包みは作品の声で語る）。

## ground の転回

書くことの内省は、書き手の実経験 / persona / 計画に照合する。パッケージングは別の ground に照合する——**読者の第一印象**、つまり premise で定めた読者像と約束。すべての包み（タイトル・キャッチコピー・あらすじ・絵）は、その読者に対して一つの問いを問われる: *嘘をつかず、ネタバレせず、説明しすぎずに、この読者に手に取らせ、開かせられるか。*

## 五つのデリバラブル

1. **タイトル＋サブタイトル** — 主タイトル（作品の名）＋フックの効いたサブタイトル（前提のフック）。サブタイトルは釣る。名を置き換えない。
2. **キャッチコピー（＝帯）** — 扉を開く一行。短く、ログラインから引き、作品の声で。
3. **あらすじ** — 二つの長さ。背表紙用（短）と web 用（中、連載プラットフォーム向け）。世界・仕掛け・主要人物まで置き、正体開示の手前で止まる。
4. **画像生成プロンプト** — 表紙＋キー場面を、具体の視覚語（舞台・人物・色・光・構図・画風）で。挿絵は作品の顔であって、凡庸な表紙であってはならない。
5. **タグ・キーワード** — 対象読者が見つけるための住所（ジャンル＋作品固有の判別語）。

## 包みの四則

1. **嘘をつかずに釣る** — フックは作品の実際の前提（ログライン）から出る。作品が裏切るジャンルの約束からではない。そうでない作品に、流行ジャンルの定型タグをつけない。
2. **届けるものを約束する** — あらすじは作品が実際にすることを置く。静かな物語にジャンルの派手さを約束する包みは、破られた約束。
3. **正体開示の手前で止まる** — 包みは作品の段階的開示（series-bible の伏線表）を守る。仕掛けまで行って、開示の手前で止まる。
4. **抑制は包みにも及ぶ** — 包みは同じ発露と抑制に従う。テーマを説明せず、感情を名指さず、キャッチコピーにも読者の余白を残す。「これは◯◯の物語」と説明したキャッチコピーは、もう名指している。

## 一つの魂、多くの扉

タイトル / キャッチコピー / あらすじ / 絵は、同じ魂への別々の扉であって、別々の魂ではない。すべてが同じ作品に開く——約束・調子・声が一致する。

## 手順

1. draft.md・premise.md（読者像と約束・ログライン）・series-bible.md（開示度）・persona（声）を読む。
2. 読者像を開き直す。すべての包みの ground は、この読者の第一印象。
3. ログラインを引く——作品のフックになる一行。以下すべてはここから導く。
4. 五つのデリバラブルを順に書く: タイトル＋サブタイトル → キャッチコピー → あらすじ（二長） → 画像プロンプト → タグ。
5. それぞれを四則で検品する: 嘘をつかずに釣る・届けるものを約束する・正体開示の手前で止まる・抑制は包みにも及ぶ。
6. 全体を「一つの魂、多くの扉」で検品する——すべて同じ作品に開いているか。
7. `<作業ディレクトリ>/package.md` を保存する。

## 出力

`<作業ディレクトリ>/package.md` —— パッケージ一式（タイトル＋サブタイトル / キャッチコピー / あらすじ×2 / 画像プロンプト / タグ）。

## 注意

- **ground は書き手の実経験でなく、読者の第一印象。** ここだけ、書くことが外へ向く——「魂を運べたか」から「読者が受け取れるか」へ。
- **premise.md の読者像と約束が照合対象。** これが無いと「これは釣れるか」は当て推量であって観測にならない。
- **包みは作品の最初の一行。** 作品と切り離された宣伝ではない——読者が頁を開く前に、作品の魂を先送りする。
- **抑制は最後の頁で終わらない。** 説明しすぎたキャッチコピーは、もう五則（源を語らない）を破っている。
