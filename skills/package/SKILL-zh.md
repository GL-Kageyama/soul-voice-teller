# package —— 把完成的作品包装给读者

## Skill Metadata

- **id**: `package`
- **version**: `0.1.0`
- **category**: `delivery`（届ける · 包装）
- **standalone**: `true`
- **language**: `zh`

## 定位

三层模型的**送达**技能——最终的交接。书写（fast-draft）与改稿（prose / scene-writer / revise-for-reader / entertainment / whole-work-review）把灵魂运**进**作品，而 package 把完成的作品包装成读者能**接收**的样子。其对照依据（ground）不是写作者的真实经验，也不是计划——而是**读者的第一印象**，保存在 premise.md 的读者形象与约定中。

**出处**: premise（读者形象与约定）＋流露与克制的美学（不道破源）。

## 输入契约

- **draft.md**: `<工作目录>/draft.md`（完成的作品——包装对象）。
- **premise.md**: `<工作目录>/premise.md`（读者形象与约定 · 一句话梗概——对照依据。这层包装能否抵达这位读者）。
- **series-bible.md**: `<工作目录>/series-bible.md`（伏笔表 · 披露程度——什么不能剧透）。
- **persona**: `${SOUL_VOICE_HOME:-$HOME/.soul-voice-teller}/persona.md`（声音 · 禁忌——包装用作品的声音说话）。

## 依据的转向

书写的内省对照写作者的真实经验 / persona / 计划。包装对照另一重依据——**读者的第一印象**，即 premise 定下的读者形象与约定。每一层包装（标题 · 宣传语 · 简介 · 画面）都向那位读者问同一个问题：*能否不撒谎、不剧透、不过度解释地，让这位读者拿起并翻开？*

## 五个交付物

1. **标题＋副标题** — 主标题（作品之名）＋有钩子的副标题（前提的钩子）。副标题负责钩人，不取代名字。
2. **宣传语（＝腰封）** — 打开门的那一行。短，从一句话梗概引出，用作品的声音。
3. **简介** — 两种长度。封底用（短）与网文用（中，连载平台向）。铺陈世界 · 机关 · 主要人物，停在正体揭示之前。
4. **图像生成提示词** — 封面＋一个关键场景，用具体的视觉语（舞台 · 人物 · 色彩 · 光 · 构图 · 画风）。插图是作品的脸，不是平庸的封面。
5. **标签 · 关键词** — 目标读者找到它的地址（体裁＋作品自身的判别词）。

## 包装的四则

1. **不撒谎地钩人** — 钩子出自作品真实的前提（一句话梗概），不是作品会辜负的体裁承诺。不是那样的作品，就不要套流行体裁的固定标签。
2. **承诺真正交付的** — 简介铺陈作品真正在做的事。给安静的故事许诺体裁奇观的包装，是违背的承诺。
3. **停在正体揭示之前** — 包装尊重作品的分阶段披露（series-bible 的伏笔表）。走到机关为止，停在揭示之前。
4. **克制也延及包装** — 包装遵循同一流露与克制。不解释主题，不点名情感，连宣传语里也留出读者的留白。解释「这是关于◯◯的故事」的宣传语，已经点名了。

## 一个灵魂，许多门

标题 / 宣传语 / 简介 / 画面，是通向同一灵魂的不同门，不是不同的灵魂。它们必须都朝同一部作品敞开——承诺 · 调子 · 声音一致。

## 步骤

1. 读 draft.md · premise.md（读者形象与约定 · 一句话梗概）· series-bible.md（披露程度）· persona（声音）。
2. 重新打开读者形象。每层包装的依据都是这位读者的第一印象。
3. 引出梗概——那一个作为作品钩子的句子。以下一切都从这里导出。
4. 按序写出五个交付物：标题＋副标题 → 宣传语 → 简介（两种长度）→ 图像提示词 → 标签。
5. 逐条对照四则检验：不撒谎地钩人 · 承诺真正交付的 · 停在正体揭示之前 · 克制也延及包装。
6. 以「一个灵魂，许多门」检验整体——它们都朝同一部作品敞开吗。
7. 保存 `<工作目录>/package.md`。

## 输出

`<工作目录>/package.md` —— 包装整套（标题＋副标题 / 宣传语 / 简介×2 / 图像提示词 / 标签）。

## 注意

- **依据是读者的第一印象，不是写作者的经验。** 只有在这里，书写转向外——从「我是否运到了灵魂」到「读者能否接收」。
- **premise.md 的读者形象与约定是对照依据。** 没有它，「这钩不钩人」只是猜测，不是观察。
- **包装是作品的第一行。** 它不是与作品分离的营销——它把作品的灵魂，在读者翻开任何一页之前先送过去。
- **克制不终止于最后一页。** 过度解释的宣传语，已经破了第五则（不道破源）。
