# theme-song —— 完成した作品を1曲の主題歌に凝縮する

## Language Mode

このスキルは既定で英語を出力する。他言語で出力するには `lang` 引数（例: `/theme-song lang=ja`）か `SOUL_VOICE_TELLER_LANG=ja` を設定する。解決順: `$ARGUMENTS.lang` ＞ `SOUL_VOICE_TELLER_LANG` ＞ `en`。

- `en`（既定）: このファイル（`SKILL.md`）と `../references/*.md` を使う。
- `ja`: `SKILL-ja.md` と `../references/ja/*.md` を読み、日本語で出力する。
- `zh`: `SKILL-zh.md` と `../references/zh/*.md` を読み、中国語で出力する。

`lang` 引数が決めるのは**このスキル自身の散文**（手順・説明欄）であって、**歌詞の言語ではない**——**歌詞は作品の言語（物語の言語）で書く**。歌は作品の声だから。

## Skill Metadata

- **id**: `theme-song`
- **version**: `0.2.0`
- **category**: `delivery`（届ける · 主題歌）
- **standalone**: `true`
- **language**: `ja`

## 位置づけ

三層モデルの**届ける**スキル——package に続く2個目。package が完成した作品を読者が**受け取れる**形に包むのに対し、theme-song は作品を歌に凝縮し、魂を**聞かせる**。照合対象（ground）は読者の第一印象（それは package のもの）ではなく——**作品の魂**：premise で定めたテーマ、そして draft で感情が立ち上がる場面。

**出所**: premise（テーマ・核心の問い）＋発露と抑制の美学（源を語らない）。

## 入力契約

- **draft.md**: `<作業ディレクトリ>/draft.md`（完成した作品——歌う対象）。
- **premise.md**: `<作業ディレクトリ>/premise.md`（テーマ・核心の問い・約束——歌が運ぶべきもの）。
- **series-bible.md**: `<作業ディレクトリ>/series-bible.md`（伏線表・開示度——歌ってはいけないこと）。
- **persona**: `${SOUL_VOICE_HOME:-$HOME/.soul-voice-teller}/persona.md`（声・禁じ手——歌は作品の声で歌う）。
- **package.md**（任意）: `<作業ディレクトリ>/package.md`——既にあれば、曲名・サビ・曲調がタイトル・帯・あらすじと矛盾しないこと。一つの魂、二つの扉。

## ground の転回

package は読者の第一印象に照合する。歌は**作品の魂**——テーマ、そして感情が立ち上がる場面——に照合する。すべてのデリバラブル（曲名・歌詞・曲調・ボーカル・説明）は、その魂に向かって一つの問いを問われる: *名指しせず、ネタバレせず、実際に歌えるものとして、この作品の魂を運べているか。*

## 歌の一式（デリバラブル6点）

1. **曲名** — 歌の名。作品の名を置き換えない。サビと重なるフックの一行。
2. **歌詞** — 構造タグ付き（`[Intro]` / `[Verse 1]` / `[Chorus]` / `[Verse 2]` / `[Bridge]` / `[Outro]`）。発露と抑制の5条を守り、読まれる散文でなく歌われる詩行として書く。
3. **曲調指定（Style of Music）** — ジャンル・テンポ・ムード・時代・楽器を、音楽生成が解釈しやすい英語タグ＋短い補足で。作品の約束を裏切らない。
4. **ボーカル指定** — 性別・声質・歌い方。作品の声と一致する。
5. **楽曲説明（Song Description）** — 物語の何を歌うか（開示の頂の手前で）。生成器への文脈＋人の理解用。
6. **挿入位置・使用意図** — OP / ED / 挿入歌 / エンディングなど、物語全体の中での役割。これが「作品全体の歌」である根拠。

## 歌の四則

1. **嘘をつかずに歌う** — 歌詞も曲調も、作品の実際のテーマと感情から出る。作品が裏切るジャンルの約束からではない。静かな物語に派手なジャンルの音を当てない。
2. **届けるものを約束する** — 歌詞と曲調が約束する情感は、作品が実際に届けるもの。抑制の効いた物語にカタルシスの爆発を約束する歌は、破られた約束。
3. **開示の頂の手前で止まる** — 歌詞と楽曲説明は series-bible の開示度を守る。仕掛けまで行って、開示の頂・結末は歌わない。
4. **抑制は歌詞にも及ぶ** — 歌詞は同じ発露と抑制に従う。テーマを説明せず、感情を名指さず、聴く者の余白を残す。「これは◯◯の物語」と歌うサビは、もう名指している。

## 歌詞は「歌われる」ための言葉（craft）

歌詞は散文の行ではない。声に運ばれるために書かれる:

- **シラブル数とリズム** — 旋律に乗る行。拍に割れる。
- **押韻と繰り返し** — サビは繰り返しで残る。一度聴いて残るべき一行。
- **サビはフック** — 帯（キャッチコピー）と同じく、テーマを名指しせずに運ぶ。
- **歌詞という媒介固有の危険** — 行が短いほど、説明・名指しが目立つ。歌詞は散文より隠れる語数が少ないから、抑制はより必要であって、より緩めてはならない。

## 読み違い予防版（混ぜ版・二つ目の歌詞）

音楽生成は歌詞を**読む**のではなく、**発音する**。外した一語は、そのまま歌われる。だから theme-song は、**歌詞を二つ**出す。

- **歌詞** — `theme-song.md`（または名のある版）。作品の表記のまま。これが正典。
- **読み違い予防版（混ぜ版）** — `theme-song-mix.md`（歌詞が名のある版なら、その名の横に `-mix` を付ける——`theme-song-rock-mix.md` など）。同じ歌詞で、**読みを外す危険のある語だけ**をかなに開いたもの（日本語以外は、その言語の危険に合わせて音を固定する）。

混ぜ版は**書き直しではない**。語も、行も、順も、構造タグも、歌うモーラも同じ。変わるのは、危ない語の**表記だけ**。混ぜ版は正典と聞き比べる**二つ目の候補**であって、正典の訂正ではない。七つ目のデリバラブルでもない——同じ歌詞の、二つ目の表記である。

### ほどほど——開くのは最小限

語を開くのは、**実際の失敗の形があるとき**だけ。

| 危険 | 例（日本語の歌詞） |
|---|---|
| 読みが割れる | 設計（せっけい／せつけい）・保守（ほしゅ／まもり）・半分（はんぶん／はんぷん）・開く（ひらく／あく）・月曜日（げつようび／つきようび——び が落ちうる）・方（かた／ほう）・親（おや／しん）・鍵（かぎ／けん） |
| 珍しい複合語・長い複合語・辞書外れ | 冪等性・枯渇・扇風機・環境変数・消費電力・先週 |
| 数字・時刻 | 500 → ごひゃく・十九 → じゅうきゅう・三百五十三 → さんびゃくごじゅうさん・二時 → にじ |
| 英字の略語・記号 | CPU・SLO・I/O・.env |
| 文脈の無い短い行 | 一語だけの行、前後が文法を助けない行 |
| 読みで意味が変わる語 | 開いた（あいた／ひらいた） |
| 耳が外せないフック | 主題語、歌が転換する一行 |

フックは部分的に開いてよい——主題語の字面は残し、危ない字だけを開く（揺れ方→揺れかた）。

漢字のまま残すのは、次のとき。

- **送り仮名が読みを決める** — 読まない・知らない・冷たい・割り込み。活用形に読みが一つしかない。
- **この文脈で読みが一つ** — 部屋・画面・光・声・指。せい・こう・し は、ここでは語にならない。
- **字面が意味を運ぶ** — 主題語、曲名、一字の転換（来るな→来た）、開くと同音で別の語になる語（二本→にほん＝日本）。
- **カタカナ語** — ひらがなに開くと、かえって不自然になる。開くのは英字の略語までで、形はカタカナ（CPU→シーピーユー）。
- **開くと区切りの手がかりが消える。** かなの境目は無料ではない。かなを増やすほど、生成器が聞き取れる語の境目は減る。

**迷ったら、漢字のまま残して「それでも聞こえたら」の表に置く。** 次の段で、実際に外れた語だけを開く。

### 日本語以外の歌詞

同じ原則を、その言語の危険に当てる。

- **中国語** — 多音字、珍しい複合語、アラビア数字、英字の略語。曖昧な複合語は空白で切り、数字と略語は開き、同音で意味の通る語にだけ置き換える。ピンインの曖昧さは歌詞欄の外の表に置く——生成器は書かれたとおりに歌う。
- **英語** — 同綴異音語（read／read・live／live・lead／lead）、略語、数字、固有名詞。数字と略語は語に開き、同綴異音語は行が成り立つときだけ曖昧でない語に替える。発音の綴りは歌詞欄に入れない——そのまま歌われる。

### 混ぜ版の規則

1. **変わるのは読みだけ** — 類語に替えない、行を足さない・削らない、順を変えない、構造タグを変えない。
2. **正典は正典のまま** — 混ぜ版が上書きしない。二つのファイルは互いを指す。
3. **一度に一つ** — 二つを同時に生成器へ貼らない。Style・Vocal・Exclude・長さは同じにし、変えるのは Lyrics 欄だけ。
4. **曲名は動かさない** — 曲名は作品の表記のまま。フックを開く場合（揺れ方→揺れかた）は、そう書き、曲名の表記を取って読み違いを引き受ける選択肢も添える。
5. **仮説だと書く** — 混ぜ版は、生成するまで試されていない。開いた語・残した語・聞く点（読み・区切り・旋律）・選び方（通しで一本ずつ。両方外すなら全部かな、または次の表を開く）をファイルに書く。

### 混ぜ版のファイルに置くもの

1. **出所と範囲** — どの歌詞から作り、変えたのは表記だけであること。
2. **仮説の印** — 「まだ試していない」と、生成器がどう読み違えるかについての見立て。
3. **歌詞欄** — 貼れる形で、同じ構造タグ。
4. **開いた語** — 表: 語 → 開いた形 → なぜ（失敗の形）。
5. **漢字のまま残した語（境界の杭）** — 残した理由。
6. **「それでも聞こえたら」** — 聞こえた読み → 次に開く形。
7. **比べ方** — 同じ条件、一度に一つ、読み・区切り・旋律。
8. **弱点** — 残る危険、かなの境目の代償、失った字面。

## 一つの魂、二つの扉

主題歌と package は同じ魂への二つの扉であって、二つの魂ではない。`package.md` が既にあれば、曲名・サビ・曲調は package のタイトル・帯・あらすじと一致する——約束・調子・声が同じ。

## 手順

1. draft.md・premise.md（テーマ・核心の問い）・series-bible.md（開示度）・persona（声）・package.md（あれば）を読む。
2. 作品全体を俯瞰する——テーマ・構造・感情が立ち上がる場面・開示の頂——そして、歌が歌う「ひとつの場面」を決める。主題歌は魂の一瞬であって、あらすじの要約ではない。
3. 歌の核心の一行（テーマを名指しせずに運ぶフック）を引く。以下すべてはここから導く。
4. 歌の一式を順に書く: 曲名 → 歌詞（構造タグ） → 曲調指定 → ボーカル → 楽曲説明 → 挿入位置・使用意図。
5. 読み違い予防版を書く——失敗の形のある語だけを開き、他の語・行・タグはそのまま残し、開いた語・残した語・「それでも聞こえたら」の表を記録する。
6. それぞれを四則で検品する: 嘘をつかずに歌う・届けるものを約束する・開示の頂の手前で止まる・抑制は歌詞にも及ぶ。
7. 全体を「一つの魂、二つの扉」で検品する——package と同じ作品に開いているか。
8. `<作業ディレクトリ>/theme-song.md` と `<作業ディレクトリ>/theme-song-mix.md` を保存する。

## 出力

- `<作業ディレクトリ>/theme-song.md` —— 歌の一式（曲名 / 歌詞 / 曲調指定 / ボーカル / 楽曲説明 / 挿入位置・使用意図）。混ぜ版への一行の案内を添える。
- `<作業ディレクトリ>/theme-song-mix.md` —— 読み違い予防版（歌詞欄・開いた語・漢字のまま残した語・「それでも聞こえたら」の表・比べ方・弱点）。名のある版の横なら、その名に合わせる（`<版の名>-mix.md`）。歌詞がもともと全部かなで、危ない語が残らない場合は、その旨を `theme-song.md` に書き、このファイルは作らない。

## 注意

- **ground は作品の魂——テーマと感情が立ち上がる場面——であって、読者の第一印象ではない。** 読者へ向くのは package の仕事。歌は魂へ向く。
- **series-bible の開示度が境界。** 開示の頂・結末は歌わない。
- **歌詞は作品の声を歌にしたもの。宣伝ではない。** 作品の魂を、歌える数行に圧縮したもの。
- **歌詞は作品の言語で、曲調指定は英語タグで。** `lang` 引数が変えるのはスキル自身の散文だけ。
- **説明しすぎた歌詞は、もう五則（源を語らない）を破っている。** 行が短いほど、抑制が要る。
- **混ぜ版が変えるのは音であって、語ではない。** 正典の訂正ではなく、二つ目の候補。正典は出所のファイル（`theme-song.md`、または名のある版）の歌詞。
- **開くのは最小限。** 開きすぎると、生成器が使う語の境目が消える——読み違いの危険を、区切りの危険に替えただけになる。
- **曲名は作品の表記のまま。** 開いてよいのは歌詞のフックまでで、その場合は混ぜ版のファイルにそう書く。
