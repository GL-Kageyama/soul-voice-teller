# whole-work-review —— 一冊として閉じているかを見直す

## Skill Metadata

- **id**: `whole-work-review`
- **version**: `0.1.0`
- **category**: `writing`（改稿・全体）
- **standalone**: `true`
- **language**: `ja`

## 位置づけ

三層モデルの**全体**改稿スキル。prose（文体）・scene-writer（場面）・revise-for-reader（読者体験）・entertainment（快楽）が場面単位で働くのに対し、whole-work-review は**一歩引いて全体を見たときだけ現れるもの**——作品が一冊として閉じているか——を検品する。その照合対象（ground）は **series-bible.md**（設定・伏線・構造の約束）であって、場面ではない。

**出所**: series-bible（台帳）＋技術目録 §15 改稿。

## 入力契約

- **draft.md**: `<作業ディレクトリ>/draft.md`（見直し対象）。
- **series-bible.md**: `<作業ディレクトリ>/series-bible.md`（照合対象——設定・伏線表・構造の約束）。
- **persona**: `${SOUL_VOICE_HOME:-$HOME/.soul-voice-teller}/persona.md`（禁じ手・声）。

## 全体の6軸（全体でしか見えないもの）

1. **構造の一貫性** — 作品の中核機構（器官＝動詞・態の傾斜・定型句など）が全章で成立しているか。機構を破る章は破綻。
2. **伏線の張り→回収** — series-bible の伏線表に照らす。張りっぱなし・回収なき伏線・張りなき回収を検出。
3. **密度とテンポの配分** — 要の章が最濃密で、他は抑制。フラット・重みの逆転がないか。
4. **章間の重複** — 同じ表現・映像・リズムが変奏なしで章を跨いで反復されていないか（リフレインでなくループ）。
5. **世界観に閉じた語への寄りかかり** — 設定語（固有名・システム用語）が、具体（物・音・身体）のすべき仕事を代行していないか。閉じた語は抽象のまま浮かせず、具体に接地する。
6. **発露と抑制の全体バランス・声の一貫性** — 説明・名指し・総括が全体を通して滲んでいないか。声が章ごとにぶれないか。

## 手順

1. draft.md と series-bible.md（設定・伏線表・約束）を読む。
2. 草稿を**全体として**読む（場面単位でなく）。判定の単位は作品。
3. 6軸で検品する。各軸について、破れている箇所（章・行）を具体で突き止める。
4. 全体レベルで改稿する。抑制との両立を守る: 説明・名指し・総括は足さない。浮いた閉じた語は、物・音・身体に接地する。
5. リフレインは反復を「稼ぐ」（震え・変奏）ものであって、ただ反復するものではない。変奏を失った反復はループ。変奏させるか、切る。
6. 改稿した draft.md を保存する。

## 出力

改稿した `<作業ディレクトリ>/draft.md`。

## 注意

- **単位は全体であって、場面ではない。** 場面が良くても作品が閉じないことはある。一歩引かないと見えないものを検品する。
- **series-bible.md が照合対象。** これが無いと「全体が成立しているか」は感想であって観測にならない。
- **世界観に閉じた語はスキャフォールドであって、具体の代役ではない。** 閉じた語が仕事を代行していたら、物・音・身体に接地する。さもなくば世界は物語でなくルールブックになる。
- **リフレインは変奏（震え）を伴う反復。ループは変奏の無い反復。** ループをリフレインに変えるか、切る。
- 昇華（否定/保存/高次化）は評価レイヤーの機構。ここではしない。
