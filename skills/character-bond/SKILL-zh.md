# character-bond —— 两人之间所生的东西

## 语言模式

本技能默认以英文写作。如需以其他语言写作，请传入 `lang` 参数（例如 `/character-bond lang=zh`）或在环境中设置 `SOUL_VOICE_TELLER_LANG=zh`。解析顺序：`$ARGUMENTS.lang` > `SOUL_VOICE_TELLER_LANG` > `en`。

- `en`（默认）：使用本文件（`SKILL.md`）与 `../references/*.md`。
- `ja`：读取 `SKILL-ja.md` 与 `../references/ja/*.md`；以日语输出。
- `zh`：读取本文件（`SKILL-zh.md`）与 `../references/zh/*.md`；以中文输出。

所有输出均以解析出的语言书写。

## 定位

三层模型中的**准备（设计）**技能。character-forge 处理「一个人物」，character-in-action 处理「以行为揭示人物」，character-bond 处理「**两人之间**」。关系不是生于一个人，而是生于两人之间（间）。**在不破坏流露与克制（留白 · 不命名 · 结尾不总结）的前提下**，以具体（身体 · 行动 · 物 · 声音）描绘关系的发生与变化。

**出处**：技术目录 §人物 ＋ §4 结构（转折）。

- **draft.md**：`<工作目录>/draft.md`（改稿对象）。
- **design.md**：`<工作目录>/design.md`（读者形象与约定 · 两人的设计）。
- **persona**：`${SOUL_VOICE_HOME:-$HOME/.soul-voice-teller}/persona.md`（禁忌 · 声音）。

## 关系的五轴

1. **关系的轴（求什么）** — 分别说出两人彼此所求。只有一方，就成了装置。
2. **反转／镜像** — 一方的主动，成为另一方的被动。对方「送」，这边就「接」。把对方的动词，反方向地还回去。
3. **转折点（关系改变的瞬间）** — 一方初次「走向」另一方的瞬间。一味被动，关系不会变。
4. **双向** — 不做单行道。A→B 与 B→A 都写。单向的关系是装置，不是羁绊。
5. **身体化** — 以身体 · 行动 · 物 · 声音描绘关系，不以解释 · 命名 · 总结。

## 步骤

1. 读入 design.md 的「读者形象与约定」与两人的设计（character-forge）。
2. 以五轴检视。找出弱在哪一轴。
3. 补足**反转／镜像**：把对方的主动动词，以反方向（被动）还回去。
4. 放置**转折点**：一方初次走向另一方的那一瞬间，以一个行动。
5. 检查**双向**：A→B 与 B→A 是否都在。
6. 关系以「身体 · 行动 · 物 · 声音」来添，不以「解释」来添。
7. 保存改稿后的 draft.md。

## 输出

改稿后的 `<工作目录>/draft.md`。

## 注意

- 用「解释」描绘关系，就破坏了魂。不写「他们很要好」，而写相触的手指。
- **反转／镜像**＝把对方的动词反方向地还回去。与向被动语态的倾斜同形。
- 没有**转折点**的关系不会动。一味被动，关系就不会诞生。
- **单向**的关系是装置，不是人。要双向。
