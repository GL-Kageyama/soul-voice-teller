# character-bond —— 二人の間に生まれるもの

## Skill Metadata

- **id**: `character-bond`
- **version**: `0.1.0`
- **category**: `writing`（設計・関係）
- **standalone**: `true`
- **language**: `ja`

## 位置づけ

三層モデルの**準備（設計）**スキル。character-forge が「一人の人物」、character-in-action が「人物を行為で露わにする」ことを扱うのに対し、character-bond は「**二人の間**」を扱う。関係は、一人では生まれない。二人の間（ま）に生まれる。**発露と抑制（余白・名指ししない・総括を置かない）を壊さずに**、関係の発生と変化を具体（身体・行動・物・音）で描く。

**出所**: 技術目録 §人物＋§4 構造（転）。

## 入力契約

- **draft.md**: `<作業ディレクトリ>/draft.md`（改稿対象）。
- **design.md**: `<作業ディレクトリ>/design.md`（読者像と約束・二人の設計）。
- **persona**: `${SOUL_VOICE_HOME:-$HOME/.soul-voice-teller}/persona.md`（禁じ手・声）。

## 関係の5軸

1. **関係の軸（求めるもの）** — 二人が互いに何を求めるかを、それぞれ名付ける。片方だけでは装置になる。
2. **反転／鏡像** — 一方の能動が、他方の受動になる。相手が「送る」なら、こちらは「受け取る」。相手の動詞を、逆方向に返す。
3. **転機（関係が変わる瞬間）** — 一方が初めて、もう一方へ「向かう」瞬間。受け身のままでは、関係は変わらない。
4. **双方向** — 片道にしない。A→B と B→A の両方を描く。一方向の関係は装置であって、絆ではない。
5. **身体化** — 関係を、身体・行動・物・音で描く。説明・名指し・総括で描かない。

## 手順

1. design.md の「読者像と約束」と、二人の設計（character-forge）を読む。
2. 5軸で検品する。どの軸が弱いかを見つける。
3. **反転・鏡像**を補う: 相手の能動動詞を、逆方向の受動動詞で返す。
4. **転機**を置く: 一方が初めて向かう瞬間を、一つの行為で。
5. **双方向**を確認: A→B と B→A の両方があるか。
6. 関係は「身体・行動・物・音」で足す。「説明」で足さない。
7. 改稿した draft.md を保存する。

## 出力

改稿した `<作業ディレクトリ>/draft.md`。

## 注意

- 関係を「説明」で描いたら、それは魂を壊す。「仲が良い」と書かず、触れる指を書く。
- **反転・鏡像**は、相手の動詞を逆方向に返すこと。受動態への傾斜と同型。
- **転機**が無い関係は、動かない。受け身のままでは、関係は生まれない。
- **片道**の関係は、装置であって人ではない。双方向を。
- **絆は「知りたさ」の経路である**。読者が落ち着いてしまう関係こそ、フックのエンジン（[../references/ja/フックのエンジン.md](../references/ja/フックのエンジン.md)）が欠けさせるもの。転機は、未知が入り込む場所。
