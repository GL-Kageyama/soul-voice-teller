# series-bible —— 作品聖典（設定・伏線・連載を一元管理する台帳）

## Skill Metadata

- **id**: `series-bible`
- **version**: `0.1.0`
- **category**: `writing`（長期・運営）
- **standalone**: `true`
- **language**: `ja`

## 位置づけ

三層モデルの**長期・運営**。作品が長くなるほど、設定・伏線・連載の整合が命綱になる。本スキルは作品の「辞書」（書くたびに参照する）を1ファイルで一元管理する。旧 `foreshadow-ledger`（伏線台帳）と `serial`（連載管理）を**レコード種として統合**（構想リスト §3-D）。

**出所**: 技術目録 §16 管理（16-1〜16-6）＋§1-C 資料の階層＋§3-9/3-10 伏線。

## 入力契約

- **作品の成果物**: premise.md・design.md・draft.md（シーン表・人物・世界・伏線を集める）。
- **既存の台帳**: `<作業ディレクトリ>/series-bible.md` があれば読み込み、整合を保って更新する。

## 手順

1. 作品の成果物（premise / design / draft）を読み、既存の series-bible.md があれば読み込む。
2. 台帳を作る（スキーマ付き・1ファイル）。**3レコード種**（構想リスト §3-D）:
   - **設定レコード（16-1）**: 固有名・年表・キャラ・世界設定。書くたびに参照する辞書（未描部分の資料化は world-iceberg を参照）
   - **伏線レコード（16-2, 3-9/3-10）**: 張った場所・回収場所・読者への開示度。張ったものの回収を保証する
   - **連載レコード（16-3, 16-4）**: 区切り・次回への約束・前話との整合・巻シリーズの約束
3. 各レコードをスキーマ（欄の構造）に沿って記録する。固有名・年号は**一行、構造は一段落**の単位で（1-24）。
4. 改稿履歴（16-5）と版の管理（16-6: 草稿・確定稿・公開稿の区別）を添える。
5. `<作業ディレクトリ>/series-bible.md` に保存する。以後、執筆（fast-draft / scene-writer / prose）はここを参照する。

## 出力

`<作業ディレクトリ>/series-bible.md`（3レコード種のスキーマ付き台帳）。

## 注意

- 台帳は**書くたびに参照する辞書**（16-1）。作って終わりにしない（voice-ledger と同じ「ためて終わりにしない」）。
- 伏線は**張ったら回収**（3-10）。回収しないものは伏せ置き（3-12）として明示して残す（開かれた結末）。
- 連載は**毎回の約束と全体の約束の両立**（16-3/16-4）。次回への約束を切らさない。
- 台帳は生きている（1-26）: 書くうちに設定が動いたら更新する。
