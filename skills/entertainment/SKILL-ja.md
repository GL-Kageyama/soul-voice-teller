# entertainment —— エンタメの快楽を、抑制を壊さずに

## Skill Metadata

- **id**: `entertainment`
- **version**: `0.1.0`
- **category**: `writing`（改稿・エンタメ）
- **standalone**: `true`
- **language**: `ja`

## 位置づけ

三層モデルの**改稿**スキル。revise-for-reader が「読者体験」（没入・再読・読後変位）を扱うのに対し、entertainment は「エンタメの快楽」（フック・ページターナー・ツイスト・カタルシス・テンポ・共感）を扱う。**発露と抑制（余白・名指ししない・総括を置かない）を壊さずに快楽を足す**——説明でなく、行為・映像・音で。

**出所**: 技術目録 §9 読者＋§4 構造（転・テンポ）。

## 入力契約

- **draft.md**: `<作業ディレクトリ>/draft.md`（改稿対象）。
- **design.md**: `<作業ディレクトリ>/design.md`（読者像と約束・文体の方向）。
- **persona**: `${SOUL_VOICE_HOME:-$HOME/.soul-voice-teller}/persona.md`（禁じ手・声）。

## エンタメの6軸（快楽の源）

1. **フック（掴み）** — 冒頭の一行で読者を掴む。抑制の中でも、冒頭だけは「何が起きるか」を強く張る。
2. **ページターナー（置けない）** — 章末に「次へ」の引力を残す。定型句だけでなく、未解決の問い・兆しを残す。
3. **ツイスト（転）** — 予想を裏切る。起承転結の転を「意外で、しかし必然」にする。
4. **カタルシス（解放）** — 感情の解放点を作る。ただし総括でなく、行為・映像で。
5. **テンポ（緩急）** — 長さ・密度に緩急をつける。すべて同トーンにしない。
6. **共感フック** — 主人公の飢えを、読者自身の飢えに重ねる。

## 手順

1. draft.md と design.md の「読者像と約束」を読む。
2. 6軸で検品する。どの軸が弱いかを見つける。
3. **抑制との両立**を守って補う: 快楽を足すとき、説明・名指し・総括は足さない。足すのは具体（行為・映像・音）だけ。
4. カタルシスは「総括」でなく「行為」で: 「救われた」と書かず、救われた瞬間の一つの行為を書く。
5. テンポは「長さの変化」で: 全話同トーンを避け、要の話だけ密度を上げる。
6. 改稿した draft.md を保存する。

## 出力

改稿した `<作業ディレクトリ>/draft.md`。

## 注意

- **エンタメの快楽を足しても、発露と抑制を壊さない**。カタルシスを総括で書いたら、それは魂を壊す。
- 快楽は「具体」（行為・映像・音）で足す。「説明」で足さない。
- **テンポの緩急**は、長さを揃えないこと。要の話だけ密度を上げ、他の話は短く抑える。
- フックとツイストは「情報の出し惜しみ」で、カタルシスとテンポは「身体・映像の具体」で作る。
