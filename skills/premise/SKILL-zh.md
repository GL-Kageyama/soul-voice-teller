# premise —— 构思（对照 persona＋声音库，定下作品的入口）

## 语言模式

本技能默认以英文写作。如需以其他语言写作，请传入 `lang` 参数（例如 `/premise lang=zh`）或在环境中设置 `SOUL_VOICE_TELLER_LANG=zh`。解析顺序：`$ARGUMENTS.lang` > `SOUL_VOICE_TELLER_LANG` > `en`。

- `en`（默认）：使用 `SKILL.md` 与 `../references/*.md`。
- `ja`：读取 `SKILL-ja.md` 与 `../references/ja/*.md`；以日语输出。源概念（内省 / 余白 / 間）在此。
- `zh`：读取本文件（`SKILL-zh.md`）与 `../references/zh/*.md`；以中文输出（留白 / 含蓄）。

所有输出均以解析出的语言书写。

## 技能元数据

- **id**：`premise`
- **version**：`0.1.0`
- **category**：`writing`（构思层 · 每部作品）
- **standalone**：`true`
- **language**：`zh`（镜像于 `SKILL.md`（en）/ `SKILL-ja.md`）

## 定位

三层模型中**构思层**的前段。`inspire`（构思）已并入此处——B 问句本身就是构思。每部作品，对照灵魂故事（persona）选择主题与一句话梗概。

**输入约定（明文化）**：`人的种子（想写什么）＋ persona（此人的偏好）＋ voice-ledger（过往的声音）`。

## 输入约定

- **种子**：用户想写的素材 · 题材片段。经 argument-hint 或对谈接收。无则通过对谈引出。
- **persona**：`${SOUL_VOICE_HOME:-$HOME/.soul-voice-teller}/persona.md`。**必需**。无则先促请 writer-persona。
- **voice-ledger**：`${SOUL_VOICE_HOME:-$HOME/.soul-voice-teller}/voice-ledger.md`。有则读（把前作的声音唤入新的问句）。可无。

## 步骤

1. 读入种子 · persona · 声音库。若 persona 缺失，促请 writer-persona 并中止。
2. 以 B 问句（[../references/zh/内省.md](../references/zh/内省.md) B 章）构思。依据 = **persona＋声音库**。但 persona 分温度不同的两层来用：
   - **灵魂之声（HOW）＝灵魂故事 · 审美 · 声音 · 禁忌** → 低温对照（忠实守护）
   - **题材偏好（WHAT）＝A-5** → 高温构思（作种子用。不拉得过近）
   - **B-1 主题**——这素材如何回应写作者「反复书写的问句」
   - **B-2 一句话梗概**——这故事用写作者的声音说，会如何回响（一句核心，非概括）
   - **B-3 人物与世界**——写作者最想写的人物 · 被吸引之处在哪里
   - **B-4 种子 × 题材摇晃**——种子的季节 · 舞台 · 时段 · 人物 · 关系若与 persona 的题材（A-5）重合过多，刻意错开。错位（例：夏日的盂兰盆对秋日的偏好）当作摇晃来欢迎，刻意的偏离用 `?` 记录
3. 将构思结果汇总为下方输出格式。舍弃「**谁都写得出**」的答案（套路化主题 · 梗概），向声音 · 审美（HOW）拉回。题材（WHAT）若与 persona 偏好重合过多，刻意离开——每次同一题材是平庸。
4. **必定义读者形象与对读者的约定**（小说是「被阅读时间的艺术」）。不写清给谁、作何约定，草稿就没有读者。约定中包含**反应轴**——指明六轴中的主 · 副（[../references/zh/六个反应轴.md](../references/zh/六个反应轴.md)）。
5. 输出存入 `<工作目录>/premise.md`。工作目录由用户指定（未指定则 `examples/<slug>/`）。

## 输出

`<工作目录>/premise.md`

```markdown
# premise —— 作品的入口

## 一句话梗概
（这故事一句。以写作者的声音发声的核心）

## 核心问句
（这故事所问、未了的问句。与 persona 的灵魂故事对照）

## 主题
（如何回应 persona 的「反复书写的问句」）

## 体裁的约定
（读者可对这部作品期待什么）

## 反应轴
（六轴中的主 · 副——读者主要感受的反应。例：恐怖为主 · 惊叹为副）

## 文体的方向
（对照 persona 的声音 · 笔触，这部作品文字的方向）

## 读者形象与约定
（给谁读 · 向那位读者约定怎样的体验）
```

## 注意

- 构思是**对照与摇晃两者**。声音 · 审美 · 禁忌（HOW）对照依据（persona）来守。题材偏好（WHAT）作种子用但不拉得过近——重合过多则刻意离开（高温摇晃）。无论哪种，都不从依据里捏造「煞有介事的主题」。
- 读者形象与约定是**必需**（构思评审 flash #1）。不得省略。
- 此处不做设计（因果结构 · 场景表是 plot-design 的活）。premise 只定「问什么 · 以怎样的文字 · 给谁读」为止。
- **约定选定反应轴**。读者将感受哪一轴（六轴），作为体裁约定＋读者形象与约定的一部分在此定下（[../references/zh/六个反应轴.md](../references/zh/六个反应轴.md)）。plot-design 把该轴展开为整体之弧。
